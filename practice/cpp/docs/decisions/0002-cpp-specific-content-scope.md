# ADR 0002：内容聚焦 C++ 特有语义，淡化与 C 重叠的基础

- 日期：2026-08-14（2026-08-15 补记）
- 状态：已接受
- 依据提交：`36a42be` 弱化指针、`fb7b918` 彻底删除指针演示类

## 背景

早期章节大纲包含指针等与 C 语言高度重叠的内容。Athena 的定位是个人学习、
练习和验证 C++ 知识点的实验工具，不是完整教程产品；把 C 基础内容混入会稀释
学习焦点。

## 决策

- 内容优先覆盖 C++ 特有能力（引用、RAII、智能指针、移动语义、模板、并发等）。
- 与 C 语言高度重叠的基础内容，只有在理解 C++ 语义确实需要时才加入。
- 不设置指针等纯 C 专题章节。

## 后果

- 学习 C 语言基础需要另行安排材料，Athena 的大纲持续按此标准裁剪。
- 章节数量上限因此可控，新增章节评审时先问"这是 C++ 特有语义吗"。
