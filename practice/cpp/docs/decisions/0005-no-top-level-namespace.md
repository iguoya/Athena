# ADR 0005：不使用项目顶层命名空间，优先 using namespace std

- 日期：2026-08-15（补记）
- 状态：已接受
- 依据提交：`69a3d43` 移除项目顶层命名空间

## 背景

项目早期存在与项目名/分类名重复的顶层命名空间，与"独立桌面应用、课程类直接
对应主题"的定位重复；教学示例反复书写 `std::` 也引入视觉噪声。

## 决策

- 项目类型和课程类直接使用类名（如 `Reference`、`SmartPointer`），不加
  `athena`、`athena::cpp` 顶层命名空间，也不统一添加 `Chapter` 后缀。
- 项目代码与教学示例优先 `using namespace std;`，放在标准库 `#include` 之后；
  出现实际名称冲突时才局部使用显式 `std::`。
- `.cpp` 内部辅助类型和函数优先放入匿名命名空间限制可见性。

## 后果

- 代码更短、更贴近教学阅读习惯；与常见企业编码规范相反，仅适用于本项目的
  个人学习定位，不应被视为通用建议。
- 头文件同样遵循该约定，改名需要同步 `athena.json` 的类名字段。
