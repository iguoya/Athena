# ADR 0027：学习页自足讲解与多媒体教案

- 日期：2026-09-09
- 状态：已接受；本阶段只整理文档、教案和页面方案，应用界面尚未按本决策完成改造
- 延续：ADR 0026 的原生场景自由组合、Markdown 不决定布局
- 修订：学习页不能把原理讲解交给可选手册；预测与练习不能代替教学叙述

## 背景

现有原生学习场景强调概念对比、预测和实验入口，但对“为什么需要这个知识、规则从何而来、
怎样帮助实践”的讲解不足。不能假定学习者已经阅读参考手册，也不能依靠 AI 讲解补齐必修内容。
文字、图像、流程图、动态图表和动画需要共同承担讲解，形成边学边练的过程。

## 决策

1. **学习页独立完成教学。** 本页应讲清学习目标所需的背景、原理、用途、例子和边界；
   即使从未打开手册，也能理解例子、完成穿插练习并说明选择理由。
   自足不等于从零重教所有前置知识：入口简短提示必需前提，缺少的基础解释就近提供。
2. **教案先于布局。** 从知识问题和正确语义确定讲解线索，再安排文字、视觉材料与实践。
   通常由“问题与用途 → 原理解释与图示 → 小范围尝试 → 对照解释 → 实际应用 → 回顾”展开，
   可多次往返，不把它固化成所有章节相同的步骤卡或强制答题流程。
3. **参考资料是可选补充。** 手册用于更完整的规则、扩展例子、边界和回查；核心解释不能只留
   一个跳转按钮。学习页与手册可以重复表达，同一规则的条件和结论必须一致。
4. **充分使用多媒体解释。** 关系用对象图，决策用流程图，变化用动态比较，时间与因果用可控
   动画；图片也可提供实际情境。每项素材明确“解释什么、读者看哪里、看完理解什么”。
   文字解释原因和条件，视觉表达结构和变化，二者相邻配合。媒介选择取决于教学目的，
   不把所有内容强制静态化，也不为使用动画而制造动作。
5. **让学习者控制动态过程。** 有语义步骤的动画提供逐步、播放/暂停和重置；变化同时给出
   当前步骤与文字说明，停止或减少动效时仍能理解。不自动循环抢占阅读注意力。
6. **区分图解和实验证据。** 概念示意、作者编排的状态演示、真实运行输出、编译诊断各自
   说明来源。运行程序打印“编译失败”不能充当编译器诊断；示意动画不能声称在追踪真实程序。
7. **保持实现边界。** 正式页面仍用 Blueprint + GTK，真实源码仍来自文件，跨页导航仍经
   MainWindow，服务不更新控件。本决策不引入 WebView、运行时 JS、多媒体依赖或通用动画引擎。
   新资产和动态模块按实际教案逐项实现、验证，不一次性建设全套平台。

## 后果

页面作者需要写出完整讲解并设计视觉叙事，不能仅绑定几个实验按钮。允许先完成一个学习单元，
验证理解与制作成本，再扩展到其他章节。判断质量以“不查手册能理解、换情境能应用、证据可核对”
为准，不以文字最少、控件最多或练习数量衡量。
