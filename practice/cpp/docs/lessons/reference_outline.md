# 引用章大纲维护记录

依据 ADR 0028，大纲只承载方向、范围、判断与章节关系。实验覆盖和开发进度在此维护，
不放进面向学习者的大纲正文。

## 章节独立性

保留独立「引用」章，不并入「类型与表达式」，也不拆进「函数与可调用对象」：

- 路线图上 `TypeSemantics → Reference`，且 `FunctionCallable` / `ClassObject`
  都以 Reference 为先修；别名接口是后续两章的地基，不是第 1 章的附录。
- 第 1 章主脊是阅读对象与表达式；本章主脊是别名在绑定／传参／返回上的接口判断。
  合并会重新变成双主脊。
- 右值引用与移动留在 RAII／模板侧，避免「引用」一词跨章含糊。

## 与实验的对齐

当前四个实验（`reference_basics`、`const_reference`、`pass_by_reference`、
`return_by_reference`）覆盖大纲主线。`const_reference` 已演示延长边界与函数
转发后不再延长；返回局部引用以注释中的危险写法对照，不实际执行 UB。

后续可补：原生学习页（现为标准代码页）；别名／指针对照的结构图（仅当文字说不清时）。
