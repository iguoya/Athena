# 地球（earth）

真实比例的地球分层 3D 可视化：大气五层（对流层 / 平流层 / 中间层 / 热层 / 外逸层）与
地球内部六层（地壳 / 上地幔 / 过渡带 / 下地幔 / 外核 / 内核），WGS 84 椭球 + PREM +
US Standard Atmosphere 1976 标准模型驱动。真实比例下薄层看不见是事实——默认以**航空视角**
打开：0–50 km 的海拔剖面专题，无人机、客机、战机、气球、跳伞纪录、鸟类按真实高度排布
（0–12 km 放大呈现并注明倍率）；**太空视角**以地面视角观空中（层界环与居民标尺按真实
高度），四分之一剖面、径向真实刻度尺、内部锚点（科拉钻孔）、径向探针与两张联动图表
负责把「薄」讲清楚。图谱/参考类，不判分（ADR 0128）。
