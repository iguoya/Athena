# ADR 0065：标线速记页——路面读法成为可浏览的内容

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/markings.json`（新）、`content/questions/subject1.json`（逐题挂
  `marking` 字段）、`lib/models.dart`（`Marking`、`Question.marking`）、
  `lib/content.dart`（加载）、`lib/marking.dart`（`paintableMarkingIds` 常量，新）、
  `lib/markings_page.dart`（新）、`lib/home.dart`（侧栏钉住区、页面分发）、
  `lib/glyphs.dart`（`Glyph.markings`）、`test/markings_page_test.dart`（新）
- 关系：与 0059（标志速记页）成对，落实仓库级 ADR 0056（可视化与交互是内容本身）；
  速记类页面先例沿用 0028（易混数字）；内容出处的硬标准仍是 0003/0008；
  格子动效收在 0058 决策 6 与 0061（玻璃浮层）的既有范围

## 背景

标线是科目一的另一块丢分重灾区：题库里题干点名列线型或问「这种标线」的题近百道
（导向箭头 24 题、白虚线 13 题、黄虚线 11 题、白实线 9 题、网状线 9 题……），但
没有一处把它们放在一起。标志速记页（0059）落地后，同结构的素材缺口就是标线：
`content/sources/catalog.json` 里 GB 5768.3—2009 已经在册（`gb5768-3`），标线题
的出处逐题挂到它，题库里还钉死了几个分类锚点——路中心黄色虚线属指示标线
（s1.signals.266）、白色实线处变道属违反禁止标线（s4.civil.238 的解释）、标线分
指示/警告/禁止三类（s1.signals.055/476）。标志页的手绘 painter 只画标志，标线是
路面俯视的线形，需要一份新的画法。

## 决策

1. **新增「标线速记」页，侧栏钉住区与「标志速记」并列。** 内容源是
   `content/markings.json`，每条：`id`、`name`（国标名称或题库通行的叫法）、
   `kind`（indicative / prohibit / warning）、`band`（频次档，同题库）、
   `meaning`（一句行动导向的「看到之后怎么开」）。页面按 `kind` 分三组，每组一张
   `BsCard`：组名、一句读法口诀、组内网格（手绘标线图 + 名称 + 含义 + 高频徽章）、
   组级「练这组的题」按钮。
2. **分组贴 GB 5768.3 的三分法，口诀讲「颜色 × 线形」的路面读法。** 题库考这个
   框架（标线分指示/警告/禁止三类），页面就按它组织：指示组口诀「白色告诉你往哪
   走」，禁止组口诀「黄线分对向、实线不许越」，警告组口诀「这些线在提醒你提前减速
   留神」。逐条归类以题库已钉死的口径为准（黄虚线属指示、白实线禁跨越属禁止）；
   没有题面锚点的条目按白色指示家族归组（出入口标线），页面不写条款号——出处是
   文件级的 `gb5768-3`，沿用 0059 决策 2「速记页不判分、不做条级 locator」。
3. **挂题用新字段 `marking`，不复用 `sign`。** `lib/clusters.dart` 对带 `sign`
   或题图的题排除出考点簇计算；标线题大多带图，本就被排除，但仍有纯文字的标线
   题——挂 `sign` 会把它们从簇池里误删，字段语义也混。`Question` 加独立的
   `marking` 字段，`content/questions/subject1.json` 逐题核对后挂上线型 id。
   挂题范围限科目一：页面「练这组」的练习通路与标志页一样走科目一日常题，
   科目四的标线题不挂。逐题挂的时候顺手核对解释里的线型名称与题面一致。
4. **painter 支持的 id 集合提取为常量 `paintableMarkingIds`。** 沿用 0059 决策 4：
   `_MarkingPainter` 是 switch 逐 id 手绘路面俯视示意（灰底路面 + 黄/白线形），
   json 加了 id 而忘了画就会落到兜底问号图；测试断言 `markings.json` 的每条 id
   都在集合里，把「加内容忘画图」挡在 check 阶段。
5. **页面结构与交互整体复用标志页的既有件。** `BsCard` 分组、格子 hover 上浮、
   点开玻璃浮层看大图（0061 收尾的既有交互）、`BsBadge` 高频徽章、组级练习入口
   （`dailyQuestions` 过滤 + 未掌握计数 + 偏难提示）——不新增动效种类，不引入
   新依赖。

## 后果

- 标线从「做错题才见到一张照片」变成一页可逛的路面读法；每个标线组都能直接起一轮
  相关题练习，与标志页、易混数字页同构。
- `markings.json` 是唯一内容源，含义文案与题库共守「与现行法规一致」的硬标准；
  标线规定改版时和题一起改。
- `Question.marking` 是可选字段，旧记录与既有页面零影响；`clusters.dart` 的簇池
  不受扰动。
- 页面只依赖已有的 `SignView` 式自绘、`BsCard`、`BsBadge` 与练习通路，不引入
  新依赖。
