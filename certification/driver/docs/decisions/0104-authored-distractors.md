# ADR 0104：自造题答案侧审计——手工干扰项盖住「格式明码」

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/quiz_options.dart`（`QuizSource.distractors`，buildQuiz 优先入选）、
  `lib/models.dart`（`CheatRow.distractors`）、`lib/numbers_cards.dart`、
  `lib/recall_cards.dart`（透传）、`content/cheatsheet.json`（刑罚行补 3 个干扰项）
- 关系：延续 0103 的自造题质量审查——使用者指出问题不只在题干：**有的答案本身就是
  明码**，格式在选项里独一份，自带正确性而非迷惑性

## 背景

全量审计 118 张正向卡发现：句尾括号与题干泄漏已清零，但「拘役并处罚金」这张卡的
干扰项全是刑期（一年以下 / 三年以下 / 三年以上七年以下 / 七年以上），唯一一个非
刑期格式的选项就是答案——格式自证正确，纯送分。其余弱点是小组的选项天然不足
（雾天 3 项、酒精 2 项、登记时限 3 项、急救 2 项），格式彼此匹配，属固有形态。

## 决策

1. **行级手工干扰项**：`cheatsheet.json` 的行可带 `distractors`（作者撰写的同格式
   假选项），在选项生成时最优先入选。机器按相似度选干扰项盖不住「格式明码」，
   这类由作者补。
2. **先修刑罚行**：「拘役并处罚金」补「管制并处罚金 / 有期徒刑并处罚金 / 单处罚金」
   ——同是刑罚格式、 plausible 但错误，四个选项格式一致、位置随机。
3. **小组的选项数不做人工填充**：组内真实值只有几个时（酒精 20/80），宁可二选一
   也不编造可能被误记为法条的数值；格式彼此匹配已保证基本迷惑性。

## 取舍

- 手工干扰项是假选项，可能被学习者误记——由答后解释（显示原文与出处）对冲；
  与其让答案靠格式送分，不如让干扰项承担迷惑性。
- 其余自造页（符号四页的名称选项、要点页的要点选项）格式天然同类，未发现明码；
  此机制留作通用能力，谁需要谁填。

## 验收

- 刑罚行四选项全为刑罚格式且位置随机（抽查脚本）；
- `flutter analyze`、quiz_options / cloze / 数字页 / 自测测试全部通过。
