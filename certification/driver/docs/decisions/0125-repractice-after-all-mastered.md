# ADR 0125：全部掌握后练习不再是死路——确认一次即可整组重新练习

- 日期：2026-10-09
- 状态：已接受
- 影响：`lib/home.dart`（侧栏待练/专题入口、科目概览页按钮、`_phaseRow`、`_topicRow`、强化练习页「练新题」、`_startPractice` 新增 `includeMastered`、新增 `_confirmRepractice`）
- 关系：补 0031「每道题只出一次」与 0044「科目一不设解锁」的收尾死路；不改变 0006/0047 的解锁条件与 0076 强化练习的选题

## 背景

练习队列跳过已掌握的题（答对就算掌握，ADR 0020），全部练完后所有练习入口集体失能：
侧栏「全部练习（已掌握）」灰着点了没反应，专题行干脆点不了，科目一概览页的「练习待练题」
按钮禁用。使用者想把全部题再过一遍时没有任何入口。

## 决定

1. **全部掌握后，练习入口保留并转为「重新练习」**：侧栏科目级入口写「重新练习（全部 n 题）」，
   专题写「标题（重练）」，概览页按钮变「重新练习全部题」——都不再禁用。
2. **重新练习要确认一次**：点开弹「全部掌握，重新练习？」，说明这一组共几道日常题；确认才
   开练，取消就什么都不动。要不要重练由使用者点出来，不自动开始。
3. **重练不过滤待练、但答题记录一律保留**：`_startPractice` 的 `includeMastered` 让整组题
   进出题队列（错题优先、档位排序的规则照旧）。错题本、强化练习、学习诊断、统计趋势、成就
   与科目解锁（科目四不重新锁上）都不受影响；这一轮里答错的题按现有规则自然回到待练。
4. **不删任何数据**：不提供「清零重练」——那是不可逆的破坏性操作，与「再练一遍」的需求不匹配；
   真要从头学，换一个新学习者就是一份空白历史（ADR 0071）。

## 验收

- `test/interaction_test.dart`：全部掌握后科目入口显示「重新练习（全部 n 题）」且可点；
  确认后起一轮包含全部日常题的练习；取消不起会话；答题记录与解锁状态不变。
- 应用 `AGENTS.md` 的「答题与考试规则」同步更新。
