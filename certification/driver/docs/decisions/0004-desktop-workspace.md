# ADR 0004：桌面工作台，不用手机题库的控件妥协

- 日期：2026-09-15
- 状态：已接受
- 影响：`apps/driver` 的窗口结构、导航与做题区
- 对齐：本应用 ADR 0001（不做手机客户端）；主仓库 ADR 0047（跨平台桌面）
- 修订：第 4 条的「一题一屏、看完解释再点下一题」由 ADR 0007 改为一页四题

## 背景

第一版界面沿用 Material 3 默认组件：大顶栏、卡片、ListTile、整页 `Navigator`
推栈。这些是给拇指和窄屏准备的——把信息收成可点的块，一层层钻进去。桌面窗口
已经是 1280×720 量级，再套这套会显得层次深、控件碎，主区却空着。

## 决策

1. **一层窗口**。左侧选科目、章节和练习方式，右侧直接是题或章节一览。不再
   首页 → 科目 → 章节 → 答题 → 结果 五层路由。
2. **主区永远是内容，不是卡片墙**。章节用表格式列表；选项用 A/B/C/D 行，不用
   Radio / Checkbox 大触控靶。题干和选项在左，标志、解释、法条出处在右。
3. **不为窄屏折中**。不使用 `SliverAppBar.large`、全宽堆叠按钮、卡片套 ListTile、
   居中 480 宽的手机列。触控最小高度按桌面排版，不按 48dp。
4. **点选项就判定，不要第二下。** 单选、判断点一下即出对错；多选点齐应选个数即判定。
   练习判定后停在当前题，看完解释再点「下一题」或回车；不按秒数自动跳。模拟考点完
   直接下一题。

## 后果

- 科目一、科目四、错题本是侧栏上的三个去处，不是三张入口卡。
- 模拟考仍是同一块做题区，只是顶栏多倒计时；结束也停在本窗，不新开一页。
- Material 仍用，但只当绘制层；组件选型以桌面工作台为准，不以 Flutter 默认
  移动模板为准。
