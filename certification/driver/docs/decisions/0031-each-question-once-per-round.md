# ADR 0031：一轮练习里每道题只出一次

- 日期：2026-09-28
- 状态：已接受
- 影响：`lib/models.dart`（新增 `practiceQueue`）、`lib/home.dart`
- 关系：ADR 0003「高频常考多练」、ADR 0027 同档按错误率排序的落实方式

## 背景

练习队列一直是 `[错题, 高频, 常考, 常规, 错题, 高频]`：错题和高频题在同一轮末尾再追加一遍
（9 月 16 日起就这样，ADR 0027 改排序时原样保留）。没有哪份决定写过要这么做，大概是想用
重复体现「高频多练」。

实际效果是同一道题几分钟内连做两遍。答对一次就算掌握（ADR 0020），第二遍在它还没开出来
之前就已经没有意义；使用者的感受是「同样的题出多次」。

## 决策

1. 一轮练习的队列里每道题只出现一次：错题、高频、常考、常规依次排，同档内按全国错误率
   从高到低（ADR 0027 不变）。
2. 「高频多练」由排在前面、模拟考按权重多抽来体现，不靠同一轮重复。
3. 排队逻辑从首页状态里抽成纯函数 `practiceQueue`，测试直接断言没有重复。

## 后果

- 每轮题量变少：原来错题和高频题各多出一遍。
- 答错的题仍会在下一轮排在最前面，直到答对；这一轮里不再回头重出。
