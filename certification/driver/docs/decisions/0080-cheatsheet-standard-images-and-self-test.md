# ADR 0080：速记页改用规范图，「考我」改名「自我测验」并推广、一轮 5 个

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/cheat_image.dart`（新：规范图组件，读不出图退回自绘视图）、`lib/recall.dart`
  （「考我」改「自我测验」、一轮 5 个、条目自带正面）、`lib/signs_page.dart`、
  `lib/markings_page.dart`、`lib/gauges_page.dart`、`lib/gestures_page.dart`（图换规范图、
  尺寸放大一倍）、`lib/notes_page.dart`、`lib/home.dart`（易混数字页）、`lib/session.dart`
  与 `lib/gesture_index.dart`（做题台右栏的手势动画）、`lib/models.dart`（四类条目加
  `image` 字段）、`content/{signs,markings,gauges,gestures}.json`（每条加 `image`）、
  `content/images/cheatsheet/`（新：标志、手势、仪表裁图）、`pubspec.yaml`、
  `scripts/check.py`（图片存在性检查）、`test/recall_test.dart`、`test/gesture_in_session_test.dart`
- 关系：修订 0077 决策 1 与 4（「考我」的名字、规模与适用范围）；修订 0078 决策 4 中
  「用应用内绘制的动画」（改放规范 GIF，绘制动画保留作兜底）；修订 0004 中「标志用
  `CustomPaint` 自绘」在速记页的适用（自绘视图保留作兜底，不再是速记页的主图）；
  不影响题库、出处合约与作答通路

## 背景

0059～0073 的速记页图都是应用内手绘的：标志、标线、仪表符号用 `CustomPaint`，手势用
关键姿势插值（0078）。使用者看过之后提了五条要求：

1. 图要规范，用互联网上的规范图、官方图，**不要自造、不要模拟**——手势也一样，找规范的
   高清手势动作或动画；
2. 图标偏小，整体放大一倍；
3. 「考我」改名「自我测验」；
4. 自我测验推广到易混数字和其他速记部分；
5. 自我测验一次测 5 个。

## 决策

1. **图源按类别各取最规范的一手来源，不取自造图。**
   - **标志（33 个）**：Wikimedia Commons 上的中国国标标志图形（GB 5768 系列的矢量图），
     取其 480px 宽的 PNG 渲染，存 `content/images/cheatsheet/sign/<id>.png`。逐张核对过
     含义（禁止停车 = 红叉、禁止停放 = 红斜杠，与 `signs.json` 的口诀一致）。33 张的 Commons
     文件名、页面与许可证记在 `sign/sources.json`，**全部是公有领域**。Commons 上有 1999 与
     2009 两套文件编号，同一标志图形一致，按「找得到、画得对」取用，不追求同一套编号。
   - **手势（8 个动作）**：交警手势图解里的 8 张动画 GIF，一一对应法定动作。画面自带的
     动作名称标注会在自我测验里泄露答案，所以逐帧把文字像素修复掉（取同列上下最近的未遮挡
     像素插值），存 `content/images/cheatsheet/gesture/<id>.gif`。**这 8 张的版权状态没查清**
     （来源是公开网页上的图解文章），按 0008「自用、不分发、不商业化」收录；若以后要分发，这
     8 张要换成有明确授权的图。
   - **标线（33 条）、仪表（34 条中的 32 条）**：直接复用题库里已有的官方题图——它们是考试
     用图，比任何二手来源都更贴近考场看到的样子。每条的 `image` 指到相关题的题图；题图里的
     红圈、问号是题目标出的位置，保留。选图规则：跳过「四个符号并排、选项为图 1～4」的组图，
     取相关题里第一张单图（远光灯手选青色横线那张——国标里远光是蓝色，绿色斜线是近光）。
   - **仪表的灰底横条**：报警灯、指示灯的题图多是 1200×450 灰底、中间一个符号，直接放进格子
     符号太小，所以沿符号边界裁成方图（`content/images/cheatsheet/gauge/<id>.png`，只裁、不改
     像素内容）。表盘图与座舱问号图原样用。
   - 题库里没有图的两条（胎压、ESC 故障灯）与手势「效力」总则不硬凑，继续用原有自绘视图。
2. **图路径写进内容文件，不写进代码。** 四个内容 JSON 的每条加可选字段 `image`
   （相对 `content/`）；`CheatImage` 按它读，开发读磁盘、发行包走 assets，读不出来就退回
   页面原有的自绘视图（`SignView`、`MarkingView`、`GaugeView`、`GestureAnimation`）。自绘
   代码一行不删（仓库 ADR 0054：宁增勿删），只是不再是速记页的主图。`scripts/check.py`
   新增一步：每个 `image` 必须存在、且落在 `pubspec.yaml` 的 assets 目录里——路径写错在运行时
   只会静默退回自绘图，不挡就没人发现。
3. **图整体放大一倍。** 格子里的图从 96 到 192（标线与仪表是横向场景，用 4:3 的框，宽约
   280），点开的浮层从 192 到 320～440，自我测验的大图 288～400，易混对撞的小图从 72 到
   144。格子宽度跟着放大，`Wrap` 自动换行。自我测验卡片整张可滚动，小窗口下按钮不掉出屏幕。
4. **手势不再用应用内的示意动画。** 速记页格子、浮层、自我测验，以及做题台答完手势题后的
   右栏，一律放规范 GIF（循环自己播）。0078 的分步与俯视控件随之不在页面上出现，
   `gesture_animation.dart` 与它的测试保留，只在 GIF 读不出来时兜底。
5. **「考我」改名「自我测验」，一轮抽 5 个。** 每轮从条目里随机抽 5 个（不够就全上），没记住的
   隔两张后重新插队，直到这一轮全部记住；一轮收尾给「再来 5 个」「去练这组题」「关闭」。
   「再来 5 个」优先抽上一轮没出现过的。自评仍然不落库、不写掌握度。
6. **自我测验推广到所有速记页。** 条目的正面由条目自己提供（`RecallEntry.front`）：
   符号页是规范图；**易混数字**是「情形」、揭示后是数字与出处；**考点速记、河南速记、记分证照
   速记**是「情景」、揭示后是要点列表。各页收尾的深链练本页全部相关题，题仍从题库里选，
   不让 AI 造题（仓库 ADR 0043）。手势页不含「效力」总则。

## 取舍

- 标志用 PNG 而不引入 SVG 渲染依赖：Flutter 官方不带 SVG 渲染，加 `flutter_svg` 只为 33 个
  静态标志不值当；480px 在 2 倍放大后的 320px 浮层里仍然清晰。
- 标线、仪表复用题库题图，而不是另找图源：规范标线的矢量图在公开图源里零散，而考场出的
  就是题库这批图；代价是个别图带红圈（标注了题目指的位置）、个别图偏小（电池灯与气囊灯题库原图
  只有 70～80px，放大后偏糊），这是原图决定的，换图源之前不处理。
- 手势 GIF 只有一个视角、背景色不完全统一（变道那张底是白的），内容是规范的，但不如 0078
  的双视角逐步分解可拆；使用者的要求是「不要模拟」，这里按要求取舍，0078 的分解能力留在代码里。

## 验收

- `python3 scripts/check.py driver`：JSON、规范图存在性与 assets 目录、`flutter analyze`、
  全部测试通过。
- `test/recall_test.dart`：手势页自我测验一轮恰 5 张、没记住的重现、「再来 5 个」进第 2 轮、
  深链起练习、自评不增加作答记录；易混数字页与考点速记页也有自我测验，正面是情形 / 情景、
  揭示后是答案。
- `test/gesture_in_session_test.dart`：答完手势题右栏出现规范动画，非手势题没有。
