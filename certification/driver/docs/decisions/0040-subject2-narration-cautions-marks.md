# ADR 0040：科目二动画加语音讲解、注意事项与画面标注

- 日期：2026-09-28
- 状态：已接受
- 影响：`lib/drill.dart`（播放器朗读同步、`Mark` 标注与绘制）、新增 `lib/narration.dart`；
  `lib/guide.dart`（`GuideStep.caution`、`narration`）；`content/subject2.json` 每一步加 `caution`
- 关系：在 ADR 0036 的动画示意上补讲解；朗读复用科目一的系统 TTS（ADR 0005）

## 背景

动画示意（ADR 0036）只有画面和一行短提示，使用者要自己对照右侧的文字。想要的是「像带解说的
视频」：边播边讲，要点和注意事项直接指在画面上——哪条线不能压、看哪个库角、哪个轮子会压线。

## 决策

1. **语音讲解**：播放时进入每一步就念这一步的讲解稿（第几步、标题、怎么做、注意什么）。
   **动画等讲解**：这一步的动画播完而讲解没念完，就停在这一步末尾等，念完才进下一步。
   暂停、跳步、拖进度都立刻停念；播放器上可以关掉语音。没有中文语音的机器按钮置灰并说明。
   朗读走系统 TTS（跟科目一念解释同一个 `Speaker`），播放器只依赖 `Narrator` 接口。
2. **注意事项**：每一步一条，写这一步最容易被扣分或判不合格的地方，**逐条标出 GA 1026—2022
   条款号**（测试检查条款在摘录里存在）。叠在画面上一行红字，步骤列表里也显示（悬停看条款号），
   讲解稿里也念。
3. **画面标注**：每一步至少一处，三种——场地上的线（控制线、库边线、边缘线）、场地上的点
   （库角、内角）、车上的部位（两个前轮、车尾、内侧后轮、转向灯），车上的部位跟着车走。
   青色高亮、一明一暗，暂停时也闪，和白黄场地线区分开；标签自动避让不叠在一起。
4. 默演口述阶段（ADR 0037）不念、不显示注意事项和标注，免得替人把答案说了；对照阶段照常。
5. 跑 `flutter test` 时不起系统 TTS 进程、不跑常驻的闪烁计时器；朗读同步用可控的假朗读器测。

## 后果

- 单项页的动画可以当一段带解说、带标注的视频看完；嫌慢可以关语音、调速。
- 注意事项与评判条款绑定，标准修订时和题目、错因一起改。
- 念得比动画慢的步骤会在末尾停一会儿——这是有意的，画面停在关键姿态上正好对着讲解看。
