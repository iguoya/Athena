# ADR 0070：章节下的「练新题」入口

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/home.dart`（侧栏章节子行）、`test/interaction_test.dart`
- 关系：侧栏树结构仍是 0050（章节挂在所属科目底下）；「偏难怪默认不练」
  的口径不变（0027、0032）；与「待练」行的分工见决策 2

## 背景

题库补收后科目一约 2500 题，使用者想专练「从未做过的题」；最初设想是单独
一个「新题练习」入口，使用者指出新题练习应该在所属章节知识点里——练哪章
的新题就到哪章去，不该多一个跨章节的入口。

## 决策

1. **每个章节行下加一行「练新题 N」**，N 是该章日常题里没有任何作答记录
   的题数（一次都没答过才算新，答过但没掌握的仍归「待练」）；N 为 0 不显示
   这一行。点击起「该章只练新题」的一轮练习，通路与章节练习同一套。
2. **不在科目层加新题入口。** 科目级的「待练」行已经覆盖「还没练熟的题」；
   新题按章分布在各章节行下，挑薄弱点时顺手看到各章还有多少没见过面的题。
3. **新题的口径与日常题一致**：偏难怪不进新题行（0027），已掌握的题天然
   不在里面（答过就有记录）。

## 后果

- 「新加的题、从没见过的题」有了逐章的练法，不与待练、强化练习混流。
- 侧栏章节行下多一层子行；只在有新题的章节显示，旧章节练满后自然消失。
