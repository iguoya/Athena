# ADR 0126：左侧目录不锁科目

- 日期：2026-10-11
- 状态：已接受
- 影响：`lib/home.dart`、`AGENTS.md`
- 关系：撤销 0006 第 4 条（科目四等科目一全部掌握才开）与 0047（科目二等科目一模拟考连着 3 场 95 分以上才开）；0044（科目一内部不设解锁）不变

## 背景

0044 去掉了科目一内部的阶段锁，科目二、科目四仍在左侧目录上挂锁：科目四要等科目一日常题全部最近一次答对，科目二要等科目一模拟考最近 3 场都不低于 95 分。锁住时点进去只看见原因，子项不展开，错题本、考前复习和强化练习也不收这两科的题。

题库一直在补题。已经练过的科目一会因为新题或一次答错重新不算「全部掌握」，科目四就整科锁回去。使用者要求左侧目录不再锁。

## 决定

1. **左侧目录三个科目都直接可进。** 科目二写「科目二（C2）」，科目四写「科目四」，都带展开箭头；点进去是练车日或练习与模拟考，不出现「未解锁」页。
2. **错题本、考前复习、强化练习按作答记录收题**，不再按科目是否「过关」把科目二、科目四的题藏起来。
3. **掌握进度仍由作答派生**（主仓库 ADR 0052）：侧栏顶部继续写科目一「已掌握 m/n」。它只说明练到哪，不挡菜单。`ProgressStore.subject1Steady` 仍表示最近 3 场科目一模拟考是否都在 95 分以上，不再当入口条件。

## 后果

- 科目一还没练完也可以做科目四、看科目二的练车日。
- 补题、答错不再把已经打开过的科目锁回去。
