# ADR 0130：科目二用真实图片/视频标记参照物讲解，文字只做短句兜底

- 日期：2026-10-17
- 状态：已接受
- 影响：`content/subject2.json`（步骤新增 `media`）、`content/images/subject2/`、`content/sources/`、`lib/subject2/`（新增 `step_media.dart`，接入项目页与点位卡）、`test/`
- 关系：延伸 ADR 0040（讲解与标注）与 T-007/T-010 的「可视化优先」；不取代俯视图（俯视图讲整体几何，真实图讲「眼睛看到什么」）

## 背景

使用者定调：讲解科目二参照物要**尽量用真实视频或真实图片并在图上标记参照物**，避免单纯文字讲要点。
此前的「后视镜里车尾接近库口」「库角与车身的夹角」这类句子，学员读完仍不知道画面里哪一块是哪一块。
俯视图（T-008/T-010）解决了「车相对于场地在哪」，解决不了「坐在驾驶座上我看到了什么」——而学车时真正对点的
恰恰是后者。

## 决定

1. **每个有参照物的步骤配一份真实素材**：优先真实照片，需要过程时用短动图（GIF/WebP）。动图由 mp4 经 ffmpeg 转出，
   不引入视频播放插件（应用已有 GIF 播放路径，ADR 0080），体积控制在每段几百 KB～数 MB。
2. **图上标记参照物**：素材旁挂 `marks`（归一化坐标 0～1，类型 `point` / `line` / `arrow`，带一个短标签，如「左后视镜下沿」
   「库角」「控制线」），由渲染层叠在图上，不烧进图片，方便改字与对不同尺寸适配。
3. **素材来源三档，按准确度排序**：
   ① 使用者**本人本车实拍**（点位因人因车而异，这是最准的一档，走点位卡，见第 5 条）；
   ② 网络公开的真实实拍图/视频（自用软件，ADR 0159：网上能找到的直接入库，出处照记，`content/sources/` 登记来源与访问日期，
   并在 `media[].source` 写出处）；
   ③ 俯视图 / 示意动画兜底（素材找不到的步骤）。
   第 ② 档素材必须与步骤语义逐条核对——图里的车型、座椅、后视镜位置不同于使用者的车，所以每张图都带「示例：点位以你自己的车为准」标注。
4. **版面主次翻转**：项目页每步先放真实图（带标记）与俯视图，文字缩为一两句短句；没有素材的步骤保持现状，不为了「有图」放不相干的图。
5. **点位卡升级为带标记的实拍图**：学员在自己车里拍的照片（点位卡已有照片能力，ADR 0037）可以在图上点选位置加标签，
   形成「我的参照物标注」，在项目页该步优先于通用素材显示。个人照片仍随仓库走、不进事件同步（沿用 ADR 0070）。
6. **宁缺毋滥**：图片质量或语义对不上的素材不收；一个步骤没有合格素材，就保留文字+俯视图，把它记进素材缺口清单，
   请使用者在自己的车里补拍。

## 取舍

- 不烧标记进图：改标签不用重做图，窄屏可缩放；代价是渲染层要写一个叠加组件（一次性）。
- 不上视频插件：动图失去进度条和暂停，但依赖最少、跨三平台一致；若以后某类素材必须长视频，再另议。
- 网络素材质量参差：靠逐张核对与「示例」标注兜底，不追求量；用户本人实拍是长期正解。
