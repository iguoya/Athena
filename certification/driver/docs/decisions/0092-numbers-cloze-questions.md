# ADR 0092：易混数字自测出题——要考的数字挖成括号，长清单拆成单条

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/cloze.dart`（新：挖空与拆单条）、`lib/home.dart`（易混数字页的条目生成）、
  `test/cloze_test.dart`（新）、`test/recall_test.dart`
- 关系：修订 0085 里易混数字页「情形做题干、数字做选项」的出题方式；四选一、判定、记录与抽题规则
  不变；题干仍取自 `content/cheatsheet.json` 的原文，不现场造内容、不违反主仓库 ADR 0043；使用者拍板

## 背景

使用者指出：易混数字的出题方式很蠢——**怎么能把要考核的数字列在题干中呢，至少也应该是个括号**；
目前的出题方式达不到考核记忆的初衷。核对数据，问题有两处：

1. **题干里写着答案。** 题干直接用「情形」原文，而 50 行情形里有 18 行的原文就带着答案数字，
   比如距离一组「警告标志设在来车方向 150 米以外」，答案选项里就有 150，等于送分。
2. **题干是一长串。** 记分一组每行的情形是五六条违法行为的清单（「闯红灯；驾驶证被暂扣期间驾驶；
   致人轻微伤事故后逃逸……」），问「这一串对应几分」考不了任何具体的记忆。

## 决策

1. **要考的数字在题干里挖成括号「（　　）」。** 只挖带着答案单位的数字（单位取答案值自带的，如
   「小于 200 米」的米，没有就用组的单位）：同一句里别的数字是条件，不是答案，留着——
   「高速车速超过 100 公里/小时：与同车道前车保持 100 米以上」，答案 100 米，只挖后面那个 100。
   区间答案（50–100）两个端点都挖；数字两侧的空格一并吃掉（「来车方向（　　）米以外」）。
2. **原文里没有可挖的数字，就在句尾补括号：** 「饮酒后驾驶 →（　　）」，选项是同组的分值。题干里
   绝不会留着答案；`test/cloze_test.dart` 遍历全部真实数据守住这一条。
3. **长清单按「；」拆成单条，每条自成一题。** 记分、限速这类一行多条的，拆开后每条违法行为 / 每种
   情形各一张卡，答案仍是这一行的数值。条目键改为「组 + 单条情形 + 数字」，以前的自测记录因此作废
   重来，影响很小（当天才上线）。
4. **答后给完整原文和出处**，挖掉的数字在原文里原样可见；提示语改为「括号里该填什么？选一个」。

## 取舍

- 单位对不上的数字不挖，例如答案是「公里/小时」，题干里的「30 米」就不动；宁可句尾补括号，也不误
  挖条件把题目挖成病句。
- 拆「；」只拆到分号一级，同一段里用逗号连着的两个事实（「小车超速 20%–50%，普通道路超速 50% 以上」）
  仍在一条里，是原文的句读决定的，不硬拆。
- 这只改了易混数字页。其他页是「图 → 名称」「情景 → 要点」，题干本来不含答案；记分证照页里少数
  情景与要点共用名称（如 C1 / C2），是名称不是答案，不处理。

## 验收

- `test/cloze_test.dart`：距离、同句两个 100、区间、无可挖数字、单位对不上、拆分各一例；遍历全部
  真实数据，每条拆出来的题干都含括号，且不留着答案数字加单位。
- `test/recall_test.dart`：易混数字自测的提示语是「括号里该填什么」，仍是四选一。
