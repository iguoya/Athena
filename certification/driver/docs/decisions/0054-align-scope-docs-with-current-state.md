# ADR 0054：范围说明对齐现状——ADR 0001 的几条已被后续决定取代

- 日期：2026-10-01
- 状态：已接受
- 影响：`README.md`、`AGENTS.md`「定位」、`docs/decisions/0001`、`docs/decisions/README.md`
- 关系：修订 ADR 0001 第 1、3、4 条；不改变任何后续 ADR 的决定

## 背景

ADR 0001 写于应用刚起步时，划了「只做科目一与科目四、不做科目二与地方卷、不拿商业
题库凑数」的范围。之后的决定陆续越过了这条线，但 0001 的状态一直写「已接受」，
`README.md` 也沿用「只练两门」「不用商业题库原题」。读文档的人（包括代码代理）
会照着旧范围判断「这个该不该做」。

已发生的变化：

- 科目二 C2 四项已做：评判规则题、动画讲解、练车记录（ADR 0036、0037、0039、0040、0047）。
- 河南洛阳地方题照收，科目一模拟考固定抽 10 道（ADR 0011、0023）。
- 公开题库直接收录，以与现行法规一致为唯一硬标准（ADR 0008、0045）；
  商业站点只作选题线索，不当内容依据（ADR 0046）。
- 科目一不再因本科目内的阶段解锁（ADR 0044）。

## 决策

1. **应用范围以 `AGENTS.md`「定位」为准**：科目一、科目四理论，加科目二 C2 四项；
   不做科目三上路，不做手机 App。
2. ADR 0001 第 1 条「只收科目一与科目四」由科目二的 ADR 0036 修订；第 3 条
   「不拿商业题库凑数」由 ADR 0008、0045、0046 取代；第 4 条「不做科目二、地方卷」
   由 ADR 0036、0011 取代。第 2 条（模拟考规则跟现行规章走）不变。
3. 本应用 ADR 只增不改正文；0001 只在头部加一行「修订」说明，索引状态同步，
   正文保留原样作为历史。
4. `README.md` 重写为现状：三科范围、题目出处原则、怎么跑；细则指到 `AGENTS.md`，
   不再自己维护一份副本。

## 后果

- 新读者看 README 就知道做了什么、没做什么；要看细则去 `AGENTS.md`。
- 以后再有范围变化，当次提交里同步 README 与索引状态，不再等它过时。
