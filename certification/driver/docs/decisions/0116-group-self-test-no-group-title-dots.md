# ADR 0116：自测只在组内，页头不再有全页自测；速记组标题左侧不放掌握圆点

- 日期：2026-10-07
- 状态：已接受
- 影响：`lib/speed/{signs,markings,gauges,gestures,notes,numbers}_page.dart`（去掉页头「自测」与组标题圆，
  组标题行加「自测」）、`lib/speed/recall.dart`（`only` 只考一组、干扰项仍从整页出，收尾文案「这一页」→「这一组」）、
  `lib/speed/recall_status.dart`（`GroupRecallButton`）
- 关系：修订 0112 决定「各速记页的每个子标题左侧也有状态圆」与 0113 组标题圆的部分（判档函数
  `statusOfIds` 不变，只是组标题不再显示）；0099、0115 的「再测一遍」随之按一组算；0115 的「已通过」
  已由「再练一遍」取代，本 ADR 不再提它

## 背景

0115 之后使用者再看速记页：页头右上角的「自测」把整页的卡一次排完，一页上百张时没有分寸；
组标题（如记分证照速记的「记分：最容易混的对子」）左边的掌握圆点与组内每条的状态点、组按钮的颜色
说的是同一件事，一级标题上再挂一颗显得重复。

使用者拍板：取消页面（章节）的全局自测，只有组内自测，放在组标题行原来「已通过」按钮所在的位置；
所有专题的组标题统一不在左侧加掌握标记点。

## 决定

1. **页头不再有「自测」。** 每个速记组的标题行右侧有「自测」，紧挨「练这组」，只考这一组的卡
   （抽卡规则不变：答错还在错题库里的先、没测过的其次，答对的不再出现，0090、0094）。
   手势速记只有一组「8 个法定动作」，它的自测就是原来的全页自测。
2. **干扰项仍从整页出。** 组里的卡可能不到四张（要点类有的组只有两三条），干扰项只从组内取会凑不满
   四个选项、也变得过于容易；`RecallSession` 收 `pool`（整页）出卷、`entries`（这一组）出题。
3. **「再测一遍」按一组算**：这一组每张卡都答对了才出现，点了重考这一组（0099、0115 的条件不变）。
   收尾文案写「这一组」。
4. **速记组标题左侧不放掌握圆点**，所有专题（标志、标线、仪表、手势、易混数字、要点类各页）一律如此。
   组的掌握看标题行的「掌握 a/b」与组按钮颜色（0115：只看自测）；组内每条的状态点、易混数字的行点、
   侧栏专题与专题分组的状态圆（0109）都保留。

## 取舍

- 「练这组」保留：使用者说的是把自测放到原来「已通过」按钮的位置，练真题仍要有入口；两个按钮并排，
  自测在左（掌握的账），练题在右（练习的账）。
- 不留全页自测当捷径：两个入口并存时又会有人从页头一次考完整页，回到使用者不要的形态。

## 验收

- `test/recall_test.dart`：15 个速记页每组都有自测入口；记分证照第一组的自测只排这一组的条数。
- `test/notes_page_test.dart`：组标题没有状态圆；组内自测答错一张，那一条变红、组按钮变红。
