# ADR 0085：速记自测改四选一——对错客观判定，自评退场

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/recall.dart`（`RecallEntry` 加 `group`、`answerTexts`，选项生成，交互改作答制）、
  `lib/signs_page.dart`、`lib/markings_page.dart`、`lib/gauges_page.dart`、`lib/gestures_page.dart`
  （条目传组键）、`lib/home.dart`（易混数字传组键）、`lib/notes_page.dart`（传组键与要点）、
  `lib/selftest_store.dart`（仅注释措辞：记录语义从「自评」改「自测作答」，接口与文件格式不变）、
  `test/recall_test.dart`
- 关系：修订 0080 决策 5、6 与 0082 决策 2 的**交互部分**（「揭示 → 自评」改为「选择 → 判定 →
  揭示」）；0083 的分层判定原样沿用（自测里答对仍只到 `selfOnly`，「认得」仍以作答记录为准）；
  0082 决策 6（不是掌握度、不同步）与决策 7（条目键稳定）不变；不违反 0043（选项全部取自
  既有条目文本，不现场造内容）与 0059 决策 2（对错仍只用于出卡过滤，不写掌握度）

## 背景

0083 把自测「认得」的判定改以作答记录为准，解决了**记录**的主观性；但**交互**仍是「看卡回想
→ 揭示 → 自评记住了 / 没记住」。使用者指出这个形式主观性还是强：看着答案说「我早就知道」、
「揭示后觉得眼熟」的错觉依旧存在，要求改成选择题选项。

## 决策

1. **自测改为四选一。** 正面不变（规范图 / 情形 / 情景），下方给选项，点选或按 1～4 即判定；
   答后选项定格（正确项标绿、选错的标红），下方照旧显示答案标题、说明与易混卡，按空格或点
   「下一张」推进。原来的「揭示（空格）」与「记住了（1）/ 没记住（2）」按钮退场。
2. **对错就是客观的「记住 / 没记住」。** 答对 = 一次就记住（本轮第一次问到时，`SelfTestStore`
   记一次、升间隔级），答错 = 没记住（清零、隔两张重现插队）。「认得以作答记录为准」的分层
   （0083）原样沿用：有相关题的条目，自测里答对仍只到 `selfOnly`（这次不再出，等做题确认）；
   没有相关题的条目以自测作答为准，同样按 1 / 3 / 7 / 21 天间隔回头确认。
3. **选项从既有条目里出，不造内容。** 正确选项取条目的答案文本：符号、标线、仪表、手势与
   易混数字就是条目名（含义 / 数字）；要点速记（考点、河南、记分证照）一个情景有多条要点，
   每次抽一条作正确选项，干扰项取其他情景的要点，答后仍显示完整要点列表。`RecallEntry`
   加 `answerTexts`（正确答案候选，空则用 `name`）。
4. **干扰项同组优先。** `RecallEntry` 加 `group`（标志 / 标线 / 仪表用手势 kind，数字与要点用
   组 id）：候选先取同组的其他条目（禁令混禁令、罚款混罚款，最易混也最有练习价值），不足
   4 个再从全页其他条目补；易混对（`confuseName`）排最前。排除与正确选项相同文本的候选，
   候选不足时选项按实际个数出。易混数字跨组补出的干扰可能量纲不同（米组混进秒组），在
   正面的组标题（含单位）对照下是可排除的弱干扰，接受。
5. **重现沿用同一考卷。** 没记住重现的卡，本次打开期间保持同一正确选项与选项集（按条目键
   缓存）——避免同一张卡两回考不同侧面；进入下一轮重新出卷。
6. **存储原样沿用。** `selftest-<学习者>.json` 仍是 version 2 格式，字段语义从「自评结果」
   变为「自测作答结果」，旧记录原样沿用、不迁移——两者都是「这人在自测里的表现」，语义漂移
   可接受。它仍不进作答、不进统计与激励、不同步（0082 决策 6）。

## 取舍

- 选项干扰性受既有内容限制：干扰项只能来自同页条目，覆盖不了「形近图混含义」之外的花样
  （比如「以下哪条做法对」的多选化）。要做更花的选择题就得给条目补手写干扰项，先不做——
  现有的同组互混已经覆盖最易混的部分。
- 要点页一次只考一条要点，「答对」不等于记住了该情景的全部要点；缺口由答后显示的完整要点
  列表与间隔复现补。
- 数字页跨组补的弱干扰（量纲不同、容易排除）比选项凑不满 4 个更可接受：一轮 5 张的节奏
  比单个选项的难度均匀更重要。

## 验收

- `test/recall_test.dart`：自测出的是四选一，点对判定「答对了」、点错判定「答错了」且原卡
  重现、判过的记录照写；一轮 5 张、没记住的重现、中途退出不丢、8 个速记页都有入口这些
  原有流程在选择题形式下全部保持；易混数字页选项是数字、要点页选项是单条要点且答后显示
  完整要点；自测作答不增加作答记录。
- `test/selftest_store_test.dart`、`test/selftest_evidence_test.dart`：接口不变，语义注释
  跟着改。
- `python3 scripts/check.py driver`：`flutter analyze` 与全部测试通过。
