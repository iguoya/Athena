# ADR 0122：侧栏专题右侧写「a/b」——通过的大类 / 大类总数

- 日期：2026-10-07
- 状态：已接受
- 影响：`lib/speed/recall_cards.dart`（`recallGroupsOfTopic`）、`lib/home.dart`（`_topicPassTag`）
- 关系：补 0109 侧栏专题圆；「通过」与组按钮变绿同一把尺子（`statusOfIds`，0113、0121），只认专题自测里的作答（0119）

## 背景

侧栏专题左边只有一个状态圆，悬停才看得到「掌握 a/b」（0119 起按条目数）。使用者要在专题条目右侧直接看到
进度，口径是**大类**：a = 已经自测通过的大类，b = 这个专题页面上的大类总数。

## 决定

1. **大类就是专题页面上的组**（`recallGroupsOfTopic`）：易混数字、要点类按组，标志、标线、仪表按种类
   （禁令、警告……），手势页只有「8 个法定动作」一组。
2. **一个大类算通过**：组里每张卡最近一次自测都答对（组内「自测」按钮变绿）。
3. 侧栏每个专题右侧常驻「a/b」，全部通过时变绿；悬停写「这个专题 b 个大类，自测全部通过 a 个」。
   左边的状态圆与它悬停时的「掌握 a/b」（条目数）不变。

## 验收

- `test/speed_nav_test.dart`：大类数等于页面组数且盖住全部卡；易混数字没测过是「0/组数」；手势整组答对是「1/1」。
