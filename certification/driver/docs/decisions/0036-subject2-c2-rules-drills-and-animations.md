# ADR 0036：科目二（C2）——评判规则题、操作动画讲解、练车错因记录

- 日期：2026-09-28
- 状态：已接受
- 影响：新增 `content/subject2.json`、`content/questions/subject2.json`、`lib/drill.dart`、
  `lib/subject2.dart`；`content/curriculum.json` 加科目二；`lib/progress.dart` 加练车记录表
  （库版本 6）与同步事件；`lib/models.dart` 的 `Subject.exam` 改为可空
- 关系：修订 AGENTS.md「不做科目二场地」；出处规则同 ADR 0003；练车统计走主仓库 ADR 0052
  的同一条回路；可视化按主仓库 ADR 0056

## 背景

使用者备考 C2（小型自动挡）。科目二是场地驾驶技能考试，成败主要靠手眼脚配合和在考场
同款车上的练习时长，软件替代不了。但有两类失分是「脑子里的」，软件管得了：

- **不清楚评判边界**：什么直接不合格、什么扣 10 分、什么扣 5 分，时限多少。
- **错因不复盘**：每次练车错在哪里没有记录，考前说不清自己反复栽在哪一项、哪一类错。

使用者还希望有讲解，最好把操作步骤和要点可视化。

## 决策

### 1. 范围

- 只做 **C2 的四项**：倒车入库、侧方停车、曲线行驶、直角转弯（GA 1026—2022 4.2.3）。
  C1 的坡道定点停车和起步不做；以后要做再加。
- 合格线按 6.2.1：满分 100，80 分合格。
- 本次不做「个人点位卡」和轨迹原理讲解（见上一轮讨论的第 3、4 项），先把规则与练车记录做实。

### 2. 评判规则题（计入掌握度）

- 题目**只从 GA 1026—2022 原文出**：6.2.1 合格标准、6.2.2 通用评判（只收对 C2 适用的条目，
  离合器、换挡齿轮撞击、制动气压、摩托车这类不收）、6.2.3.1 / 6.2.3.4 / 6.2.3.5 / 6.2.3.6
  四项专项评判、5.2.2 / 5.2.5 / 5.2.6 / 5.2.7 操作要求里的时限与路线。
- 每题 `source_refs` 指到 `ga-1026` 的条款号，`note` 抄条款原句；原句另存
  `content/sources/reference/excerpts.md` 便于离线核对。
- 题目进课表的 `subject2`，知识点前缀 `drive.s2.`；走现有练习、错题本、考前复习，
  不另做一套。科目二不按科目一解锁——现实里科目二的练车可以和科目一的学习并行。
- 科目二没有笔试，`Subject.exam` 改为可空；科目一、科目四不受影响。

### 3. 操作讲解：动画示意 + 步骤 + 要点

- **不嵌外部视频**：ADR 0004 定了不嵌 WebView；网上的教学视频有版权问题，车型和考场也对
  不上。改做**应用内的动画示意**：场地线形、车辆轮廓、行驶轨迹，按步骤播放，可以播放、
  暂停、单步、调速；右侧步骤列表与动画同步高亮，当前步骤的要点叠在画面上。
- 轨迹由**运动学几何**算出（直线 + 定半径圆弧，按后轴中心走），不是手绘曲线。
  **测试验证**每一帧车身（倒车入库、侧方停车）或车轮（曲线行驶、直角转弯）都不出线——
  示意动作本身不能是一个会被判不合格的动作。
- 图是示意、不按比例；尺寸以所在考场为准，页面上写明。
- 「要点」是操作经验（控速、看哪里、什么时候回正），**不计分**、不进题库，标注
  「经验要点，以教练和考场车型为准」，不写具体的后视镜点位——点位和车型、座椅、考场绑定，
  写通用点位反而会误导。
- 文字内容（步骤、要点、评判条目、错因清单）放 `content/subject2.json`，界面按数据渲染
  （主仓库 ADR 0058）；动画几何在 `lib/drill.dart`，属于 ADR 0056 的专属可视化。

### 4. 练车错因记录

- 每练一把记一条：哪一项、出了哪些错（从该项的错因清单里勾选），也可以记「这把没毛病」。
- 错因清单**逐条对应评判条款**，所以每一把能按考场规则算出分数：有不合格项就判不合格，
  否则 100 减去扣分，80 分及格。
- 统计：每项练了几把、按考场规则能过的比例、最常见的错因、最近 7 天的趋势。记了就要给人看。
- 存进度库新表 `drill_runs`（库版本 6），随仓库走；跨机器同步加一种事件 `drill`，
  按「项目 + 时间」去重，跟作答记录同一套并集合并（ADR 0010）。
- 练车记录**不写掌握度**：掌握度只由答题写入（仓库 ADR 0052 / 本应用 AGENTS.md）；
  练车记录是另一条统计线。

## 后果

- 科目二页面同时承担「讲」（动画、步骤、要点）、「考」（评判题）、「记」（练车错因）。
- 评判题的数字全部来自标准原文；以后标准修订，改 `excerpts.md`、题目和 `subject2.json`
  三处，测试会检查题目的条款号在摘录里存在。
- 动画几何的合法性由测试守着：调场地尺寸或轨迹参数时，出线会直接让测试失败。
