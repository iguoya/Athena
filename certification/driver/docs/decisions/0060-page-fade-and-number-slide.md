# ADR 0060：动效第三处——换页淡入与数值滑入

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/look.dart`（新增 `PageFadeIn`、`BsTweenFraction`，`BsProgress`、
  `MasteryRing`、`RateRing` 接入）、`lib/home.dart`（内容区换页淡入）、
  `lib/reinforce_page.dart`（漏斗与优先章节横条接入）
- 关系：修订 0058 决策 6 的「动效收窄为两处固定投入」——扩为三处；其余约束
  （时长令牌化、新代码用现成零件、做题高频操作不被挡）不变

## 背景

0058 把动效收窄成两处（概览 stagger、选项判色），换页与数据展示全是瞬时换帧。
实际用下来有两个具体不顺手：侧栏换页是一帧黑替——旧页消失新页直出，硬切感明显；
掌握度环、进度条、漏斗每次进页面都是终态直出，「掌握度在长」的反馈出不来。
做题回路（选项、翻页、自动滚动）的节奏不动，这两处都发生在做题之外的浏览动作上。

## 决策

1. **动效第三处固定投入：换页淡入。** 内容区用 `PageFadeIn` 零件——`pageKey`
   变化时新内容从 0 淡到 1（`Bs.durIn` + easeOut）。只淡入、不交叉溶解：页面底
   是同一层环境色斑，淡入即够；交叉溶解会让新旧两棵页面树并存 300ms，测试的
   唯一性断言和内存都跟着变贵。
2. **动效第四个零件：数值滑入。** 进度条、掌握度环、就绪度环、漏斗、优先章节
   横条这类占比图形，用 `BsTweenFraction` 从 0 长到目标值（进页面一次），
   目标值变化时从旧值滑到新值。数字本身不跳、不循环，做题中产生的作答反馈
   不在此列。
3. **时长与曲线全部走令牌。** 两处都用 `Bs.durIn` + `Curves.easeOut`（环与条
   用 easeOutCubic），不新增时长常量；零件放 `look.dart`，页面不自己调参。
4. **做题台不动。** 会话内（题目、选项、右栏依据）不引入任何新动效，
   0058 决策 6 的理由原样成立。

## 后果

- 进页面时环形图与横条有一次 300ms 的生长动画；数据重载（答完题回概览）时
  从旧值滑到新值，掌握度变化看得见。
- 换页从一帧黑替变成 300ms 淡入；测试不受影响——旧页立即卸载，新页淡入中
  照常可查。
- 动效总清单：概览 stagger（0058）、选项判色（0058）、换页淡入、数值滑入
  （本 ADR）。再加新的动效类型须另立 ADR。
