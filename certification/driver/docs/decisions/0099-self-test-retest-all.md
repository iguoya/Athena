# ADR 0099：自测全对后给「再测一遍」——重考的入口不缺席

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/recall.dart`（收尾页加「再测一遍」按钮与 `_retestAll`）
- 关系：补 0090 的出口——「答对的不再出现」在整页答对后会让自测无卡可出、又没有
  重考入口，使用者撞上后指出不能「不让我测」；与 0098 的「再练一遍」同一思路：
  重考靠主动动作，不动已有的作答记录

## 背景

0090 定了「答对的不再出现」，0094 又把自测作答并进作答记录——旧的「重新自测」清自测
记录的机制随之失效（作答记录不可手动清，0020）。两者叠加：一页全部答对后，自测直接
收在「没有要考的了」，除了关闭没有任何再考的入口。

## 决策

1. **整页全部答对时，收尾给「再测一遍」。** 点击后绕开档位过滤，把整页卡重新排队
   考一遍（这次答对的也考）；平时抽卡不变，仍然只出没答对过的。
2. **作答照写。** 重测的每次作答照 0094 写进作答记录——重测中答错的卡重新进错题库，
   被强化练习、考前复习带出；答对的刷新掌握状态。不需要也没有「清空记录」。
3. **收尾文案说明出口。** 「没有要考的了」的提示补一句「想再过一遍，点『再测一遍』」。

## 取舍

- 「再测一遍」整页重考而不是只考错题：它服务的场景是主动巩固（自测过了还想再过一遍），
  按错题过滤是强化练习的职责，不在这里重复。
- 重测沿用同一张卷（选项不打乱重生）：同一张卡两回考同一侧面，判定才可比。

## 验收

- `flutter analyze` 通过；全对收尾出现「再测一遍」，点击后回到卡片流重新考全页，
  作答与错题库随之更新。
