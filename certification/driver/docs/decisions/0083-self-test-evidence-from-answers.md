# ADR 0083：自测的「认得」以作答记录为准，自评只作兜底，认得的按间隔回头确认

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/recall.dart`（`classifyEntry` 档位判定、抽题顺序、进度与收尾反馈、练习深链）、
  `lib/selftest_store.dart`（自评记录加时间戳与间隔阶梯）、`lib/home.dart`、
  `lib/{signs,markings,gauges,gestures,notes}_page.dart`（每个条目带相关题，传入作答历史与
  已掌握集合）、`test/selftest_evidence_test.dart`（新）、`test/selftest_store_test.dart`、
  `test/recall_test.dart`
- 关系：修订 0082 决策 2、3、5、6（「认得」不再由自评决定；自评记录降为兜底）；
  不改 0059 决策 2（速记页仍不判分、不计掌握度）与 0043（判分内容必须有出处）——没有
  新增任何判分，客观依据全部来自既有题库与作答记录

## 背景

0082 让自测记住「第一次问就记住」的条目、以后不再出。使用者指出：**「认得」由自评决定，
主观性太强**——人容易高估自己，看着答案说「我早就知道」，也有「揭示后觉得眼熟」的错觉。
要求找更科学、客观的办法。

## 决策

1. **「认得」的客观依据是作答记录，不是自评。** 速记卡大多有真实的相关题（标志、标线按
   `Question.sign` / `Question.marking`，手势、仪表按反向映射），题有出处，作答对错已经
   记在进度库里，掌握度的定义也已经现成。一张卡有相关题时：
   - 相关题**全部答对并掌握** → 认得（`known`），自测不出；
   - **答错过** → `wrong`，最该考，自评再肯定也压不过它；
   - 只做了一部分、或没做过 → `partial` / `fresh`，要考。
   不新增任何判分、不另出题，所以不动 0059（速记页不判分）与 0043（判分内容必须有出处）。
2. **自评降级：只决定「这一次还出不出」，不能让一张卡变成「认得」。** 有相关题的卡，自评
   「一次就记住」最多得到 `selfOnly`（自评认得、待做题确认）：自测先不出它，但进度里单独
   记为「自评认得 N，待做题确认」，与作答记录证明的「已认得 K」分开写、分开画（深浅两色）。
   同一次打开期间自评记住的卡也不再重复抽。认得与否仍等**做题**来证明。
3. **自评只在没有客观证据时兜底。** 没有相关题的条目（胎压灯、ESC 灯，标志里的 9 个：限速
   40 / 80、禁止右转、注意危险、注意行人、人行横道、向左 / 向右转弯、指路牌）无处取证，
   才用自评结果直接决定，并同样按间隔复现。这部分诚实地仍是主观的，界面不把它说成客观。
4. **认得不是永久的，按间隔回头确认。** 阶梯 1 → 3 → 7 → 21 天（`SelfTestStore.intervalDays`，
   遗忘曲线的间隔重复做法）：
   - 作答记录证明已掌握的卡，离相关题**最近一次作答**超过间隔就重新归为 `due`，自测抽到它
     确认还记得；阶梯按相关题里「连对跨过天数最少」的那道定，越稳固间隔越长；
   - 兜底的自评认得，到期同样 `due`，再次一次记住就升一级，没记住就清零。
5. **抽题按急缓排档。** 一轮 5 个，依次从这几档取：`wrong`（答错过 / 自评没记住过）→ `due`
   （到期复现）→ `fresh`（没考过）→ `partial`（只做了一部分）；每档内打乱，上一轮刚出现
   的排后。`known` 与 `selfOnly` 不抽。可抽的不足 5 个就按实际个数出一轮；可抽的为 0 时
   明说（全是作答证明认得 → 「这一页作答记录都证明你认得了」；还剩自评认得 → 「没有要再考的了，
   剩下的作答记录还没证明」）。
6. **闭环落在做题上。** 收尾的「去做这几个的题」只带这一轮没记住的、以及只有自评还没作答
   证明的条目的相关题（去重、排除已掌握的）——让作答记录来确认，而不是让使用者再自评一遍。
   「重新自测」只清自评记录，不动作答记录。
7. **粒度的限制要明说。** 易混数字与考点速记类页面的相关题只能关联到「组」，同一组的条目
   共用一份证据：组里相关题都掌握了，整组条目都视为认得。这比逐条目粗，是题库当前的关联
   粒度决定的；以后若给条目补上逐条关联，只需填 `RecallEntry.related`。

## 取舍

- **相关题答对 ≠ 记住了这张卡的全部内容**：题考的是这个知识点的某个侧面。但它是客观的、
  有出处的、已经存在的证据，比自评可靠得多；缺口由间隔复现与「待做题确认」补。
- **从没做过相关题的新手，自测一开始会把所有卡都当 `fresh`**，这是对的：没有证据就该考。
- **自评记录仍在**，但只用于兜底、本次去重与间隔，不再被当作「认得」；它仍不是掌握度，不进
  作答与统计，不同步（0082 决策 6 不变）。
- 没引入用时、犹豫度这类信号：0020 已撤销「迟疑」概念，避免规则本身产生死角。

## 验收

- `test/selftest_evidence_test.dart`：有相关题时没做过 / 只做一部分 / 答错过分属 `fresh` /
  `partial` / `wrong`；自评只得到 `selfOnly`，作答答错过则自评压不过 `wrong`；作答证明掌握
  才是 `known`，离最近作答超过间隔（按连对天数的阶梯）变 `due`；没有相关题时退回自评，
  没记住过 `wrong`、认得 `known`、到期 `due`、没考过 `fresh`。
- `test/selftest_store_test.dart`：自评的间隔阶梯 1 / 3 / 7 / 21 天与封顶、到期后再次一次记住
  升级、没记住清零；按学习者落文件、换人空白、重置只清本页、0082 老文件当作到期重考、文件损坏当空白。
- `test/recall_test.dart`：给手势相关题写入真实作答（两个动作答对、一个答错）后，自测进度显示
  「已认得 2 / 8（以作答记录为准）」，第一轮 5 张里一定有答错的那个、一定没有已证明认得的两个；
  一轮 5 张、没记住的重现且不算认得、中途退出不丢、8 个页面都有入口；自评不增加作答记录。
