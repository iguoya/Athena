# ADR 0059：标志速记页——手绘标志成为可浏览的内容

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/signs.json`（每条加 `meaning`，修正 no_parking / no_stopping 两条
  名称）、`lib/models.dart`（`RoadSign.meaning`）、`lib/sign.dart`（`paintableSignIds`
  常量）、`lib/signs_page.dart`（新）、`lib/home.dart`（侧栏钉住区、页面分发）、
  `lib/glyphs.dart`（`Glyph.signs`）、`test/signs_page_test.dart`（新）
- 关系：落实仓库级 ADR 0056（可视化与交互是内容本身）；是 0058 决策 5「其余页后续
  顺手换 BsCard」的一部分；沿用 0028（易混数字页）的速记类页面先例；内容出处的
  硬标准仍是 0003/0008

## 背景

`sign.dart` 已经用 Canvas 手绘了 30 多种交通标志，但它们只作为题目配图出现——
一道题做错才见到那一个标志。`content/signs.json` 有 33 条标志的 id、名称、分类
（禁令/警告/指示/指路）与频次档，却没有含义文案；标志是科目一丢分重灾区
（信号类题占比高、易混标志多），缺一个把「形状 → 名称 → 看到之后怎么开」放在一起
速记的地方。速记类内容的先例是易混数字页（0028）：内容在 `content/`、每组能直接
练相关的题、参考性质不判分。

## 决策

1. **新增「标志速记」页，侧栏钉住区与「易混数字」并列。** 内容源就是
   `content/signs.json`，每条加一个 `meaning` 字段：一句行动导向的「看到之后怎么开」，
   不写标志学。页面按 `kind` 分四组（禁令、警告、指示、指路），每组一张 `BsCard`：
   组名、一句形状口诀、组内网格（手绘标志图 + 名称 + 含义 + 高频徽章）、组级
   「练这组的题」按钮——相关题按 `Question.sign == 标志 id` 关联，练习通路、
   未掌握过滤与易混数字页同一套。
2. **含义文案是文件级出处，不做条级 locator。** 速记页不判分、不计掌握度，
   条级出处只留给数字这类硬规定（0028 先例）；标志含义按 GB 5768.2—2022 的
   语义写，`signs.json` 文件头已挂 `gb5768-2` 出处，页面不再逐条注条号。
3. **修掉两处内容错位。** `no_parking` 与 `no_stopping` 在 `signs.json` 里的名称
   恰好互换：题面（`drive.s1.signals.033/034`）与 painter 的画法都把一道斜杠当
   「禁止停放车辆」（可临时停靠上下客）、红叉当「禁止停车」（全禁），GB 也是
   这个语义；json 里 no_parking 却写着「禁止停车」。改为：`no_parking` =
   禁止停放车辆，`no_stopping` = 禁止停车，与题面、画法、国标三方对齐。
4. **painter 支持的 id 集合提取为常量 `paintableSignIds`。** `_SignPainter` 是
   switch 逐 id 手绘，json 加了 id 而忘了画就会落到兜底的问号图。把支持清单
   提成常量（加标志时与 switch 同步改），测试断言 `signs.json` 的每个 id 都在
   集合里，把「加内容忘画图」挡在 check 阶段。
5. **格子的动效只有 hover 上浮，复用 `BsCard` 的语言与令牌。** 速记页是浏览型
   参考页，不做入场动效、不做放大浮层，不新增 0058 决策 6 之外的动效投入。

## 后果

- 标志从「做错题才见到」变成一页可逛的内容；每个标志组都能直接起一轮相关题练习，
  速记与练题闭环。
- `signs.json` 是唯一内容源，含义文案与题库共守「与现行法规一致」的硬标准；
  标志规定改版时和题一起改。
- 页面只依赖已有的 `SignView`、`BsCard`、`BsBadge` 与练习通路，不引入新依赖。
