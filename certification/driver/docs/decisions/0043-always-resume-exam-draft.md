# ADR 0043：开始模拟考总是接着上次没交的那一卷

- 日期：2026-09-28
- 状态：已接受
- 影响：`lib/home.dart`、`lib/progress.dart`（`exam_drafts` 加 `saved_at` 列，数据库版本 8→9）、
  `lib/session.dart`
- 关系：修订本应用 ADR 0016 第 4 条（有草稿时弹窗问「继续上次 / 放弃重新开始」）和
  第 5 条（续答用时按原始开考时刻算）；接着 ADR 0042 的「只计时不收卷」

## 背景

ADR 0016 在有草稿时弹窗二选一，选「放弃」就把没答完的一卷丢掉重抽。使用者的要求是：
每次开始测试，就接着上次没答完的模拟考。

去掉弹窗之后还有一个问题：用时原先从草稿里的原始开考时刻算。一卷隔几天再续，用时会
显示成几千分钟、一直是红的，没有参考价值。

## 决策

1. 点「模拟考试」时有同一科目的草稿就直接续上，不弹窗、不提供「放弃重新开始」。想换
   一卷就把这一卷交了（交卷随时可以点，没答的按错计分、不写作答记录，ADR 0023）。
2. 草稿每存一次（交一题）同时记下 `saved_at`。续答时用时 = 上次已用（`saved_at` −
   开考时刻）+ 续上以后的时间：实现上把开考时刻平移成「续上的时刻 − 上次已用」，
   答题页照旧按开考时刻算用时，不必知道是不是续答。
3. 版本 9 之前存下的草稿没有 `saved_at`，已用时间按 0 算——宁可少算，也不把挂起的
   几天算进去。
4. 题库改动导致草稿里的题一道都找不到时，仍然丢掉草稿、重抽一卷（ADR 0016 原样）。

## 后果

- 没交的卷不会被误点丢掉；代价是想重抽只能先交卷，这一卷会记一次不及格。
- 用时只计到最后一题交上的那一刻：停下前在一道没交的题上想了多久不算进去。
