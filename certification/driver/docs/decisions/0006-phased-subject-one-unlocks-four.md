# ADR 0006：科目一分阶段，过关后才开科目四

- 日期：2026-09-15
- 状态：已接受
- 影响：`content/curriculum.json`、`content/questions/subject1.json`、练习与模拟考入口
- 对齐：本应用 ADR 0001（只做两门理论）、0003（题目有出处）
- 修订：第 1 条的四阶段划分由 ADR 0009 重排，解锁规则不变

## 背景

科目一和科目四（法规名：科目三安全文明驾驶常识）在考场上是两门考试，但学习顺序
不能倒：没证、不会让行、不识标志，就去做情景处置，等于跳级。把两门并排放在侧栏
里随时可点，会让人以为可以先刷科目四。

科目一内部也不该一次摊开全部难度。资格底线、通行规则、标志怎么开、高速公路，
认知负担不同。

## 决策

1. **科目一按难度分成四阶段**，写在课表 `phases` 和每题 `phase` 上：
   资格与底线 → 通行与让行 → 标志怎么开 → 高速公路。
2. **当前阶段全部掌握**（最近一次答对且非迟疑）才解锁下一阶段的练习和阶段测试。
3. **科目一模拟考**要等四个阶段都掌握。阶段测试只抽本阶段题。
4. **科目四整门锁住**，直到科目一全部掌握。侧栏显示未解锁，点进去只说明原因，
   不开练习、不开模拟考。科目四跟路考分开记分，不要和科目三路考混成一门。
5. 掌握度仍只由作答写入，不另做手动解锁。

## 后果

- 先学科目一的人看不到科目四题干，避免跳级。
- 科目一模拟考在未过关前不是考场 100 题全库，避免把未解锁阶段提前考掉。
- 以前若已做过科目四，那些记录仍在库里；界面在科目一过关前不再把科目四错题
  送进错题本。
