# ADR 0028：易混数字对照页

- 日期：2026-09-27
- 状态：已接受
- 影响：新增 `content/cheatsheet.json`；`lib/models.dart`、`lib/content.dart`、`lib/home.dart`、
  `pubspec.yaml`
- 关系：新增一个侧栏入口；不改练习、模拟考和掌握度规则

## 背景

科目一丢分集中在硬数字上：记分 12/9/6/3/1、各种限速、50 米和 30 米、150 米、期限、罚款
区间、酒精 20 和 80。这些数字散在几十道题里，逐题练时只见到一个，见不到它和相邻数字的
区别——错往往错在把两个档记串了。

## 决策

1. **新增「易混数字」页**：按组（记分、限速、高速低能见度、距离、期限、罚款、酒精）把
   同类数字并排列出，每行写数字、适用情形和出处条号。内容放 `content/cheatsheet.json`，
   跟题库一样是内容，不写死在代码里。
2. **每行都有出处**：对照页不判分、不计掌握度，但它是用来记的，记错比不记更糟，所以
   每行照样指到条文（法规写条号，GB 19522 写节号），写之前对着原文核过。
3. **数字画成横条**：同一组里能比大小的数字（分值、车速、距离）配一根按数值换算长度的
   横条，高低一眼看出来（仓库 ADR 0056）；区间、期限这类不好比的只列文字。
4. **每组配「练这组」**：用组里写的匹配式从**已解锁**的日常题里找相关题直接练，掌握度照常
   由作答写入；没解锁的阶段不因为这里而提前开放（ADR 0006）。

## 后果

- 数字规定改了要同时改题和 `cheatsheet.json`；组里的匹配式按题面文字找题，题面改了措辞
  可能漏掉，靠 `content_test` 检查每组至少找得到题。
