# ADR 0009：科目一四阶段按题量重划

- 日期：2026-09-16
- 状态：已接受
- 影响：`content/curriculum.json` 的 `phases`、`content/questions/subject1.json` 的 `phase`
- 关系：修订本应用 ADR 0006 第 1 条的阶段划分，解锁规则（第 2–5 条）不变

## 背景

按 ADR 0008 收录公开题库后，科目一从 334 题涨到 908 题。原来的四阶段是
「资格与底线 → 通行与让行 → 标志怎么开 → 高速公路」，新题按原归属落下去，
第一阶段会堆成 300 多题，第三阶段只剩 40 来题——而 ADR 0006 要求当前阶段
全部掌握才解锁下一阶段，第一阶段就成了一道劝退的墙。

## 决策

四阶段的名字与内容重划，按题量摊平（各阶段 110–300 题）：

| 阶段 | 内容 | 章节 |
|---|---|---|
| 1 车与人的资格 | 驾驶证、车辆登记与检验、酒驾疲劳 | license、registration、alcohol |
| 2 通行与让行 | 让行、超车、限速、装载与停放 | rules、occupants |
| 3 信号、标志与灯光 | 信号灯、标志标线、夜间与低能见度灯光 | signals、lights |
| 4 高速、事故与处罚 | 高速公路、事故处理、记分与罚则 | highway、accident、penalty |

阶段序仍按认知负担排：先弄清自己和车有没有资格上路，再是日常通行，然后是
读懂信号与灯光，最后是出了事怎么办、违了法怎么罚。

ADR 0006 的其余条款不变：当前阶段全部掌握才解锁下一阶段，模拟考等四阶段
过关，科目四整门锁到科目一全部掌握。

## 后果

- 题的 `phase` 由所属章节决定，新增章节时先定它归哪个阶段，不再逐题写。
- 阶段名与侧栏、阶段测试标题一致，界面不需要改代码。
- 掌握度记录不受影响：阶段只决定练习与测试抽哪些题，不参与掌握度计算。
