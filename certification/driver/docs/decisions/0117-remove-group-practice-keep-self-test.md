# ADR 0117：去掉速记组的「练这组」，组里只留「自测」，按钮颜色挪到「自测」上

- 日期：2026-10-07
- 状态：已接受
- 影响：`lib/speed/{signs,markings,gauges,gestures,notes,numbers}_page.dart`（去掉组按钮与组级关联题）、
  `lib/speed/recall_status.dart`（删 `GroupPracticeButton` 与 `practiceButtonStyle`，`GroupRecallButton` 按状态上色）、
  `lib/home.dart`（`_speedGroupQueue` 不再有整组重练的分支）、各页说明文字
- 关系：撤销 0109 的「练这组」按钮、0114 与 0115 决定 1～3（待练口径、「再练一遍」、按钮颜色）的按钮部分；
  0115 的 `speedPending` 留给自测收尾「去做这几个的题」；0116 的组内自测成为组里唯一的按钮；
  适用于全部速记专题（六种页面组件承载的 15 个专题）

## 背景

0115、0116 之后组标题行并排两个按钮：「自测」考本组速记卡（掌握的账），「练这组」刷本组关联真题
（练习的账）。使用者问清两者的逻辑后决定：「练这组」这套逻辑去掉，保留自测，所有专题一律如此。
另一个理由是易混数字页的「练这组」练的就是自测卡本身（0102 行与题一对一），在那页它其实是换了个
样子的自测，作答还会改掉掌握状态，两个按钮说不清分工。

## 决定

1. **速记组里只有「自测」。** 「练这组 N 题」「再练一遍 M 题」「没有相关题」三种状态连同按钮一起去掉；
   页面不再为组按钮算关联题与待练题。全部速记专题适用。
2. **颜色挪到「自测」按钮上**：仍是 `statusOfIds`——红 = 有自测卡答错未移出错题库、绿 = 每张都答对过、
   灰 = 没测完（0112、0113、0115 的口径不变）。组标题左侧依旧不放圆（0116）。
3. **真题的入口只剩自测收尾的「去做这几个的题」**：这次答错的卡的关联真题，经 `speedPending` 筛
   （错题库里的在前、没做过的其次，偏难一视同仁，没错过的做过一次即止，0115）。没有待练就不给这个按钮。
4. 页面说明文字里的「每组都能直接练相关的题」「再练相关的题」改为「自测」的说法。

## 取舍

- 关联真题的映射（`sign_ref`、`marking`、`gauge.questions`、组的 `match`）都保留：自测收尾要用，
  挂题契约测试也照旧守住「每条都有题」。
- 想整组刷真题的需求交给章节练习与强化练习，速记页不再重复一个入口。

## 验收

- `test/speed_nav_test.dart`：组里没有「练这组」；「自测」按钮没做过灰、有答错红。
- `test/notes_page_test.dart`：组内自测答错一张，那一条变红、组的「自测」按钮变红。
- 原「点『练这组』起一轮练习」的五个页面测试删除。
