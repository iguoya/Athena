# ADR 0129：去掉「重练」术语——全部掌握的组点了直接练，入口不灰显

- 日期：2026-10-16
- 状态：已接受
- 影响：`lib/home.dart`（侧栏科目/章节入口、科目一概览按钮与文案、`_phaseRow`、`_topicRow`、强化练习页「练新题」、删除 `_confirmRepractice`）、`test/interaction_test.dart`、`AGENTS.md`
- 关系：修订 0125 的呈现方式；「入口不死路」与「不删任何数据」两条原则原样保留；侧栏永不锁（0126）加一条：永不灰显

## 背景

0125 把「全部掌握后入口集体失能」修成了「确认一次整组重新练习」，但落地后每个层级都带
一套「重练」的痕迹：侧栏科目行写「重新练习（全部 n 题）」，章节行写「标题（重练）」还配
38% 透明度的禁用灰，概览按钮变「重新练习全部题」，点哪儿都先弹一次确认对话框。使用者反馈：
「重练」入口太多、这个词本身不要、左侧菜单更不能灰着像点不了。

灰显的问题尤其实：0126 已经定了侧栏永不锁，一个可点的入口长着不可点的样子，等于把
「能不能点」的答案从交互里挪到了猜测里。

## 决定

1. **术语清零**：界面上不再出现「重练 / 重新练习」，统一叫练习。待练清零的组，侧栏科目行
   写「练习全部 n 题」，章节行就写章节名（不加后缀、不变灰），概览页按钮写「练习全部题」。
2. **点了直接练，不弹确认**：待练清零的组，点开就是这一组全部日常题再过一遍
   （`_startPractice` 的 `includeMastered` 不变）。0125 的确认环节删除——要不要练由「点不点」
   这个动作本身表达，多出来的一问只是摩擦。
3. **侧栏入口永不灰显**：`_navLine` 的 muted 不再用于「待练清零」，入口永远是正常文字色；
   有没有待练用数字有无表达（清零就不显示数字）。
4. **0125 决定 3、4 原样保留**：答题记录一律保留，错题本、强化练习、统计趋势、科目解锁都
   不受影响，答错的题自然回到待练；不提供清零重练。

## 验收

- `test/interaction_test.dart`：专题全部掌握后章节名正常色显示、无「（重练）」字样，点击
  直接起一轮整章日常题练习、无确认对话框；科目一全部掌握后侧栏「练习全部 n 题」、概览按钮
  「练习全部题」，点击直接开练；答题记录与解锁状态不变。
- 应用 `AGENTS.md` 的「答题与考试规则」同步更新。
