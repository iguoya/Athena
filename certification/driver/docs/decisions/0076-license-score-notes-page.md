# ADR 0076：记分证照速记页——按作答记录里错得最多的点整理

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/license_notes.json`（新）、`lib/models.dart`（`Bank.licenseGroups`）、
  `lib/content.dart`（加载）、`lib/home.dart`（侧栏钉住区、页面分发）、
  `lib/glyphs.dart`（`Glyph.licenseNotes`）、`pubspec.yaml`（登记内容文件）、
  `test/license_notes_page_test.dart`（新）
- 关系：复用 0064（考点速记页）与 0068（河南速记页）的「组—条目—条级出处」结构与
  `NotesPage` 组件；条级出处的硬标准沿用 0028；与易混数字页的分工见决策 3

## 背景

使用者的作答记录里，累计答错 2 次以上的科目一题有 266 道，其中记分（penalty）与证照
（license、registration）三个知识点占了大头；最近两场模拟考共错的 24 题里，记分 9
道、证照 7 道，每一道都是以前做过的题。问题不是没见过，是记不牢：记分档位的相邻两档、
证照罚款的 20–200 / 200–500 / 500 以下 / 2000 以下几个档、几年内不得再申领的几档。
这些题散在题库里，没有一个把它们放在一起比的地方。

## 决策

1. **新增「记分证照速记」页，侧栏钉住区与「手势速记」「考点速记」并列。** 内容源是
   `content/license_notes.json`，格式与 `notes.json`、`henan.json` 同构，直接复用
   `NoteGroup` / `NoteItem` 与 `NotesPage`，不另写布局。
2. **七组，条目按使用者作答记录里错得最多的点选：** 记分最容易混的对子（10）、记分周期
   与满分学习与学法减分（8）、证照期限年龄与实习期（9）、准驾车型增驾审验与补领（6）、
   证照违法的罚款与后果（10）、禁考禁领的年限（4）、号牌行驶证与登记（9），共 56 条。
   每条把容易混的几项放在一起比，每条的要点与出处取自对应题的依据（法规原文摘录），
   出处写到条款，跨条款的写多条。
3. **与易混数字页分工，不重抄同一张表。** 易混数字页是「数字 → 情形」的查表（记分分值
   五档、期限、罚款区间）；本页是「情形 → 容易混的对子」，只收那里没有、或需要并排比
   才记得住的内容：罚款档位与对应事由（20–200 / 200–500 / 500 以下 / 1000 以下 /
   2000 以下）、满分学习与学法减分的细则、准驾车型与增驾、禁考年限、登记与号牌细节。
   刑罚档位已在易混数字页（0074），本页不收。
4. **组级「练这组」沿用 0064 的正则 `match`。** 抓取面在测试里校验：每组至少抓到 30 道
   题，合起来覆盖记分、证照、登记三个知识点题的八成以上（实测约 84%）。
5. **内容是静态的，不随个人记录变。** 页面不读作答记录；「按错得最多的点整理」是写内容
   时的选条目依据（这一轮的选择依据是 2026-10-04 的记录）。要随记录更新，下次再按同样
   办法整理一遍，不在页面里做动态个性化（那会让页面的内容不可核对）。

## 后果

- 使用者错得最多的那批记分与证照点，有了一页并排对照，每组能直接练相关题。
- 相邻两档、相近规定放在一起：例如闯红灯 6、准驾车型不符 9、酒驾 12；号牌伪造 12、
  遮挡 9、安装不规范 3；不按规定使用灯光 1，故障停车不设警告标志 3。
- 条文改了要和题一起改：这页的数字都有出处，改规定时同步更新。
