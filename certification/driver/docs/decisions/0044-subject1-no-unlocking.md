# ADR 0044：科目一不设解锁，四个阶段和模拟考全部开放

- 日期：2026-09-29
- 状态：已接受
- 影响：`lib/home.dart`、`lib/models.dart`、`content/curriculum.json`、`AGENTS.md`
- 关系：撤销本应用 ADR 0006 第 2、3 条（阶段逐级解锁、科目一模拟考要等四阶段过关）；
  ADR 0006 第 1 条（按内容分四阶段）和第 4 条（科目一全部掌握才开科目四）不变

## 背景

ADR 0006 让科目一按阶段逐级解锁：当前阶段日常题全部掌握，才开放下一阶段的练习；
四个阶段都掌握，才开放科目一模拟考。

实际用下来，这套锁只剩副作用：

- 题库在持续修正和补题。往已经过关的阶段里补一道新题，或者某道题答错一次，
  前面的阶段就不再算「全部掌握」，后面已经练过的阶段整片被锁回去。
- 模拟考本来就是检验手段，想什么时候测一次水平都该能测；非要四阶段全过才能考，
  等于先练完才准知道自己差在哪。
- 使用者要求科目一不再有解锁的概念。

## 决策

1. **四个阶段只是按内容分的四组题**，全部开放，点哪组练哪组；阶段行只显示掌握进度，
   不再有「当前阶段」「未解锁」。
2. **侧栏与概览的练习入口改为「待练 N 题」**，覆盖整个科目一，顺序照 ADR 0031：
   错题、高频、常考、常规。
3. **科目一模拟考随时可以开**，从科目一全部题目组卷（偏难怪按 ADR 0032 封顶）。
4. **科目四仍要等科目一日常题全部掌握**（ADR 0006 第 4 条），这是科目四的入口条件，
   不是科目一内部的解锁。
5. 删除 `unlockedThrough` 与 `QuestionBank.unlocked`，不留无人调用的解锁逻辑。

## 后果

- 补题、改题不会再把已经练过的阶段锁回去。
- 侧栏徽章从「第 N 阶段」改为「已掌握 m/n」，进度由作答记录派生（主仓库 ADR 0052）。
- 「易混数字」页每组的相关题不再区分是否已解锁，全部可练。
