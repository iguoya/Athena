# ADR 0112：专题掌握只由专题自测写入——判卡、判条目、判组、判专题都不看关联真题；速记页的题不分偏难；组标题加状态圆

状态：已接受

## 背景

ADR 0094 决策 4 让自测判卡在「这张卡自己没有记录」时回退看**关联真题**的作答（答错的
`wrong`、全掌握的 `done`、只做一部分 `partial`）；ADR 0109 修订后的「练这组」按钮也是
相关真题与自测卡**一起**看（`groupStatus`）；标志、标线、仪表、手势各格子的微点
（`statusOf`）干脆只看关联真题。结果是日常练习把专题的掌握「灌满」：真题练熟了，自测就
不再考那些卡，条目圆点也是绿的——专题强化形同虚设。使用者指出：**判别是否掌握不应该跟
练习题关联**，专题的价值就是「在专题里测过才算会」；顺带的两条：速记页里不要再有偏难的
概念（标志、标线页把偏难题排除在「练这组」外，还写「还有 N 道相关题在偏难里」，一视同仁
即可）；考点速记这类页的每个子标题左侧也该有圆环标记，跟易混数字行点的观感统一。

## 决定

1. **掌握只由专题自测写入**：判一张卡（`classifyEntry`）、一个条目（格子/行微点）、一组、
   一个专题，都只看速记题（`drive.recall.*`）**自己的**作答记录；关联真题的作答不参与任何
   掌握判定，真题只是自测收尾「去做这几个的题」和「练这组」的练习入口。`classifyEntry`
   删掉真题回退：没答过就是 `fresh`，不再有「真题全掌握所以不再出卡」——没测过的卡照样考。
   `RecallBucket` 与 `SymbolStatus` 收敛为三态（`wrong / fresh|mastered / done|fresh`），
   `partial`（只来自真题）随之删除。
2. **全站一个判档函数**：`statusOfIds(ids:)` 取代 `statusOf` 与 `groupStatus`——有答错过
   且还在错题库里（累计答对没到答错的 2 倍，ADR 0079）→ 红；答对过 → 绿；一张没答过 → 灰。
   侧栏专题圆（`_topicStatus`）、组标题圆、格子/行微点、「练这组」按钮全部用它；「未掌握」
   的判据统一为 `retiredFromWrongPool`（与自测抽卡同一把尺子），不再借练习口径的 mastered 集合。
   「练这组」的文案跟自测状态走：绿才写「这组已掌握 · 再练一遍」；按钮上「练 N 题」的 N
   仍是这组真题里还没练熟的道数（那是练习的账，不是掌握的账），为 0 时不带数字。
3. **速记页的题不分偏难**：标志、标线、仪表、手势、考点各页的相关题从本科目**全部**题里取
   （不再先过 `dailyQuestions` 滤掉偏难），「还有 N 道相关题在偏难里，不挡过关」的提示删除。
   偏难只在日常题的出题权重与模拟考封顶里存在（ADR 0032），在速记页没有概念。
4. **组标题左侧加状态圆**：全部速记页（易混数字、标志、标线、仪表、手势、考点、河南、
   记分证照、事故、停车等）每个子标题左侧放一枚 `TopicDot`（size 20，实心圆加黑心，与
   易混数字行点同一套样式），口径同组状态。侧栏专题与分组的圆（ADR 0109）不变。

## 后果

- 自测抽卡只看自己的记录：没考过的永远会出，练习再熟也替不了自测；「收尾没有要考的了」
  只在整页都答对过时出现，旧文案「没考过的卡，因为关联的真题都已掌握，不再自动出」连同
  不可达的 `_drawable` 一起删除。
- 侧栏专题圆的绿从「答对过任一张」收紧为与全站一致（有作答且无未移出的错）——语义不变，
  判据与抽卡对齐。
- 各速记页的 `daily` 参数改名为 `questions`（全部题）；「练这组」的真题池变大（含偏难）。
- `test/recall_classify_test.dart` 改为断言「真题作答不影响判档」；`test/recall_test.dart`
  收尾文案断言随新文案更新。
