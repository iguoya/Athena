# ADR 0014：把已经记录的成就实际展示出来

- 日期：2026-09-20
- 状态：已接受
- 影响：`lib/session.dart`、`lib/home.dart`
- 关系：落实主仓库 ADR 0052「激励与统计是同一条回路」在本应用里被漏掉的一半

## 背景

`progress.dart` 早就有一整套成就记录：连对 5/10/20 题、章节过关、错题本清空、模拟考
及格/首次及格，都会写进 `achievements`/`notices` 表，`recordAttempt`/`recordExam`
也都把新解锁的 `Notice` 作为返回值传出来。但 `session.dart` 调用这两个方法时直接把
返回值丢了，`progress.dart` 里现成的 `notices()`/`unreadCount()` 在 `home.dart` 里
也没人调用——数据全在，界面上一次都没露出来过。ADR 0052 自己写的「记了不给人看，
等于没记」在这条回路上正好被违反。

## 决策

1. **练习中实时弹提示条**：`_commit()`（练习模式逐题判定）拿到 `recordAttempt` 返回
   的 `Notice` 列表后，用 `SnackBar` 挨个弹出来。
2. **模拟考的提示条挪到结果页**：模拟考中途弹的提示条会被交卷后立刻跳转的结果页盖掉，
   所以 `_submitExam()` 把整卷判分过程中产生的 `Notice` 攒起来，连同 `recordExam` 自己
   产的那条一起传给 `_finish()`，在 `_ResultPane` 里跟着分数一起展示。
3. **首页加一块「最近提醒」**：`_HomePageState._reload()` 拉最近 5 条 `notices()`，
   在科目一、科目四的概览页各展示一块，位置紧跟模拟考战绩图表之后。看到即算已读——
   本机单人使用，没有「谁看过」的问题，进首页刷新一次就调用 `markAllRead()`。
4. **不新增页面、不新增导航项**：现有的「最近提醒」卡片和练习中的提示条已经覆盖
   「记了要给人看」的要求，没有必要为了成就系统单独开一个战绩页——保持界面轻。

## 后果

- 「今日目标」「连续练习天数」这两项 AGENTS.md 提到的激励要素依旧没有实现，
  是本 ADR 未覆盖的后续工作，不在这次范围内。
- `_Result` 新增 `notices` 字段，`_finish` 签名多一个可选参数；练习模式的
  `_finishPractice()` 不传，因为练习模式的提示条已经在逐题作答时实时弹过了，
  结果页不用重复。
