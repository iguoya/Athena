# ADR 0027：练习按全国错误率排序，易错题标出来

- 日期：2026-09-27
- 状态：已接受
- 影响：`content/questions/*.json`（新增 `error_rate`）、`lib/models.dart`、`lib/home.dart`、
  `lib/session.dart`
- 关系：细化练习队列的顺序；ADR 0003 的分档（高频/常考/常规/偏难）不变，模拟考组卷
  （ADR 0023）不变

## 背景

练习队列是「错题 → 高频 → 常考 → 常规」，同一档内按题库文件顺序出。公开题库每道题
都带全国考生的错误率（科目一收录的 1173 道，中位数 10.3%，最高一成在 34% 以上）。
考场丢分主要丢在大家都容易错的题上，同一档里先练这些，时间花得最值。

## 决策

1. 从公开题库导入的题带 `error_rate`（百分数），取自原题的 `errorRate`。自己按条文写的题
   没有这项数据，不填。
2. **练习队列在同一档内按错误率从高到低排**；没有错误率的题按本科目的中位数排，不把
   按条文写的核心题压到最后。档的先后（错题、高频、常考、常规）不变。
3. **练习时错误率 20% 及以上的题标「易错 xx%」**（约占最难的四分之一），低的不标，免得
   题面上全是数字。模拟考不标——考场上没有这个提示。
4. **错误率不进模拟考**：模拟考仍按分档权重随机抽，保持跟考场一样的难度分布。
5. 错误率不参与掌握度，只影响练习的先后和题面提示。

## 后果

- 同一档里先遇到难题，前几轮正确率会比以前低，这是有意的。
- 以后收录公开题库的题要连同 `error_rate` 一起写入。
