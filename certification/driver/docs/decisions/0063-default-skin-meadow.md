# ADR 0063：默认皮肤改为青野（绿）

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/skin.dart`（`Skins.fallback` 指向 meadow）
- 关系：修订 0058 决策 1 中「晴空（蓝，默认）」的默认指定；四套明色皮肤、
  机器级持久化等其余内容原样

## 背景

0058 落地时默认指定了晴空（蓝），理由是「继承旧观感」——迁移日当天界面不变。
皮肤系统用下来，使用者的口味落在了绿：青野的「平和护眼」比晴空的蓝白更耐看，
默认值应该跟着落定后的口味走，而不是跟着迁移日的历史走。

## 决策

1. **默认皮肤改为青野。** `Skins.fallback` 从「清单第一套」改为显式指向
   `meadow`；皮肤清单顺序不变（晴空仍在首位，它的「继承旧观感」说明保留）。
2. **机器级偏好的语义不变。** `skin.json` 存在且有效时永远赢过默认值；
   已在侧栏选过皮肤的其他机器不受影响。本机由使用者在侧栏切换（或首次写入）
   后生效。

## 后果

- 新机器、清掉偏好后的界面默认绿意；四套皮肤与切换器照旧。
- 0058 决策 1 的「晴空（蓝，默认）」从此按本 ADR 读作「晴空（蓝）」；
  默认值的变更只落在 `fallback` 一处，diff 一行。
