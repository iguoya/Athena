# ADR 0050：侧栏按科目分目录，章节挂在所属科目底下

- 日期：2026-09-30
- 状态：已接受
- 影响：`lib/home.dart`（`_sidebar`、`_subjectBranch`、`_navLine`）、`lib/glyphs.dart`
  （`Glyph.expand` / `Glyph.collapse`）
- 关系：修订 ADR 0004「侧栏上的去处」的排列方式；不改任何入口、练习和解锁规则

## 背景

侧栏原来是一列平铺：科目一、科目二、科目四、错题本、考前复习、易混数字、跨机器同步，
选中某个科目后，它的模拟考试、待练和各章节才出现在整列最底下的分隔线之后。章节离它所属的
科目隔着四个工具入口，看不出是谁的子项；换科目时底下那一截整块换掉，位置也不稳。

## 决策

1. **科目一、科目二、科目四是三个一级目录。** 每个科目展开后，模拟考试（有笔试的科目）、
   待练 N 题、各章节缩进挂在该科目下面，内容与原来底部那一截相同。
2. **展开由使用者控制**：默认展开科目一；点科目名进入概览并顺手展开，点右侧箭头只展开 /
   收起、不换页。几个科目可以同时展开。
3. **锁着的科目没有子项、没有箭头**，点进去仍只说明原因（ADR 0006、0047）。
4. 错题本、考前复习、易混数字、跨机器同步跨科目，放在科目目录之下的分隔线后，条目不变。
5. 子项的选中态按当前练习或模拟考所属的科目判定，不同科目的同名章节不会一起亮。

## 后果

- 章节一眼看得出属于哪个科目；切换科目不再让底部整块跳动。
- 三个科目都展开时侧栏较长，靠 `ListView` 滚动，不为此压缩字号（界面基准 20pt）。
