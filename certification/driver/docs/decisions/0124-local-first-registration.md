# ADR 0124：新学习者默认只存本机——填了外网访问凭据才碰中心目录

- 日期：2026-10-09
- 状态：已接受
- 影响：`lib/app/user_gate_screen.dart`（`_enter`、`_create`、新增 `configLoader` 参数）、`lib/main.dart`
- 关系：修订 0078「输入没人用过的名字自动注册到服务器」；收紧 0123（本地新建从「目录连不上时的出路」升级为默认路径）；编号段与「本地学习者不参与同步」沿用 0123

## 背景

0123 让本地学习者成为「目录连不上时的出路」，但默认路径仍是 ADR 0078 的「输入没人用过的
名字 → 自动注册到中心目录」——一台没打算联网同步的机器上，随手输入的名字就悄悄关联了
远程数据库。使用者决定把默认反过来：**单机是默认形态，远程是明确选择**。

## 决定

1. **「进入」遇到本机缓存里没有的名字，默认在本地新建**（1000 段编号，0123）：只存这台
   电脑、永不参与同步。不再自动注册到服务器（取代 0078 的自动注册）。
2. **碰中心目录的开关是「外网访问凭据配齐」**（`ApiConfig.wanUsableBase` 非空，即同步设置
   里明确填写了 Cloudflare 服务令牌一对）：登录页才会去问目录——找到就登录（异地登录的
   场景），重名再问编号，目录里也没有才落到本地新建。没配凭据时登录页完全不发请求。
3. **建到服务器是显式动作**：配了凭据时，「我是另一个同名的人，新建」走中心目录注册
   （跨机器可同步）；没配凭据时它建到本地（先确认同名）。
4. **目录不可达的出路保留**（0123）：配了凭据但连不上时，报错并给出「在这台电脑上新建
   （不同步）」——这时建本地学习者是知情选择，因为使用者本来以为会同步。
5. 编号段、本地学习者不启动同步引擎、改名只写本机、临时断网照常补发——全部沿用 0123。

## 验收

- `test/user_gate_test.dart`：无凭据时输入新名字点「进入」得到本地学习者（编号 1000 起），
  目录零调用；配了凭据时目录里有的人照常登录、没有的人才本地新建；显式新建按凭据开关
  分别落到服务器/本地；目录不可达的出路按钮只在配了凭据且连不上时出现。
- 应用 `AGENTS.md` 的「多用户」段同步更新。
