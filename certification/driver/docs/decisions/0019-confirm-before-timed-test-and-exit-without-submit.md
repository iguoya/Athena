# ADR 0019：开考前先确认一次，考试中途能退出不用交卷

- 日期：2026-09-20
- 状态：已接受
- 影响：`lib/home.dart`、`lib/session.dart`
- 关系：给 ADR 0016（模拟考草稿续答）、ADR 0018（章节测试）补一道安全网

## 背景

模拟考、阶段测试、章节测试三个入口原来都是点了就立刻抽题、立刻开始计时，
没有任何确认步骤；进去之后也没有退出按钮——`onClose` 只挂在结果页的
「回到章节」上，交卷前唯一能做的事就是把整卷答完或者强行关应用。手滑点错、
或者只是想看看这一章考多少分钟，都会被迫开始一场真正计时的测试。

## 决策

1. **开考前弹一次确认**：`_startExam`/`_startPhaseTest`/`_startTopicTest` 在真正
   `Paper.draw()` 抽题之前，都先弹「「XXX」限时 N 分钟，交卷才判分，确定现在
   开始吗？」，点「再看看」就什么都不发生。**续答草稿不用再问**——「继续上次
   /放弃重新开始」那个弹窗本身就是一次确认，不叠加第二层。
2. **做题台顶栏加一个退出按钮**（`_confirmExit`）：
   - **练习模式直接退，不用问**——练习本来就逐题落盘（ADR 0007），退出不丢
     任何东西。
   - **模拟考/阶段测试/章节测试退出前弹一句提示**：说清楚「退出不交卷、不
     判分，答案存草稿，下次能续上」——不能让人以为点退出等于交了卷。

## 后果

- 章节测试、阶段测试、模拟考现在都是「二次确认才真正开始，随时能退出」，
  跟交卷前「可以反悔」的模拟考规则（ADR 0007 考场规则那一条）在体验上对齐。
- 退出不提交这件事，跟 ADR 0016 的草稿机制天然衔接：退出时草稿已经存在（边
  答边存），不需要额外处理；唯一要注意的是退出**不清草稿**，跟交卷成功才清
  草稿的逻辑分开。
