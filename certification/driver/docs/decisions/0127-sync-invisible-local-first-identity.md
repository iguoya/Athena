# ADR 0127：同步不进界面——学习者先在本机创建，检测到路由器后台自己绑定并同步

- 日期：2026-10-13
- 状态：已接受（使用者 2026-10-13：「默认优先本地创建用户、本地存储，只有检测到 6.1 环境才今后后台同步；同步的概念软件界面全程不体现，弱同步功能」）
- 影响：`lib/main.dart`（启动门）、`lib/home.dart`（侧栏）、`lib/app/user_gate_screen.dart`、`lib/core/{binding,sync,user_directory,users}.dart`；删除 `lib/app/api_config_screen.dart`
- 关系：**取代 0123、0124**（本地学习者「永不同步」、碰中心目录要显式配外网凭据）；**修订 0070 决策 4**（待同步状态界面可见）与决策 8（配置屏）；0074、0075 的「新建/异地登录要联网、登录页问目录」不再由界面承担；延续 0070 的本地优先、主仓库 ADR 0155（学习进度本机优先、同步对使用者透明）与 0077（不设令牌）

## 背景

0123、0124 把学习者分成「中心学习者」（1～999，会同步）与「本地学习者」（1000 起，永不同步，两类互不迁移），
并让同步成为需要显式配置的功能：登录页有「同步设置」入口，侧栏常驻「待同步 N 条 / 已同步 / 本地模式」，
新建学习者后弹提示条解释「不会同步到其他设备」。

这把一个本该是**基础设施**的东西变成了使用者要理解和操作的**概念**。使用者的取向相反（主仓库 ADR 0155）：
单机永远可用，路由器在身边时同步在后台悄悄发生，不需要被感知，也不需要被管理。

## 决定

1. **学习者一律先在本机创建。** 登录页只有名字：本机缓存唯一命中就进；没有就在本机新建（本机段编号，
   1000 起，`UserRegistry.nextLocalId`）。登录页不碰网络，不出现「同步」「服务器」「设置」「联网」这类字样，
   新建后也不弹解释性提示。「我是另一个同名的人，新建」保留（本机已有同名先确认，靠编号区分）。
2. **中心身份由后台静默绑定。** 本机学习者在 `users.json` 条目里多一个 `server_id`（中心目录里的编号）。
   `LearnerBinder`（`lib/core/binding.dart`）在应用运行时检测路由器：按名字问目录，**唯一同名者就认领**
   （同一个人换了台电脑），**没有就登记**，**不止一个就不动**（无界面时无法判断是谁，宁可保持仅本机，
   也不把记录写到别人名下）。失败、超时、被拒都不抛、不提示，每 10 分钟再试。本机编号不变，所以本地库
   文件名、照片清单、记录归属都不动；中心段编号（1～999）的既有学习者本来就是自己的中心编号。
3. **同步只在检测到路由器之后发生。** 引擎的请求头 `X-Athena-User` 用的是中心编号。没有绑定、
   没检测到路由器时什么都不发；检测到之前，探测过一次失败的内网在 `lanProbeInterval`（10 分钟）内不再重复
   探测，每次写入不再白等一轮超时。数据照常落本地库与待发队列，路由器出现后自然补发。
4. **界面里没有同步。** 删掉侧栏的同步行（「待同步 N 条」「已同步」「本地模式」「N 条记录无法同步」）、
   登录页的「同步设置」入口与整个配置屏（`api_config_screen.dart`）。`SyncEngine.status` 只留给首页
   在后台拉回新数据后重读本地库用，不渲染。外网访问凭据仍可由 `api.json` / 环境变量
   `ATHENA_DRIVER_API` 提供（离开内网才用得上，没有就不参与外网），但不再有配置界面。
5. **改名只写本机缓存。** 名字是称呼；已绑定的中心编号不受改名影响。中心目录里的名字不随本机改名更新
   （按名字认领只发生在首次绑定时）。
6. 出站的数据面（`/api/driver/v1`）、合并规则、幂等与游标、拉取并行等同步引擎行为不变。

## 后果

- 一台机器离开路由器环境使用，与有路由器的机器在使用上没有区别；同步失败永远不会被使用者看见，
  代价是**同步长期失效也无人知晓**。要排查只能看日志或由开发者读本机状态，这是本决定接受的取舍（主仓库
  ADR 0155 同）。
- 中心目录出现同名重名时（目录里不止一个同名者），该学习者在这台机器上一直只存本机，直到有人在
  目录里把同名者处理掉；没有界面可提示。单人使用时极少发生。
- 本地学习者与中心学习者不再是两类：「中心学习者 1～999」只是历史上就在中心登记过的人，
  新人一律先 1000 起、联网后各自绑定一个中心编号；`UserProfile.isLocal` 仅表示「本机段编号」。
- 测试：`test/user_gate_test.dart` 改为本机创建与「页面里没有同步概念」；新增 `test/binding_test.dart`
  （认领、登记、重名不动、不在家不抛、重启后绑定还在）与 `test/sync_test.dart` 的探测间隔用例。
