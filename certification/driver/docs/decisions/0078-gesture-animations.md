# ADR 0078：交警手势做成动画——正面加俯视，答完手势题右栏也放

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/gesture_animation.dart`（新：关键姿势、插值、正面与俯视两个绘制器、交互控件）、
  `lib/gesture_index.dart`（新：手势题到动作的反向索引）、`lib/gestures_page.dart`
  （格子与浮层改用动画）、`lib/session.dart`（答完手势题右栏放动画）、`lib/content.dart`
  （加载时填索引）、`test/gesture_animation_test.dart`、`test/gesture_in_session_test.dart`（新）
- 关系：修订 0073 决策 2 的「简化人形静态图」（人形与法定动作不变，改成会动的）；
  挂题的反向映射仍是 0073 决策 3；出处仍是 0073 决策 4

## 背景

0073 的手势图是静态的：一个姿势，手臂画成直线。使用者的反馈是两条：静态图看不清，
而且「太难猜测交警手势动作的完整流程」。这是对的——手势是**一段动作**，不是一个姿势：
先摆到哪里、再怎么摆、摆的是哪只手，静态图画不出来。题库里的手势题图也一样，每张只是同一
动作的两个姿势，前伸的手臂冲着观看者，又被躯干挡住，更看不出方向。

## 决策

1. **每个法定动作写成一串关键姿势，播放时在姿势之间插值。** 8 个动作各一段，首尾回到
   自然下垂，循环没有跳变。手臂用「方位角 + 仰角」描述，上臂与前臂各一个方向，所以能画出
   弯着的手臂；手掌有朝向（向前、向下、向左、向右），按朝向画成圆片或窄椭圆。
2. **两个视角并排：正面（交警面向你）与俯视。** 正面看左右与高低，俯视看前后——「前平伸」
   「向右前方」这类方向只有俯视才一眼看清。动作覆盖的范围用淡色「残影」画出来，手点颜色
   表示高度（红 = 举过肩，灰 = 垂在腰下）。
3. **姿势用题库里的手势题图逐个核对过。** 8 个动作各取题图（科目一、科目四共 20 余张）
   对照。核对出一条原先没画对的事：**摆动的那条手臂在第二个姿势里是弯的**——上臂仍在身侧，
   前臂横过身前（直行、左转弯、右转弯、变道、靠边停车都是这样；待转是从侧平伸摆到身前）。
   最初的版本把摆动臂画成伸直扫过，据此改正。
4. **三处用上动画。** 手势速记页的格子循环播放；点开的浮层带控件：播放 / 暂停、上一个 /
   下一个姿势、进度条，以及分步要领文字（当前步高亮）；做题台里答完手势题，右栏在解析下面放上
   这个动作的完整动画——答完才出现，因为动作名会泄露答案。手势效力总则（无动画）不放。
5. **要领文字按动作要领的要点与题图写成，不照抄规范原文。** 本环境读不到规范原文，
   所以逐条写的是动作做法（哪只臂、朝哪、掌心向哪），数字只有「与身体成 135° 角」一处，
   由测试守住。后续拿到规范原文，改 `gestureClips` 的 `captions` 与姿势即可。
6. **测试把要领翻成断言：** 每个法定动作都有动画、首尾姿势相同、每步要领有姿势对应、
   逐帧角度变化不超过 12°（没有瞬移）、停止信号的手臂与身体的夹角恰为 135°、
   左转弯与右转弯镜像对称、各动作的左右与掌心朝向。

## 不做的

- **不是真人视频。** 是简化人形，没有画手指、面部朝向与目光（规范里「面部及目光视左方」
  这类细节没有表现）。认手势以现场指挥为准。
- **不做手势效力总则的动画。** 它是一条规则，不是一个动作。

## 后果

- 手势从「做错题才见到两个姿势」变成可以看完整动作、可以暂停和一步步跳的内容；
  做错手势题时，解析下面直接有这个动作的动画。
- 动画由代码里的关键姿势表驱动，不进 `gestures.json`；加动作时 `gestureClips` 与
  `gestures.json` 同步改，测试挡住漏掉。
- 格子里的小图一直在播，页面上会有 8 个并行的循环动画；开销可忽略（只画几十个图元），
  暂时不加「减弱动效」开关。
