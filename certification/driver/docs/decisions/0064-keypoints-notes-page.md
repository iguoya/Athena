# ADR 0064：考点速记页——灯光、让行、高速、恶劣天气、应急与急救的文字对照

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/notes.json`（新）、`lib/models.dart`（`NoteGroup`/`NoteItem`）、
  `lib/content.dart`（解析）、`lib/notes_page.dart`（新）、`lib/home.dart`
  （侧栏钉住区、页面分发）、`lib/glyphs.dart`（`Glyph.notes`）、
  `test/notes_page_test.dart`（新）
- 关系：沿用 0028（易混数字）的速记页先例与结构，0059（标志速记）的页面语言；
  落实仓库级 ADR 0056（可视化与交互是内容本身）；出处硬标准仍是 0003/0008

## 背景

易混数字与标志速记之后，题库里最大的主题仍然没有速记化的载体：灯光（约 470 题）、
高速公路行为（约 450 题）、恶劣天气（约 360 题）、让行（约 250 题）、爆胎与
避险（约 190 题）、伤员急救（约 50 题）。它们都是「情景 → 要点/第一动作」的
文字对照——与易混数字的「数字并排比大小」不同构，与标志速记的「图形网格」
也不同构，塞进任何一页都会名不副实。

## 决策

1. **新建「考点速记」页与 `content/notes.json`。** 六个分组：灯光使用、让行
   规则、高速公路、恶劣天气、应急避险、伤员急救；每条是一个情景（如「夜间
   会车」）加一到三条要点（「150 米以外改用近光灯」），组级 `match` 正则把
   相关题接成「练这组」。条目是速记不是教科书——每组 7～9 条，只装最常考、
   最易混的那一句。
2. **条目行级挂出处。** 条文类挂《道路交通安全法》《实施条例》的具体条号
   （这些题库里的 `source_refs` 已核对过，速记条目从题面解释反推条文，不引入
   题库没有的新依据）；急救与避险的处置要点挂 2022 版考试大纲的对应要点章节，
   具体数字（心肺复苏 100–120 次/分）以题库答案为准。
3. **页面语言与易混数字一致。** 页头 + 每组一张 `BsCard`（组名、一句口诀、
   条目列表、组级「练这组 N 题」），出处以小字随条目显示；无横条比大小——
   那是数字组的表达。
4. **不做图。** 交警手势（19 题）绘制成本高收益小，仪表灯（几十种图标）成本
   远超易混收益，本页纯文字；标线另立（GB 5768.3 已在 catalog，与标志成对，
   值得单独一轮）。

## 后果

- 数字（易混）、图形（标志）、情景（本页）三类速记齐了：科目一与科目四的
  高频主题都有「先速记、再练题」的闭环。
- notes.json 是唯一内容源；要点与题库解释冲突时以题库为准改速记。
- 侧栏钉住区增至六行（错题本、考前复习、强化练习、易混数字、标志速记、
  考点速记），接近上限——再加速记类内容应进本页新分组，不再开新页。
