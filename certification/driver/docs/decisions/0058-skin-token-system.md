# ADR 0058：皮肤令牌系统——一套组件换氛围，只做明色

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/skin.dart`（新）、`lib/look.dart`（`Bs` 由常量类改令牌门面，新增卡片/
  玻璃/环境背景/入场动效零件）、`lib/main.dart`（主题接线）、`lib/home.dart`
  （侧栏切换器、概览卡片）、`lib/session.dart`（选项颜色过渡）；`Bs.*` 的全部引用点
- 关系：落实仓库级 ADR 0056（可视化与交互是内容本身）、0058（内容驱动 UI——皮肤
  只进零件库，不按页手写）、0052（激励只展示由记录派生的量）；不修订任何条款

## 背景

界面一直是 Bootstrap 5 的网页表单观感：4px 直角、1px 描边、实色卡片，没有层次、
没有材质、没有动效。使用者希望界面往「拾阶」的层次感走，并能像拾阶（ascent）与
math-tools 那样切换几套皮肤（一套组件、令牌换氛围）。

## 决策

1. **皮肤令牌系统，与 ascent / math-tools 的 skins 同构。** 语义色全局共享
   （对错绿红、警示黄、题型与频次色——这些含义人人认得，不随皮肤变）；氛围色归
   皮肤：主行动色、侧栏、页面底、卡片底、hairline、环境色斑。首发四套明色皮肤：
   晴空（蓝，默认，继承旧观感）、青野（绿）、曙途（橙）、暮汐（紫）。
2. **只做明色，不做暗色模式。** 四套皮肤都是明色。省下的是长期税：每个新界面都要
   双模式验证；语义色与皮肤色分离后，将来真要暗色，改的也只是令牌层。
3. **`Bs` 保留为令牌门面。** 色值成员由 `static const` 改 getter，指向当前皮肤；
   语义色仍为常量。全库引用点（150+ 处）不动名字、不改语义，diff 集中在令牌层。
   皮肤切换经 `ValueNotifier` 重建 `MaterialApp`，整树一帧内换装。
4. **环境背景自绘，不引窗口材质。** 不用 flutter_acrylic、不自绘标题栏：原生插件
   跟版、平台分支与自绘标题栏细节是长期税。环境背景用 Flutter 画静态柔和色斑
   （`CustomPainter` + `RepaintBoundary`，每帧零成本），垫在 `MaterialApp.builder`
   里全局生效，侧栏半透明透出。
5. **圆角与阴影分级。** 控件 10、卡片 16、徽章胶囊；卡片用双层软阴影替代 1px
   描边的「表格感」（`BsCard` 零件，首页概览先行收编，其余页后续顺手换）。
6. **动效收窄为两处固定投入。** 概览卡片入场 stagger（45ms/张）与答题选项颜色
   过渡（200ms）；时长令牌化（`Bs.durFast`/`durIn`），新代码用现成零件，不自己调参。
   做题是高频操作，反馈动效不许挡节奏。
7. **皮肤选择持久化到机器级 `skin.json`**（用户数据目录，模式同 `api.json`），
   不按学习者分——一台机器一个口味，跟着学习者走没有场景。

## 后果

- 切皮肤整树重建（`MaterialApp` 换 theme），切换瞬间完成，无中间态。
- 原 `const` 表达式里引用色值的位置（约 20 处）去 `const`，编译器逐个点出，已改。
- `Bs` 名字继续指 Bootstrap 色板的来源，但语义已是「语义色 + 当前皮肤氛围令牌」；
   改名是零行为变化的大 diff，不做。
- 环境色斑与卡片阴影在核显上的开销可忽略（静态 + RepaintBoundary）；若日后加
  大面积模糊，只允许给小面积浮层用（`GlassPanel`），不给整窗。
