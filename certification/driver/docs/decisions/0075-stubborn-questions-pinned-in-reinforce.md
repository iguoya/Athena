# ADR 0075：累计答错 3 次以上的题常驻强化练习

- 日期：2026-10-04
- 状态：已被 [0079](0079-reinforce-retire-by-correct-ratio.md) 取代（改为按「对的是错的 2 倍」动态移出）
- 影响：`lib/reinforce.dart`（`QuestionHistory.stubbornWrong`、`retiredFromWrongPool`、
  `StubbornQuestion.pinned`）、`lib/reinforce_page.dart`（反复错题区文案）、
  `test/stubborn_pinned_test.dart`（新）
- 关系：修订主仓库 ADR 0086 的验收规则（只对错 3 次以上的题加一条例外，其余原样）；
  承接本应用 ADR 0069（反复错题清单）；清单与备选库都是作答记录的派生量，遵守主仓库
  ADR 0052，不新建表

## 背景

使用者的作答记录里，累计答错 3 次以上的题有 113 道，全部已经「验收通过」移出了强化练习
的备选库（0086：自最近一次答错以来，在强化练习里测过且之后没有出错）。也就是说，错得最
多的这批题，反而一道也不会再被抽到。使用者要求：错过 3 次以上的题（含 3 次），全部放进
强化练习里。

## 决策

1. **累计答错 3 次（含）以上的题是「顽固题」，不再被验收移出备选库。** 做法是
   `QuestionHistory.retiredFromWrongPool` 加一个条件 `wrong < stubbornWrong`
   （`stubbornWrong = 3`）；其余的移出规则（强化练习里测过且没出错，或同簇变式答对）
   对错 1、2 次的题不变。
2. **不另做一个「顽固题专区」。** 它们回到原来的备选库，照常按权重参与抽取
   （`wrongWeight` 本来就是错得越多越重），每轮的变式、覆盖保证、补足顺序都不变。
   备选库因此变大，每轮仍抽 `count` 道，不是把顽固题一次摆出来。
3. **门槛 3 是经验值**：错 2 次可能是手滑，错到 3 次说明一次验收说明不了记牢了。没有数据
   支撑，要改只改 `stubbornWrong` 一处。
4. **反复错题区的文案**：错 3 次以上的行标「常驻强化练习」，不再标「已修补，移出错题库」；
   区头说明里讲清这条规则。清单的收录门槛（2 次）不变，`StubbornQuestion.pinned`
   是新增的派生标记。

## 后果

- 使用者那 113 道题全部回到备选库；之后新错到 3 次的题也一样。
- 题再怎么答对都不会因验收离开，除非将来调高门槛。备选库不会只出不进地缩小，
  「还要练的错题」数字块会比以前大；这是预期的，不是故障。
- 「已修补」在清单里只剩错 2 次的题。
- 到期复习仍按间隔管它们（`dueRatio`），与本条无关。
