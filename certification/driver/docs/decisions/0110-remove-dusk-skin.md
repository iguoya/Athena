# ADR 0110：去掉深紫皮肤「暮汐」

状态：已接受

## 背景

四套皮肤里的「暮汐」是深紫的深色皮肤（ADR 0081 起，夜学用）。使用者反馈：太黑，文字看不清，失去实用价值。

## 决定

1. 删除 `暮汐`（id `violet`）：皮肤只剩晴空、青野（默认）、曙途三套，全部明色、各带色温。
2. 本机 `skin.json` 里存着 `violet` 的，读取时因 id 不在清单里自动回到默认皮肤青野，不需要迁移。
3. 注释里「暮汐深色下……」的说明一并删掉；`isDark` 无人使用，随之删除；明暗相关的取色（`Bs.onColor`、
   `onPrimary`、玻璃底取 `surfaceContainerLow`）保持按皮肤取值、不写死，将来再加深色皮肤也不用改页面。
4. `test/semantic_test.dart` 的「只有暮汐是深色」改成「全部皮肤都是明色、页面底够亮、正文对比度不低于 7」，
   并断言清单里没有 `violet`，防止深色皮肤悄悄回来。

## 后果

- 修订 ADR 0081 中「四套里有一套深色」的部分；已有的明色皮肤约束与对比度测试不变。
