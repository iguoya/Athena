# ADR 0069：强化练习——轮量可调与反复错题清单

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/reinforce.dart`（`StubbornQuestion`、`stubbornQuestions`）、
  `lib/reinforce_page.dart`（轮量选择、反复错题区）、`lib/home.dart`（轮量状态、
  重建计划）、`test/reinforce_test.dart`、`test/reinforce_page_test.dart`
- 关系：落实主仓库 ADR 0087 决策 1「`count` 仍是参数，可调」的界面面；
  顽固题的验收语义仍是主仓库 ADR 0086；清单是统计派生展示，遵守 0052
  （激励与统计同一条回路）；题库核对机制仍是 0003/0008

## 背景

使用者用强化练习后提了三点：一轮 50 题不该是必须的（状态差的时候想少练点）；
反复打错、后来又修补好的题应该能列出来看；有的题反复答错，怀疑是题目或答案
本身有问题，要有地方核对。`planReinforcement` 的 `count` 本来就是参数
（0087 决策 1），只是界面没暴露；「反复错又修补」的数据在 `HistorySet` 里
（每题的累计错次与最近连对），只是没有展示位。

## 决策

1. **「每轮抽取」数字块可点，弹出轮量选择（25 / 50 / 75 / 100）。** 选中即重抽
   一轮，四个数字块与其余统计跟着刷新。选择只在本会话内生效，重启回默认
   50——0087 定的默认值不变，这里只是把「count 是参数」落到界面上；轮量跟着
   当天的状态走，不做成持久化配置。备选库不足一轮时的补足行为不变（0087
   决策 3）。
2. **页面加「反复错题」区，收累计答错 2 次及以上的题，分「还在错」与
   「已修补」两组。** 「还在错」的在备选库里，照常参与抽取；「已修补」的是
   错过多次、最近一次答错之后连着答对、已按 0086 验收移出备选库的题——
   它们不再出现在抽取里，但值得回头扫一眼。只错过一次的题不进这个区，
   走错题本的常规流程。
3. **每行显示稳定编号、题干摘要与累计错次，编号点击复制，配一句核对
   引导。** 反复答错不自动判定题目有错；但清单让人能自己审视「这道题
   为什么总错」，怀疑题目或答案本身有错时，点编号复制、报编号核对——
   题库的核对机制是逐题出处（0003/0008），人工反馈靠编号定位。

## 后果

- 轮量从固定值变成随手可调；说明文字里的「每轮抽多少」与数字块始终一致。
- 已修补的顽固题从「验收后就看不见」变成一页可回顾的清单；题面可疑的题
  有了明确的反馈通路。
- `HistorySet` 的数据不新增、不落库，清单每次进页面从作答历史现算。
