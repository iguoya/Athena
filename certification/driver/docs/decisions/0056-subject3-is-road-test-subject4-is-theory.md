# ADR 0056：叫法统一——科目三 = 路考，科目四 = 安全文明驾驶常识

- 日期：2026-10-01
- 状态：已接受
- 影响：`content/questions/*.json`（题面与解释）、`content/curriculum.json`、`AGENTS.md`、`README.md`、`test/content_test.dart`
- 关系：取代 ADR 0055 第 2 条（术语规则）；修订 ADR 0001 第 1 条的写法（出处不再要求写「科目三安全文明驾驶常识」）

## 背景

公安部令第 162 号把道路驾驶技能（路考）和安全文明驾驶常识合称「科目三」，而考场与学员
口头、本应用侧栏都把常识那一卷叫「科目四」。同一个应用里「科目三」有时指路考，有时指
常识，有时指两者，使用者与代码代理之间屡次因此产生误解；ADR 0055 的补救是「写清楚是
哪一部分」，仍然要读者自己分辨。

## 决策

1. **全应用只用一套叫法：科目三 = 路考（道路驾驶技能），科目四 = 安全文明驾驶常识。**
   界面、题面、选项、解释、课表、文档都按这个写；不写「科目三安全文明驾驶常识」，
   不用「科二」「科三」这类缩写。
2. **规章原文照原样保留**：`source_refs` 的 `note`、条文引用里的「科目三」不改，那是
   引用。需要对照时，在解释里用一句话说明（如「规章原文把它写作科目三名下的安全文明
   驾驶常识考试」），而不是改引文。
3. **只有一道题专讲这个对应关系**（`drive.s1.license.054`：「按规章原文，道路驾驶技能
   考试和安全文明驾驶常识考试合称科目三」），其余题面不再出现合称。
4. 改写只换叫法，不改题意：判断题的答案、选择题的选项与答案、出处、题 id 都不动。
5. 课表里科目四的 `official_name` 改为「安全文明驾驶常识考试（规章原文列在「科目三」
   名下）」，界面的「法规名称」一行据此显示，不再直接写「科目三安全文明驾驶常识」。
6. `test/content_test.dart` 守住：科目一、科目四的题面与选项不得出现「科目三…安全文明
   驾驶常识」的合称写法，解释里不得出现「科二」「科三」。

## 后果

- 6 道题的题面和解释、1 处课表名称已改写（`license.046`、`054`、`140`、`166`、`262`，
  `s4.crash.009`）。
- 以后新增题目或文档遇到合称写法，按第 2、3 条处理。
- 历史 ADR（0001 至 0006 等）正文保持原样，不回改。
