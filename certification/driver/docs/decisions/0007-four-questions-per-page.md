# ADR 0007：练习一页四题，答错才朗读，解析按需回看

- 日期：2026-09-16
- 状态：已接受
- 影响：`apps/driver` 的做题区（`lib/session.dart`）
- 关系：修订本应用 ADR 0004 第 4 条的「一题一屏」与 ADR 0005 第 1 条的「判定后自动朗读」；
  其余条款不变

## 背景

做题区原来一屏一题：点选项即判定，看完右侧解释再点「下一题」。一轮八题就要点
七次，节奏被切得很碎；解释每题都自动念一遍，答对时也念，等于逼着人听完才能往
下走。选中的选项只加一层 12% 淡底和 3px 左边条，判断题两个两字选项答完几乎看
不出点的是哪一个。

## 决策

1. **四题一组**。练习和模拟考都按四题分组，一页把四题列完，组内答完才出现
   「下一组」；最后一组是「结束本轮」。组内不自动跳题，也不按秒数跳（沿用
   ADR 0004 的精神，只是把「一题」放大成「一组」）。
2. **只有答错才自动朗读解释**。答对不念——还要听完一段解释反而拖住手上的节奏；
   蓝条上的「系统朗读 / 停止朗读」随时可以手动听。朗读内容与 ADR 0005 第 1 条
   相同（先 `explain`，再条款定位与 `source_refs.note`）。模拟考仍不展示解释，
   也不朗读。
3. **右栏依据跟着最近作答的那道题**，题干右侧的「解析」按钮把右栏调回本组任意
   一题。按钮只在该题答完后出现：答之前点得开，等于把答案摆在题面上。
4. **选中的选项整块上色**。选中项整块实色填白字（未判定棕、答对绿、答错红），
   答错时正确项只用淡绿底补位，比「我的选择」弱一档；未选中项是白底。选项块不描边，
   靠色块本身区分；块宽占栏宽三分之二，跟题干那一段呼应，不再拉满整栏。
5. **键盘落在本组第一道还没答的题上**：A–D / 1–4 / T / F 作答，组内答完后回车或
   空格翻页。

## 后果

- 作答仍是即时入库（一题一条 attempts），掌握度、迟疑判定和激励回路都不变；
  迟疑用时改成从上一题判定的那一刻算起，因为一页里没有「本题出现」这个时刻。
- 模拟考的组与考场的题序无关，只是翻页单位；交卷判分仍按整卷。
- 右栏从「当前题的依据」变成「被点到的那道题的依据」，需要一个显式的焦点状态。
