# ADR 0087：答案选项的点击区域占栏宽九成

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/session.dart`（选项块宽度因子）
- 关系：修订 0012 决策 4 的「选项块宽度占栏宽八成」；使用者拍板

## 背景

0012 把选项块宽度从栏宽三分之二改成八成。使用者反馈点击区域还是偏窄，要求八成改九成。

## 决策

1. **所有题目选项块（含图片选项、标志选项）占题干栏宽的 90%**，左对齐，不拉成整条。
2. 选项间距、内边距、判定后的颜色过渡都不变；整个色块本来就是点击区域（`InkWell` 在色块上），
   变宽即点击区域变宽。

## 后果

- 选项右侧留白从 20% 缩到 10%；窄窗口下长选项文字多折一行的概率略降，不影响
  一页十题的滚动节奏（0022）。
