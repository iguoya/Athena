# ADR 0017：题库按小型汽车（C1/C2）准驾车型精确裁剪，不收其他车型专属内容

- 日期：2026-09-20
- 状态：已接受
- 影响：`content/questions/subject1.json`（共删 28 题：首轮 17 题 + 补充轮 11 题）；
  `content/questions/subject4.json`（审查后不删）
- 关系：修订 ADR 0003「盖住与驾驶人有关的每一条」的范围——不是「法条每一条都收」，
  而是「跟使用者要考的准驾车型有关的每一条」

## 背景

使用者要考的是小型汽车，优先 C2（小型自动挡），最多到 C1（手动挡）。但题库是照着
《道路交通安全法》《实施条例》《驾驶证申领和使用规定》等法规「盖住每一条」的思路
收的（ADR 0003、0008），没有按准驾车型过滤——法规里本来就有大量条款是专门给大型
客车、城市公交车、中型客车、大型货车、牵引车、摩托车这些其他准驾车型的驾驶人看的，
C1/C2 驾驶人考试不会碰到，混在日常练习和模拟考的抽题池里純粹是干扰。

## 决策

1. **只删「明确是其他准驾车型专属」的题，不删「拿其他车型举例的通用安全知识」**。
   判断标准：题目考的是不是「这些车型的驾驶人才需要遵守/办理的事」——申领资格、
   信息变更申报、定期体检、专属限速、专属载人载货规则、专属记分门槛都算专属；
   「怎么应对路上遇到的这些车」（让校车、防追尾大货车、给摩托车让道）算通用安全
   知识，跟开什么车无关，照样保留。
2. **科目一删了 17 题**（都是判断/单选，不影响题型比例）：
   - 大型客车/中型客车/城市公交车/大型货车/重型牵引挂车驾驶人的信息变更申报、
     记分周期报告、两年一次体检要求（这几条法规原文本来就只列这些车型，不含
     小型汽车）；
   - 摩托车专属载人规则、货车与半挂车牵引挂车规则、商用车辆行驶记录仪要求；
   - 大型客车/中型客车驾驶证的申领年龄、准驾车型升级路径；
   - 70 周岁以上驾驶人对三轮汽车/轻便摩托车的准驾限制（跟小型汽车准驾无关）；
   - 校车、公路客运、旅游客运车辆的专属超员记分门槛、校车专属超速记分门槛。
3. **科目一保留的相关题**（判断依据）：
   - 首次申领驾驶证不能直接申领大型货车驾驶证——这是「申领条件」通用体系的一部分，
     不是大型货车驾驶人才需要知道的；
   - 70 周岁以上可以申请的准驾车型里包含小型自动挡汽车——直接关系到 C2；
   - 前车是大型客车挡住视线导致闯红灯——考的是「视线被挡时的责任」，谁开的车不
     影响这条通用交规；
   - 危险驾驶罪里拿校车/客运业务举例的条款——考的是刑法 133 条本身，例子用哪种
     车不改变这题在考「什么构成危险驾驶罪」；
   - 河南地方限速题（三轮车、拖拉机、摩托车限速）——按 ADR 0011 的理由保留，
     是「知道路上这些车能开多快」的通用道路知识，不是「怎么开这些车」。
4. **科目四逐条查过，没删**：涉及大型车/摩托车/校车/牵引的题全是案例分析（大货车/
   大客车事故责任分析）或通用规则（给校车让行、牵引故障车开双闪），科目四本来
   考的就是「安全文明驾驶常识」，不是某个车型的操作技能，这类内容不分车型，
   C1/C2 驾驶人一样要考。

## 补充：轻型牵引挂车准驾车型也不属于 C1/C2（同日发现，一并删）

第一轮排查漏看了一整类——「轻型牵引挂车」是 C1/C2 之外的一个**附加**准驾车型
（需要在拿到小型汽车驾驶证若干年后另外申请、另外考科目二），不是基础 C1/C2
考试内容。删了 11 题：申请条件、科目二考试内容、实习期内牵引挂车的处罚（都是
在问「持有/申请这个附加资格的人要遵守什么」，前提就已经不成立）。

**跟保留的「牵引故障车」类题目要分清楚**：故障车被别的车拖走、拖车时开双闪、
限速多少——这是任何驾驶人都可能遇到的路上场景，谁都要懂，照样保留；「轻型
牵引挂车」专门指自己额外考出来、平时开车拖挂一个专用挂车的资格，跟前者是两
回事，只有型号名字里都带「牵引」容易看混。

## 后果

- 科目一题量从约 1297 降到 1269，落在 AGENTS.md 「约 1260 道」的覆盖面目标区间内，
  不需要为了凑数再补题。
- 这条裁剪跟着使用者当前的备考目标走：**如果以后要考大型客车、牵引车、摩托车等
  其他准驾车型，这批题需要重新评估要不要收回来**，不能默默假设「删了就永远不需要」。
- 判断标准写清楚了（专属 vs 通用），以后新增题目时能直接照这条 ADR 的口径过滤，
  不用每次重新判断。
