# ADR 0082：「自测」只考没认得的——记住认得了的、可退出、有反馈

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/selftest_store.dart`（新：认得了没有的本地记录）、`lib/recall.dart`（改名、抽题、
  退出、进度与收尾反馈）、`lib/home.dart`（持有记录、易混数字页的条目键）、
  `lib/{signs,markings,gauges,gestures,notes}_page.dart`（传入记录与页面键、改名）、
  `test/recall_test.dart`、`test/selftest_store_test.dart`（新）
- 关系：修订 0080 决策 5、6（名字改「自测」；抽题从「随机抽 5 个」改为「只从没认得的里抽」）
  与 0077 决策 1 中「自评不落库」的一半（评过的结果现在记下来，但**只用于决定还出不出卡**，
  仍不写掌握度、不进作答与统计）；不改题库、出处合约与作答通路

## 背景

0080 的自测每一轮都是从全部条目里随机抽 5 个，会一遍遍考使用者早就认得的内容。使用者的
要求是：改名叫「自测」；要有退出、有反馈；设法识别已经考过且认对的条目，**不再考它们**，把
时间花在还没认得的内容上，而不是反复考已经掌握的。

## 决策

1. **改名「自测」。** 页面按钮、弹窗标题、起练习的题单标题都叫「自测」。
2. **记下每张卡的自评结果，只用来决定还出不出。** 一轮里**第一次问到就记住**，算「认得」一次，
   认得了的条目以后不再出现；**没记住**则认得次数清零、没记住次数加一，下一轮优先再考；
   没记住后经重现才记住的，**不算认得**——那是被提醒出来的，不是自己想起来的，下一轮还要
   从头自己想一次。认得的门槛 `SelfTestStore.knownAfterClean = 1`（使用者要的是「认知正确
   的不再测试」），要更严就改这一个常量。
3. **抽题只从没认得的里抽。** 一轮 5 个：先取没记住过的（至多一半，免得一轮全是难的），再取
   从没考过的，不够用没记住过的补满；上一轮刚出现过的排在后面。没认得的不足 5 个就按实际
   个数出一轮；**全部认得了就明说「这一页你都认得了」**，不再硬出题，给「重新自测」（清空本页
   记录从头来）、「去练这组题」和「关闭」。
4. **随时可退出，评过的不丢。** 卡片右上角有退出按钮（Esc 同效），每评一张就写一张，中途退出
   下次接着考没认得的。
5. **反馈让使用者看得见自测在往前走。** 卡片头与收尾都有「已认得 K / N」进度条，写明
   「只考没认得的」，说清楚为什么有些条目不再出现；每一轮收尾列出这一轮「需要再看看」的条目
   名字，并按剩余个数写「再来 N 个」；评分按钮下写明规则：第一次就记住的以后不再考，没记住的会再来。
6. **这份记录不是掌握度，也不同步。** 掌握度仍只由作答对错写入（0020、主仓库 0052），这里的
   「认得」只是自测的出卡过滤：不进作答记录、不进统计与激励、不参与过关。存成每位学习者
   一份本地文件 `selftest-<学习者>.json`（用户数据目录，写法同 `skin.json`），不进中心库——
   中心库表结构由服务端管理，为一个出卡过滤改它不值得；代价是换一台机器要重新自测一遍，
   损失很小。没有登录名的场景（测试）只存内存。文件缺失或损坏都当成空白记录，不报错。
7. **条目键要稳定。** 符号页用条目 id；考点速记、河南速记、记分证照速记用「组 id + 情景原文」，
   易混数字用「组 id + 情形原文 + 数字」，不用序号——以后在组里插条目，旧记录不会错位
   到别的条目上；内容改了字，就当新条目重考一次。

## 取舍

- **自评可能高估自己**（以为记住了其实没有）。缓解有三：揭示答案后才自评；一次记住才算认得；
  真正的检验仍是「去练这组题」走作答通路，那里才写掌握度。不为此加第二次确认——自测的目的是
  省使用者的时间，不是给自评再设一道关。
- **没有间隔复习。** 认得了就不再出，哪怕几周后忘了。要重新考就点「重新自测」；真正的遗忘
  曲线由作答通路里的强化练习、考前复习按答题记录处理，这里不重复造一套。
- 门槛 1 次偏宽松，是照使用者「认知正确的不再测试」的字面要求取的。

## 验收

- `test/selftest_store_test.dart`：第一次问就记住算认得、没记住清零、重现后才记住不算认得；
  按学习者落文件、重开还在、换人空白、重置只清本页；文件损坏当空白。
- `test/recall_test.dart`：手势页一轮 5 张；没记住的重现且不算认得（4 / 8），第二轮只剩 4 张没认得的；
  全部认得后说明并给「重新自测」，重新自测回到 5 张一轮；中途用按钮或 Esc 退出，已评的记着、
  再开接着考；自评不增加作答记录；8 个速记页都有入口、一轮 5 张。
