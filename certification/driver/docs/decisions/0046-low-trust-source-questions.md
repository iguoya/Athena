# ADR 0046：低可信来源的题量不大时也收，答案逐道按条文重核

- 日期：2026-09-29
- 状态：已接受
- 影响：`content/questions/subject1.json`、`content/sources/catalog.json`
- 关系：ADR 0003（题目必须指到法规或标准）、ADR 0008（公开题库以现行法规为准）、
  ADR 0045（补收公开题库剩余题目）不变

## 背景

ADR 0045 之后，公开题库已经收完。再往外找，只剩商业驾考站点公开的练习页
（驾驶员考试网 jsyks.com）。这类站点不公开出处，抽查时还发现过错题：
把「科目一考试 100 题」写成 50 题，把「上高速开右转向灯」当正确答案。
所以它不能当内容来源。

但抽检里也有公开题库没有的考点（新能源车充电、ETC、自学直考标识、
载货汽车超载记分档、学习驾驶证明内第 5 次科目二不合格的后果等）。
使用者的意见：没有可信来源的题，题量不大的话也可以融入现有题库。

## 决策

1. 低可信来源只登记为 `selection_basis`（说明题从哪里发现），不当内容依据；
   每道题的内容出处必须另外指到法律、法规、规章、国家标准或考试大纲的具体条款。
2. 答案不照搬站点：逐道对照条文原文判断，对不上的改题或不收；解析按条文重写。
3. 只收公开题库和自有题没有覆盖的考点或问法，量控制在几十道以内；
   量大时另开 ADR 重新评估。
4. 出处目录登记 `jsyks-web`，`usage_note` 写明只作线索。

## 结果

- 科目一新增 21 道（`rules.963–967`、`penalty.200–206`、`license.271–274`、
  `alcohol.062`、`accident.157`、`lights.169–170`、`highway.171`），
  内容出处分别是道交法、实施条例、162/163 号令和考试大纲。
