# ADR 0051：错题本、考前复习等跨科目入口钉在侧栏底部

- 日期：2026-09-30
- 状态：已接受
- 影响：`lib/home.dart`（`_sidebar`、`_navLine`、侧栏宽度）
- 关系：修订 ADR 0050 第 4 条（跨科目入口的位置）

## 背景

ADR 0050 把科目改成可展开的目录后，科目一默认展开就挂出 13 行（模拟考试、待练、11 个章节），
错题本、考前复习、易混数字、跨机器同步排在它们下面，窗口不够高就被挤出视野，得先滚动侧栏
才找得到。使用者要求错题本、考前复习一直露在外面。

## 决策

1. 侧栏分两段：上段是标题、掌握徽章和三个科目目录，可以滚动；下段是跨科目的四个入口
   （错题本、考前复习、易混数字、跨机器同步），固定在侧栏底部，不随上段滚动。
2. 四个入口一起钉住，不只钉错题本和考前复习：它们同属跨科目的一组，拆开放反而要解释为什么。
   条目、文字和顺序都不变。
3. 钉住之后上段变矮，科目一展开的 13 行会把科目二、科目四挤出 1000px 高的窗口。为让三个
   一级目录在常见窗口高度里都露得出来：侧栏从 272 放宽到 312，章节名不再折成两行；一级行
   上下内边距 10→8，缩进子项 10→4。**字号不动**，仍是界面基准 20pt。

## 后果

- 科目展开得再长，错题本和考前复习都一眼看得见、一下点得到。
- 主区少了 40px 宽；窗口比 1000px 还矮时科目目录要滚动，这是可接受的代价。
