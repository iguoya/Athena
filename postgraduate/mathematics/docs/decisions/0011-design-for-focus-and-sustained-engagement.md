# ADR 0011：为专注与持续投入设计；区分有效困难与无效挫折

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0001（毫秒级判等）、0002（预测—验证闭环）、0005（两条防线）
- 第 4 节待定项：由仓库 [ADR 0052](../../../../docs/decisions/0052-incentives-and-records-cooperate.md) 裁定——连续日和每日目标要做，但是统计的显形，不用恐吓文案、不锁功能

## 背景

使用者要求：专注力和专注时间要给足——多做交互、多给反馈激励，把注意力集中到
软件上。专注时间越长、投入越多，对数学的认识越真切。**不要让他分心、觉得无聊、
觉得畏难、觉得沮丧而放弃。**

这条要求切中要害：**自学失败的主因是放弃，不是学不会。** 前十份 ADR 全在解决
「教得对不对」，没有一份解决「学得下去吗」。

### 但直接执行会滑向两个错误方向

把「不让使用者沮丧」当成最高目标，结果通常是：

1. **降低难度** —— 那就没有学习发生，与 ADR 0005 防线二（不得削弱应试能力）
   直接冲突；
2. **用奖励掩盖** —— 只在表面加符号，底下的卡点原封不动。这不是说不该给激励
   （第 4 节已修订：激励必须做足），而是说**激励替代不了把卡住的地方修好**。

### 关键区分

| | 定义 | 处置 |
|---|---|---|
| **有效困难** | 题目本身需要思考、概念本身需要绕弯 | **必须保留**。学习就发生在这里，消除它等于取消学习（Bjork 的 desirable difficulty） |
| **无效挫折** | 卡住了不知道下一步、不知道还要多久、连续失败没有回调、面对一大块未知不知从哪下口 | **全部消除**。它们不产生任何学习，只消耗意志力 |

本 ADR 消除无效挫折，**不碰**有效困难。

## 决策

### 1. 逐条消除无效挫折

| 无效挫折 | 机制 |
|---|---|
| **卡住不知下一步** | **分级提示**：方向 → 方法 → 关键一步，逐级展开，使用者自己决定看到哪一级。**不直接给答案**（ADR 0001 第 1 节：不当计算器） |
| **不知还要多久** | 每个环节进入前显示它包含几步、当前第几步。长内容切成可独立完成的小块 |
| **连续失败** | 连错两题自动插入一道同类但更简单的题，做对后再回到原难度。**回调的是难度序，不是标准** |
| **面对大块未知** | 渐进披露：一屏只呈现当前需要的东西。后续内容折叠但**可见其存在**（知道有多少，不等于一次全看） |

### 2. 难度动态匹配，不是降低难度

心流的条件是挑战与技能匹配：太难产生焦虑，太易产生无聊——**使用者点名的两种
状态恰好是这条曲线的两端**。

因此下一题的难度由实时表现决定，而不是固定序列。匹配的是难度**排序**，
掌握标准（ADR 0005 防线二）不随之下调。

### 3. 反馈即时性——ADR 0001 的第二个理由

ADR 0001 用「超过 100 ms 使用者会放弃逐步写」论证引擎必须常驻。本 ADR 给出更
根本的依据：**反馈延迟直接破坏心流**。即时反馈是专注的必要条件，不只是体验优化。

这条使 ADR 0001 的常驻决策**不可因实现成本而回退**。

### 4. 激励要做足；但成年自学者吃的不是符号（本节已修订）

**修订说明**：本节初版写作「禁止外部奖励系统」，理由是「外部奖励挤出内在动机」。
**这条禁令和它依据的那个研究观点，都由作者引入，使用者从未提出、也未表示认同**，
却被写成了否决式条款。使用者明确指出了这一点，并要求「使用软件过程中一定要时时
注意鼓励、激励和奖励用户，提高心理体验」。

本节据此重写。下面的内容分两部分标明来源，**不再把作者的判断记成使用者的要求**：

- **使用者的要求**：激励必须做足，时时鼓励，提高心理体验；并且问了「成年人该用
  什么样的激励方式」。
- **作者的建议**（可推翻）：下面六项具体手段，以及末尾那个待定项。

#### 儿童与成年人的差别在哪

小红花对儿童有效，因为符号本身带来社交价值，且内在动机尚未分化。同一套东西给
成年自学者，多数时候会**显得廉价**，反而降低整个产品的可信度——「我又不是小孩」
这个念头一起，激励就变成了减分项。

成年人要的不是能力的**符号**，是能力的**证据**。

#### 该做的六件事

| 手段 | 具体做法 | 为什么对成年人有效 |
|---|---|---|
| **1 具体的能力证据** | 「三周前这道题你错在第 3 步，今天一次过了」 | 来自他自己的行为，可验证，无法自我怀疑 |
| **2 让看不见的进步显形** | 累计走过多少节、图谱上点亮的知识点、「以前不会现在会」的清单 | 自学最挫败的是「感觉没进步」——实际进步了但看不见 |
| **3 自主与掌控** | 先学哪个、要不要跳过、深到什么程度，都由他定 | 自我决定理论的三需求之一；对成年人，选择权比奖励更有激励作用 |
| **4 意义与用处** | 每节说清它能解决什么现实问题（建模线，ADR 0003） | 成年人需要知道「这东西有什么用」才投入得下去 |
| **5 里程碑的完成感** | 走完一章、走完一遍，给一个明确的收束：走过了什么、下一遍会看到什么 | 成年人对「我做成了一件事」反应最强，而学习天然缺少完成时刻 |
| **6 具体而非通用的肯定** | 不说「答对了」，说「这题很多人选 C，因为把趋近和等于混了——你没上这个当」 | 通用表扬廉价且可疑；指向具体思维动作的肯定才有分量 |

**产出也是激励**：建模线要求的「可留存物」（能跑的模型、一张图、一个结论）
本身就是最强的完成感来源（ADR 0003 第 2 节）。

#### 一个待定项（已由仓库 ADR 0052 裁定）

连击天数、「你的连续记录就要断了」、每日必须完成的指标——这类机制能提高留存，
但作者认为它靠制造焦虑驱动，与 ADR 0013、ADR 0015 第 5 节禁止的 PUA 式施压
性质接近。**这只是作者的判断，使用者尚未就此表态**；本应用当前未实现这类机制，
若使用者要求加入，按其要求实现，不以本段为由推辞。

**2026-09-15 裁定**：仓库 ADR 0052 要求各应用都做连续日和每日目标，并把它们
定义成由作答记录派生的状态，而不是外部压力。采用「要做」；不采用恐吓文案、
断签保险和「今日必须完成否则扣分」。上面六项与此无关，全部是加法，应当主动做。

### 5. 三处最可靠的激励来源

| 来源 | 具体做法 |
|---|---|
| **能力感可见** | 保存使用者每一步推导的轨迹，回看时能看到具体对照：「上次这道题你错在第 3 步，这次一次过了」。**这是进步的证据，不是奖章** |
| **好奇心闭环** | 预测 → 验证本身就是最强激励（ADR 0002 第 3 节）。猜错了想知道为什么，猜对了获得确认 |
| **理解的瞬间** | 统一视角（ADR 0004）与可视化（ADR 0005 第 3 节）制造的「原来如此」。第一章的 `det=0` 压扁演示就是一例 |

推导轨迹同时是复习材料，一举两得。

### 5b. 标绿是事实陈述，不是奖章——但只能标真的通过了的

第 4 节禁止外部奖励，第 5 节要求能力感可见。两者的界线必须说清楚，否则要么滑向
积分系统，要么因噎废食连状态都不敢显示。

| | 性质 | 处置 |
|---|---|---|
| 连击天数、「记录就要断了」、每日强制指标 | 靠制造焦虑驱动 | 仓库 ADR 0052：连续日和每日目标作为统计显形要做；恐吓、强制、断签保险仍禁止 |
| 答对的组标绿、进度条、「上次你错在第 3 步，这次一次过了」 | **内容状态的如实呈现**，信息全部来自作答本身 | **应当做** |

判据：**拿掉它，使用者是否就看不出自己掌握到哪了？** 是 → 它是状态呈现，
属于第 4 节第 2 项，应当做。

**但有一条硬约束：只能标真的通过了的。**

- 诊断组全部答对 → 标绿，因为那是判过对错的；
- `overview` 层只是「走过」→ **不得标绿**。第一遍不判对错（ADR 0012 第 2 节），
  把「看过」显示成「掌握」是虚假激励，比不显示更糟——它制造的正是
  ADR 0014 第 2 节要消灭的流畅性错觉。

因此界面上需要两种不同的记号：走过（中性）与答对（绿）。不可合并。

### 6. 消除分心：只暴露当前需要的自由度

呼应 ADR 0010 第 2 节（不内嵌 GeoGebra 的第二条理由）：教学组件只暴露这一节
要考察的那一个自由度，其余收起。界面噪音本身就是分心源。

**同时明确不做的事**：不使用无限滚动、变动比率奖励、打断式通知等注意力劫持
手段。它们对学习无效，且是不正当的设计。

### 7. 拉长的是累计投入，不是单次连续时长

「专注时间越长越好」需要一处修正：**连续硬坐会降低效率，间隔反而提高总投入。**

- 长环节之间提供自然的停顿点，进度可随时保存并精确恢复到中断处；
- 复习按间隔重复安排（对齐 Khan Academy 的掌握度衰退模型，见 `docs/REFERENCES.md`）；
- 不设「今日必须完成否则扣分」的强制目标。每日目标条按仓库 ADR 0052 展示「还差几道」，未完成不锁功能、不改掌握度。

## 后果

- 分级提示要求每道题额外编写三级提示文案，**编写量显著增加**。但它是消除「卡住」
  这一最主要放弃原因的唯一手段，不可省略。
- 推导轨迹需要持久化，进度库 schema 要能存储每一步的表达式与判定结果，
  而不只是对错。
- 第 2 节的动态难度要求题目按难度分级且同类题有多道，与 ADR 0003 的 SymPy
  自动出题能力配合（题型模板 + 参数随机化）。
- 第 4 节改写后，激励从「尽量不做」变成「必须做足、但要用对方式」。第 5、5b 两节
  是它的具体落点，实现时应主动加，而不是等使用者提出。
- 留存本身不是目标，掌握才是；但对自用软件而言，**学不下去就什么都谈不上**，
  所以两者在这里并不对立——正是第 4 节六项要解决的问题。
- 本 ADR 全部机制只消除无效挫折。若使用者反馈「还是觉得难」，应先判断属于哪一类：
  有效困难只应通过 ADR 0005 的直观手段降低**理解门槛**，不降低**掌握标准**。
