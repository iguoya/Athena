# 0022 词库分阶与教材导入路径

- 状态：已采纳
- 日期：2026-10-09
- 决策人：tiger

## 背景

tiger 要求（2026-10-09）：把大学英语教材（四六级）和高中通用教材的词汇、句子导进资料库，
四六级与高中分开、各自先易后难切成若干子阶段逐步掌握，配套朗读、短文与写作练习，并把激励和
统计做好。同时确认：软件个人自用、不分发不售卖（ADR 0019 补充），出处必须真实、不编造。

事实约束：已入库的真实词表只有 ECDICT 的考试标签词表（高中 3678 / 四级新增 1654 / 六级新增
1755）和本机统计的四级真题词频；《新视野》《全新版》等教材的单元词表与课文没有可核实出处的
开放版本，凭印象编一份就是伪造出处。

## 决策

### 分阶基于已入库的真实词表，不引入出处不明的教材词表

「高中教材的词 = 高考课标词，四级教材的词 = 四级大纲词」——教材换哪一版，教的词都是大纲词。
所以分阶的底座用已有词表，教材差异以后用单元索引补充（见下）。先易后难的排序只用真实信号：

```
难度分 = -log10(frq + 1)                    ECDICT 语料词频，主信号
       + (collins ? (5 - collins) * 0.35 : 0.35)   Collins 五星高频更易
       + (oxford3000 ? -0.3 : 0)           Oxford 3000 更易
       + min(词长, 12) * 0.02              长词略难
       - log10(四级真题词频 hits + 1) * 0.2  真题里真考的词稍微往前（ADR 0019 排序原则）
```

分数小者先学。每阶约 460 词 ≈ 每天 15 个新词（AGENTS.md 上限）学一个月：高中 8 阶、四级 4 阶、
六级 4 阶。生成脚本 `pnpm content:stages`，产物 `content/vocab/<考试>/stages.json`，可复现。

### 阶段进度是活动量，不是掌握度

没有作答测验之前，阶段进度只按「学过」（翻看并朗读、收进生词本）计，界面不出现「掌握」；
主仓库 ADR 0052：掌握度只由作答写入，激励只展示由记录派生的量。首屏的连续天数、周统计同样
改由学习记录派生，demo 数字退场。

### 朗读用系统 TTS，不打包音频

Web Speech API（WebView2 走 Windows 本地语音），离线可用、零授权负担。以后真题录音走
`local-only` 导入，不冲突。

### 教材内容的导入路径：本机导入，进 private/

教材课文、单元词表原文登记为 `local-only`（ADR 0019 已有 `textbook` 来源），导入命令
`pnpm content:textbook` 把本机文件解析进 `content/private/textbook/`，之后由后续脚本生成
句组、短文与写作素材。仓库里进的是机制和格式约定，不是教材内容。词表级的「词 → 册次/单元」
事实索引（哪个词在哪册哪单元）不受版权约束，找到可核实来源后可直接进仓库并登记。

## 后果

- 三个词库立刻有了可学的阶段结构，不需要等任何教材数据。
- 教材单元级的内容（按《新视野》第几课学）依赖使用者本机放入教材文本，导入脚本是第一步。
- 排序公式在生成脚本里，改系数重跑即可；stages.json 是产物不手改。
