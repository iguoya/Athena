# ADR 0002：随堂测验与章末考核；题量按内容实事求是

- 日期：2026-09-12
- 状态：已接受；写作规范即时生效，课表字段与前端渲染已接通
- 修订：2026-09-12 — 明确「总结」与考核**不互斥**；有必要就写总结（可称章节总结）；
  **掌握度仅由章节「随堂考核」全部作答后自动写入，取消手动标记熟练度**
- 延续：ADR 0001（导读 / 讲解 / 实验）；回顾自查精神对齐主仓库 AGENTS，但**不**采用
  「有考核就不写总结」的互斥写法

## 背景

自学 DSA 不能只「看懂讲解、跑过示例」。概念要能归类判断，技能要能下手实现，策略要能
在新情境选型。若从不设检查点，熟练度只能靠自觉点亮，闭环是空的。

同时，为「每节固定 N 道题」「每章必须 10 题」之类数量 KPI 会逼出注水题，或该考的没考。
题量与形式必须由**这一节/这一章实际教了什么**决定。

另：考核验证的是单点判断；**总结**收束整体脉络与知识点关系——二者职责不同，可以同时
存在。曾有「充分考核就不必再凑小结」的说法，那是机械化互斥，已撤销。

## 决策

### 1. 随堂：有必要就测，形式随知识类型

写讲解（`lesson.blocks`）时，在关键判断点插入检查，不设下限也不设上限：

| 知识类型 | 随堂优先形式 |
|---|---|
| 概念 | 归类 / 正反例判断 / 预测（可 `quiz` 或现有 `predict` / `scenario`） |
| 技能 | **随堂实现**：短代码改写、补全、对照实验 `open_lab`；必要时再加选择/填空 |
| 策略 | 情境选型并说明理由（`scenario` / `quiz`） |

「有必要」的判据：读者若跳过这里，后面会带着错误模型继续——就在这里卡住测一次。
若一段只是铺垫、下一块实验会自然证伪，可以不插题。

已有 `predict` / `scenario` / `practice` 继续算随堂检查；需要标准对错与解析时用
显式 `quiz` 块（可多题）。

### 2. 总结：有必要就写，与考核不互斥

- 文案统一用 **「总结」**；章级收束可用 **「章节总结」**（不再用「小结」作规范名）。
- **只要有必要存在就编写**：例如多知识点需要串起来、易错点需要收口、和后章衔接要
  点明。极短铺垫段可以没有总结。
- 总结与随堂/章末考核**不是互斥关系**：考核逐题判分给解析；总结给整体脉络、关系与
  易错清单。可以只有考核、只有总结、或两者都有——按内容判断，不要套「有 A 就不写 B」。
- 课表用 `type: "summary"` 块（`title?` 默认「总结」，章末可用「章节总结」+ `text`）。

### 3. 章末：可出覆盖本章知识点的综合考核

章节可选字段 `assessment`：一套习题，目标是**覆盖本章已写知识点的掌握目标**，
不是再讲新课。用于章末综合自检。

- 题型可混合：选择、情境、短实现说明、指向已有 `labs` 的改写任务。
- 覆盖面按本章 `topics` 的 `mastery_goal` 加权：标「精通 / 掌握」的应有对应题；
  「了解」可以轻测或并入综合题的一小问。
- **可以没有**章末考核——缺省不强制；有考核也不因此省略该写的章节总结。
- **章末卷不写入掌握度**；掌握度只由随堂考核（下一节）决定。

### 3b. 随堂考核决定掌握度（取消手动标记）

- 章节字段 `checkpoint`：挂在**章节导航下方**的「随堂考核」入口。
- 每题宜带 `covers`（知识点 id）。学员逐题作答，**全部选完后自动评判掌握度**：按各
  `covers` 分组的正确率映射为 0–5，写入进度库；改选任意题会按当前作答立即重评。
  不再提供「提交并评判」按钮。
- **禁止**在实验页或其它处提供「标记熟练 +1」之类手动点亮；图谱上的点状掌握度
  只反映随堂考核结果。
- 可反复改选重考，以当前作答的自动评判为准。

### 4. 题量：禁止数量配额，按覆盖实事求是

- 不写「每节至少 3 题」「每章必须 10 题」「最多 N 题」之类规则。
- **随堂考核必须充分覆盖本章已写出的知识点与典型误区**；缺一块就补，重复注水就删。
- 作者自问：这些题合在一起，读者能否暴露本章关键判断失误？不按题数达标，按覆盖达标。
- 同一知识点讲解里随堂已测过的点，章考核可换情境复测，避免原题复制粘贴充数。

### 5. 课表与界面

- `lesson.blocks`：`quiz`（讲解内随手测）；`summary`（总结 / 章节总结）。
- `chapter.checkpoint`：随堂考核（掌握度唯一来源）；左侧章节下入口。
- `chapter.assessment`：可选章末综合卷；左侧章节下入口；不改掌握度。

## 后果

- 写课须按需要设计检查点与总结；评审看覆盖、误区与脉络，不看题目个数，也不因有考核
  而删除有必要的总结。
- 无 `checkpoint` 的章在图谱上掌握度会一直为 0——作者应尽快补随堂考核，或接受该章
  暂不进入掌握统计。
- 实验只负责跑通与体感，不负责点亮进度。
