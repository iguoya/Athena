# ADR 0002：八章的演化切分——每章只回答一个演化问题

- 日期：2026-10-12
- 状态：已接受（使用者 2026-10-12：「不要局限于 5 章数量，实事求是」；「本质上讲就是演化的显式化——告诉初学者，程序是怎样一步步、一个个阶段变成现在的样式的」）
- 关系：修订仓库 ADR 0153 决策 2 的章节划分；[0001](0001-independent-raylib-chapters.md) 的每章单程序不变

## 背景

立项时切成五章，但有两章各塞了多件事：一章里同时进了状态机、计分、最高分，另一章里同时进了逻辑分离、测试、插值、声音。这不是演化，是打包。而且原来的第三、四章跳过了一个真实阶段：固定长度的蛇永远不会咬到自己——「自吃」是在变长之后才诞生的死法，被提前写进去了。

## 决策

1. 八章，章数由演化阶段数决定：窗口与循环、格子与节拍、蛇身（固定长度）、食物与变长、状态机、计分与最高分、规则出窗、手感。
2. 每章只回答上一章留下的一个真实问题。前一阶段的凑合保留到被收编的那一章：第三章用一行 `game = Game{}` 凑合重开，第五章被状态机收编——「先凑合、再收编」本身是教学内容。
3. 规则自第七章住在 `logic.hh`（零 raylib 依赖，tests 直测）；第八章的 `logic.hh` 演化出「吃到加速」，测试跟着长出断言。第七章只搬运不改行为，第八章才改行为。
4. 目标名 `snake-01` … `snake-08`，第 7、8 章各带 `logic-test` 目标。

## 后果

`check.py` 与壳白名单各八项；`--native` 编八章、跑两份规则测试。讲解与题目按新切分重写，第 1、2 章不变。章数不设上限：以后长出新阶段（AI 对手、穿墙模式、音效资源），按同一判据增加或重切。
