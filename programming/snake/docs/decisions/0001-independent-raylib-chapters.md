# ADR 0001：每章一个 raylib 程序，无界面文件对照，规则集中在第 5 章

- 日期：2026-10-12
- 状态：已接受（立项见仓库 ADR 0153）

## 背景

chinese-chess 的每章有两扇窗：界面文件版与代码版，因为 gtkmm 的教学主路径是界面
文件，代码版用来对照。raylib 是 immediate mode，没有界面文件这一层——每一行都会
画的东西就写在主程序里，没有「另一套写法」可对照。

## 决策

1. 每章一个目录、一份 `CMakeLists.txt`、一份单文件主程序 `src/main.cc`，只有一个
   运行按钮。讲解直接以主程序为主路径。
2. 章与章不抽公共库，源码有意重复：合并会让「这一章当时只有这些代码」讲不清楚。
3. 蛇的规则只在第 5 章的 `logic.hh`，配一份不链接 raylib 的测试 `tests/logic_test.cc`。
   前四章的 main.cc 各自抱着自己当时的写法，不回头改。

## 后果

章节文件的校验规则与 chinese-chess 不同：不要求界面文件版在前、不要求两个运行 id，
只要求主程序里看得见游戏循环（`EndDrawing`、`GetFrameTime`）。壳的白名单一章一项。
