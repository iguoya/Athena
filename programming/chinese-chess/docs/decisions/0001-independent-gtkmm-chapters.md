# ADR 0001：棋盘用独立的 gtkmm 章节，教程壳不画棋

- 日期：2026-10-12
- 状态：已接受（使用者 2026-10-12：「先采用gtkmm技术体系吧」，并要求教程分章、每章一个放在 exercise 目录下的独立子程序）。「每章一个程序」由 [0002](0002-two-windows-per-chapter.md) 修订为每章两个窗口。
- 关系：立项见仓库 ADR 0151

## 背景

要做的是一盘常见桌面布局的中国象棋，同时用它讲程序是怎么一步步写出来的。棋盘若画在教程的网页里，讲解和能下的程序就缠在一起，某一章无法单独打开。

## 决策

1. `exercise/` 下五章，每章一个 Meson 工程，包含自己的源码和 glib 垫片。不抽共享库。
2. 第 5 章是当前能下的版本：布局、合法走子、记谱、悔棋、新局、将军、将死、困毙。长将和长捉不在这一版。
3. 走子规则只放在第 5 章的 `Position`。第 4 章用一张写死的开局表画子。
4. 教程壳只按章节 id 白名单调用 `meson` 并启动对应可执行文件。

## 后果

改棋盘规则只改 `exercise/05-move`。前面四章保持当时的样子，不跟着第 5 章自动更新。重复的绘制代码是教学材料，不是要合并的副本。
