# Athena · 数据结构与算法（独立应用）

与主程序**平级**的独立学习应用（ADR 0032）。技术栈自选：Tauri 2 + Web UI +
本机 C++ 工具链。主程序首页图谱上的「数据结构与算法」节点只负责把它拉起来；
**不启动主程序也可以完成全部学习业务**。

## 设计原则

1. **业务自足**：课程内容、进度、实验编译运行全在本目录闭环。
2. **内容驱动**：`content/curriculum.json` 是唯一课表；UI 只做渲染与互动。
3. **实验真源码**：`content/cases/` 里是可编辑的 C++；保存后本机编译运行。
4. **谁都能拉起它**：启动器、终端、C++ 教程首页图谱，走的都是本目录 `app.json` 的 dev 声明；进度写在本应用自己的库里。

## 架构（与 GTK 主程序无关）

```
content/          课表、教案块、C++ 案例（唯一内容源）
src/              前端：导航 + 导读/讲解/实验
src-tauri/        壳：读内容、进度库、compile_and_run
app.json          启动声明：怎么构建、怎么跑、怎么算就绪
docs/decisions/   本应用 ADR
```

页面结构（精神对齐主程序学习页，布局按 Web 重做）：

- **左侧**：章 → 知识点 → **本章实验（每题独立入口）** → 随堂/章末考核
- **右侧**：知识点下仅「导读 · 讲解」；实验不再走顶栏 Tab，点左侧实验项进入独立工作台
- **左侧章节下**：有则显示「随堂考核」（答完自动写入完成度）/「章末考核」（仅自检）
- **完成度**：只由随堂考核全部作答后自动评判产生，不能手动标记
- **编写章节/大纲**：可视与多媒体（ADR 0001）；测验与总结实事求是（ADR 0002）；实验用接口骨架（ADR 0003）
- **实验工作台**：题干卡 · 编辑器 · 输出 · 观察区（一题一页）

## 构建与运行（完全独立）

依赖：Node.js、Rust（rustup）、本机 `c++`/`clang++`，以及系统 `sqlite3`（pkg-config）。
**不需要**先开 Athena。协作规则见 [`AGENTS.md`](./AGENTS.md)。

```sh
# 推荐：开发（自动补 PATH，打开 Tauri 窗口——实验依赖此壳）
athena-dev open dsa

# 或手动
export PATH="/usr/local/opt/node/bin:/opt/homebrew/bin:$HOME/.cargo/bin:$PATH"
cd apps/dsa
npm install
npm run tauri:dev
```

不要只跑 `npm run dev` 再用浏览器打开：那只有前端，没有磁盘读写与本机编译，
实验页会出现「无法加载案例 / invoke」类错误。

Athena 首页点「数据结构与算法」会 spawn `app.json` 的 dev 声明（热更新），**不要**
先 `build:app` 再打开 `bin/` 或 `/Applications` 里的打包副本。

`npm run build:app` 只在真正要交付一份可分发的包时才用。

## 内容怎么规划（当前课表）

四条学习带，图谱按 `requires` 自动分层：

1. **度量与线性**：复杂度度量 → 数组（含尾插均摊）→ 链表 → 栈队列  
2. **关联与层次**：哈希表 → 树遍历 → BST → 堆  
3. **排序与图**：基础排序与二分 → 图表示 → 遍历与最短路径；高效排序另接堆  
4. **解题范式**：基础排序之后即可学分治 → 动态规划与贪心对照；回溯接图遍历（双指针等算技巧，不单列范式节点）  

讲解以 **西科大 823** 为主。第二档只收**仍自主命题且考数据结构**的师范（东北师大 876、山东师大 832、河南师大 846、吉林师大 838、重庆师大 819、西北师大 821、四川师大 831、赣南师大、闽南师大 830 等；广西师大 / 曲阜师大等综合卷含数据结构的也算）。陕师大、福建师大计算机、南师大等已改 **408** 的不按第二档。408 统考作第三对照。

首页是**可点知识图谱**（仿 C++ 分类图谱：白卡片、主色描边、先修边）；点节点进入导览 / 大纲 / 讲解 / 实验。
