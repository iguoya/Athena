# ADR 0001：只做科目一与科目四理论

- 日期：2026-09-15
- 状态：已接受
- 影响：`apps/driving` 的课表、模拟考规则与界面文案

## 背景

中国机动车驾驶证考试分科目一（法规）、科目二（场地）、科目三（道路驾驶技能 +
安全文明驾驶常识）。学习者把安全文明驾驶常识口头叫「科目四」。桌面应用能做好的
是闭卷理论：题干、选项、标志示意、限时组卷。场地和上路需要车和考场，不在范围里。

## 决策

1. 只收 **科目一** 与 **科目三安全文明驾驶常识**。界面标题用「科目四」，并写明
   法规名称，避免和科目三路考混成一门。
2. 模拟考规则跟现行规章走：科目一 100 题、45 分钟、100 分制 90 分合格；安全文明
   驾驶常识 50 题、45 分钟、90 分合格。题量与时长以 GA 1026 为准，合格分以公安部
   令第 162 号为准。
3. 本期题库小于考场题量时，从现有有出处的题里抽，按答对比例折合百分制，结果页
   写明「题库还没铺满」。不拿商业题库凑数。
4. 不做科目二、科目三路考、地方卷、手机客户端。

## 后果

- 首页两张主卡片就够：科目一、科目四；错题本共用。
- 扩充题库时仍按这两门的章来挂，不新开「科目二」。
