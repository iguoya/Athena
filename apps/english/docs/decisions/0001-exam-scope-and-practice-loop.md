# ADR 0001：考研英语二；主练句子与短文，词在语境里强化

- 日期：2026-09-13
- 状态：已接受
- 精神对齐：主仓库 ADR 0028（三层分工）、0029（难度与掌握目标）、0031（知识类型决定教学动作）

## 背景

作者要自用一份英语学习应用，目标是通过**研究生入学考试英语二**（考研英语二），
服务对象是普通计算机或电子信息专业考生。英语二没有听力、口语；分数集中在完形、
阅读、新题型、翻译和两篇作文。计算机 / 电子信息术语能帮读论文，对这张卷子提分
有限——正文多是社科、经济、教育，不是电路或操作系统。

若按「通用学英语」或「整卷模考平台」起步，范围会立刻膨胀。作者明确收窄：
**主要做句子和短文练习**，并强化对英语二单词范围的认识。做题只在电脑上进行。

## 决策

1. **唯一考试目标是考研英语二。** 不覆盖四六级、专四、雅思、学位英语或专业英语。
   专业术语做成日后可选包，不进入主线 `requires`，不挡过线训练。
2. **第一期只做三件事**，其它题型（完形、阅读 A/B 整篇四选一、翻译工坊、大小作文、
   整卷模考）不进课表，除非另开 ADR：
   - **句子**：切分从句、看清指代、用自己的话说出句意。
   - **短文**：低于真题阅读篇的篇幅，练主旨、细节定位和文中用词。
   - **词在语境里**：用英语二词表范围内的词，但必须带义项和例句；不按字母表背中文。
3. **单词不是首页唯一功能。** 词为句子和短文供弹药；认识一个词等于能在本句里选对
   义项，而不是背下一个gloss。
4. **电脑做题，手机只看。** 计时、选项、对照、复习评分只存在桌面应用。手机端若出现，
   只消费同一份 `content/` 导出的讲解 / 精读 / 日词，不判分、不记进度。
5. **学习闭环**仍是「建立预期 → 做一句/一篇 → 对照解析 → 修正 → 到期再练」。
   掌握度只由做完并出结果写入，禁止手动「标记已掌握」。
6. **不做听力、口语、社交打卡、账号云同步。** 英语二不考听说；本应用是自用训练器。

## 后果

- 课表短、主线清楚：词 → 句 → 短文，用 `requires` 表达先修。
- 作者写内容时必须给词配句子，给句子标出用到的词，给短文挂文中词；三层互相指认。
- 以后若要加完形或作文，是新的章节和新的 ADR，不塞进现有三章凑数。
