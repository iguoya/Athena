# ADR 0003：课表驱动；词、句、短文互相指认

- 日期：2026-09-13
- 状态：已接受

## 背景

英语二的词表大约五千余词，若做成「单词 = 一个中文」的卡堆，既背不动，也帮不了
阅读。句子练习若没有词表约束，会滑向语法课。短文若没有文中词和句子作业，会滑向
被动精读。三件事必须共用一份内容模型，UI 只负责按类型出练习。

## 决策

### 1. 唯一课表是 `content/curriculum.json`

章与知识点用稳定 ASCII id，前缀 `en.`。标题、数组位置不是身份。每条知识点写
`kind`（concept / skill / strategy）、`difficulty`、`mastery_goal`、`requires`。
难度与掌握目标只给已经写出内容的条目评定。

当前主线三章，顺序即先修方向：

1. `en.vocab` 词在句子里（概念：义项；技能：在本句选对意思）
2. `en.sentence` 句子（技能：切分、指代、句意）
3. `en.passage` 短文（技能：主旨与细节；策略：先读什么）

### 2. 练习数据按类型分文件，课表只引用路径

| 类型 | 权威文件 | 一条记录必须有 |
|---|---|---|
| 词 | `content/vocab/*.json` | 词形、义项、例句、本句提问、解析；可选干扰项 |
| 句子 | `content/sentences/*.json` | 原句、练习动作、参考回答、用到的词 id |
| 短文 | `content/passages/*.md` + 旁路 `*.json` | Markdown 正文；JSON 里挂题和文中词 |

词不得只有中文 gloss。一词多义按义项出题，不按词形合并成一张卡。

### 3. 教学动作按类型选（ADR 0031 精神）

- **词（概念 + 技能）**：先给句子，再问这个词在这里是哪个意思；对完对照义项和
  「不是哪个意思」。
- **句子（技能）**：示范切分后立刻变式；动作为切层、找指代或用中文说清句意，
  不要只问「语法名称是什么」。
- **短文（技能 + 策略）**：先读短文，再做少量主旨 / 细节题；文中词可点回词卡。
  篇幅短于真题阅读篇，服务「看懂」，不是模拟 40 分阅读 A。

### 4. 复习写在本应用库里

每条练习项有自己的到期时间。答完按简易间隔重复更新（先 SM-2 量级即可，算法
可替换，不要为此另起服务）。章节掌握度由该知识点下条目的近期正确情况汇总，
不设「标记熟练」按钮。

### 5. 内容作者约定

- 用英语二词表范围内的词；第一期不追求五千词一次进库，按已写句子和短文收录。
- 短文自写或改写，风格贴近英语二（议论 / 社会现象），不写成技术文档。
- 解析写「为什么是这个意思 / 为什么这层是修饰」，不写空泛的「详见语法书」。

## 后果

- 加新练习主要是加 JSON / Markdown，不为新题复制页面。
- 词表会小于「完整英语二大纲词表」——这是刻意的：没进句子或短文的词先不收。
- 公众号导出只取短文 Markdown 和词的例句，不导出可点选项。
