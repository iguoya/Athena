# ADR 0005：界面按能力路线组织；练习与考核分开

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0004（三个等级，每级三条轨）

## 背景

ADR 0004 把课表改成三个等级、每级三条轨之后，界面还停在「一列阶段卡片 +
练习台」的形态：看得到有哪些轨，看不出**这一级还差什么才算过**。三条轨的
进度混在一句「0/4 练过」里，既不知道哪条拖后腿，也不知道下一级什么时候开。

同时，练习一直是「答一题、看一题解析」。这对学是对的，但它永远在提示下答题，
没有一次是**合上书自己来**的——分不清「看着解析能选对」和「真的会」。

## 决策

1. **首页就是能力路线**。左栏按顺序列出三个等级（已过打勾、当前高亮、未解锁
   说明差什么），右栏是当前等级的全貌：三条考核状态带 + 三张轨道卡 + 解锁说明。
   先修与解锁状态由 `requires` 和做题结果算出来，不写死在代码里。
2. **专注练习与首页分开**。进练习页只剩这一轮要做的事：左侧是本轮条目、各自的
   到期状态和当前位置，右侧先给语境（短文轨先渲染正文），再给题目与解析。
3. **练习与考核是两种模式**：
   - 练习：答一题给一题解析，答错立刻进错题本，可以在左栏来回跳题。
   - 考核：成套作答，作答期间不给解析、不显示词形、不能跳题，交卷后一次性
     给分并逐题摊开对错与解析。
4. **考核题库与练习题库分离**，组卷和提交规则由 ADR 0006 取代本 ADR 最初的
   同题库权宜方案。
5. **每条轨单独判定是否通过**，由独立考核结果写入；三条轨分别过关，不取平均分。
   一级的三条轨全过，下一级才解锁，已取得的阶段资格不因后续复习答错而撤销
   （ADR 0006）。
6. **不做四档自评复习**。不提供「再来 / 费劲 / 尚可 / 轻松」这类自评按钮：
   排期只由答对答错驱动，错题靠「跨日答对 + 做对变式」出库（ADR 0001 第 5 条
   「禁止手动标记熟练」的同一条道理——自评就是换了个说法的手动标记）。
7. **界面上不出现技术状态**：数据库路径、运行环境、`concept/skill` 这类标签
   都不进界面；英语二只在路线终点和高级阶段出现，不淹没前期的实用学习目标。

## 后果

- `index.html` 只剩三个视图容器（路线 / 练习台 / 错题本），`src/` 按职责分成
  `types.ts`（内容模型）、`backend.ts`（Tauri 桥与降级）、`practice.ts`（排序、
  判定、组卷，纯逻辑）、`main.ts`（渲染与事件）。
- 加一个等级或一条轨仍然只改 `content/`，界面按 `track.kind` 决定卡片配色与
  按钮，不需要为新轨复制页面。
- 考核题来自 `content/assessments/`，练习覆盖率与考核通过状态分开保存（ADR 0006）。
