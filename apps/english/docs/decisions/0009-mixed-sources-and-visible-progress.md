# ADR 0009：综合取材；学习成果要看得见

- 日期：2026-09-14
- 状态：已接受
- 依赖：ADR 0005、0007、0008
- 部分作废：ADR 0008 第 4 条「整本教辅不进库」；ADR 0006「不复制第三方教材」仅仍约束练习 JSON 正文

## 背景

本地参考原先只收公开词表、考试说明和公有领域课文，教辅一律挡在门外。写题时
实际会对照多家材料：词频定先后，公开大纲定任务，教辅补搭配、熟词生义和长难句
切法。再卡「正统出处」会把有用的笔记挡在仓库外。

同一时期首页只报「今日复习 / 错题」，看不出连续天数、稳住了多少、哪条轨在长。
课表文案偏规则，缺少「你已经走了多远」的反馈。

## 决策

1. **有必要就落到本地。** 公开词表、考试说明、公有领域课文、教辅摘录、个人笔记
   都可以进 `content/sources/reference/`。教辅放到 `textbooks/`：词表、搭配、长难句
   笔记、阅读词汇摘录都行。不要求一家正确，多家对照、一定程度上可靠即可。
2. **练习题从具体材料转化，不凭空起稿。** 投放区不是把整本书当课表。进入
   `vocab|sentences|writing|assessments` 的每个条目，都要先选定现实教材的例句、篇目
   或习题，再转成可练习的义项、判断和受控变式；条目级 `source_refs` 要精确定位。
   词频表与考试说明只能解释“为何选它”和“对齐什么”，不能冒充例句或题面出处。
3. **选词综合权衡。** 写题时打开 `working-mix.json`：已上课表、建议下一词、尚未覆盖的
   公开搭配。频率、考试词组、教辅摘录互相校正，不把任何一张表当成唯一真理。
4. **激励写进课表，不另做社交打卡。** 首页展示连续天数、已稳住条目、通过考核、累计
   作答，以及单词 / 例句 / 作文覆盖条和本地徽章。数据来自本机进度库，不上传、不排名。
5. **文案鼓励前进。** 课表 `lead` 和底部约定改成「能看见自己在长」，规则仍在，不靠
   恐吓或冲刺班口吻。

## 后果

- ADR 0008 第 4 条改为：整本扫描件不必进练习 JSON；摘录和笔记欢迎进 `textbooks/`。
- 徽章和连续天数不替代间隔重复与阶段考核；它们只让已有进度被看见。
- 浏览器预览没有进度库，成就只反映本次会话。
