# 界面草图（来源：2026-09-13 与 Codex 的设计对话）

`english-learning-roadmap.html` 是这一版界面的**原始草图**，由 Codex 在对话里
生成并预览，当时没有落进仓库（它后来只改完了 `content/`，界面没动）。这份文件
是从 `~/.codex/visualizations/` 取回的原件，未作修改，作为配色与版式的权威参照
留档。

直接用浏览器打开即可交互：顶栏切「今日复习 / 错题本」，轨道卡上的按钮切到
专注练习视图，`data-view` 在 overview / practice / mistakes 之间切换。

## 实现按它对齐的部分

- **调色板**：只有蓝、绿、橙三个色相，没有紫色和正红。答错用橙，不用红。
  进度条一律蓝色，不按轨道分色。三张轨道卡都是白底，「下一件该做的事」靠
  主按钮实心蓝区分，不靠卡片底色。
- **层次**：窗口底 `#f7f9fc`，卡片与左栏 `#ffffff`，说明块 / 状态带 / 语境框
  `#f1f5fa`，分隔线 `#d4dde8`。
- **圆角**：轨道卡与问题卡 15px，状态带 13px，便签与说明块 12px，按钮 10px。
- **字重**：标题和强调一律 500，不用更粗的字重。

## 实现有意偏离的部分

- **字号**：草图用 12–13px 的小字，本项目的字号下限是 15pt（按 27 寸 4K 的
  阅读距离定的），所以小字统一抬到 0.88em，层级差比草图小。
- **文案**：草图里的「考研」「英语二」字样不进界面（见 `AGENTS.md` 定位一节）。
- **深色模式**：草图用 `light-dark()` 写在一处；实现改成
  `@media (prefers-color-scheme: dark)`，色值照搬，以兼容 Ubuntu 的 WebKitGTK。
