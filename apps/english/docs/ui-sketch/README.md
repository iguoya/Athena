# 界面草图（来源：2026-09-13 与 Codex 的设计对话）

`english-learning-roadmap.html` 是这一版界面的**原始草图**，由 Codex 在对话里
生成并预览，当时没有落进仓库（它后来只改完了 `content/`，界面没动）。这份文件
是从 `~/.codex/visualizations/` 取回的原件，未作修改，作为配色与版式的权威参照
留档。

直接用浏览器打开即可交互：顶栏切「今日复习 / 错题本」，轨道卡上的按钮切到
专注练习视图，`data-view` 在 overview / practice / mistakes 之间切换。

## 实现怎么用它

`src/styles.css` 里**原样嵌着这份草图 `<style>` 的全文，一个字符都没改**，
页面根元素带上 `id="english-stage-map"`，它的作用域就成立了。`index.html` 的
结构也照搬草图骨架，class 名与层级一致，所以配色、字号、圆角、间距全部是草图
自己的值，不存在「照着改一遍」的走样空间。

文件末尾另有一段「桌面适配」，只做三件事：让窗口铺满应用而不是画成一个圆角
示意框、给各栏加滚动、补几条草图里静态写死而实现中要按数据生成的元素规则
（考核报告行、空态提示等）。**要调样式，先改草图再同步回来，不要在原文段里
就地改。**

交互也照草图实现：三个阶段可点切换（锁定态显示「预览」和解锁说明）、顶栏
今日复习 / 错题本 / 继续当前任务、每轨两个按钮、练习页左栏条目跳题、选项作答
后正确项绿底错项橙底、错题本左列右详情加两栏答案对比和移出规则条。

## 有意偏离的地方

- **文案**：草图里的「考研」「英语二」字样不进界面（见 `AGENTS.md` 定位一节），
  阶段副标题相应改为「独立表达」。
- **考核**：草图的规则卡写「考核使用未见材料」，但仓库里没有独立题库，实现改成
  「考核成套作答，交卷后统一反馈」，不谎称未见材料（见 ADR 0005）。
- **深色模式**：草图的 `light-dark()` 原样保留，另在适配段给根元素补了
  `color-scheme: light dark` 让它真正生效。
