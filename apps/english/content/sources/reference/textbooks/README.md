# 教辅与笔记投放区

写题用得上就放进来：恋练有词一类的词表摘录、黄皮书阅读词汇、长难句切分笔记、
真题搭配整理都可以。不要求出处正统，也不要求一家正确；多家材料综合看，
一定程度上可靠即可。

## 建议怎么放

- 一个来源一个子目录或一个 Markdown / JSON，文件名写清材料俗称。
- 词表用一行一个 lemma，或 `{ "lemma", "gloss", "note" }` 的 JSON。
- 长难句只保存切分步骤和改写后的短句，不必贴整篇阅读。
- 进入练习库之前仍要写成带义项和例句的题目，并在 `source_refs` 里标明依据。

这个目录不会被 `check:content` 当成课表。空着也不影响运行；有摘录时先对照
`../working-mix.json` 再决定写哪几条。
