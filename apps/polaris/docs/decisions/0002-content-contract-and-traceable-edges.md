# ADR 0002：内容来源与依赖理由都纳入可执行契约

- 日期：2026-09-15
- 状态：已接受

## 决策

`content/polaris.json` 是节点、边和地图的唯一内容来源，`content/sources/catalog.json`
是唯一来源目录。C++ 读取两者并拒绝以下情况：重复 ID、引用失效、节点无来源、边无来源、
`requires` 与边不一致、跨图强先修、以及强先修环。

节点还必须有 `practice`、`validation` 和 `validation_note`。这使路线图不能只写“学习某
技术”，而必须可回答：做什么、看什么数据、怎样判定完成。C++ 层基于强先修拓扑排序生成
确定性布局；QML 不计算课程关系，也不硬编码节点位置。

## 后果

新增内容会比纯文本清单更费工，但所有图的顺序、箭头和来源都能被机器检查。当前不把连接
其他 Athena 应用的 ID、启动命令或进度字段放入契约；未来若要加入，必须另立 ADR，避免
路线图内容与启动编排耦合。
