# 内容

C 语言的章节、文档、图和实验源码都放在这个目录下，**不进主程序的
`resources/athena.json`**。两边的内容体系相互独立，各自演进。

共用的是方法而不是格式：`docs/LEARNING_DESIGN.md` 的教学动作分类、
`docs/decisions/0028` 的大纲三层分工、`0029` 的难度与掌握目标、`0031` 的
知识类型——这些规范照着用，但字段名、文件格式和渲染方式这边自己定，
不必套主程序的 schema。套 schema 会立刻产生耦合，复用规范则零成本。

唯一需要对齐的是**知识点 ID**：写进共用学习库的 ID 一律以 `c.` 开头
（例如 `c.Pointer.basics`），这样和主程序的 `cpp.*`、`practice.*` 同表共存
而不冲突。
