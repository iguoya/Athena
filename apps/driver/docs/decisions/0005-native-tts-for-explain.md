# ADR 0005：答题解释用系统 TTS 朗读

- 日期：2026-09-15
- 状态：已接受
- 对齐：英语应用的朗读/停止交互；数学应用 ADR 0026（本机 TTS，不走 Web Speech）

## 背景

练习判定后解释出现在右侧蓝条里，来不及看清楚。英语应用用「系统朗读 /
停止朗读」读题干；那是 WebView 的 `speechSynthesis`。本应用是 Flutter
桌面，没有这条路。

## 决策

1. 练习判定后自动朗读：**先读题目解释（`explain`），再读法条条目（条款定位 +
   `source_refs.note`）**；两段相同只读一遍。不按秒数跳下一题。
2. 蓝条上提供「系统朗读 / 停止朗读」，两个按钮同一套字号和高度；朗读用绿色、停止用灰色，避免和下一题挤成一排蓝按钮。切题或离开时停掉上一句。
3. 本机合成：macOS `say`，Windows `System.Speech`，Linux `espeak-ng`。
   优先中文、增强音色。不嵌入云 TTS，不走 WebView。
4. 模拟考仍不展示解释，因此也不朗读。

## 后果

- 解释仍写在题目 JSON 里，朗读只是同一段文字的出口。
- 没有中文音色时按钮不可用，练习本身不受影响。
