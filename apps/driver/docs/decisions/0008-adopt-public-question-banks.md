# ADR 0008：自用软件不受版权束缚，公开题库可以直接收录

- 日期：2026-09-16
- 状态：已接受
- 影响：`content/questions/`、`content/sources/catalog.json`、题库导入流程
- 关系：修订本应用 ADR 0003 的「不搬商业整库」，ADR 0003 的出处要求不变并加强

## 背景

ADR 0003 定了两件事：题目必须能指到法条或标准；不收录商业驾考题库原题。
第二条的理由是版权与分发风险。

但这个前提不成立：本应用是**个人自用**，不分发、不上架、不商业化，没有第三方
会拿到这份题库。为一个不存在的分发场景付代价，换来的是题量和真题手感上的长期
欠账——公开题库里那 4000 多道题带着真实考场的出题口径和错误率，自己按条文一条
一条造题补不回来。

## 决策

1. **取消「不收录商业驾考题库原题」的限制**。公开渠道能拿到的现成题库（GitHub
   上的开源题库、政府与驾培机构公开的练习题）可以直接收录进 `content/questions/`。
2. **唯一的硬标准是与现行法规一致**：题目、选项和答案必须符合现行《道路交通
   安全法》《实施条例》以及公安部令第162、163、164号、第146号和相关国标。与
   现行规定冲突的（例如按 2022 年之前的记分分值作答）一律改正或丢弃，不因为
   「原题就这么写」而保留。
3. **出处要求不变并加强**（ADR 0003 第 1、2 条继续有效）：收录的题同样要带
   `source_refs` 指到条文。外部题库自带的解析只当线索，条号要自己核对过才写进
   `locator`——实测公开题库的条号引用有错。
4. **不收这三类**：需要看图才能作答而本应用没有图的题；只在某个考区有效的地方
   性法规题；解析与现行条文冲突且无法核对到条文的题。
5. **导入要留痕**：`source_refs` 里注明题目来自哪个公开题库（`selection_basis`），
   同时必须另有一条指向法条的内容来源。

## 后果

- 题量不再受「不搬整库」约束，科目一可以涨到接近考场题库的规模。
- 校验的重心从「有没有出处」转到「答案跟现行法规对不对得上」：分值、期限、
  罚款额度这类硬数字要能自动核对。
- 这条决定建立在「自用、不分发、不商业化」这个前提上。**如果将来要把这个应用
  分发给别人，必须回头重新评估收录范围**，这一段不能默默失效。
