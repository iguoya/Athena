# ADR 0001：只做科目一与科目四理论

- 日期：2026-09-15
- 状态：已接受
- 影响：`apps/driver` 的课表、模拟考规则与界面文案

## 背景

中国机动车驾驶证考试分科目一（法规）、科目二（场地）、科目三（道路驾驶技能）。
安全文明驾驶常识在规章条文里挂在科目三名下，但考场上是**另外一卷**：满分 100、
90 分合格，跟路考分开记分；常识考不合格，已通过的道路驾驶技能成绩仍然有效。
学员按「一、二、三、四」来记这四场考试，桌面应用按这个切。场地和上路不在范围里。

## 决策

1. 只收 **科目一** 与 **科目四**（安全文明驾驶常识）。侧栏就叫科目四。出处引用
   规章原文时写「科目三安全文明驾驶常识」，界面不拿全称去纠正使用者。
2. 模拟考规则跟现行规章走：科目一 100 题、45 分钟、100 分制 90 分合格；科目四
   50 题、45 分钟、90 分合格。题量与时长以 GA 1026 为准，合格分以公安部令第
   162 号为准。
3. 本期题库小于考场题量时，从现有有出处的题里抽，按答对比例折合百分制，结果页
   写明「题库还没铺满」。不拿商业题库凑数。
4. 不做科目二、科目三路考、地方卷、手机客户端。

## 后果

- 侧栏三个去处就够：科目一、科目四、错题本。
- 扩充题库时仍按这两门的章来挂，不新开「科目二」。
