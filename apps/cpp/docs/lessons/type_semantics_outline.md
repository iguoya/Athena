## 历史内容与视觉调整

- 区分对象生命周期与表达式值类别；不把允许移动写成一定移动。
- 实验用于检验理解，单次输出不能排除未定义行为。
- 保留五个正文领域和末尾小结，删除正文中的 ADR 说明；恢复覆盖内容、判断步骤、
  选择代价、章节落点和易错点的列表结构。相邻章节边界也使用简短列表表达，避免表格。
- 只保留两张 SVG：对象与表达式的关系、五个检查点的往返循环——它们表达的是线性
  文字表达不了的结构。风险地图、演进时间线、章节思维导图和权衡轴四张已删除：
  正文里已有同样的清单，图只是把清单排成方框，没有增加信息（图不是越多越好，
  为图而图会稀释真正有用的那几张）。两张留存图为 640×640，大纲沿用全局文档
  22pt 正文，图片高度固定、宽度适应容器。
- 纯文字引用区去掉局部底色。SVG 填充由表达与美观决定，不受纯文字背景约束。
- 大纲作为学习 Notebook 的第一个标签页，当前使用 Blueprint 原生控件与统一滚动区；
  不再通过 DocumentView 加载 Markdown。

## 后续覆盖核对

当前配置有初始化、对象生命周期、auto、decltype、值类别、转换、枚举七个实验入口。
旧大纲曾将 const、生命周期和隐式转换整体记为缺口，但现有推导实验已涉及顶层 const，
初始化实验也涉及隐式构造边界，不能继续简单写成“没有实验”。
后续按理解目标核对讲解、练习与证据的完整性：只读访问与对象自身约束的区别，存储期与
生命周期、临时对象寿命与悬垂风险，隐式数值转换的范围与信息损失，类型别名与独立类型。
这些是待核对和补齐的方向，不代表本轮已添加相应实验。
