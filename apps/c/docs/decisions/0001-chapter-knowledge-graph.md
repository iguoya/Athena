# ADR 0001：C 语言按章划分，首页画章级知识图谱

- 日期：2026-09-14
- 状态：已接受
- 对齐：主程序 C++ 分类知识图谱（`render/knowledge_graph_view.cc`）、ADR 0028 三层分工

## 背景

独立 C 应用一度把「对象就是一段字节」「指针存的是地址」两个**知识点**当成首页
图谱。那是主程序**章内** `RoadmapView` 的粒度。C++ 分类页上的卡片是「类型与表达式」
「引用」「RAII」这种**章**；点进章，大纲里才出现该章知识点路线图。

把知识点直接铺成首页，等于跳过了「这门课有哪些章、章与章谁先修谁」。

## 决策

1. **课表先分章。** 章从 C 自己的知识脊长出来，不抄 C++ 章名：对象与字节 → 指针 →
   （数组 / 结构体 / 函数与地址 / 堆与寿命）→ 字符串。`prerequisites` 画章间先修。
2. **应用首页只画章图谱。** 卡片展示标题、简介、难度、已写知识点名单。点卡片进入
   该章大纲。
3. **教案只能从章内知识点路线图点进来。** 大纲承担方向；路线图承担跳转。没有标签条
   用来跳课。
4. **规划中的章仍可点进大纲**，以便看清这一章要讲什么；没有 `qml` 的知识点保持灰色、
   点不进教案。

## 后果

- 已写成的教案仍是对象与字节、指针两节；其余章先有大纲和节点，后补 QML。
- 进度库未接前，卡片上的细条表示「已写成的节」，不是熟练度。
