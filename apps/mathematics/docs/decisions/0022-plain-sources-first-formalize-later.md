# ADR 0022：参考来源一律选通俗的；严谨不等于形式化，形式化留到后期

- 日期：2026-09-14
- 状态：已接受
- 修正：ADR 0017 第 2 节（阶段教材表）、ADR 0020 第 2 节（严谨视图的来源）、
  `docs/REFERENCES.md` 第五节
- 依赖：ADR 0012（螺旋三遍，第一遍选薄选直观）、0015（起点假设）、0013（信心）

## 背景

使用者说：**「对同济都有阴影了」**，要求**换通俗化一点的教材作为参考**，
**后期再考虑严谨化、形式化**。

这条批评成立，而且指出的是**已有决策没有落实到具体来源上**的问题：

- ADR 0012 早就写明第一遍「选薄、直观、完整覆盖的，不要考研向」；
- ADR 0015 的起点假设是「不假设学过、不假设中学代数三角仍熟练」；
- 但 ADR 0020 落地时，行列式一节四条严谨陈述里有三条把同济《工程数学·线性代数》
  当作依据，界面上「出处」一栏也把它摆在显眼位置。

**嘴上说直观、手上却把形式化教材当依据**——使用者看到的就是这个。

### 1. 「严谨」与「形式化」是两件事

这是本 ADR 最要紧的区分，ADR 0020 没说清楚，导致落地时跑偏。

| | 要求 | 例子 |
|---|---|---|
| **准确** | 陈述在数学上正确、条件完整、术语标准 | 「`|det A|` 等于列向量张成的平行四边形的面积，符号表示定向是否改变」 |
| **形式化** | 用尽可能少的原始概念、尽可能一般的记号书写 | 用置换的奇偶性与求和号定义 n 阶行列式 |

ADR 0020 的严谨视图要的是**准确**，不是形式化。可汗学院讲行列式同样准确，只是
不用置换符号写定义。**在第一遍内容里追求形式化的写法，等于把当年劝退他的那种
教材搬进应用里**——这正好撞上 ADR 0013（写作服务信心）和 ADR 0015 第 5 节。

## 决策

### 1. 内容依据一律选通俗、免费、可点开核对的来源

判据三条，缺一不可：

1. **通俗**：面向初学者，不以「读者已经会」为前提；
2. **免费可访问**：能给出一个点开就能看到那一段的链接——使用者要能当场核对
   （ADR 0017 第 3 节），翻纸质书做不到；
3. **准确**：定义、条件、结论经得起核对。

### 2. 已核对的来源清单（2026-09-14 实地打开页面确认）

| 来源 | 覆盖 | 语言 | 核对到的结构 |
|---|---|---|---|
| **可汗学院中文版·线性代数** | 第一顺位。分块极细、语气对初学者友好 | **中文** | 单元 2「矩阵的变换」下设「寻找逆矩阵及行列式」（含 3×3 行列式、n×n 行列式、按行列展开、萨吕法则）与「关于行列式的深入讲解」（含行加法之后的行列式、行变换之后的行列式、**行列式与平行四边形的面积**、**作为缩放因子的行列式**） |
| **Immersive Math《Immersive Linear Algebra》** | 有编号的定义与定理，且**每个概念配可拖的交互图** | 英文 | 10 章：Vectors / Dot Product / Vector Product / Gaussian Elimination / The Matrix / **Determinants（第 7 章）** / Rank / Linear Mappings / Eigenvalues。7.1 给出二阶行列式定义与有符号面积解释；定理 7.1 倍加不变；定理 7.10 可逆 ⟺ 行列式非零 |
| **3Blue1Brown《线性代数的本质》** | 建立图景 | 英文（有中文字幕） | 见 ADR 0017 第 2 节 |
| **MIT OCW 18.06** | **习题**来源（ADR 0019 第 5 节） | 英文 | 同上 |

**中文优先。** 使用者用中文学习且基础薄弱，全英文来源不该作为第一顺位；
Immersive Math 用在需要一条有编号、可引用的准确陈述时。

### 3. 同济教材退回「坐标」角色

同济《高等数学》《工程数学·线性代数》**继续作为 `textbook_ref` 的章节坐标**
（ADR 0009 的用途：回答「这属于教材哪一章」，便于和习题集、他人进度对齐），
但：

- **不再作为 `formal.source` 或 `sources.rigorous` 的内容依据**；
- 界面上「出处」区块里它的标签改为**「教材坐标」**并加一句说明用途，不让它
  显得像主要参考书。

这不是贬低那本书，是**分工**：它是坐标系，不是讲解者。

### 4. 形式化的东西留到后期

按 ADR 0012 的三遍：

| 遍 | 严谨视图写到什么程度 |
|---|---|
| `overview` | 准确的自然语言陈述 + 二阶/低维的具体式子。**不写一般 n 阶的形式定义** |
| `full` | 一般情形的陈述与标准计算步骤 |
| `exam` | 形式化记号、完整证明——**到这一层再考虑** |

判据：**这一条陈述，能不能让一个没学过的人读懂它在说什么？** 读不懂就说明它
超前了，该留到后面那一遍。

## 后果

- 行列式一节四条严谨陈述的出处全部替换为可汗学院中文版与 Immersive Math，
  同济撤出；`sources.rigorous` 同步换成 Immersive Math 第 7 章。
- `docs/REFERENCES.md` 第五节「第二遍 `full` 用同济」需要改写：`full` 阶段的
  讲解来源是可汗学院与 Immersive Math，同济只作坐标。
- 后续每节写 `formal` 时，**先去可汗学院中文版找对应课程**，找不到再用
  Immersive Math，两处都没有的（实对称矩阵的对角化、二次型、正定二次型——
  ADR 0017 第 4 节已记录）要在界面上如实说明，而不是退回同济当依据。
- ADR 0020 第 2 节「严谨视图」的措辞需要补一句：它要的是准确，不是形式化。
