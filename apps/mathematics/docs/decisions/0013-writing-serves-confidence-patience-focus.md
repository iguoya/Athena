# ADR 0013：编写学习内容时时刻服务信心、耐心、专心

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0011（为专注与持续投入设计）、0005（直观顺序）、0012（先薄后厚）

## 背景

使用者提出：**信心、耐心、专心很重要，编写学习过程教材要时刻服务这一点。**

ADR 0011 已处理**产品机制**——分级提示、难度回调、进度可见、禁止外部奖励。
但那些机制管不到**文字本身**：同样的知识点，措辞和结构不同，读者是坚持下去还是
合上页面，差别极大。本 ADR 补上写作侧的准则。

### 一条要先说清的心理机制

**承认难，反而增强信心。**

如果文本假装一切都简单，读者卡住时会归因于「我笨」——这是最伤信心的归因，
且直接导致放弃。如果文本预先说明「这里是本章最绕的地方，多数人第一次都过不去」，
读者卡住时会归因于「这东西本来就难」——他会继续试。

**归因去向决定放弃与否。** 下面三节都围绕这一点。

## 决策

### 1. 信心：禁用打击性措辞，明确回指已有的成功

#### 禁用词表（否决式）

以下表述**一律不得出现**在讲解正文中：

| 禁用 | 为什么 |
|---|---|
| 显然 / 容易看出 / 不难证明 | 读者看不出来时，归因立刻指向自己笨。数学教材最经典的伤害 |
| 只需注意到 | 「注意到」那一步往往是全题最难的一步，说成「只需」是掩盖 |
| 简单的计算表明 | 后面通常跟着三页计算 |
| 众所周知 / 读者自证 | 把作者的责任推给读者 |

**替代办法**：真的容易就直接写出来——容易的步骤本来就不占篇幅；不容易就说明
它为什么成立，或标注它是一个需要练习才熟的动作。

#### 必须写出「这一步为什么想得到」

数学写作最大的信心杀手，是只给出正确的步骤、不说这一步怎么想到的。读者读完
觉得「我自己肯定想不到」。

每个关键步骤要交代**是什么线索让人往这个方向想**。这与 ADR 0006 的思想层是同一
件事——通用解题思想就是「怎么想到的」的答案。想不出线索的，说明该步骤属于技巧
（ADR 0006 第 1 节），应移入应试区。

#### 明确回指已有的成功

新内容登场时，指明它依赖的哪一件事**读者已经做到了**。例如：「你在上一节已经
看见过压扁——`det=0` 就是那件事的符号写法。」

这不是鼓励话术，是**事实陈述**，与 ADR 0011 第 5 节的「能力感可见」同源：
给证据，不给奖章。

### 2. 耐心：承认难度，给出时间预期，允许先用后懂

1. **难点预告。** 一节中最绕的地方要提前点明，并说明它难在哪。
   例：「这一段是本章唯一需要反复看的地方，难在它同时动了两个量。」
2. **给时间预期。** 不承诺「五分钟学会」。该慢的地方明说需要多花时间，
   与 ADR 0011 第 1 节「不知还要多久」配套。
3. **允许先接受、后理解。** 有些概念要用过几次才懂（`dx` 的用法、特征值的意义）。
   明确告知「现在先按规则用，用熟之后回头看第 X 节会更清楚」，
   **不制造「必须当场彻底理解」的压力**——那是 ADR 0012 第 2 节在写作层的对应。
4. **不用「加油」「别放弃」一类空话。** 没有信息量的鼓励会降低文本可信度。

### 3. 专心：一节只讲一件事

1. **一节一个焦点。** 判据：能用一句话说出这一节要解决的问题。说不出，
   说明该拆。
2. **旁支不进正文。** 有趣但偏题的内容放脚注或后续节，正文保持单线。
3. **不制造来回翻。** 需要回看前面才能读懂的地方，把关键结论就地重述一遍，
   不写「参见第 X 节」了事。
4. **符号前后一致。** 同一对象在全应用用同一记号；确需换记号时明确说明并给出
   对照。
5. 呼应 ADR 0011 第 6 节：界面只暴露当前需要的自由度，文字同理。

### 4. 审查清单

每节写完后逐条过：

- [ ] 全文搜索禁用词表，命中即改；
- [ ] 每个关键步骤都能回答「为什么想得到」；
- [ ] 最难的地方有预告，且说明难在哪；
- [ ] 有一处明确回指读者已经做到的事；
- [ ] 能用一句话说出这一节解决什么问题；
- [ ] 没有「参见第 X 节」式的来回翻；
- [ ] 没有无信息量的鼓励话。

## 后果

- 禁用词表看似琐碎，但它是**可机械检查**的，应在内容构建期加一个 lint 步骤自动
  扫描，不靠人工自觉。
- 「为什么想得到」这条会显著增加写作难度：作者必须真正理解思路来源，
  而不能照抄教材的正确步骤。这与 ADR 0004、0005、0006「不能靠改写教材」的结论
  再次叠加——照抄的步骤答不出这个问题。
- 第 2 节第 3 条（先用后懂）与 ADR 0005 第 4 节（分阶段严格化）配套；
  两者都要求在文中标明「什么时候回来」，否则会退化成永远不解释。
- 本 ADR 的准则适用于全部三层深度（ADR 0012），但 `overview` 层因为薄，
  重点在第 3 节（专心）与第 2 节第 3 条（允许先接受）。
