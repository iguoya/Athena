# ADR 0023：每节分对等的两遍讲解，各配各的习题

- 日期：2026-09-14
- 状态：已接受
- 修正：ADR 0020 第 2 节（严谨视图的分量）、第 4 节（例题与练习不进标签页）
- 依赖：ADR 0012（三遍）、0014（习题是检验器）、0019（题目必须有所本）、
  0022（来源选通俗的）

## 背景

使用者把 ADR 0020 的要求讲得更具体，构成实质修正：

> 每个子章节知识点分成 2 个小部分。第一部分从容易理解的角度编写，口语化、
> 直观化、直觉化；第二部分从数学描述正式化、教材化。**同一问题概念描述 2 次。**
> **每个部分都配有习题。** 习题来源不要自造，要跟现实结合起来，要有所本。

### 1. ADR 0020 落地成了「一份讲解 + 几条摘要」

现状盘点：行列式一节，直觉侧有 `hook`、`overview`（问什么/说什么/三步走/值得
记住的一点）、`walkthrough`（六帧动画带语音）、`widget`（可拖的画布）、
`experiments`（先猜再验）；严谨侧只有**四条陈述**。

**两侧分量差了一个数量级。** 这不是「同一概念描述两次」，是「详细讲一次，
再列几条定义」。使用者要的是第二遍本身也是一遍**完整的讲解**。

### 2. 习题共用一份，等于只检验了一侧

ADR 0020 第 4 节把例题与练习放在标签页之外，理由是「放进任一侧另一侧就看不到」。
这个理由在两侧对等之后不再成立，而且它掩盖了一个实际问题：

**两遍检验的不是同一件事。**

| | 检验什么 | 题长什么样 |
|---|---|---|
| 第一部分（口语） | 直觉判断 | 看着两根箭头，说面积是变大、变小、翻面还是压没了 |
| 第二部分（教材） | 规范计算与条件核对 | 按定义算出 `det A`；已知 `det A = 0`，判断能否求逆 |

一份共用的习题只能测其中一种。现在的 31 道题全是前一种——**教材化那一遍从来
没有被检验过**。

## 决策

### 1. 每节两个部分，分量对等

| | 第一部分「直觉与图像」 | 第二部分「严谨表述」 |
|---|---|---|
| 讲解 | `hook`、`overview`、`walkthrough`、`widget`、`experiments` | `formal.intro`、`formal.entries`（定义/定理/性质/计算方法/术语） |
| 例题 | `examples` | **`formal.examples`**（本 ADR 新增） |
| 习题 | `drills` | **`formal.drills`**（本 ADR 新增） |

「对等」指**职责对等**，不是字数对等：两侧都要做到「讲清楚 + 示范一遍 + 检验一遍」。
第二部分只有定义没有例题习题，就是没写完。

### 2. 同一个例子，两种说法

**两部分尽量用同一个具体对象。** 直觉侧的动画用 `[[2,0],[0,2]]` 演「面积变成 4 倍」，
严谨侧就用同一个矩阵算 `det = 2×2 − 0×0 = 4`。

这是「同一问题概念描述 2 次」最有效的落法：换了说法而没换对象，读者才看得出
**这两段讲的确实是一件事**，而不是两个知识点。ADR 0020 的 `pairs` 与 `plain`
是段落级的接缝，本条是例子级的接缝。

### 3. 两部分的习题各有分工

- **第一部分的习题**：判断、识别、预测，允许不动笔。检验的是「图看懂了没有」。
- **第二部分的习题**：按定义计算、核对定理条件、判断方法适用范围。
  **必须有要动笔算的题**——`src/drills.ts` 开头那行注释早就写着「这里必须有要动笔
  算的题，全是看图选，人可以一次笔不动就走完整章」，本 ADR 让它有地方落。

`formal.drills` 同样受 ADR 0019 全部约束：`source` 必填，自造受配额，不得假冒出处。

### 4. 「跟现实结合」的判据

> **本节整条已由 ADR 0024 作废。** 下面那条「去掉情境题目还成立吗→成立就删」
> 方向是反的：数学例子的情境本来就可以剥离，照这条执行下去会把例子全删光。
> 使用者的原话是「知识点绑定应用是很好的大方向和习惯，**越多越好**」，
> 且「哪怕看起来不够现实，但有助于直观化理解」。现行判据见 ADR 0024 第 2 节：
> 该防的是例子**写错**，不是例子**写多**。


使用者要求习题跟现实结合。这与 ADR 0003「**禁止**用『每个知识点挂个应用例子』
冒充建模线」有张力，必须把界划清楚：

| 算数 | 不算数 |
|---|---|
| 题目的情境**真的有人这么用**：网页排名反复迭代到稳态、照片拉伸后面积变几倍、人口在两个状态间转移 | 给纯计算题套一个壳：「小明有 3 个苹果……求行列式」 |
| 来源本身就取自应用场景的题 | 为了凑「应用」而硬安的背景 |

判据一句话：**去掉那层情境，题目还成立吗？** 成立就说明情境是装饰，删掉它比留着好。

标注方式：drill item 可带 `context` 字段，一句话说明这道题对应的真实用法。
**不强制**——强制会直接逼出上表右栏那种假应用。lint 只统计覆盖率。

### 5. 界面

两部分各自完整，标签切换后**例题与习题跟着切**。ADR 0020 第 4 节「例题与练习
不进标签页」作废。

练习进度分别计数（`0 / 3` 与 `0 / 4` 各显示各的），两侧的题都计入掌握度。

## 后果

- **ADR 0020 第 4 节作废**，其表格改为本 ADR 第 1 节的表格。
- 16 节都要补第二部分的例题与习题。这是很大的编写量，且受来源可得性约束
  （ADR 0019）——**宁可少出题，不自造凑数**。
- `formal` 仍不设为必填（ADR 0020 后果一节），但**一旦有 `formal`，它的 `drills`
  就必填**：只写定义不配习题，正是本 ADR 要纠正的那个状态，lint 报错。
- 第一部分的习题此前是唯一的检验手段，现在它的定位收窄为「检验直觉」，
  规范计算的检验责任移交第二部分。存量 31 道题不需要改写，它们本来就是前一种。
- 教材选材方向（ADR 0022）进一步放宽：**高职高专教材那种偏实践、浅层、少证明、
  多步骤、多应用实例的层次，正是第二部分要的**。但实地核对发现高职高专教材
  **普遍没有免费可点开核对的在线版**（国家职业教育智慧教育平台的课程需登录，
  第三方 PDF 是盗版不可引用），不满足 ADR 0022 的第二条判据。当前用可汗学院
  中文版达到同等深度——它的分块粒度与浅度实际就是这个层次；找到合规的职教
  资源再补进来源清单。
