# ADR 0011：为专注与持续投入设计；区分有效困难与无效挫折

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0001（毫秒级判等）、0002（预测—验证闭环）、0005（两条防线）

## 背景

使用者要求：专注力和专注时间要给足——多做交互、多给反馈激励，把注意力集中到
软件上。专注时间越长、投入越多，对数学的认识越真切。**不要让他分心、觉得无聊、
觉得畏难、觉得沮丧而放弃。**

这条要求切中要害：**自学失败的主因是放弃，不是学不会。** 前十份 ADR 全在解决
「教得对不对」，没有一份解决「学得下去吗」。

### 但直接执行会滑向两个错误方向

把「不让使用者沮丧」当成最高目标，结果通常是：

1. **降低难度** —— 那就没有学习发生，与 ADR 0005 防线二（不得削弱应试能力）
   直接冲突；
2. **用游戏化奖励掩盖** —— 徽章、积分、连击、排行榜。这类外部奖励有充分研究
   表明会**挤出内在动机**；Duolingo 式的连击压力确实提高留存，但它培养的是
   「保持连击」的动机，不是「学会」的动机。对一个目标是真正掌握数学的自用软件，
   方向是错的。

### 关键区分

| | 定义 | 处置 |
|---|---|---|
| **有效困难** | 题目本身需要思考、概念本身需要绕弯 | **必须保留**。学习就发生在这里，消除它等于取消学习（Bjork 的 desirable difficulty） |
| **无效挫折** | 卡住了不知道下一步、不知道还要多久、连续失败没有回调、面对一大块未知不知从哪下口 | **全部消除**。它们不产生任何学习，只消耗意志力 |

本 ADR 消除无效挫折，**不碰**有效困难。

## 决策

### 1. 逐条消除无效挫折

| 无效挫折 | 机制 |
|---|---|
| **卡住不知下一步** | **分级提示**：方向 → 方法 → 关键一步，逐级展开，使用者自己决定看到哪一级。**不直接给答案**（ADR 0001 第 1 节：不当计算器） |
| **不知还要多久** | 每个环节进入前显示它包含几步、当前第几步。长内容切成可独立完成的小块 |
| **连续失败** | 连错两题自动插入一道同类但更简单的题，做对后再回到原难度。**回调的是难度序，不是标准** |
| **面对大块未知** | 渐进披露：一屏只呈现当前需要的东西。后续内容折叠但**可见其存在**（知道有多少，不等于一次全看） |

### 2. 难度动态匹配，不是降低难度

心流的条件是挑战与技能匹配：太难产生焦虑，太易产生无聊——**使用者点名的两种
状态恰好是这条曲线的两端**。

因此下一题的难度由实时表现决定，而不是固定序列。匹配的是难度**排序**，
掌握标准（ADR 0005 防线二）不随之下调。

### 3. 反馈即时性——ADR 0001 的第二个理由

ADR 0001 用「超过 100 ms 使用者会放弃逐步写」论证引擎必须常驻。本 ADR 给出更
根本的依据：**反馈延迟直接破坏心流**。即时反馈是专注的必要条件，不只是体验优化。

这条使 ADR 0001 的常驻决策**不可因实现成本而回退**。

### 4. 禁止外部奖励系统

**不做**徽章、积分、连击天数、排行榜、虚拟货币。

理由见背景第 2 节。这条是否决式的：任何「为了提高留存」而增加的、与学习内容
无关的奖励机制，需另开 ADR 推翻本条才能加入。

### 5. 激励只来自三处内在来源

| 来源 | 具体做法 |
|---|---|
| **能力感可见** | 保存使用者每一步推导的轨迹，回看时能看到具体对照：「上次这道题你错在第 3 步，这次一次过了」。**这是进步的证据，不是奖章** |
| **好奇心闭环** | 预测 → 验证本身就是最强激励（ADR 0002 第 3 节）。猜错了想知道为什么，猜对了获得确认 |
| **理解的瞬间** | 统一视角（ADR 0004）与可视化（ADR 0005 第 3 节）制造的「原来如此」。第一章的 `det=0` 压扁演示就是一例 |

推导轨迹同时是复习材料，一举两得。

### 6. 消除分心：只暴露当前需要的自由度

呼应 ADR 0010 第 2 节（不内嵌 GeoGebra 的第二条理由）：教学组件只暴露这一节
要考察的那一个自由度，其余收起。界面噪音本身就是分心源。

**同时明确不做的事**：不使用无限滚动、变动比率奖励、打断式通知等注意力劫持
手段。它们对学习无效，且是不正当的设计。

### 7. 拉长的是累计投入，不是单次连续时长

「专注时间越长越好」需要一处修正：**连续硬坐会降低效率，间隔反而提高总投入。**

- 长环节之间提供自然的停顿点，进度可随时保存并精确恢复到中断处；
- 复习按间隔重复安排（对齐 Khan Academy 的掌握度衰退模型，见 `docs/REFERENCES.md`）；
- 不设「今日必须完成」的强制目标——那是第 4 节禁止的外部压力的变体。

## 后果

- 分级提示要求每道题额外编写三级提示文案，**编写量显著增加**。但它是消除「卡住」
  这一最主要放弃原因的唯一手段，不可省略。
- 推导轨迹需要持久化，进度库 schema 要能存储每一步的表达式与判定结果，
  而不只是对错。
- 第 2 节的动态难度要求题目按难度分级且同类题有多道，与 ADR 0003 的 SymPy
  自动出题能力配合（题型模板 + 参数随机化）。
- 第 4 条与常见的「提高用户粘性」做法相反。本项目是自用软件，**留存不是目标，
  掌握才是**——若两者冲突，以掌握为准。
- 本 ADR 全部机制只消除无效挫折。若使用者反馈「还是觉得难」，应先判断属于哪一类：
  有效困难只应通过 ADR 0005 的直观手段降低**理解门槛**，不降低**掌握标准**。
