# ADR 0021：标题用规范术语，直觉说法降为副标题

- 日期：2026-09-14
- 状态：已接受
- 依赖：ADR 0005（直观优先）、0009（教材与考纲坐标）、0020（两个视图）
- 影响范围：**只有标题**。讲解顺序、讲法、比喻一概不动

## 背景

使用者指出：**子章节标题应当术语化、规范化**，现有标题「跟数学术语概念关联不
起来」。同时他明确保留了直觉表达的位置——理解过程中可以口语化、直觉化，**具体
讲解过程可以采用非标准讲法**。

### 1. 现状：18 个标题里 0 个术语

| 讲的是 | 现在的标题 |
|---|---|
| 行列式 | 面积变成了几倍 |
| 特征值与特征向量 | 方向没变的那些方向 |
| 向量组的线性相关性 | 两个箭头能够到多远 |
| 矩阵的秩 | 压到了几维 |
| 齐次线性方程组的基础解系 | 被压没的那些方向 |
| 二次型及其标准形 | 交叉项是怎么消掉的 |

每一个都是好比喻，但 5 章 16 节合起来，**没有一个标题里出现过数学术语**。

### 2. 三处实际损失

- **导航失效。** 想复习行列式，在侧边栏、知识图谱、章节目录上都搜不到这三个字。
  ADR 0008 让路径按先修图走、不按教材章节走，前提是使用者**能认出每个节点是什么**
  ——认不出，图谱就只是一堆漂亮的短句。
- **对不上任何外部资料。** 教材、考纲、习题集、视频课全按术语组织。ADR 0009 花
  力气标了 `textbook_ref` 与 `syllabus_ref` 的坐标，标题却和它们对不上，等于把
  对齐的负担又推回给使用者。
- **浪费了术语的最佳复现位置。** 标题是一节里出现频率最高、最显眼的文字。术语
  本身就是要掌握的内容（ADR 0017 第 1 节把「术语的标准叫法」列入必须依据来源
  的一栏），把这个位置让给比喻，就少了一个高频接触点。

### 3. 这不与「直观优先」冲突

ADR 0005 管的是**讲解的顺序与方式**：动机先于定义、低维先于一般。本 ADR 管的是
**标题这一层的命名**。一节可以叫「行列式」，而第一句话仍然是「搬完之后，一块面积
变成原来的几倍？」——顺序没变，变的只是这一节在目录里叫什么。

做法与 ADR 0020 的两个视图同构：**严谨的那一份负责可核对、可对齐外部资料，直觉的
那一份负责讲得进去，两者并置而不是二选一。**

## 决策

### 1. 标题拆成两层

```json
"title": "行列式",
"plain_title": "面积变成了几倍"
```

- `title` 是**规范术语**，名词短语，作主标题；
- `plain_title` 是原来的直觉说法，**必填**，作副标题，与主标题同时显示。

章（`chapter`）同样处理。

### 2. 术语不自己编，从已有坐标取

每节的 `syllabus_ref` 里已经写着考纲的标准叫法，`textbook_ref.covers` 里写着教材
章节名。**术语标题一律据此确定**，不凭印象另造一个说法。

考纲外的拓展节（`scope: beyond`）没有考纲叫法，按教材或通行文献的标准术语命名，
并在 `textbook_ref.note` 里说明依据。

### 3. 主标题不得是句子

术语标题是**名词短语**：「行列式」「矩阵的秩」「实对称矩阵的对角化」。不是问句，
不是陈述句，不含疑问词，不以「了」「吗」收尾。

这一条做成 lint 检查——否则一次改完，下次新增又会滑回去。判据用疑问词与句末助词
的词表加长度上限，**误报时改标题而不是放宽规则**：真的需要一个句子当主标题，说明
该句子属于 `plain_title`。

### 4. 副标题不是装饰，不得省

`plain_title` 必填，与主标题**同时显示**，不做成 hover 或次级信息。理由与 ADR 0020
第 5 节相同：起点假设是不假设学过（ADR 0015），只给「实对称矩阵的对角化」会把人
挡在门外，「对称矩阵的两条轴互相垂直」才是让人肯点进去的那一句。

**两者缺一都不行**：只有术语，读者不知道这节在说什么；只有直觉，读者不知道这节
叫什么。

### 5. 各处显示规则

| 位置 | 显示 |
|---|---|
| 节页面大标题 | 术语为主、副标题紧随其下 |
| 侧边栏「正在读」 | 术语 + 副标题（小字） |
| 知识图谱节点 | **只显示术语**——节点框窄，术语短且正是这里最需要认出的东西 |
| 上一节 / 下一节 | 术语 + 副标题（小字） |
| 先修提示、里程碑 | 术语 |

## 后果

- 16 节 5 章的标题全部重命名，`plain_title` 由现有 `title` 平移而来，不丢内容。
- 知识图谱从「一堆漂亮的短句」变成能按术语认节点，这是本 ADR 收益最直接的地方。
- 正文里的自指措辞需要复核：「这一节问什么」之类不受影响，但若有正文写「前面
  『压到了几维』那一节」，要改成术语或改成副标题的准确引用。
- 新增节时要先确定术语再写内容——术语从 `syllabus_ref` 取，而 `syllabus_ref`
  本来就是必填（ADR 0009），所以不增加额外调研。
