# ADR 0004：算法与技巧分界；按统一视角组织，不按计算对象分章

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0003（经世致用是总纲；考试只是约束）
- 精神对齐：主仓库 ADR 0040（篇幅与掌握目标匹配、不写八股）

## 背景

### 1. 使用者的批评

现实中大量「茴字有四种写法」式的内容：局限细枝末节、偏难怪题，有意把知识与现实
应用剥离，缺乏全局意识。使用者点名**线性代数中简化行列式的手段**为这类产物，
并要求本应用避免。

### 2. 这类内容为什么会大量存在——机制性解释

不是「有些人偏好如此」这么简单。**选拔机制会自动繁殖这类内容**：一个知识点要
成为好考点，需要计算量可控、答案唯一、有多种技巧可以拉开区分度。行列式恰好
全占：它是一个数，对错分明，n 阶有一堆构造法。

于是它在考试中的权重，**系统性地超过了它在现实中的地位**。这不是阴谋，是指标
驱动的必然结果——与 ADR 0003 记录的「论文数替代学问」是同一种病。

### 3. 但「简化行列式」里混着两种东西，不能一刀切

这是本 ADR 必须澄清的事实，否则按使用者的立场一刀切下去会砍掉真东西。

**行变换化上三角 = 高斯消元**，它不是应试技巧，是数值线性代数的核心算法，是
计算机真正在跑的东西。实测对比（20 阶行列式，按每秒十亿次运算估算）：

| 方法 | 规模 | 耗时 |
|---|---|---|
| 按定义 / 代数余子式展开 | 2,432,902,008,176,640,000 项 | 约 **77 年** |
| 高斯消元（行变换化简） | 2,666 次乘除 | 约 **2.7 微秒** |

差 9×10¹⁴ 倍。**「为什么要化简」由此从技巧变成必然**——不化简根本算不出来。
这个对比本身就是最好的教学材料，比任何「技巧讲解」都有说服力。

而「爪型行列式的凑法」「特定构造的递推」「加边法的花式用法」换个矩阵就不管用，
只为手算特制，那才是茴字写法。

### 4. 一个支持使用者的事实

行列式在现代应用中的地位，确实**低于**考试给它的权重：

- 数值计算中几乎不用行列式判断可逆性（用条件数、SVD，因为行列式数值稳定性差）；
- 克拉默法则现实中基本不用（远慢于消元）；
- 行列式真正重要的地方是**几何意义**（有向体积的伸缩比）和**雅可比行列式**
  （重积分换元）——恰恰是考试讲得最少的两处。

所以使用者的不满有事实依据，只是靶子要换：不是「简化手段」有问题，是**教学
重心放错了地方**。

## 决策

### 1. 算法与技巧的分界判据

每个计算方法入库前必须通过三问，**任一为否即归入应试区**（ADR 0003 第 2 节）：

| 检验 | 算法 | 技巧 |
|---|---|---|
| 对任意输入都能跑？ | 是 | 否，依赖题目的特殊结构 |
| 有确定的复杂度？ | 是 | 无意义，只为手算特制 |
| 计算机会这么做吗？ | 是 | 否 |

**「计算机会这么做吗」是最锋利的一问。** 如果答案是否，那它多半是手算时代的
产物或纯粹的出题装置，不该占用主线篇幅。

保留的算法必须给出**它解决的现实约束**——高斯消元解决的是「不化简就要算 77 年」。
说不出约束的，说明它进错了区。

### 2. 行列式的具体裁定（作为范例）

| 内容 | 归属 | 理由 |
|---|---|---|
| 行变换化上三角（高斯消元） | **主线，重点** | 算法；后面解方程组、求逆、求秩、LU、最小二乘全建在它上面 |
| 行列式的几何意义（有向体积伸缩比） | **主线，重点** | 统一视角；解释为什么 det=0 等价于降维、等价于不可逆 |
| 雅可比行列式 | **主线** | 重积分换元的现实依据 |
| 按定义 / 代数余子式展开 | **主线，但只作对照** | 它的价值是被高斯消元击败，用来说明为什么必须化简 |
| 爪型、三对角、加边法等特殊构造 | **应试区** | 技巧；换个矩阵不管用 |
| 克拉默法则 | **应试区，附注现实中不用** | 理论意义在，计算上已被淘汰 |

### 3. 线性代数按统一视角组织，不按计算对象分章

使用者要求的「全局意识」，在数学教学里的具体形态是**不把一件事拆成互不相关的
碎片**。线代是重灾区：行列式、矩阵、向量空间、特征值、二次型，考纲里是五章各自
独立的计算。

它们其实是**一件事的五个侧面——线性变换**：

| 章 | 在「线性变换」视角下是什么 |
|---|---|
| 矩阵 | 变换本身（在选定基下的坐标表示） |
| 行列式 | 这个变换把体积放大多少倍（带定向） |
| 向量空间 / 秩 | 变换的像与核，它把空间压到几维 |
| 特征值与特征向量 | 变换下方向不变的那些方向 |
| 二次型 | 变换对应的对称双线性形式，主轴即特征向量 |

**本应用按这条主线组织线代**，章节之间显式互相引用；允许与考纲顺序不同
（ADR 0003 第 1 节：考纲决定覆盖下限，不决定组织顺序）。

判据：讲完一章后，要能回答「这一章和上一章讲的是同一个对象的哪两个侧面」。
答不上来，说明组织成了碎片。

### 4. 同类审查扩展到其他分支

本 ADR 的判据不限于线代，编写任何章节时同样适用：

- **微积分**：换元积分的各种「凑法」中，凑微分的一般思想（`d(g(x))` 的识别）是
  方法，特定函数的特殊凑法是技巧；三角有理式的万能代换是算法（对整类问题都有效），
  而针对个别题目的构造是技巧。
- **概率**：分布的推导与关系（二项 → 泊松 → 正态的极限过渡）是统一视角，
  而各种分布的矩的机械计算是练手。

## 后果

- 应试区会比预想的大。这是诚实的结果，不是失败——ADR 0003 第 2 节已决定隔离而非
  删除它们，因为约束仍需满足。
- 按线性变换重组线代，与市面教材和考纲顺序都不同，**内容编写不能靠改写教材**，
  必须自己搭主线。这是本应用最大的一笔前期成本。
- 第 1 节的三问需要作者对数值计算有基本了解（知道计算机实际怎么算），否则会把
  技巧误判成算法。拿不准时以「换个输入还管用吗」为准。
- 「行列式在现代应用中地位低于考试权重」这类判断要写进讲解，让使用者知道**某个
  内容为什么在应试区**——这种诚实本身就减少心理消耗（ADR 0003 第 2 节）。
