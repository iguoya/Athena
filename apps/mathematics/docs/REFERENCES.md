# 外部参考：现有的数学自学工具

本清单只作**讲法**与**工程做法**的对照参考，不作为章节结构、路径顺序或措辞来源
（内容组织以 ADR 0004、0005、0008 为准）。引用需按正确数学语义重新核对，
遵守版权限制，不整段复制。

## 一、和本项目意图最接近的

| 工具 | 网址 | 值得学的 | 它没解决的 |
|---|---|---|---|
| **3Blue1Brown《线性代数的本质》** | 3blue1brown.com | **内容主线与本项目 ADR 0004 完全一致**：矩阵＝线性变换、行列式＝面积伸缩比、特征向量＝方向不变的方向。它已经验证了这条主线讲得通 | **是视频，不能交互、不能验证、不判分**。看完觉得懂了，做题仍不会——这正是本项目的增量所在 |
| **Mathigon / Polypad** | mathigon.org | ① 有**知识地图**，课程按依赖推进（同 ADR 0008 拓扑序）；② 交互**嵌在叙述流里**，不是「读一段再做一题」 | 内容为中学与通识，无高数线代深度，不对考研 |
| **Immersive Math** | immersivemath.com | 免费在线线代教材，每个概念配可交互图形，交互与正文同步 | 只有线代；无练习、无进度、无判等 |
| **Better Explained** | betterexplained.com | 方法论 **ADEPT**：比喻 → 图 → 例子 → 大白话 → 技术定义。**与 ADR 0005「动机先于定义」高度吻合**，是个成熟可抄的顺序模板 | 纯文章，无交互无练习 |
| **Seeing Theory** | seeing-theory.brown.edu | 概率统计交互可视化，质量标杆 | 数学二不考概率；仅建模线的贝叶斯部分可参考 |

## 二、练习与掌握度机制

| 工具 | 值得学的 | 它没解决的 |
|---|---|---|
| **Khan Academy** | **掌握度机制**：不是做对一次就算会，分「熟练 → 精通」且会衰退、需复习。本项目的进度库可直接借鉴这套分级 | 内容体系是美国课标，不对考研 |
| **Brilliant** | **几乎不讲，直接给问题**，在解题过程中把概念带出来——与 ADR 0008「问题当引入动机」同源 | 订阅制、闭源、不对考研 |
| 国内考研数学刷题 App | 只有**错题本的错因归类**与按题型的薄弱统计值得参考 | 基本都是「重解题轻思想」，正是本项目 ADR 0003 摒弃的方向 |

## 三、符号判等与自动批改（对应 ADR 0001）

| 工具 | 值得学的 | 关系 |
|---|---|---|
| **STACK**（基于 Maxima，开源） | **最值得研究的一个。** 它就是做符号等价判定的在线数学作业系统，学术界长期验证。核心可借鉴的是它的**反馈树**（potential response tree）：不只判对错，而是按**常见错误模式**分支给出针对性反馈——这正是 ADR 0001 第 1 节第 2 条「报错要落到步骤上」的成熟工程做法 | 内容是传统作业题，不涉及思想组织。本项目借它的**判等与反馈机制**，不借它的内容形态 |
| WeBWorK / Möbius | 同类在线作业系统，题库与批改流程可对照 | 同上 |
| Symbolab / Photomath / Mathway | 只有**分步骤的呈现形式**值得看 | **方向相反**：它们「替你算」，本项目「判你自己算的」（ADR 0001）。不可参照其交互设计 |

## 四、一个结论：三者的交集是空的

调研范围内，**没有任何一个工具同时做到**：

1. 用思想与直观组织内容（3Blue1Brown 做到了，但无验证闭环）；
2. 对使用者自己的推导逐步判等（STACK 做到了，但内容是传统作业题）；
3. 对准中国研究生入学考试数学（国内 App 做到了，但重解题轻思想）。

这是本项目存在的理由，也意味着**没有现成的东西可以整体照搬**——可借的是局部
做法：3Blue1Brown 的线代主线、ADEPT 的讲述顺序、STACK 的反馈树、Khan 的掌握度
衰退模型。

## 五、按遍数分配的教材参照（ADR 0012）

第一遍求通不求全，**选薄 + 直观 + 完整覆盖，不要考研向**；考研辅导书第二、三遍
才上场。教材在此只作**范围参照与进度锚**，不作内容来源（同 ADR 0009 的坐标性质）。

| 遍 | 科目 | 参照 | 理由 |
|---|---|---|---|
| **第一遍** `overview` | 线代 | **3Blue1Brown《线性代数的本质》**（15 集，约 3 小时） | 最薄的完整概览，主线与 ADR 0004 一致 |
| | 高数 | **《Calculus Made Easy》**（Silvanus Thompson，1910，**公版免费**） | 极薄，强调直觉，对齐 ADR 0005 |
| | 高数补漏 | 可汗学院微积分 | 免费，分块极细 |
| **第二遍** `full` | 两科 | 同济《高等数学》《工程数学·线性代数》 | 即 ADR 0009 的坐标教材，便于与习题集、他人对齐 |
| **第三遍** `exam` | 两科 | 真题 + 考研辅导讲义 | 只在应试区使用（ADR 0003 第 2 节） |

注意《Calculus Made Easy》是 1910 年的书，**记号与术语与今日教材有出入**，
且不覆盖考纲全部（例如多元部分）。它承担的是「建立直觉」，覆盖范围以第二遍的
同济教材为准。

## 六、现在就能用的现成工具组合（不必等本应用）

本应用的第一遍 `overview`（ADR 0012）**本来就不需要软件**，用下列现成工具即可走完。
建议两条线并行：用现成工具立刻开始第一遍，本应用跟着第一遍的真实体验做——
哪里卡住、哪里无聊、哪里想要一张能拖的图，有反馈再设计，比凭空设计准。

| 用途 | 工具 | 说明 |
|---|---|---|
| 高数讲义 | **Paul's Online Math Notes**（tutorial.math.lamar.edu） | 英语世界自学微积分最常被推荐的免费讲义，例题极详尽 |
| 高数直觉 | 《Calculus Made Easy》 | 公版免费，极薄（见第五节） |
| 线代全局 | 3Blue1Brown《线性代数的本质》 | 15 集约 3 小时（见第五节） |
| 分块补漏 | 可汗学院微积分 | 中文版，免费 |
| 可视化探索 | **GeoGebra** | 免费离线；自由度远超本应用内嵌的受控组件（ADR 0010 第 4 节） |
| 验算 | SymPy / WolframAlpha 免费版 | 立刻可用 |
| 间隔复习 | **Anki** | 掌握度衰退与间隔重复的现成实现（ADR 0011 第 7 节） |
| ~~考研网课 + 辅导讲义~~ | ~~B 站网课~~ | **已由 ADR 0015 修正**：该建议基于「已学过一遍」的错误起点假设，见第七节 |

**一条诚实的判断**（同样受 ADR 0015 修正）：若学习者**已经学过一遍**且目标仅是通过
考试，最高效的现成方案是考研网课加真题，自造软件在时间上是净支出。但对基础薄弱、
需要从直观概念学起的人，那条路径是劝退——见第七节。本应用的价值在补它缺的三样——
思想与来龙去脉（ADR 0002、0006）、**对使用者自己推导的逐步判等**（ADR 0001，
现有工具确实没有；Symbolab 那类是替你算）、以及考完不弃（ADR 0003）。

## 七、基础薄弱起点的第一遍主力（ADR 0015）

适用于**不假设高数线代学过、也不假设中学代数三角仍然熟练**的起点。
选择标准：从最基础处起步、分块细、讲解直观、**不含任何贬低或施压式表达**。

| 用途 | 资源 | 为什么适合这个起点 |
|---|---|---|
| **主力** | **可汗学院**（中文版） | 从代数、函数、三角一路到微积分，分块极细，单个视频 5–10 分钟；纯讲解，无话术。**它是主力，不是补漏** |
| **前置补齐** | Paul's Online Math Notes 的 Algebra / Trig Review | 专为基础不牢者写的复习章，例题详尽 |
| **友好的微积分入门** | 《普林斯顿微积分读本》 | 开篇即有预备知识章（函数、三角、极限），语气对初学者极友好，明确写给「觉得微积分难」的人 |
| **建立大图景（无公式压力）** | 《微积分的力量》（Strogatz） | 叙述性，读完知道微积分在干什么、为什么重要 |
| **直观骨架** | 3Blue1Brown（线代本质、微积分本质） | 建立图景，不教计算——与上面几项配合，不单独使用 |
| **薄而直观** | 《Calculus Made Easy》 | 公版免费（见第五节） |

**关于主流考研网课**：使用者指出两点，本项目认同并据此排除它们作为第一遍主力——
① 长篇大论在解题技巧，正是 ADR 0003、0004、0006 摒弃的方向；② 讲课中的 PUA 式
话术制造「归因于我笨」，是 ADR 0011、0013、0015 第 5 节明令禁止的。
它们留到第三遍 `exam` 层，只取题型与真题讲解部分。

## 使用约定

- 参考的是**该怎么讲、常见误区在哪、机制怎么设计**，不是它们的组织方式。
- 3Blue1Brown 的主线可对照，但**不可照搬其叙述**——本项目须有交互验证与判等，
  这是它没有的部分。
- STACK 的反馈树在实现推导验算前应先研究一遍。
- 任何工具都不构成「本项目该教什么」的依据（ADR 0003 第 5 节：考纲只定下限，
  外部工具连下限都不定）。
