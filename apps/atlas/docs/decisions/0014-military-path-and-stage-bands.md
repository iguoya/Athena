# ADR 0014：课图按军工研制链筛选，章节分初级 / 中级 / 资深

- 日期：2026-09-20
- 状态：已接受
- 相关：ADR 0001（航天软硬融合是取舍准则）、ADR 0010（两章课图）、ADR 0011（真先修）、ADR 0012（指南针）、仓库级 ADR 0054（宁增勿删）

## 背景

两章课程图有两种失败方式，上一轮对照培养方案时两边都碰到了。

一种是**铺成百科**。ADR 0011 / 0012 曾要求对照 ACM CS2023 十七个知识领域、OSSU Core、工程教育认证，把编译、数据库、软件工程、安全、图形、伦理、模电、数电、通信、电磁都做成对等节点，免得「学完两章仍不知道这门学科还有这些课」。那把尺子回答的是「大学课表里有没有这门」，信息量大，但人面对满图会无所放矢：不知道先打哪一层，也不知道哪一门是研制链主干、哪一门是平行专业。

另一种是**收成口号**。只留「C、RTOS、FPGA」几个词，必要性和能力说不清，指南针退化成目录。司南的节点必须仍能回答三件事（ADR 0012 第 3 条）：为什么必须学、学完能判断或设计什么、能交出哪一类可验证产出。筛选掉的是对等课位，不是这些判断。

本 ADR 把上一版核对过的信息量留下来。章节用初级 / 中级 / 资深给人瞄准；必要程度仍回答「这门课对学科有多必要」，军工是第二句兼顾，不能倒过来当裁课尺子。

**必要性先写学科，再兼顾军工，而不是相反。** 专页「必要性」第一段回答：这门课在计算机 / 电子信息里为什么必须学（培养方案里的核心、缺了就不构成这个学科）。第二段才写：军工研制里它还支撑探测、实时、试验、系统软件里的哪一类闭环。不得用某一家控制系统总体所的业务（飞控软件、固体测发、某一种弹上链路）当第一句，更不得用「那个岗位用不用得到」决定一门课是主干还是台阶。实时控制对照图仍锁在内容里（ADR 0012），不驱动课图分级。

## 决策

1. **课图的取舍准则是学科培养，军工是远方兼顾，不是倒过来的过滤器。** 一门课能不能进主干，先问三条：

   1. 缺了它，这门学科的培养目标还能否成立（程序设计、系统、电路、信号这类核心，而不是百科里每一个知识领域都占一格）；
   2. 军工软硬闭环里它是否仍用得上——探测 / 数字后端、嵌入式与实时、试验测控、系统软件、控制与仿真——用来写第二句，不用来一票否决；
   3. 产出仍应可测（一段程序、一块板、一次频谱、一次联调），不是论文方向或证书方向。

   不得用「某一种弹上飞控用不用得到」单独决定主干或台阶。CS2023、OSSU、认证课表仍是对照，用来检查「是不是把素养也一起扔了」；不再要求十七个知识领域各占一格。被筛掉的能力若仍有素养价值，折进已有节点或留在 `theory`。

   CS2023、OSSU、认证课表仍是对照，用来检查「是不是把素养也一起扔了」；不再要求十七个知识领域各占一格。ADR 0012 第 6 条「盘面必须能指认每一块知识领域」对课程图不再作为列课清单。被筛掉的能力若仍有素养价值，折进已有节点或留在 `theory`，并在节点正文里写明折到了哪里。

2. **章节的主分级是阶段：用来判断这一阶段该学什么，并且按顺序解锁。**
   它不是难度，也不是必要程度。打开一张图，人要能回答「我现在是初级 / 中级 / 资深，这一层该把力气花在哪些课上」。
   **原则上一个阶段没解锁，不应该学习高阶课程**：初级主干没打完，不上中级；中级主干没打完，不上资深。后面的课可以在图上被看见（指南针要标出目的地），但不能当成当前该学的课来进。解锁只发生在本次打开窗口里，不记掌握度、不建进度库。
   每个学术层节点必填 `stage` 和 `stage_reason`：

   | 档 | 能干什么 | 计算机上像什么 | 电子上像什么 |
   |---|---|---|---|
   | `junior` 初级 | 能进实验室，在已有框架里改、测、复现 | C 语言、工程实践与工具链 | 电路基础、仪器、可选的 51 台阶 |
   | `intermediate` 中级 | 能独立交付一个分系统 | 组成、操作系统、并发、C++、数据结构、网络 | 模电、数电、微控制器与接口、总线、实时内核、FPGA、信号与系统 |
   | `senior` 资深 | 能判断接口、最坏情况和联调收口 | 应用实践、地面侧模型实验 | DSP、测控数据链、反馈控制、电磁与传输线、合机验证 |

   侧栏、画布分层和底部滤镜都按这三档排。默认瞄准初级；更高一层带锁，点锁住的课只能查阅，不能把瞄准点跳过去。打开一张图，人先看见该打哪一层，再看见这一层里有哪些课。`priority` 仍保留，先回答它对这门学科是核心（`essential`）、系统/工程能力（`important`）还是台阶/选修（`optional`）；军工里它还支撑什么另写 `industry_reason`。台阶课仍出现在对应阶段里，避免「删掉就当没这回事」。
   阶段闸门不写成假的 `requires`：C++ 仍然不必先修 C，信号与系统仍然可以没有入边。闸门在阶段轴上，先修轴继续只连真门槛。一张课图里，`requires` 不得指向比自己更高的阶段。

3. **编译和安全：素养要，对等课不要。** 上一版把它们写成学科核心，是因为 CS2023 FPL / SEC 和认证计科含编译、OSSU 把 Core security 放进所有主修。用军工尺子看，写编译器、做渗透 / 等保 / 密码工程是平行工种，从业口径窄，不能和操作系统平级占一格。但素养不能丢：

   - **编译**：交叉编译、读反汇编、讲清优化如何改时序和调用约定。折进「计算机系统基础」与「工程实践与工具链」。不建「编译原理」节点，也不把 Godbolt / 链接脚本写成教程步骤。
   - **安全**：威胁模型、不信任输入、完整性、分域。折进工程实践与计算机网络。不建「信息安全」节点，不培养安全工程师。CS2023 自己也只给 SEC 约 6 小时 CS Core，并允许渗进其他课。

   同样不进课图主干、只在 ADR 里留名以免假装不存在的：图形与交互、专业伦理独立课、分布式共识 / 云原生、数据库大课（遥测落盘挂在实践主干的数据管线）、半导体物理深课、微波天线全套、信息论证明课。

4. **已有节点不删 id，缺的研制链能力用新节点补。**

   **计算机：留 / 并 / 降**

   | 处理 | 节点 | 上一版核过的理由（压缩后仍要写在节点里） |
   |---|---|---|
   | 留，主干 | C、C++、数据结构、系统基础、操作系统、并发、工程实践 | 计科培养的工程基础；操作系统讲调度与隔离，不是因为某一种实时内核岗位 |
   | 留，支撑 | 汇编、Linux 系统编程、计算机网络、应用实践 | 读懂机器、会在 Unix 上写系统程序、会判断网络分层；收口作品 |
   | 并进别的节点 | 网络编程；交叉编译 / 编译产物；威胁模型 | 不再单独占主干一格，正文写清并进了哪一门 |
   | 降为台阶 | 设计模式、模型开发 | 设计模式不是计科核心；模型课是方向选修 |
   | 初级选修 | Python | 脚本与科学计算常用，但不是计科主语言主干 |

   **电子：留 / 拆 / 补 / 降**

   | 处理 | 节点 | 理由 |
   |---|---|---|
   | 留，初级主干 | 电路基础 | 入门仍是集总电路 + 仪器，三段原文不改 |
   | 拆开补上 | 模拟电子、数字逻辑 | 认证和培养方案里模电 / 数电是两门学位课；并进「电路入门」会让 FPGA 和传感的真先修看不清 |
   | 从理论升成可验证课 | 信号与系统、测控与数据链、反馈控制 | 理论栏原文按吸收契约保留；实践课写必要性、能力和产出，避免只剩脚注 |
   | 补中间带工具 | MATLAB / Simulink、电磁与传输线 | 电子信息的建模与场路工具；高速走线要场的语言，但不做成微波专业 |
   | 改标题，不改 id | STM32 → 微控制器与接口；FreeRTOS → 实时内核 | 能力域是 MCU / RTOS，料号是教学实例 |
   | 资深支撑 | 嵌入式 Linux | 带 MMU 的嵌入式系统课，不是硬实时的唯一入口 |
   | 降为台阶 | 51 单片机；端侧 AI；电机控制；Linux 驱动 | 51 是入门台阶；后三门是方向落地，不另起主干 |

5. **画布按阶段分层。** 课程图布局改为初级 → 中级 → 资深三层；层内再按主干 / 支撑 / 台阶排序。更高一层默认锁住，完成当前层主干后才解锁下一层。`requires` 仍然只表示真门槛：51 改为虚线来路，不发明学期链。节点专页要让阶段理由、必要性和能力先被看见；未解锁的课先看见闸门，再看见内容。

6. **每门课有自己的细分学习流程，知识点按 CS2013 掌握度分级。** 课程节点带 `chapters[]`：章名、一句干什么、课内先修。掌握度采用 ACM / IEEE-CS *Computer Science Curricula 2013* 知识单元的三档（计科课表最通用的标法，电子课同样套用）：
   - `familiarity` 熟悉：能指认这个概念，知道它解决什么；
   - `usage` 运用：能在常规情境里动手做；
   - `assessment` 评估：能比较方案、判断边界和失效。
   运用和评估是这门课的重要知识点，必须标 `kind=practice`（界面用实践卡片，和理论卡片分开画）：实践用来直接感到这门课为什么必要、能解决什么；熟悉走理论卡片，只给实践一把尺子，不和动手抢视线。

## 后果

- 侧栏主列变成初级 / 中级 / 资深。默认锁在初级；滤镜切已解锁的一层，其余层压暗。未解锁的课带锁，专页先说明「先打完上一层」。满图仍能看见目的地，但不能跳层当当前课。
- ADR 0011 第 1、2、4 条里「按必需 / 重要 / 可选列完整学科」的呈现方式被本 ADR 取代；真先修规则仍有效。原料 28 个节点的 `stable_definition` / `engineering_role` / `pitfall` 仍不得改写，新增判断写在 `stage`、`stage_reason`、`priority_reason` 和新节点上。
- 检查器要求课程节点带细分章节，每章有合法 `mastery`（familiarity / usage / assessment）；运用 / 评估必须能标出实践。学术层若写了 `stage`，必须合法且带 `stage_reason`。
