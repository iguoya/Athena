# ADR 0013：桌面表达深度是一等目标，内容正确是底线

- 日期：2026-09-20
- 状态：已接受
- 相关：ADR 0012（指南针：必要性 / 能力 / 产出）、ADR 0011（真先修、节点专页）、ADR 0002（内容契约）、ADR 0007（单实例、不做热重载）、仓库级 ADR 0056（可视化是内容本身）、仓库级 ADR 0057（开发机基线，选型不按安装成本裁）、仓库级 ADR 0047 / 0051（跨平台，macOS ≈ Windows 优先）

## 背景

Atlas 不是学习闭环，是一张给人看清学科全局的地图。指南针要有效，人必须**看见**结构：哪一层是核心、哪条边是门槛、哪门课可以单独起步。把节点排成白卡片、把理由堆在图外说明书里，地图就退化成目录——内容也许还在，引路已经失败。

仓库级 ADR 0056 要求学习应用「能画的就画、能算出来的画成活的」。Atlas 不受那一条的掌握度 / 战绩约束，但同一条判断在这里更硬：图谱**就是**产品。如果呈现力停留在「能用的信息列表」，这个项目没有做成桌面软件的理由。

本项目因此有两项目标，地位不对等：

- **约束**：内容必须正确。课在不在、先修是不是真的、出处能不能点开核对，不因界面实验而改写。
- **目标**：把桌面软件的表达深度、可视化、交互性，以及 Qt 6 场景图能提供的当代能力，做到尽可能满。这是炫技，也是实验——允许为了一种更强的看见方式推翻当前页面，不允许为了好看去编造知识。

「炫技」在这里不是贬义。桌面端有 GPU 合成、粒子、镜头、毛玻璃、原生暗色窗口、高 DPI 文字、空间手势，这些能力如果不在 Atlas 上练，就会被「先把内容摆出来」永远挤掉。内容摆出来而看不见结构，等于没摆。

## 决策

1. **内容正确是底线，不是天花板。** 节点 id、真先修、虚线来路、分级、出处、两章课是否覆盖学科培养要求，继续由 `atlas.json` 与 `scripts/check.py` 守。界面实验可以换视觉语言、换交互范式、换整页结构；**不得**为构图发明 `requires`、不得把可选课藏起来让图更疏、不得改嫁 id、不得把职业图为了画面丰富而重新铺进主路径（ADR 0012 第 4 条）。特效与内容冲突时，改特效。

2. **炫技与实验是一等目标。** 做界面时默认问：桌面软件在 2026 年还能怎样让人读一张知识地图？Qt 6 Quick 的场景图、RHI（Windows 上 Direct3D）、多重采样、粒子、形状、多层效果、镜头运动、手势、原生控件与暗色标题栏，凡是能加强「看见全局、看见航路、走进一处再走出来」的，都应当用，不为「显得朴素」「先做能用的」自我设限。仓库级 ADR 0057 已规定：技术合不合适比好不好装更重要，依赖体积不计入权衡。

3. **允许推翻当前页面，不允许沿用信息列表当完成态。** 现有侧栏、图谱、专页只是一次实验的落点，不是模具。下一轮可以换空间结构、换导航、换进入专页的方式。判断完成的标准是：打开窗口后，人能否在几秒内说出这门学科的主次和去向，以及「我刚才走的那条边为什么存在」——不是控件是否还叫现在这些名字。

4. **交互必须承载判断，特效必须解释关系。** 合法的炫技都指向读图：
   - 悬停 / 选点照亮邻域，其余压暗：回答「这一点连着谁」；
   - 实线流动、虚线走带：回答「这是门槛还是来路」；
   - 分层地形与滤镜：回答「这一阶段该学什么」；更高一层带锁，回答「还没解锁，先别跳」；
   - 镜头飞向节点：回答「我现在站在哪」；
   - 编号航标可点开理由：回答「为什么有这条边」；
   - 专页先给必要性 / 能力 / 产出三块：回答指南针的三问。
   解释不了关系的光斑、为动而动的循环动画、挡住读图的装饰，不算达标，直接删。

5. **用满 Qt 6 桌面栈，不做成浏览器套壳。** 节点继续是 QML 控件，边继续可以画在场景图或 Canvas 上，但不因此拒绝 Shader、Particles、MultiEffect、Quick Shapes、Fluent 原生控件、系统暗色方案、ClearType、捏合与滚轮对着焦点缩放。需要三维空间关系时直接上 Qt Quick 3D，不先做一套退化的线框「等以后再评估」。平台差异仍走仓库级 ADR 0047：先确认 macOS 与 Windows 可用；没有通用解的能力关在单独模块里，并写明另一边怎么降级。

6. **实验失败可以撤效果，不能改内容凑效果。** 一条粒子航路看不清、一次模糊挡住文字、一种转场让人找不到返回，就关掉或改参数。不要去改 `requires`、不要删节点、不要把理由写短来迁就卡片高度。内容契约是实验的夹具，不是实验对象。

7. **验收分两条，都不省。** 内容正确走 `python3 scripts/check.py` 与领域测试。表达是否成立必须在 macOS 或 Windows 上打开窗口：拖、悬停、选点、进专页、Esc 回来。构建通过不等于看见了结构。不做 QML 热重载（ADR 0007），改了呈现就重开。

## 后果

- 写节点仍先保证 ADR 0012 的三问和 ADR 0002 的出处；写界面则按「桌面能力有没有用上、读图判断有没有变快」评审，不再把「能显示 JSON」当成 UI 完成。
- `qml/` 可以持续推翻自己；`content/atlas.json` 的 id 与真先修不能为画面服务而改嫁。
- 新增 Qt 模块（粒子、多层效果、3D、矢量）只要对读图有用就可以进主路径，不必另找「轻量替代」。
- 职业图、掌握度、账号、启动其他应用，仍不在未另行决定前加入——炫技的对象是这张学科地图的表达，不是把 Atlas 做成别的产品。
