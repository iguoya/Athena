1.2 类型推导

auto 会保留什么，又会丢掉什么？

先形成判断，再用真实成员函数验证。结果与预期不一致时，要解释差异，而不是只看“运行成功”。

1 建立判断，并先给出预测 思想 → 预期

普通 auto 按值推导，会去掉顶层引用和顶层 const； 只有 auto& 才保留别名关系。判断类型时看的是“推导规则”，不是初始化表达式长什么样。

如果 auto copy = original;，修改 copy 会改变 original 吗？
预测是软引导，可跳过 —— 但跳过时这里会记一笔“未预测”。
2 运行当前实验 行动 → 观察
你的预测：不会，它是独立副本 要验证的命题：auto 按值推导，拷贝而非绑定

观察结果 · 紧贴产生它的源码 copy=20   original=30
3 对照预期与实际 证据 → 判断
你的预期
copy 是独立副本，改它不影响 original
实际结果
copy=20，而 original=30
✓ 一致 改 copy 确实没动 original；把 original 改成 30 的是第 20 行的 alias。
这里验证的是 推导之后的类型关系（copy 是 int，alias 是 int&），不是赋值语句本身。
