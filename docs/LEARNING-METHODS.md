# 四大类学习方法与软件设计映射

> 定位：[ADR 0096](decisions/0096-retrieval-spacing-interleaving-lead-curriculum.md)
> （检索练习、间隔重复、交错练习为主导学习策略）的**领域展开**。共同地基不再重复；
> 本文按数学、语言（英语）、考试认证、编程四大类，各自叠加该领域公认特化的方法，
> 并映射到软件设计与内容组织。只收有实证依据的方法（标注代表人物/效应），不收
> 流行噱头；「约束不继承」（ADR 0062）——各应用落地时自定字段与形态。
>
> 证据基线与 0096 相同：Dunlosky 等 2013 综述（*Psychological Science in the
> Public Interest*）——高效用：检索练习、间隔练习；中等效用：交错练习、精细提问、
> 自我解释；低效用：重读、划线、摘要。

## 数学（mathematics、math-tools）

| 方法 | 依据 | 软件与内容组织映射 |
|---|---|---|
| 样例学习 → 逐步撤除 | Renkl & Atkinson；认知负荷理论（Sweller：工作记忆是瓶颈） | 每个概念先给完整解答样例，再给缺步样例，最后空白题——「骨架不给白板」（ADR 0059）的数学特化 |
| 交错练习 | Rohrer & Taylor 2007：混合题型显著优于分组刷题 | 出题器按已学知识点**交错**组卷，不按章节顺序成串出题 |
| 掌握学习 | Bloom：单元达标才进入下一单元 | 章节考核达标解锁下一章（`requires` 先修已有） |
| 多重表征联动 | Ainsworth；双重编码（Paivio） | 同一概念代数式↔图形↔数值三表示联动切换（math-tools 的活图表，ADR 0056） |
| 错误样例分析 | erroneous examples 研究 | 「找错、改错」题型：给一份含典型错误的解答让学生定位修正 |
| Pólya 四阶段 | 《怎样解题》：理解→计划→执行→回顾 | 解答题的提示梯按四阶段分级展开，不直接给答案 |

## 语言·英语（ascent 摘星、english 磨砚）

| 方法 | 依据 | 软件与内容组织映射 |
|---|---|---|
| 可理解输入 i+1 | Krashen 输入假说 | 句子与短文按当前水平分级、略高半级（摘星的难度渐进分阶） |
| 词汇检索 + 间隔重复 | Nakata；FSRS 算法 | 生词卡 FSRS 调度（摘星 ADR 0014），永远换新句复习（ADR 0005） |
| 输出假说 | Swain：输出迫使注意缺口 | 写作、翻译、造句作为与输入平级的必做项（摘星读写听说排序，ADR 0011） |
| 语块学习 | formulaic sequences（Lewis 词汇法） | 短语和搭配整块学，不孤立背单词（ADR 0005 同源） |
| 任务型教学 | TBLT（Ellis）：以完成任务组织语言使用 | 真题写作题/翻译题即任务：真实任务 → 尝试 → 对照范文 |
| 泛读 | extensive reading（Day & Bamford）：大量略高于水平的易读材料 | 分级读物流（后期 passages 目录），不查词典连续读 |
| 考试反拨 | washback：按考试分值定权重 | 读写听说按考试分值排序（摘星 ADR 0015：阅读最大） |

## 考试认证·知识型（software、embedded 软考；driver 驾考）

| 方法 | 依据 | 软件与内容组织映射 |
|---|---|---|
| 检索练习/测试效应 | Roediger & Karpicke 2006 | 选择题本身就是检索练习——**做题即学习**，不是「学完再测」（driver 强化练习先行） |
| 间隔重复 + 连对扩间隔 | Cepeda 2006 元分析 | 连对次数定复习间隔（1/2/4/8/16/32 天，driver 已实现；softcert 同构推进） |
| 交错与变式 | Rohrer & Taylor；同考点变式（ADR 0079） | 同考点换题干换数字反复出现，跨章节交错组卷 |
| 全真模拟 | practice testing 的成套形态 | 整卷模式：限时、不给解析、交卷一次评分（磨砚 ADR 0006：考核与练习物理分离、平行题） |
| 双重编码可视化 | Paivio；ADR 0056 | 抽象机制配活的交互图（softcert viz：进程状态、调度甘特、进制转换、页置换） |
| 精细提问与自我解释 | 中等效用（Dunlosky 2013） | 每题解析必须说清**错误选项错在哪**（softcert 契约已要求），引导自我解释 |
| 认知负荷控制 | Sweller：样例效应 | 新考点先样例后练习；正文块有限集（ADR 0058），不堆纯文字 |

## 编程（machine、c-plus-plus、algorithm；practice 出口）

| 方法 | 依据 | 软件与内容组织映射 |
|---|---|---|
| PRIMM 课程结构 | Sentance & Waite：Predict→Run→Investigate→Modify→Make | 编程节的标准五段：先**预测**代码输出（形成预期），再**运行**验证（TEACHING.md 学习闭环的编程特化），然后调查、修改，最后**创作** |
| Parsons 问题 | Ericson & Guzdial：拖拽代码行排序，负荷介于读码与写码之间 | 打乱代码行排序题：初学者的高效中间形态，写作题之前的台阶 |
| 代码追踪 | code tracing 研究：手推变量状态表 | trace 题：给代码填变量状态表（algorithm 的 trace-player 已有渲染器） |
| 样例 → 实验 | 认知负荷理论；ADR 0059 | 实验骨架可编译（不改一行也能跑），学生只改标记处 |
| 即时反馈的刻意练习 | Ericsson 刻意练习：明确目标+即时反馈+重复精化 | 编码实验沙箱：真编译、真运行、真报错（ADR 0091 路线；softcert ADR 0002 的 SQL lab 同构） |
| 建造主义 | Papert constructionism：在造真实物中学 | 造物出口（practice）：c-gui-lab、pocket-cube——学完的语言拿来造真东西 |
| 低层记忆检索 | 语法/API 的检索练习 | 语法填空、API 补全用间隔复习调度（语言学习的 FSRS 同理） |

## 负清单（明确不采用的）

- 重读、划线、摘要作为主学习手段（Dunlosky 2013：低效用，恰是学生最常用的）。
- 「费曼技巧」等无对照证据的流行法作为机制依据（可作为输出练习的动机话术，不作设计依据）。
- 纯视频/纯听讲的被动消费形态（不做视频课）。
- 学科间互相照搬形态：数学不做「跟读」，编程不做「背知识点卡片」为主——低层记忆
  检索只作辅助，主导形态各归各的领域方法。
