# ADR 0118：课程本体归权重更高的考试——408 夺走软设手里的四门课

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「优先级高的分组有权利夺走优先级低或者权重低的分组
  节点」「408权重比软件设计师权重高 所以可以夺走它的节点」「从这个角度判断和设置启动器
  节点布局」）
- 关系：修订 [ADR 0116](0116-reference-attach-and-cs408.md) 决策 4 的挂法表（`parent`/
  `also_under` 字段语义与解析规则、引用连线种类照旧）；同时修订
  [0099](0099-dsa-reattach.md) 的「dsa 挂 software」与
  [0103](0103-practice-courses-as-attached-subapps.md) 在 os、network 上的适用

## 背景

1. ADR 0116 决策 4 的挂法表是先来后到的产物：数据结构、算法、操作系统、计算机网络先为
   软设而建，本体留在 software；组成原理在 408 已定后立项，本体直接挂 cs408。五门 408
   科目课于是有两种相反的表达——一门「本体在考研圈、软设引用」，四门「本体在计算机圈、
   考研引用」。这种不对称不代表哪个考试更重要，只记录了谁先立项。
2. tiger 定下挂法原则：**优先级高的分组有权夺走优先级低或权重低的分组的节点**。
3. 权重的事实判据——考试把这门课当什么：
   - 408 里，这五门课各自是独立科目（数据结构 45 分、组成原理 45 分、操作系统 35 分、
     计算机网络 25 分，算法设计是数据结构卷的第 41、42 题大题），整门课就是考试范围；
   - 软件设计师里，它们只是第 3、4、8、10 章的承接，占一门考试的部分章节。
   整课必考重于章节承接，所以 408 对这五门课权重更高。

## 决策

1. **挂法原则（夺走规则）**：一门课同时服务多个考试时，本体（`parent`）归权重更高的
   考试，其余考试以引用节点（`also_under`）承接。本体只有一份，「夺走」在数据上就是
   `parent` 与 `also_under` 的对调；引用节点同 id、同图标、点开是同一个进程、同一份
   进度（ADR 0116 机制照旧），被夺走的一侧功能上没有损失。
2. **五门 408 科目课全部本体挂 cs408**：

   | 课程 | 主挂靠 `parent` | 引用 `also_under` | 承接 |
   |---|---|---|---|
   | data-structures | cs408 | software | 408 数据结构 45 分；软设第 3 章 |
   | algorithms | cs408 | software | 408 第 41、42 题算法设计；软设第 8 章 |
   | organization | cs408 | software | 不变（0116 已定）；软设第 1 章 |
   | os | cs408 | software | 408 操作系统 35 分；软设第 4 章 |
   | network | cs408 | software | 408 计算机网络 25 分；软设第 10 章 |

   organization 本次不动——0116 已经把它放对了，本次是把其余四门统一成同一方向。
3. **软设的承接不缩水**：课程树文字指引、分工（承接章的理论侧讲解、viz 演示与纸笔考核
   留在软件设计师，实验留在课程应用）全部照旧；软设外圈的五个节点从真挂靠变引用，连线
   淡一档——正好表达「主场在 408，这里借来承接」。
4. **非 408 科目的实践子课程不动**：database、design-patterns 只服务软设，不构成争夺，
   照 ADR 0103 挂 software；firmware、microcontroller、rtos 照旧挂 embedded。
5. **启动器零代码改动**：布局只由清单决定（ADR 0083、0116 决策 6），数据对调后考研
   扇区的 cs408 外圈挂着五门课本体（实线挂靠），计算机扇区同五门变引用节点（淡线）。
6. **权重序只裁决这一对**：本次只定 408 > 软件设计师。以后别的考试对再争一节课，按
   同一判据（整课必考 > 章节承接）裁决后补进决策 2 的表；不引入显式的「分组权重」
   字段——一个场景用清单数据就能表达，第二个场景出现时再议。

## 后果

- 考研圈成为 22408 专业课的完整入口：cs408 外圈直接挂五门科目课本体，不用先知道
  「本体在软设」才能找到课。
- 软件设计师外圈五门课变引用节点：点开、进度、内容都不变；思维导图上一眼可见这五门课
  的主场在考研。
- 挂法表此后只有一个方向；新增课程与考试的重叠时，先按权重判据定 `parent`，再写引用。
- 顺带同步文档：organization `AGENTS.md` 里 0116 落地时漏改的「不设 parent、计算机圈」
  表述，REPOSITORY.md 结构树里 dsa 拆分（ADR 0108）后未更新的过时行。
