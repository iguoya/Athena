# ADR 0175：新增顶层目录 `self-study/`——自考本科数学三课（线性代数、高等数学、概率统计）

- 日期：2026-10-21
- 状态：已接受（使用者要求：「我打算通过中国自考本科的学习考试……编写线性代数和高等数学的
  自考版本的数学教材，有余力的话把概率论数理统计的自考版教案也编写了，严格参考官方教材和
  官方真题」。目录归类、id 与教材对准按仓库判据与 ADR 0149 先例推定；使用者尚未逐项确认
  这些细节，落地先按本条执行，报考省份/专业确定后如有出入以新 ADR 修订）
- 关系：沿用 [ADR 0149](0149-postgraduate-directory.md)「圈里应用同属一个考试目标时目录与
  分组合一」的先例与做法；沿用 [ADR 0142、0147](0147-exam-apps-into-certification.md) 的
  「一门应用绑定一门真实考试」；出处分档按 [ADR 0043、0089](0089-source-tiers.md)；
  壳用 [ADR 0161](0161-shared-course-shell-crate.md) 的共用课程壳，更新器按
  [ADR 0172](0172-app-updater-for-all-tauri-apps.md)；真题入库按 [ADR 0159](0159-public-domain-by-default.md)；
  内容三不走 [ADR 0028](0028-three-layers.md)，宁缺毋滥按 [ADR 0129](0129-quality-over-quantity.md)

## 背景

使用者备考高等教育自学考试本科（自考），需要线性代数与高等数学的自考版教材，之后再加
概率论与数理统计。三门都是全国统考的公共课，对着真实外部考试，判分内容必须有可核对的出处。

自考正处于考试计划课改过渡期（2024 年起各省陆续执行新专业计划）：线性代数（工）新代码
13175（旧 02198）、概率论与数理统计（工）新代码 13174（旧 02197，另顶替工程数学 10993 的
概率部分），各省过渡节奏与顶替规则不同。数学内容本身在新旧计划间几乎不变，教材版本稳定：

| 课程 | 新代码 / 旧代码 | 指定教材（全国考委组编） |
|---|---|---|
| 线性代数（工） | 13175 / 02198 | 申亚男、卢刚主编，北京大学出版社 2023 年版，附考纲 |
| 高等数学（工本） | 00023（新计划各省过渡中，代码以省考试院为准） | 陈兆斗等主编，北京大学出版社 2023 年版，附考纲 |
| 概率论与数理统计（工） | 13174 / 02197 | 孙洪祥、张志刚主编，北京大学出版社 2023 年版 |

高等数学（工本）2023 年版全书六章（空间解析几何与向量代数、多元函数微分学、重积分、
曲线积分与曲面积分、常微分方程、无穷级数），不含一元微积分——一元微积分是本课程的先修，
在专科段高等数学（工专）里。

## 决策

1. **新增顶层目录 `self-study/`**，装自考应用；`group` 为「自考」。不挂 `certification/`：
   那里是职业资格考证（驾考、软考、嵌入），自考是学历考试，圈不同；「自考」这一圈与
   「考研」（ADR 0149）同理不跨目录——圈里应用同属一个考试目标（同一张自考本科专业
   考试计划），目录和分组合成一回事。未来自考的其他课程（离散数学、专业课等）都进这个目录。
2. **规划三个应用，一门课一个应用**（同 certification/ 的「一门应用绑一门考试」）：
   - `self-study/linear-algebra`：线性代数（工）；id `linear-algebra`，进程
     `athena-linear-algebra`，知识点前缀 `linalg.`，dev 端口 1524。
   - `self-study/advanced-mathematics`：高等数学（工本）；id `advanced-mathematics`，
     进程 `athena-advanced-mathematics`，前缀 `advmath.`，端口 1525。
   - `self-study/probability-statistics`：概率论与数理统计（工）；id `probability-statistics`，
     进程 `athena-probability-statistics`，前缀 `probstat.`，端口 1526。**分期落地**：
     本条批准三个应用的结构与前缀，但概率统计应用按宁缺毋滥（ADR 0129）等前两门有第一批
     可交付内容后再建，不落空骨架。
   - id 取裸课名，语境由目录限定（同 `postgraduate/mathematics` 的先例）；目录名用英文
     `self-study`（自学考试通行英译 Self-taught/self-study Examination），不用拼音。
3. **都是学习应用、出处档位 `exam`**（ADR 0043、0089）：判分内容必须有真实可查的出处且
   检查阻断。出处主体是**历年真题**（`verbatim` 记年份、月份卷次与题号）与官方教材例题
   （记教材节号与例题号）；改编题标 `adapted` 并写明改动；自造题标 `authored` 并写明
   外部覆盖不到的理由，受配额约束。真题按公域直接入库（ADR 0159），整卷存
   `content/exams/`（年份-月、题目、答案与评分参考），出处指向它。
4. **对准「理工类（工）」组合**：使用者是程序员背景，按计算机类自考本科的典型组合准备
   （高数工本 + 线代工 + 概率统计工）；「工」类比「经管类」内容更深，向下覆盖。若后续
   报考专业落在经管类，再按新 ADR 调整对准。课改过渡期的新旧代码在应用内**并记**
   （如 `13175 / 02198`），具体报考以考生所在省考试院当年的课程安排表为准，应用不替
   使用者断言某省用哪个代码。
5. **内容形态是自编教案，不是教材精读**（区别于 `guide/`）：官方教材是版权出版物，
   不逐字复制原文、不做段落指纹同步；章节结构与编号跟随官方教材目录与考纲
   （`textbook_ref` 与 `syllabus_ref` 必填，界面上显著显示、可反查），讲解文字全部自编。
   一元微积分对高数工本是先修（`prereq` 层），不在本课考纲内不铺开讲。
6. **方法原型**（ADR 0113）：主**问题解决**（先自己动笔算，再看分步解答——自考数学
   试卷就是计算题与证明题的现场），辅**检索强化**（节首考点自测、跨章混合的错题回顾）。
   每节至少一个可提取动作，出现在揭示内容之前；真题练习默认跨知识点混合组卷。
7. **技术栈与壳**：Tauri 2 + React + KaTeX（本地打包）；Rust 壳用共用课程壳
   `athena_course_shell`（ADR 0161），更新器按 ADR 0172 接入。进度库自建（ADR 0037、
   0155），`app.json` 声明 `progress`（`mastery`、`quiz_picks` 两张表，`lww`）。
8. **登记**：`docs/REPOSITORY.md` 结构树与名字表、根 `README.md`、根 `AGENTS.md`
   （结构块与考试档清单）、`docs/TEACHING.md` 考试档清单、`docs/LEARNING-METHODS.md`
   方法画像表、根 `scripts/check.py` 的 `APP_ROOTS`、`pnpm-workspace.yaml`、根
   `Cargo.toml` 成员、`.github/workflows/ci.yml`。启动器不用改代码。

## 后果

- 「自考」成为新的顶层分组目录，启动器思维导图出现「自考」圈；目录名 `self-study`
  是首个带连字符的考试类目录（`artificial-intelligence` 先例）。
- 三门课的章级结构跟随 2023 年版教材目录；**节级结构与编号在逐章编写时与教材实物核对**，
  发现与互联网二手资料不符时以版权页目录为准并就地修正。
- 真题整卷入库的工作量集中且琐碎，适合拆给协作代理分年分卷整理（见 comms 舱任务书）；
  每道题入库时必须带答案与评分参考，不带的不入库。
- 高数工本不含一元微积分：若使用者专科段未修过高等数学（工专），先修缺口在本应用内以
  `prereq` 层补，不为此扩进考纲内容。
- 课改过渡结束、各省代码稳定后，应用内的课程代码并记可按新 ADR 收敛为单一代码。
