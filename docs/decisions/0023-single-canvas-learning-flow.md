# ADR 0023：单画布连续学习流与分阶段实验界面

- 日期：2026-09-04
- 状态：已接受，分阶段实施中
- 依据：`AGENTS.md` 的学习闭环与分层约束；
  `docs/LEARNING_WORKSPACE_PROPOSAL.md`；
  `docs/LEARNING_WORKSPACE_FLOW_SKETCH.html`；
  对 ADR 0020 / 0022 原型的实际使用反馈

## 背景

ADR 0020 先尝试让文档与实验左右同屏，文档约占 58%，实验坞约占 42%。这种布局让
两边各自形成一套长内容和滚动位置，学习者需要在正文、整章源码和运行结果之间反复
搜索对应关系。ADR 0022 随后把文档恢复成独占页面，把实验迁进模态窗口；它解决了
面积不足，却又打断了文档上下文，而且实验窗口内部仍是“左侧整章源码、右侧目标与
结果”的工具型分栏。

这两种形态都能完成“打开源码并运行”，但没有把项目已经定义的学习闭环直接表达成
界面顺序。Athena 的默认形态不应是文档阅读器旁边附一套小型 IDE，而应让一个知识点的
问题、判断、行动、证据与修正沿同一条主线展开。

## 决策

### 1. 默认采用单画布连续学习流

主窗口同一时刻只保留一个主要任务区域。知识点的认知顺序是：

```text
核心问题 → 思想与边界 → 形成预期 → 真实源码 → 运行 → 观察结果 → 对照修正 → 自测
```

- 全局目录只负责定位与学习状态，可以收起，不与主内容竞争宽度。
- 源码与结果按纵向相邻排列；结果紧跟产生它的源码，不再作为常驻右栏。
- 默认聚焦当前成员函数，同时保留查看整章真实源码的能力，不把教学代码复制进 UI。
- 预测是后续增强，是可跳过的软引导；第一阶段不为追求完整形态一次性增加新数据模型。

### 2. 分阶段从低风险布局调整开始

#### 阶段一：纵向实验窗口

保留现有 `ExperimentDialog`、`ExperimentDock`、运行线程与稳定 `function_id` 结果保护，
只把实验窗口从左右分栏调整为：

```text
当前实验与验证目标
真实源码
运行操作与状态
观察结果
```

这一步不改变执行、存储、跨平台渲染或文档链接协议，用最小风险先验证纵向证据链的
阅读体验。

#### 阶段二：同窗口专注实验页

确认阶段一方向有效后，再把实验从模态窗口迁入主内容 `Gtk::Stack` 的专注状态：

- 文档小节末尾的实验入口切换到专注实验页；
- 顶部“返回原文”恢复原来的文档、锚点和滚动位置；
- `ArticleView` 保持常驻，不因切换反复创建 WKWebView / WebKitGTK；
- 跨页行为继续经 `MainWindow` 协调，下层模块不反向持有窗口。

#### 阶段三：闭环增强

只在前两阶段的真实使用证明有价值后，再加入可跳过的预测、预期与语义结论对照、
针对具体偏差的 AI 解释等能力。运行输出只是观察证据，不能替代正确 C++ 语义成为判定
依据。

### 3. 移除运行历史功能

运行历史的双记录源码/输出比较偏向版本审计，与“当前问题 → 当前实验 → 当前证据 →
修正理解”的主闭环关系较弱；同时它给知识点行增加操作噪音，让每次实验额外抓取源码
快照和 Git 状态，并持续追加数据库记录。

因此移除运行历史入口、对话框、运行时记录和新数据库建表逻辑。已有用户数据库中的
`run_history` 表不执行 `DROP TABLE`，历史数据原样保留，避免不可逆删除；新版本只是不再
读取和追加它。SQLite 继续用于熟练度、AI 讲解缓存和应用设置。

## 与既有 ADR 的关系

- 取代 ADR 0020 的左右工作台布局，但保留“文档发起、实验响应”和 `teaches` 映射。
- 取代 ADR 0022 的最终左右实验窗口及“文档窗口 → 模态实验窗口”终态；阶段一暂时复用
  该窗口作为低风险过渡。
- 保留 ADR 0014 / 0016 已完成的模块边界。移除 `HistoryDialog` 后，
  `LearningDialogs` 仍作为设置、AI 讲解和 AI 自测的轻量门面。
- 修订 ADR 0009 的运行历史范围，但不改变 SQLite 技术选择。

## 后果

- 界面顺序与学习闭环一致，源码、输出和反馈不再形成相互竞争的平行轨道。
- 阶段一可以单独构建、测试和体验，不必先解决 WebView 与 GTK 控件的内联组合问题。
- 阶段二涉及顶层页面状态和返回锚点，必须在 macOS 与 Ubuntu 分别验证 ArticleView
  生命周期、长文档滚动恢复、焦点和窗口尺寸。
- 运行历史旧数据仍占用少量磁盘；这是用可恢复性换取安全迁移的有意选择。
