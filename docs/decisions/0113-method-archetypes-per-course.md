## 背景

0096 定了所有学习应用共用的地基（检索、间隔、交错为主，自我解释、双重编码为辅），
LEARNING-METHODS.md 按数学、语言、考试、编程四大类做了领域展开。但两处缺口仍在：

1. **课程数量已远超四大类**。0103/0106/0108/0109 之后有了 data-structures、
   algorithms、os、rtos、network、database、design-patterns、linux、
   firmware、microcontroller 等子课程，它们的学习对象差别很大：有的要「看见看不见
   的过程」（调度、封包），有的要「真跑出结果」（SQL、shell、硬件），有的要
   「在相似选项间做判断」（设计模式、算法范式）。只套「编程类」一张表，会让 os
   和 design-patterns 用同一种界面骨架。
2. **专注力没有落到界面上**。注意力相关的实证结论（任务切换成本、目标设定与执行
   意图、有界的工作块）至今只是学习者的个人习惯，界面没有对应的设计约束；而
   「无限刷」「弹窗打断」恰恰是软件最容易犯的错。

## 决策

### A. 七种方法原型

一种原型 = 主导方法 + 学习单元骨架（界面块顺序）+ 主提取题型 + 明确不做的事。
0096 的三项主策略在每个原型里都在，差别在**以什么形态出现**。

| 原型 | 适合的学习对象 | 主导方法 | 学习单元骨架 | 主提取题型 | 不做 |
|---|---|---|---|---|---|
| **R 检索强化** | 规则、事实、考点（考试知识） | 检索 + 间隔 + 同考点变式交错 + 全真模拟 | 首页即今日到期复习；讲解退为第二层，题后解析给错因 | 有出处真题、同考点变式、整卷限时 | 把讲解当主入口；只给对错不给错因 |
| **P 预测–运行** | 代码语义、程序行为 | PRIMM（预测→运行→调查→修改→创作）+ 样例撤除 | 代码 → 预测框（必填）→ 运行 → 对照 → 改一处再跑 → 骨架实验 | 输出预测、trace 状态表、Parsons 排序、填空、骨架实验 | 先给运行结果再问为什么；白板实验 |
| **M 机制模拟** | 看不见的过程（调度、置换、封包、时序） | 双重编码 + 先预测后模拟 + 计算题检索 | 情境 → 预测结果 → 模拟器单步 → 偏差解释 → 换参数再算 | 计算题（甘特、缺页数、子网）、单步预测「下一步是什么」 | 只播动画不要求预测；静态图冒充活图 |
| **E 真做校验** | 真实工具与设备上的操作 | 刻意练习的操作结构（明确目标 + 即时真实反馈 + 针对弱点重复）+ 骨架 | 任务卡（目标 + 预期结果）→ 编辑器/终端/板子 → 自动比对 → 错因 → 同类再练 | SQL 结果集比对、命令输出比对、编译运行校验、上板现象预测 | 只演示不让做；做了不校验 |
| **D 辨析决策** | 相似选项间的判断（模式、范式、协议、范式级别） | 交错（类别辨析证据最强）+ 正反例并排 + 精细提问 | 两三个易混对象并排对比 → 混合情境判别 → 要求写依据 | 「这是哪种 / 该用哪种」的混合判别题，相似项必须同卷出现 | 按类别一块块学完再测；只记定义不练判别 |
| **S 问题解决** | 数学方法与推理 | 样例撤除 + 交错组卷 + 分级提示梯（Pólya）+ 错误样例 + 多表征 | 完整样例 → 缺步样例 → 独立题，卡住时逐级展开提示 | 交错组卷、找错改错、多表征互译 | 一章题型成串刷；直接给答案 |
| **L 语言习得** | 词汇、语块、读写听说 | 可理解输入 + 语块间隔重复 + 输出 + 泛读 | 语境先行（先句后义）→ 输出任务 → 对照参考 | 语境回忆卡、翻译/写作任务、分级阅读 | 孤立背单词；只输入不输出 |

### B. 选型规则

1. **每个学习应用声明一个主原型、至多两个辅原型**，写进本应用 `AGENTS.md` 的
   定位节（一句话即可），各应用初版画像见 LEARNING-METHODS.md。
2. **按章节选，不按应用一刀切**：同一应用里不同章可落不同原型。软考两应用用 0107
   三维评级定章节原型——实验性高 → M；实践性高 → 计算题变式（R 的变式形态）；
   三维都低（如软设第 11、12 章）→ 纯 R 检索卡。
3. **原型决定界面骨架与题型优先级，不决定题源**：出处规范（0043、0089）不变。规则
   封闭的计算题可由**确定性生成器**出参数变式（答案由代码算出、生成器进版本库），
   这不是 AI 现场出题；但它不替代有出处的真题，考试档判分范围仍由各应用 ADR 定。
4. **辅原型不得稀释主原型**：一节里主提取形态占多数，辅形态是台阶或补充；
   「每节都配齐七种」正是 ADR 0040 反对的八股。

### C. 0096 的补充机制（新增，不改原条款）

5. **前测效应**：新章开头可放一两道不计分的预测题（不写掌握度），把「先问后讲」从
   节级扩到章级。c-plus-plus 的 `scored=false` predict 块是现成形态。
6. **专长反转**：样例对新手有益，对已掌握者是负担。样例撤除序列按作答记录自适应——
   某知识点已连对，跳过完整样例直接给独立题。属 0096 成本第 3 档，各应用排期。
7. **流畅性错觉**：「看懂了」不等于「会了」。界面不设「已掌握 / 看懂了」自评按钮
   （与 ADR 0052、LEARNING-METHODS P5 同一结论，此处补机制）。
8. **刻意练习的采纳口径**：只取「明确目标 + 即时反馈 + 针对弱点重复」这一操作结构
   （E 原型）；Macnamara 等 2014 元分析显示它在教育领域解释的成绩差异有限，故不采纳
   「一万小时」类说法，也不以练习时长作为任何激励指标。

### D. 专注：会话形态的三条界面原则

接在 LEARNING-METHODS P1–P5 之后，编号 P6–P8：

9. **P6 有界会话**：学习以「一轮」为单位。开始前显示本轮内容与题量（到期复习 N 题
   + 新内容一节），完成有明确结束页，不做无限流。轮次大小按 25–50 分钟可完成来定，
   各应用自校（driver 一轮 50 题是先例）。依据：具体目标与执行意图（Gollwitzer &
   Sheeran 2006）。
10. **P7 作答视图零打扰**：讲解与作答视图里不放与当前任务无关的入口、动画、弹窗；
    激励（0052）照记，但集中在轮次结束页展示，不在作答中途打断。依据：任务切换
    成本（Monsell 2003）。
11. **P8 收尾自由回忆（可选）**：轮次结束页可提供「凭记忆写下本轮要点」的输入框，
    提交后才展示本轮知识点清单供对照；不评分、不写掌握度。依据：自由回忆是检索
    练习的一种（Karpicke & Blunt 2011）。
12. **不做**：番茄钟计时器、冥想、睡眠与运动提醒、强制锁屏。环境设计（手机离开
    房间、关通知）和作息是学习者自己的事，不是课程软件的职责；界面能做的只是
    「不制造干扰」与「给出清楚的边界」。

### E. 不做自动门禁

13. 与 0096 决策 14 一致：原型是设计判据，`check.py` 不新增检查位。评审时多问一句：
    「这一节属于哪个原型，骨架和题型对得上吗？」

## 后果

- 新课程（尤其子课程）开工时先定原型，再定界面块与题型，不再默认照搬隔壁应用。
- os、rtos、network 的模拟器必须带「先预测」入口；database、linux 的实验
  必须带自动比对；design-patterns、algorithms 的练习必须混合相似项——这是三类最
  容易做偏的地方。
- 专注从个人习惯变为可评审的界面约束（P6–P8），但只约束软件「别添乱」，不越界做
  健康管理。
- 改造按 0096 的成本五档推进，宁增勿删（ADR 0054）：存量页面不专项回改，新写与
  正在改的页面按原型落。
