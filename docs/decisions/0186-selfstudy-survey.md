# ADR 0186：自考专业调查——`mentor/` 新增 `selfstudy-survey`（计算机、电子信息类自考本科全国调查）

- 日期：2026-10-24
- 状态：已接受（使用者要求：开发一个应用，调查截至 2025–2026 年全国各省份「弱电」方向的自考本科——计算机、电子信息等大类下的专业，
  含开设的专业课、实践课、参考教材，从多个角度提供调查与参考；界面布局与内容编排自行设计，与 zcode 分工讨论，并做大方向规划）
- 关系：按 [ADR 0144](0144-mentor-directory.md) 的三类判据归「图谱/参考类」，落 `mentor/`；形态与数据纪律取
  [ADR 0114](0114-competitions-group.md)（赛历：事实数据必带核对信息）和 [ADR 0174](0174-mathematics-compass-in-mentor.md)
  （构建期内容打进前端的薄壳）；`group` 并入 [ADR 0175](0175-self-study-math-exam-apps.md) 之后的「自考」圈；
  协作机制 [ADR 0165](0165-agent-comms-service.md)；宁缺毋滥 [ADR 0129](0129-prefer-quality-over-quantity.md)；公域口径
  [ADR 0159](0159-jiuzhou-academic-layer-in-repo.md)；约束不继承 [ADR 0062](0062-apps-own-their-constraints.md)

## 背景

「自考」圈目前是三个学习应用（线代、高数、概率统计）加两个视频课，全是公共数学课，**没有任何一份回答「这条路本身长什么样」**：
各省开了哪些计算机、电子信息类本科专业？谁主考？考哪些课、几个学分？有没有实践课与毕业设计？教材是什么？
这些信息分散在 31 个省级教育考试院、几十所主考院校和一堆第三方自考网里，口径不一、版本混杂，新旧计划并存
（例如广东 2026 年起另有新计划、江苏计算机 2021 版与 2024 版并存、思政课代码已由 03708/03709 换成 15040/15043/15044）。
使用者要做的是**摸清全国格局并给出可比较的参考**，不是学某一门课。

三类判据：主问题是「要不要教会人什么、要不要证明学习者进步了」——否。只呈现信息供查阅、比较和决策 → **图谱/参考类**，
不建进度库、不建出处契约（`content-contract.json`），跨应用教学规范不生效。

## 决策

1. **新增 `mentor/selfstudy-survey`，界面名「自考专业调查」。** 目录 `mentor/selfstudy-survey`，`group` 为「自考」，
   进程 `athena-selfstudy-survey`，dev 端口 1535（hmr 11535），环境变量 `ATHENA_SELFSTUDY_SURVEY_ROOT`，数据目录名
   `AthenaSelfstudySurvey`（薄壳不建数据，仅占名）。不建进度库、不建知识点前缀。
2. **调查范围**（「弱电」不是自考的官方分类，这里落成可操作的口径）：
   - 层次：**本科**（独立本科段与专科起点本科；统称自考本科）。专科只作为「报考门槛 / 衔接」一栏记录，不调查专科计划。
   - 专业类：核心两类——`0809` 计算机类、`0807` 电子信息类；边缘一类——`0808` 自动化类（只收各省实际开考的，作对照）。
     `0806` 电气类以强电为主，**不收**，导引里一句话说明边界。
   - 专业清单以教育部本科专业目录为准，`scope.json` 逐个登记；是否在某省开考由开设矩阵回答，不预先假设。
   - 时间：**截至 2025–2026**，即 2025 年 4 月、10 月，2026 年 4 月、10 月四个考期的现行计划；每份计划标明版本与生效考期；
     新旧计划并存的如实并列，不合并。
3. **调查角度**（决定数据模型与界面）：
   | 角度 | 回答的问题 |
   |---|---|
   | 开设格局 | 省 × 专业：开考 / 停考 / 新计划 / 未开 / 待查 |
   | 主考院校 | 谁主考，在哪个层次 |
   | 课程计划 | 公共课、专业基础、专业核心、选考；学分与门数、总学分与毕业学分 |
   | 实践环节 | 课程内实践考核、独立实践课、毕业设计（论文）与答辩、实践考核的时间与方式 |
   | 教材与大纲 | 每门课的指定教材（书名、作者、出版社、版次）与考试大纲来源，全国统编 / 主考院校 / 省编 |
   | 报考与毕业 | 专科起点要求、考期与报名、毕业学分、学位授予条件（含学位英语）、课程免考与互认 |
   | 变动 | 新旧计划切换、停考、课程代码更换，按时间排列 |
   | 课程对照 | 同一门课跨省的代码、学分、实践要求差异；课程与 Athena 已有课程的对应（只写显示名，ADR 0032） |
   官方不公布的（通过率、难度）**不做估计**，只在方法页注明「无官方数据」，不引第三方的臆测数字。
4. **数据纪律沿赛历（ADR 0114），并按本领域加严**：
   - 每条事实数据带 `verify`：`level` ∈ `official`（省考试院或主考院校原文）/ `notice`（教育部考试中心、各省自考官方门户或官方转发）/
     `report`（第三方自考网转载，只作线索，**不得单独支撑「课程表」类结论**）/ `pending`（没查过）；非 `pending` 必须有 https 来源与
     `YYYY-MM-DD` 核对日期；`pending` 不得带来源或日期。查不到就标 `pending`，**绝不凭印象或相邻省份推断补空**。
   - 课程表（`plans`）只收 `official` 或 `notice`；`report` 级信息只能落在开设矩阵的线索栏，等待升级。
   - 核对超过一年的数据界面标「可能过期」；每个考期换版时重核。
   - 原始证据（页面文本快照、PDF）放协作舱 `comms/selfstudy-survey/artifacts/`，**不进应用目录**；应用目录只放结构化结论加来源链接。
     来源页面 sha256 与抓取日期写在证据清单里，供抽查。
5. **数据模型**（`content/*.json`，每份文件头 `_` 写字段含义；详细字段见 `comms/selfstudy-survey/artifacts/claude-code/DESIGN.md`）：
   `scope`（专业类与专业）、`provinces`（31 个省级行政区的考试院、考期、政策）、`offerings`（省 × 专业 × 方向的开设状态与主考院校）、
   `plans`（一份具体计划：版本、总学分、课程行、毕业环节）、`courses`（按课程代码的课程库，含 Athena 对应）、`textbooks`（教材）、
   `events`（变动）。课程行引用课程库，教材引用教材库——同一组东西不写两遍。
6. **界面与内容编排**：Tauri 2 + React + Tailwind v4 薄壳（渲染栈按摘星基线，ADR 0138），数据构建期打进前端，
   Rust 侧只开窗口。左侧导航分八个视图：总览（含省 × 专业覆盖矩阵与「核对覆盖率」）、专业、省份、课程、教材、实践环节、变动、方法与来源。
   跨省比较是本应用的主价值，因此「专业」视图里有课程对比矩阵（行是课程、列是省 / 计划），其余视图为这张矩阵服务。
   覆盖不全时**如实显示「待查」**，覆盖率比漂亮的整图更重要。
7. **协作**：开协作舱 `comms/selfstudy-survey/`，leader 为 claude-code（负责本 ADR、数据模型、采集规程、应用与验收），
   worker 为 zcode（按规程逐省采集、交证据与结构化草稿）；cursor 暂不入舱（额度问题，见舱 README）。
   采集分波次：波 A 省份基线 → 波 B 开设矩阵 → 波 C 逐省课程计划（先试点五省再铺开）→ 波 D 教材与大纲。
   验收由 leader 抽查**原文**逐条核对，不凭记忆（核对已下载原文，不是转述）。
8. **第一批可交付内容**（ADR 0129 不建空壳）：`scope` 全量、31 省基线、至少三份核对到原文的试点计划（广东、江苏各一，覆盖计算机与电子信息各一）、
   对应的课程库与教材条目。其余格子如实标 `pending`，随舱内采集波次逐步升级。

## 后果

- 新增一个图谱/参考类应用与一个协作舱；登记 `docs/REPOSITORY.md`（结构树，`mentor/` 一行）、根 `README.md` 应用表、根 `AGENTS.md` 结构树。
  不建 CI 构建矩阵项以外的发布配置，随图谱类惯例；CI 登记照 `mathematics-compass` 的做法。
- 数据会过时，且过时得很快（每个考期换计划）。同步义务写进应用 `AGENTS.md`：`updated` 是最后一次整体核对日期；
  单条数据的 `verify.date` 才是该条可信度的依据。
- 风险：来源页面改版 / 下架；各省口径不一导致字段硬塞——模型允许 `note` 与 `track`（方向）兜底，但不允许把无法确认的信息写成确定值。
- 本应用不教课，也不替人决定该报哪个专业；「选择参考」一栏只列事实对照与取舍维度，不下推荐结论（与数学罗盘「给唯一路径」不同：
  这里的事实随省份、人的背景差异巨大，唯一推荐会误导）。
