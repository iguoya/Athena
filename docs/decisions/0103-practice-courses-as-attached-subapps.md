# ADR 0103：实践性课程按子课程单元独立成挂靠子应用——软件设计师与嵌入式系统设计师细分

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「以子课程为单元划分」「实践性强的课程、类似
  数据结构这种，才有必要」「根据不同的节点采用不同的合适的技术架构」「先不考虑
  内容填充问题」）
- 关系：收窄 [ADR 0091](0091-experiments-inside-subject-apps.md) 决策 1 的适用
  范围（强实践课程不再由考试应用的 lab 块独占承接）；挂靠机制、单父与一层深度
  沿 [ADR 0092](0092-launcher-tree-attach-and-softcert-rename.md)、
  [ADR 0099](0099-dsa-reattach.md)；名字规则延续
  [ADR 0097](0097-spell-out-app-ids.md)、[ADR 0100](0100-single-word-app-ids.md)；
  大类与领域圈语义见 [ADR 0102](0102-exam-apps-as-top-level-groups.md)、
  [ADR 0101](0101-domain-circle-siblings-no-links.md)；章节实践评级依据
  software [docs/content-plan.md](../../subjects/software/docs/content-plan.md)

## 背景

1. content-plan（2026-10-09，tiger 修订口径）把两门考试的章节按实践路径评级：
   实践只有两条路径——A 真硬件实验、B 独立技术体系真编码/真执行。软件设计师
   第 2、3、4、5、7、8、9、10 章与嵌入式第 2、4、5、6、8、9、11 章实践性强，
   其余为理论侧。
2. ADR 0091 当时决定：实验能力长在学科应用内，不另建独立实验应用；唯一拆出去
   的是 algorithm（数据结构与算法）——它承接软设第 3、8 章编码实验，挂靠
   software（ADR 0092 决策 4、0099 恢复挂靠），自带 C++ 即时编译实验体系，
   可单独使用。algorithm 证明了一件事：**一门实践性强的课程，以独立应用承载
   （自己的技术架构、自己的实验引擎、挂靠考试应用）比内嵌实验块更成体系**。
3. tiger 2026-10-10 提出细分：软件设计师与嵌入式系统设计师都以子课程为单元
   细分子节点，判据是「具有独立可验证、可实践、在信息世界或现实世界有具体
   产出的课程」，类似数据结构与算法；不同节点采用不同的合适技术架构；先不
   考虑内容填充。

## 决策

1. **细分判据，三条同时满足才独立**：
   - **以子课程为单元**——不是按章拆（同一门课程横跨多章的实验归一个应用），
     也不是按实验介质拆（介质决定技术，不决定课程边界，见决策 3）；
   - **实践性强**——content-plan 评级 B ✓✓ 及以上，或路径 A（真硬件）；
   - **有具体产出**——实验产物是可运行、可校验的东西：SQL 结果集、编译通过的
     程序、真实串口字节。纸笔计算题、记忆测验不产生产出，不算。
2. **新增六个挂靠子应用**（都在 `subjects/`，都是学习应用，单父一层挂靠，
   壳一律 Tauri 2，构建完全隔离 ADR 0032）：

   | id | title | group（领域圈） | parent | 承接 | 实验引擎（本应用自有） | 端口 |
   |---|---|---|---|---|---|---|
   | database | 数据库 | 数据库 | software | 软设第 9 章 | rusqlite 嵌进程执行 SQL，结果集比对判分 | 1490 |
   | design-patterns | 设计模式 | 设计模式 | software | 软设第 7 章 | 本机 g++ 编译运行模式代码，输出与结构断言 | 1491 |
   | operating-system | 操作系统 | 操作系统 | software | 软设第 4 章 | 本机 gcc 真跑 pthread 并发实验 + 调度/页置换模拟引擎 | 1492 |
   | network | 网络与信息安全 | 网络 | software | 软设第 10 章 | Tokio 真 socket 收发（hex 视图）+ 子网计算 + 加密真算 | 1493 |
   | firmware | 嵌入式程序设计 | 嵌入式程序设计 | embedded | 嵌入式第 6、8、11 章 | 本机 gcc 真编译 + 位操作/寄存器可视化 | 1494 |
   | microcontroller | 硬件实验台 | 硬件实验 | embedded | 嵌入式第 2、4、5 章 | serialport 串口终端 + 白名单烧录 + QEMU/交叉编译工具链 | 1495 |

   不满足判据的实践章维持 ADR 0091 的 lab 块路径，长在考试应用内：软设第 2
   （正则）、第 5（单元测试）；嵌入式第 8（模块测试）、第 9（加密真算）。
   理论侧章节不受影响。
3. **前端按考试家族归并，实验引擎按学科甄别**。软设家族四个子应用用
   React（与 software 同体系），嵌入家族两个用 Vue 3 + Tailwind（与 embedded
   同体系）——同一考试的使用者跨子应用界面习惯一致，家族间保持两套体验样本
   的对比格局（ADR 0090 的拆分初衷）。实验引擎则逐应用按学科特点选型（上表
   末列），这是「不同节点采用不同技术架构」的落点：介质与学科决定引擎，家族
   只归并前端壳。
4. **design-patterns 素材坑转正**为学习应用：id 与目录名沿用（0100 决策 4：
   既有连字符名不强制拆改），`docs/` 下 inherited-from-cpp 等素材全部保留为
   内容基础；补齐 app.json、check.py 等全套后，根验证入口不再跳过它。素材坑
   的「设计模式是独立领域」结论（其 README）由本条兑现。
5. **考试应用与子应用分工**（沿 0092 决策 4 的 algorithm 模式）：承接章的
   理论侧讲解、viz 演示与纸笔考核留在考试应用；考试应用课程树在承接章放
   「去〈子应用〉做实验」的内容指引（文字与链接说明，不做代码引用，ADR 0032）。
   子应用都是学习应用：自带 `progress/learning.db`、`AGENTS.md`、`CLAUDE.md`、
   `scripts/check.py`、`content-contract.json`。出处档位 **exam**（ADR 0089）：
   判分实验内容直接对应真实考试教材与真题，实验骨架代码本身不是判分条目。
6. **内容层归属**：子应用知识点 id 前缀用各自短名（`db.`、`dp.`、`os.`、
   `net.`、`fw.`、`mcu.`），与 id 解耦（0097 决策 3 同规）。两考试之间的公共课
   隔离原则（0095 决策 3）对子应用同样成立：同名课程只归实践性更强的一侧，
   另一侧理论保留——嵌入式不另建算法应用，其数据结构理论内容留在 embedded 内；
   嵌入式第 4 章通用 OS 部分的实验由 operating-system 承接（原 course.json 已
   声明的共学关系收窄为文字指引）。
7. **命名**：单词优先——database、network、firmware、microcontroller。
   operating-system 是显式词组例外：单词候选（kernel、process、simulator）
   无一能达课程全意，按 0097「不要词不达意」的动机收完整词组；禁缩写、禁拼音
   的底线不变（0100 决策 4 的「新增应用按单词取」由本条作此补充）。

## 后果

- 应用 +6，领域圈 +6（各为单成员圈，同 algorithm「算法」圈先例）；启动器零
  改动——parent 机制已支持同一挂靠者的多个子应用平分外弧段（0092 决策 2）。
- software 挂五个子应用（algorithm、database、design-patterns、
  operating-system、network，另有 c-gui-lab 的「C 语言技术体系实践出口」挂靠），
  embedded 挂两个（firmware、microcontroller）。数量不对称如实反映两考纲的
  实践分布。
- 六条发布/验证线各自独立；骨架先行（本条落地时只建工程壳与规范文件），
  内容填充按 content-plan 的建设优先级推进：database（SQL，rusqlite 已验证）
  与 firmware（嵌入式 C，零硬件成本）最先。
- ADR 0091 决策 1 的「实验能力长在学科应用内」收窄为：弱实践章与理论侧实验
  仍以 lab 块长在考试应用内；强实践课程按本条独立成子应用。两 ADR 并存，
  各管一段。
- 端口登记：1490–1495 归这批子应用。
- microcontroller 的真硬件部分仍有 ADR 0091 决策 5 的购置前置（入门开发板 +
  ST-Link + USB-TTL）；QEMU/交叉编译路径零硬件可先行，串口实验等板到位。
