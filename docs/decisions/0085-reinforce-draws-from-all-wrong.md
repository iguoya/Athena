# ADR 0085：强化练习从历史上全部错题里按权重抽取（修订 ADR 0076 第 7 条的选题规则）

- 日期：2026-10-03
- 状态：已接受；修订 [ADR 0076](0076-attempt-attribution-and-reinforcement-practice.md) 第 7 条中
  「`retest` 只收最近一次答错的题、固定排序取前几道」「初始配额 retest 40%、weak 30%、due 30%」两处。
  0076 其余部分（作答归因、考点簇、派生统计）与原文不变，原文不改
- 影响：`subjects/driver` 的 `lib/reinforce.dart`、`lib/home.dart`、`lib/reinforce_page.dart`
- 关系：延续 [ADR 0079](0079-clusters-computed-at-runtime.md)（同考点变式）；掌握度仍只由作答写入（ADR 0052）

## 背景

使用者的说法：强化练习应该是**从历史上全部错题组成的整体里抽取**，而不是只盯最近一次的几道错题；
并且题目应当每轮都不一样，现在「似乎不会自动更新」。

核对代码后，现在的做法和这个意思有两处偏差：

1. **错题池太窄。** `retest` 只收「最近一次作答是错的」的题。一道题历史上错过三次，只要后来答对过一次，
   就掉出复测池，之后只能靠「到期复习」碰运气回来。
2. **不是抽取，是取前几名。** 池子按固定顺序排（错得多的先、隔得久的先）然后取前 N 道，池子再大，
   每一轮也总是靠前的那一批；没有随机，所以不更新。

## 决策

1. **错题池 = 历史上答错过至少 1 次的全部题**（在强化练习的可选题池内），不管后来是否答对。
2. **按权重随机不放回地抽。** 权重 = (1 + 累计错次) × 状态系数 × 间隔系数：
   - 状态系数：最近一次还是错的 3.0；已答对的按掌握度——学习中 1.2、巩固 0.8、稳固 0.4；
   - 间隔系数：1 + min(距上次作答天数, 30) / 15，最高 3 倍。
   答对过的题不会消失，只是更少被抽到，所以遗忘也能被抽检到；错得多、最近又错、隔得久的更容易被抽到。
3. **整轮默认全部来自错题池。** 考点簇就绪时，同考点变式占整轮的 1/4（20 题里 5 道），其余是错题池里抽到的题；
   `weak`、`due`、`fill` 只在错题池不够时按 retest、weak、due、variant 的顺序补足，变式不超过名额，
   除非别的都没有了。原来 40 / 30 / 30 的配额取消。
4. **每一轮都重新抽。** 做完一轮（关闭做题台，或离开做题台去别处）自动重抽；强化练习页加「换一批」按钮，
   随时手动重抽。页面停留期间题单保持稳定，不会自己变。
5. **页面说明实情。** 页面写明「错题池共 M 题，本轮抽 N 题」和抽取的依据；没有错题的新学习者仍然
   用薄弱章节的新题，行为不变。
6. 每题每轮最多一次、偏难怪题封顶、科目锁定等既有约束不变（driver ADR 0031、0032、0006）；
   `reason` 取值不变，`retest` 的含义改为「从历史错题池抽到」。

## 后果

- 错题很多时，一轮 20 题只是错题池的一个样本，下一轮是另一个样本；错题少于 20 道时，错题全部出现，
  其余用薄弱章节补。
- 「复测错题 · 转正率」（driver 学习诊断）的口径随之改变：分母是从历史错题池抽到的题，不再只是最近一次答错的题。
  新旧数据混在一起时，历史数据按旧口径记录、不回改。
- 1/4 变式、权重里的几个系数是经验值，没有数据支撑；放在 `lib/reinforce.dart` 开头的常量里，
  用过一段时间后可以按「强化练习成效」的数据再调。
