  哪些体系课程」；优先项选「计算机组成原理」）
- 关系：主原型按 [ADR 0113](0113-method-archetypes-per-course.md)；命名按
  [0100](0100-single-word-app-ids.md)/[0112](0112-network-rename-back.md) 单词优先；
  单父挂靠限制见 [0092](0092-launcher-tree-attach-and-softcert-rename.md)；壳与

## 背景

### 11408 / 0854 对照现有应用

11408 = 101 政治 + 201 英语一 + 301 数学一 + 408（数据结构 45、计算机组成原理 45、
操作系统 35、计算机网络 25）。0854 电子信息初试常见 11408、22408 或院校自命题。

| 科目 | 现有应用 | 缺口 |
|---|---|---|
| 101 政治 | 无 | 整门缺 |
| 201 英语一 | english 是英语二 | 缺；按 0095 是另一场考试，另建 |
| 301 数学一 | mathematics 以数学二为约束，`scope` 预留 `math1` | 概率论与数理统计全缺；数一独有的高数部分（三重积分、曲线曲面积分、场论、傅里叶级数）缺 |
| 408 数据结构 | data-structures（软设第 3 章定位） | 缺 408 算法设计大题与真题层 |
| 408 组成原理 | 无（machine 是程序视角的「C 与机器」） | **整门缺，45 分** |
| 408 操作系统 | os（软设第 4 章实验课） | 缺理论全量与 PV 大题 |
| 408 计算机网络 | network（软设第 10 章） | 缺数据链路层与 TCP 拥塞控制等 |
| 408 整卷 | 无 | 缺考试主应用（真题组卷、整卷模拟） |
| 0854 自命题 | 无 | 电路、信号与系统、模电、数电、通信原理等，待定目标院校再议 |

组成原理是 408 里唯一完全没有承载的一门，分值与数据结构并列最高。

## 决策

1. **新增 `subjects/organization`**：title「计算机组成原理」，group「计算机」（与
   software 同圈），**不设 parent**；端口 1501，进程/二进制 `athena-organization`，
   知识点前缀 `org.`；技术学习类学习应用，出处 open 档，建自己的
   `progress/learning.db`。壳复制 linux 的 Tauri 2 + 本机 C++ 实验架构，此后独立演进。
2. **不挂 software**：软设第 1 章「计算机系统」与本课重叠，但 os、network、
   data-structures 已挂 software，408 主应用将来也要挂它们，单父限制（0092）下
   挂靠关系要在 408 主应用立项时统一决定。现在用课程树文字指引承接软设第 1 章。
3. **章节骨架按 408 考纲七章**：计算机系统概述、数据的表示和运算、存储系统、指令
   系统、中央处理器、总线、输入输出系统。topics 与实验后续填充。
4. **学习方法原型**：主原型**机制模拟**——Cache 映射、虚实地址转换、流水线冒险、
   数据通路都是「看不见的过程」，先预测（命中与否、各段时钟周期、控制信号）再单步
   揭示；辅**预测–运行**——补码溢出、IEEE 754、访存模式对性能的影响，用 C++ 实验
   真跑验证预期。
5. **与 machine 的边界**：machine 从 C 程序往下看（变量在内存里的样子、汇编、调用
   栈）；organization 从硬件往上看（运算器、存储层次、控制器、总线与 I/O）。数据
   表示两边都碰：machine 讲 C 类型的内存表示，organization 讲运算电路、溢出判断与
   规格化。各写各的，不共享代码。
6. **其余缺口记为待办，不在本条立项**：政治、英语一、数学一扩展、408 主应用（连同
   挂靠方案）、0854 自命题课程，各自开工前另立 ADR。

## 后果

- 「计算机」圈多一个顶层应用；启动器零改动。
- 408 四门有了全部落点，408 主应用立项时需处理单父挂靠冲突。
- 根 `AGENTS.md`、`docs/REPOSITORY.md`、`README.md` 应用清单与 CI 矩阵同步登记。
