# ADR 0158：九州本机学术地理层优先，并采纳史图馆 / 谭图系 / 杨利辉的表述手段

- 日期：2026-10-13
- 状态：已接受（使用者确认：自用不分发；Q2B、Q3C、Q4A、Q5B；历史与地理两侧尽量丰富）
- 修订：[ADR 0157](0157-athena-maps-shared-package.md)（学术层从「可选点缀」升为**本机优先主真相**；
  再分发顾虑不约束本机自用路径）
- 衔接：[ADR 0156](0156-jiuzhou-history-atlas.md)

## 背景

1. 使用者要对齐「史图馆」断代色块时间轴、「左图右史 / 舆图」叠谭图与古今对照、以及杨利辉
   地图讲史（古今地名一眼懂、人物落州府、行军线、模块提亮、前后对照）的观感与知识密度。
2. CHGIS / Hartwell / 谭其骧图集数字化成果等**通常禁止再分发**；仓库若公开推送，不得把原始
   或派生矢量 commit 进 git。使用者明确：软件**本机自用、不分发**，因此产品上应吃满这些
   材料，而不是因许可证降级成空白示意。
3. ADR 0157 已定 `@athena/maps` 与「CHGIS 本机可选」；需把优先级与表述手段写死，避免继续
   只堆事件点。

## 决策

1. **本机学术层 = 地理主真相（有则必用）。** 支持来源（择一或叠加，均不入库）：
   - CHGIS / Hartwell（Harvard Dataverse 等官方包），经 `packages/maps` 或应用脚本拉到
     `.cache/maps/`（根 `.gitignore` 已忽略 `.cache`）；
   - 使用者自备的谭图数字化 / GeoJSONcn 类学习包，路径由环境变量
     `ATHENA_MAPS_DATA` 或 `mentor/jiuzhou/.cache/maps/config.json` 指向。
   - 无学术层时静默降级到 `@athena/maps` 公域/自研示意（岸线、河网、走廊）+ 内容里的示意
     疆域帧，**不阻塞启动**。
2. **git 纪律不变：** 禁止把 CHGIS、Hartwell、谭图衍生 GeoJSON/SHP 默认提交；检查与文档写明
   「本机自用、版权自负」（与 0156 一致）。对外若将来要发行，须另立 ADR 收窄数据层。
3. **表述手段（第一期必做，对齐三家）：**
   - **史图馆：** 断代色块；**年份 scrub 为主轴**（可切回事件序列）；自动播放像翻帧。
   - **左图右史 / 舆图：** 古今地名对照（古名显著、今地旁注）；点选地点/政区出卡片（角色、
     存续、相关事件）；可检索飞到点。
   - **杨利辉：** 事件相关州/走廊/河段**模块提亮**；事件可选 `route` 折线；关键节点支持
     **前后对照**（如割让前后两态）；人物以落点标签呈现（头像棋子动画二期）。
4. **实施顺序：** 丰富年层疆域与表述 UI，同时铺公域山河底图；学术包用脚本接入 `.cache`，
   有数据即叠府州/政区面。知识性靠政区与古今对照，趣味性靠提亮、路线与对照，不靠花哨特效。
5. **`@athena/maps` 职责扩展：** 纸本 Style、公域/自研水系岸线、学术层路径约定与 fetch/转换
   脚本；不把事件模型写进包（仍属 jiuzhou `atlas.json`）。

## 后果

- 修订 0157：学术层表述从「可选降级」改为「本机优先」；索引注明由 0158 修订。
- 九州 UI：默认年份轴；双模式；提亮 / route / 对照；侧栏强化地理说明。
- 无 `.cache` 学术数据时仍可用示意层完整浏览——丰富度取决于本机是否准备学术包。
