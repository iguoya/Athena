# ADR 0187：自考专业调查——范围按各省实际开考课程决定，并放宽第三方来源

- 日期：2026-11-03
- 状态：已接受（使用者三次指示：①很多目录专业在真实自考里不存在，不应列举调查；②电子系核心课程（单片机、EDA、数字信号处理、电路、模拟电子等）
  所在的开考专业不要忽略，哪怕只有一所院校开考；③第三方自考网页面可信，可作课程表与结论的来源）
- 关系：修订 [ADR 0186](0186-selfstudy-survey.md) 决策 2（调查范围）与决策 4（来源分级）；其余沿用 0186。公域口径
  [ADR 0159](0159-jiuzhou-academic-layer-in-repo.md)

## 背景

0186 把范围钉在教育部目录的 0807、0809、0808 三类共 50 个专业，另一边把电气类整类排除。实际采集发现：

- 50 个目录专业里 40 个没有任何省开考，界面上全是「待查」「不开设」，调查成本花在不存在的东西上；
- 反过来，自考里带强弱电子核心课程的专业并不都在这三类里：电气工程及其自动化（0806）、机械电子工程、机械设计制造及其自动化、
  车辆工程、汽车服务工程（0802）的开考课程里都有电路分析、模拟/数字电子技术、单片机、微机原理、电力电子、电机等；
- 第三方自考网（自考本科网、华夏大地教育网、山西自考网等）转载的计划、专业与院校一览表，抽查与官方原文对得上（有的就是官方附件原件的转存），
  官网反爬严重的省份（天津、山西、黑龙江）几乎只能靠它们。

## 决策

1. **范围由各省实际开考的课程决定，不再由目录门类反推。** 一个本科专业只要在任一省的开考课程里出现电子系核心课程，就纳入调查，
   不论它在目录里属于哪一类，也不论有几个省、几所院校开考。电子系核心课程的判据（任一专业出现下列课程中的两门及以上）：
   单片机、EDA/VHDL/FPGA、数字信号处理、信号与系统、电路分析、模拟电子技术、数字电子技术/数字电路与逻辑设计、微型计算机原理与接口、
   嵌入式、通信原理、电磁场与电磁波、集成电路、半导体器件、电力电子、电机、传感器、自动控制原理。判据与扫描结果记在
   `comms/selfstudy-survey/artifacts/claude-code/` 的采集脚本里，新专业按同一判据补入。
2. **`scope.json` 增类**：`0806` 电气类（电气工程及其自动化）、`0802` 机械类中带电类课程的专业（机械电子工程、机械设计制造及其自动化、
   车辆工程、汽车服务工程），均为 `edge`。0807、0809 仍为 `core`。2026-11-03 补充：使用者要求新增「机械大类」并把自动化类并入，0808 的专业改归 `0802`「机械大类（含自动化类）」，不再有独立的 0808 类。
3. **界面不穷举不存在的专业。** 左侧菜单、总览矩阵、省份开考表只列：至少 3 个省开设过（开考、新计划、已停考）的专业；
   以及电子相关类（0807、0806、0802）只要有 1 个省开设就列。其余专业不列，采集时也不必为它们逐省查证「不开设」。
   阈值与类写在 `src/data.ts`（`MIN_PROVINCES`、`ALWAYS_CLASSES`），数据增长后自动重算。
   使用者可逐个裁决某专业太小众而不列（`EXCLUDED_MAJORS`，目前只有 080802T 轨道交通信号与控制）：数据保留，界面一律不显示。
4. **来源分级放宽**：`report`（第三方自考网转载）也可作课程表、政策、教材、考期和「不开设」结论的来源，级别照实标，界面显示「第三方转载」，
   官方原文到手后替换；第三方页面有缺字、旧版计划或明显错码时，按课程库与总学分求和复核后再录，不能复核的不录，页面是旧计划的标 `legacy`。

## 后果

- 采集量降下来：不再为 40 个无人开考的专业逐省取证；电类扩展的 5 个专业要按各省总表补开设记录。
- 「不开设」结论的可信度取决于来源；第三方来源写的 none 在备注里标明来源是第三方。
- 目录里没有的自设方向仍登记在 `offerings.track`，不新造专业代码。
