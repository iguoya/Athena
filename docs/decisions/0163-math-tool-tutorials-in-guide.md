# ADR 0163：数学工具教程——一本书或一门课对应一个 `guide/` 应用

- 日期：2026-10-14
- 状态：已接受（使用者要求：结合互联网上成熟的数学工具教材或视频教程，在 `guide/` 里编写绑定该工具的使用教程，
  学 Octave、GeoGebra 这类对线性代数和高等数学有帮助的通用工具，目的是借工具的表现力让两门学科直观化；
  随后补充：一门视频课或一本书绑定一个学习软件，互不干扰；遇到疑问优先自行决定）
- 关系：沿用 [ADR 0143](0143-guide-directory.md)（`guide/` 手册类）与
  [ADR 0162](0162-linear-algebra-books-in-guide.md)（一本书一个应用、新开「数学」圈）；
  工具选择与 `tools/math-tools`（自家数学工具）无关，互不引用

## 背景

线代与高数的两门课里，已有的教材精读应用（ADR 0162）讲的是「数学」。使用者还想要另一条线：
**学会一个通用数学工具**，用它把向量、矩阵、函数图像、导数积分画出来、算出来，反过来加深对数学的直观。
做法与教材精读一致——挑一本口碑好的书或一门课，一本（一门）一个应用，跟着原书走。

## 选源：能不能拿到决定能不能做

云会话只能克隆 GitHub 上的仓库；视频站（B 站、YouTube）、GeoGebra 官网与 wiki、Octave 文档站、
大学站点的 PDF 都被出口代理拒绝。所以能**逐字入库**的只有 GitHub 上有源码的教程。实测：

| 候选 | 形态 | 能否入库 | 结论 |
|---|---|---|---|
| Lachniet《Introduction to GNU Octave: A brief tutorial for linear algebra and calculus students》（CC BY-SA 4.0，约百页，口碑最好的 Octave 入门小册，题材正是线代与微积分） | 只有大学站点上的 PDF | 否 | **首选但拿不到**；使用者把 PDF 放进 `guide/octave-tutorial/upstream/` 后再起应用（PDF 无结构化源码，按页精读） |
| GNU Octave 官方手册（GPL/GFDL） | `gnu-octave/octave` 仓库 `doc/interpreter/*.txi` + 源码里的函数文档 | 能 | **选**，按线代与微积分需要裁剪；是参考手册而非教程，所以每节配「试一试」 |
| SymPy 官方教程（BSD） | `sympy/sympy` 仓库 `doc/src/tutorials/intro-tutorial/*.rst`，约 130 KB | 能 | **选**；真正的教程，含微积分（极限、导数、积分、级数）与矩阵（零空间、特征值、对角化），自带可运行示例 |
| GeoGebra 官方手册 | MediaWiki 站点，仓库 `geogebra/geogebra` 只有软件源码 | 否 | **做不了**；GitHub 上也没有以 GeoGebra 为主的开源书。使用者提供手册 PDF 或讲义后再议 |
| 3Blue1Brown「线性代数的本质」「微积分的本质」 | 视频；字幕在 `3b1b/captions` 仓库 | 字幕能 | 是直观化的标杆，但讲的是数学不是工具；不在本 ADR 范围，需要时另起 ADR，按「视频课 = 字幕文本 + 外链」做 |
| 《Linear Algebra with SageMath》《Understanding Linear Algebra》（PreTeXt，GitHub） | 书 | 能 | 把工具嵌进线代教材；暂不选，留作后备 |

**视频课的规则**：视频不进仓库、不嵌播放器。一门视频课只有在字幕或讲稿文本能取得时才建应用，
内容是字幕文本加原视频外链，习题照旧自编并可机器核对；取不到文本的视频课不建占位应用。

## 决策

1. **两个独立应用**：`guide/octave-manual`（GNU Octave 官方手册，裁剪）、`guide/sympy-tutorial`（SymPy 官方教程）。
   id 是工具名加书的性质；进程 `athena-octave-manual` / `athena-sympy-tutorial`；知识点前缀 `octave.` / `sympy.`；
   dev 端口 1519 / 1520；`group` 都是「数学」。两者互不引用、各自钉上游、各自进度库。
2. **钉版本**：SymPy 钉 `sympy-1.14.0`（与仓库内已有的 SymPy 引擎同版本）；Octave 钉 `release-8-4-0`
   （与本机复核用的发行版同版本）。上游升级是一个单独的提交（沿用 gtkmm 的快照同步做法）。
3. **逐字入库、译文手写**：`en` 来自上游，`zh` 手写，指纹对齐，规则同 ADR 0162 决策 3。代码与输出
   逐字保留不翻译，只译代码之外的说明；代码里的注释若是教学内容，译在旁边而不改代码。
4. **示例必须是真的**：入库的每段「输入—输出」示例，同步时用真工具复跑一遍与手册里的输出对照
   （SymPy 用 doctest；Octave 用 `octave --eval`），对不上的在快照里标出来而不是悄悄改。
5. **练习是「试一试」**：每节配若干道自编练习，要求在本机工具里动手算出一个可机器判的结果
   （数、向量、矩阵、是/否、选择），答案先用真工具算出再入库，核对点标 `authored`（工具教程里
   书本身没有习题）。先做、再核对、再展开参考做法；不做「看懂了」自评。
6. **范围按用途裁剪**：以「用工具学线代与高数」为准，裁掉与这两门学科无关的章节（图形界面细节、
   音频、打包、对象系统、符号物理等），裁剪清单写在各自 `docs/COVERAGE.md`。被裁掉的不留占位。
7. **出处档位 `open`**，方法原型：主 **预测–运行**（先预测输出再在工具里运行），辅 **检索强化**。
8. **工具安装不在教程里兜底**（ADR 0057）：假定使用者已装好 Octave 或 Python + SymPy；应用在显眼处
   给出一行版本要求，不写安装教程。
9. **缺口如实写明**：GeoGebra 没有可入库的书，应用不假装覆盖；使用者提供源后再起 ADR。

## 后果

- 两个应用的界面壳复制自 `guide/siefken-linear-algebra`，加一种「代码块」内容块（等宽、输入与输出分开、
  可复制），此后各自演进。
- 两本教程都是「工具」不是「数学」：知识点掌握度记录的是「会不会用这个工具做这件事」，
  不与线代、高数的数学掌握度合并。
- Octave 手册的函数说明由 `@DOCSTRING` 引用、实际文本在源码注释里；同步脚本借本机 Octave 展开，
  所以同步（不是使用）需要装有同版本的 Octave。
