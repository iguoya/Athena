# ADR 0116：引用挂靠——一个应用可同时挂在多处；新增 408 主应用 cs408

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「我觉得可以挂在不同的地方，类似引用的方式，同样的
  图标，同样的应用」「算法部分可以由目前的算法应用弥补」；408 主应用 id 选 `cs408`）
- 关系：扩展 [ADR 0092](0092-launcher-tree-attach-and-softcert-rename.md) 的单父挂靠
  （`parent` 语义不变）；解决 [0115](0115-organization-app.md) 决策 2 留下的挂靠冲突；
  挂靠深度一层的约束（0095）对引用同样成立；考试档出处按 [0089](0089-source-tiers-by-app-nature.md)

## 背景

1. 408 的四门课里，数据结构、操作系统、计算机网络已经挂在 software 下（承接软设第 3、4、
   10 章），组成原理刚建。`parent` 只能写一个，408 主应用要「拥有」这几门课就得把它们从
   software 下摘走，软设那边又失去承接。
2. 课程本身只有一份：数据结构就是数据结构，不该为 408 再复制一个应用。两个考试共享同一门
   课是常态，不是例外。
3. 408 数据结构的算法设计大题（第 41、42 题）落在算法范式与复杂度分析上，现有 algorithms
   应用承接软设第 8 章，正好补上这一块。

## 决策

1. **新增 `app.json` 字段 `also_under`（字符串数组）——引用挂靠**。`parent` 仍是唯一的
   「主挂靠」，决定应用在思维导图上的本体位置；`also_under` 列出的每个应用下再出现一个
   **引用节点**：同 id、同图标、同标题，点开就是同一个进程、同一份进度，状态点同步。
   引用节点用单独的「引用」连线种类，与主挂靠线区分（颜色更淡）。
2. **解析规则**：目标 id 解析不到、指向自己、与 `parent` 重复、或目标自己也是挂靠节点
   （深度一层，0095）的条目忽略，不报错（与 `parent`、`related` 同规）。引用节点不占领域
   扇区、不画领域分支线。
3. **新增 408 主应用 `subjects/cs408`**：title「408 计算机学科专业基础」，新领域圈「考研」
   （以后政治等考研应用进同一圈）；端口 1503，进程 `athena-cs408`，知识点
   前缀 `cs408.`；**考试档**学习应用（出处 exam，判分内容必须有出处）。职责是考试本身：
   考试结构与分值、真题组卷、整卷模拟；各科的讲解与实验留在课程应用里，不在这里重复。
4. **408 的课程挂法**：

   | 课程 | 主挂靠 `parent` | 引用 `also_under` | 承接 |
   |---|---|---|---|
   | data-structures | software | cs408 | 408 数据结构 45 分的结构部分 |
   | algorithms | software | cs408 | 408 第 41、42 题算法设计（范式与复杂度） |
   | organization | cs408 | software | 408 组成原理；引用回软设第 1 章「计算机系统」 |
   | os | software | cs408 | 408 操作系统 |
   | network | software | cs408 | 408 计算机网络 |

   organization 的本体挂到 cs408（408 是它的主场，修订 0115 决策 1 的「不设 parent」与
   group），并以引用承接软设第 1 章。

5. **目标考试更正为 22408**（tiger 2026-10-10：「按照 22408 判定，刚才说错了」）：
   22408 = 101 政治 + 204 英语二 + 302 数学二 + 408。修订 0115 背景表与决策 6 的缺口清单
   （0115 原文不改）：英语二由 english（磨砚）承载、数学二由 mathematics 承载（其约束本就是
   数学二），**不再是缺口**；英语一与数学一扩展（概率论与数理统计、数一独有的高数部分）
   撤出待办。剩余缺口只有 **101 政治** 与 408 的真题层（由本条的 cs408 承担）。
6. **思维导图的扇区按角度需求分配**：引用挂靠让挂靠层的子节点变多，原先「按成员数平分
   扇区」会让相邻单应用领域互相压住、挂靠者的子节点铺进隔壁扇区。改为每个领域取「第一圈
   成员排开所需角度」与「挂靠层子节点（真挂靠 + 引用）排开所需角度」的大值，整圈放不下就
   把第一圈外推；子节点的角距优先按弦长下限，扇区有余量才放宽到 0.35 rad。画布因此变大
   （真实清单下第一圈半径约 342 → 650），窗口放不下时照旧滚动。

## 后果

- 启动器 `manifest`、`mindmap`、GUI 三处支持引用节点；macOS 菜单栏版是列表，不受影响。
  布局测试覆盖引用节点的位置、连线与解析规则，真实清单测试守住新布局不重叠。
- 一门课可以服务多个考试而只维护一份；课程应用里「承接哪个考试哪一章」的说明照常写在
  各自 `AGENTS.md`，不因引用而复制内容。
- 「考研」圈出现；政治建应用时进这个圈。english、mathematics 是否也以引用挂到考研圈下，
  等 22408 的整体入口需要时另议。
