# ADR 0069：驾考进度的网页只读仪表盘——挂在 nas_admin，外网走 Access、内网免登录

- 日期：2026-10-02
- 状态：已接受；补充 ADR 0068（不修订其任何条款，新增「人的只读通道」这一形态）
- 影响：`practice/nas_admin`（新增页面与聚合查询）；软路由 PostgreSQL（只读访问）；Cloudflare
  Access（复用现有 `www` 应用策略，无新增配置）
- 延续：ADR 0068（三层存储、外网走 REST API）、0067（中心 PG）、0060（`practice/` 项目应用）
- 关联：`practice/nas_admin/docs/driver-api.md`（设备通道）

## 背景

ADR 0068 落地后，驾考个人数据有了权威库（软路由 PostgreSQL）和设备通道（`/api/driver/v1`，
设备令牌认证），但「人看数据」仍只有驾考客户端一条路：想在外网看进度，要么在内网，要么
装客户端。而 www.yatiger.cn 已经通过 Cloudflare Access + cloudflared 隧道连到路由器上的
nas_admin——浏览器打开就能到后台。缺的是一个给人看的页面。

REST API 不能直接当这个页面用：它要求设备令牌，令牌放进浏览器就等于泄露（任何拿到页面
的人都能拿令牌写数据）。设备通道面向程序，人看的页面需要另一条通道，且只能是只读的。

## 决策

1. **nas_admin 新增驾考进度仪表盘页面：服务端聚合、只读、面向浏览器。** 服务端用 SQL
   聚合出统计（各科目正确率与题量、每日趋势、模拟考分数曲线、连续学习天数、成就墙），
   页面模板 + 浏览器端图表渲染。不提供任何写端点；不展示笔记正文（`point_notes` /
   `drill_notes` 是私人记录，一期不做，将来要做再决策）。
2. **访问边界：外网过 Cloudflare Access（复用 www.yatiger.cn 现有策略），内网免 FAB
   登录。** 免登录的理由：内网是家庭信任域（PG 的 pg_hba 本就放行整个 /24），再要求一次
   后台登录只会让手机上查看变麻烦；外网的门由 Access 把着。**这是 nas_admin 里第一种
   「免登录展示个人数据」的页面**，边界必须锁死：严格只读、错误信息不带堆栈与路径、
   测试断言页面不出现写行为。
3. **数据访问复用 driver API 的低权限角色连接**（无 DDL，见 driver-api.md 部署一节），
   聚合查询只发 SELECT。没配连接串时页面降级提示「未配置」，不影响后台其他功能——与
   REST API 的降级口径一致。
4. **统计口径与客户端一致，用测试锁住。** `at` 是客户端本地的 ISO-8601 字符串，服务端
   原样保存（0068 的同步模型），所以「按天分组」就是字符串前缀（`substr(at, 1, 10)`），
   与客户端的字符串比较同口径，不引入数据库时区。凡服务端新算的统计（如连续天数），
   与客户端（`subjects/driver`）口径不一致时以客户端为准、改服务端。
5. **图表在浏览器渲染，echarts.min.js 随仓库与部署包走，不走 CDN。** 路由器在国内环境，
   公共 CDN 不可靠；一个本地文件（gzip 后约 300 KB）随 deploy 上传，页面完全离线可用。

## 状态

已落地并部署路由器：`/driver/` 页面与 `/driver/data.json` 聚合端点可用（2026-10-02 验证，
真实数据 5079 次作答聚合正确）；68 条测试（含口径对拍与只读断言）通过。外网入口
www.yatiger.cn/driver/ 由现有 Cloudflare Access 策略保护，无需新增配置。

## 后果

- 内网任何设备打开即看：这是接受的暴露面（家庭信任域）；若日后网络环境变化（如开放
  来宾网络），需要重新审视免登录决定。
- 服务端出现第二套统计算法（SQL 版），与客户端（Dart 版）存在漂移风险，靠「口径不一致
  以客户端为准」的规矩与对拍测试约束；客户端算法变更（如连续天数规则调整）要同步服务端。
- 外网可用性 = Cloudflare + cloudflared + 路由器三者在线，比内网直连多两个环节；页面
  对 API 短暂不可用要有降级提示，不白屏。
- 将来若想给他人看（脱敏公开），是**另一条通道、另一个决定**（内容裁剪、免 Access 的
  暴露面评估），不在本 ADR 范围内。
- 科目三就绪度（`readiness.dart` 的通过率/扣分组合算法）暂不移植服务端，二期再说。
