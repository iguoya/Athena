# ADR 0162：线性代数手册类教程——两本书各一个应用，进 `guide/`，新开「数学」圈

- 日期：2026-10-14
- 状态：已接受（使用者要求：找互联网口碑好的线性代数教材，仿照 gtkmm 的做法放到 `guide/`，
  一本书一个应用，id 与书绑定，归到数学领域；随后补充：内容与习题并存、通俗易懂、
  学有所得，两本书同时编写、互不干扰，方便对比；书要薄（100～200 页最好，不超过 300，
  长书只算与考研重合的部分），按考研考纲裁剪；遇到疑问优先参照 gtkmm 自行决定）
- 关系：沿用 [ADR 0143](0143-guide-directory.md)（`guide/` 手册类）；增补
  [ADR 0148](0148-regroup-domain-circles.md) 的 `group` 取值；与 `postgraduate/mathematics`
  （考研数学二自编课程）并存，互不引用

## 背景

`postgraduate/mathematics` 是围绕考研数学二自编的课程，线代部分借 Selinger 教材做出处。
使用者想要另一种学法：**挑一本口碑好的教材，吃透它**——章节、顺序、例题、习题都跟着原书走，
不被别的教材干扰，且想把两本书放在一起比较，选更合口味的。这正是 `guide/gtkmm` 的做法。

选书约束（使用者逐步给出）：口碑好；书薄——原书 100～200 页最好，不超过 300 页；
若原书更长，**与考研数学二线代重合的部分**不超过 300 页也可以；内容与习题并存、通俗、
学有所得；学习范围按考研考纲裁剪，除"理解必需"外不扩到考纲之外。云会话只能从 GitHub
克隆，Axler、Treil、Hefferon 的站点与 GitLab 不可达，只有 GitHub 上有 LaTeX/XML 源的
开源教材能逐字入库。实测候选：

| 书 | 许可 | 原书规模 | 按考纲裁剪后 | 结论 |
|---|---|---|---|---|
| Peter Selinger《Linear Algebra: A First Course》（Lyryx/Kuttler 教材的开源改编） | CC BY 4.0 | 608 页（LaTeX 源 1.2 MB） | 约 275 页（去掉抽象向量空间、几何向量积、复数与酉、各类应用章） | **选**；每节开头列目标，节末习题，书末部分解答；自述"not a proof-oriented book" |
| Jason Siefken《MAT223 Workbook / IBL Linear Algebra》（多伦多大学） | CC BY-SA 4.0 | 284 页（源 524 KB） | 更少 | **选**；每个模块分讲解、练习题、核心探究题；几何与概念导向，少机械计算 |
| Robert Beezer《A First Course in Linear Algebra》 | GFDL | 约 700 页 | 预计仍 > 300 | 不选 |
| Siefken《LinearAlgebra》（2018 草稿） | CC BY-SA 4.0 | 108 页 | 未写完（线性变换起只有探索题） | 不选 |

Siefken 的书在机械行变换与逆矩阵计算上有意留空，且没有二次型：这两处不会补别的教材
（见决策 2），应用内在覆盖表里标明"原书未讲"，机械计算由使用者在
`postgraduate/mathematics` 练。

## 决策

1. **两个独立应用**：`guide/selinger-linear-algebra`、`guide/siefken-linear-algebra`。id 是
   作者名加学科，与书绑定；进程 `athena-selinger-linear-algebra` / `athena-siefken-linear-algebra`；
   知识点前缀 `selinger.` / `siefken.`；dev 端口 1517 / 1518。
2. **两本互不干扰**：不共享内容、不互相引用路径、各自钉各自的上游提交、各自的进度库。
   界面壳最初复制自 `guide/gtkmm`（去掉 C++ 演示相关部分），此后各自独立演进，
   不抽共用包（ADR 0062：约束不继承；两书的数据形态——LaTeX 与 XML——本就不同）。
3. **跟随原书，不自编大纲**（同 gtkmm），但**按考纲裁剪**：课表只收考研数学二线代用得上的
   章节，章节顺序与原书一致，节标题保留原书编号（"原书 §1.3"），被裁掉的节不进课表、
   不放占位；"理解必需"的前置节可以保留。裁剪清单与理由写在应用的 `docs/COVERAGE.md`
   （考纲点 → 原书节 → 有无练习），原书没讲的考纲点也要写明。原文段落逐字入库，
   每段带指纹；`zh` 是唯一手写内容；同步脚本按指纹对齐，原书一变，git diff 显示哪一段变了。
   公式保持 LaTeX 原样，用 KaTeX 渲染；译文里的数学符号也用 LaTeX。
4. **内容与习题并存**：每节页面 = 原文翻译 + 该节原书的例题与习题。习题由我补一个
   **可机器核对的最终答案**（数、向量、矩阵、是/否、选择），先作答再展开原书解答；
   需要写证明的习题只展开原书解答并给"对照要点"，不做"看懂了"自评，也不计入掌握度
   （掌握度只由作答写入，ADR 0052）。每节至少一个检索动作（节首目标变成自测题或节末小测），
   出现在揭示答案之前。答案用 SymPy 复核，复核脚本入库。
5. **出处档位 `open`**（ADR 0089）：这两本书不对着外部考试。题目出处就是原书的节号和习题号，
   必填 `locator`；我补的核对点标 `authored`，不冒充原书。
6. **方法原型**（ADR 0113）：主 **问题解决**（先自己算再看原书解法），辅 **检索强化**
   （节首目标自测、节末混合回顾）。
7. **新开「数学」圈**：两个应用的 `group` 是「数学」。既有的 `mathematics`、`math-tools`
   暂留「考研」圈不动，是否并入另议。`group` 取值不是写死的名单（ADR 0148 第 5 条），
   启动器无需改代码。
8. **许可与署名**：每个应用带一页声明（书名、作者、许可、改编说明、上游地址与钉点）。
   Selinger：CC BY 4.0，译文是改编，注明；Beezer：GFDL，随附许可文本与"修改声明"。
   原文只在本机自用，不分发（项目自用定位）。
9. **起步范围（ADR 0129）**：课表是裁剪后的子集；节页状态分 `translated` / `原文`
   （未译的节直接显示英文原文，标明"待译"，不放空骨架）。第一批可交付内容：各书的
   "线性方程组"一章全部译完，习题带核对点。之后按章推进，一章一个提交。

## 后果

- 想加 Axler 或 Treil：使用者提供 PDF 放进 `guide/<id>/upstream/`（gitignore），再起 ADR；
  PDF 没有结构化源码，只能按页面精读，不走段落指纹同步。
- 两本书并行写，**应用内不做对照页**，对比靠使用者在启动器里分别打开。
- Siefken 的书是工作册：核心探究题没有标准答案（作者的意图是"过程比答案重要"）。这些题
  我补"核对点"并标 `authored`，不冒充原书答案。
- `docs/REPOSITORY.md` 名字表、结构树、根 `README.md`、根 `AGENTS.md` 的结构块同步登记。
- 译文量大：长篇证明和应用章节排在后面，课表里显示原文。
