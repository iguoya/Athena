# ADR 0117：磨砚并入摘星后退役；引用挂靠扩展到领域圈

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「磨砚和数学学习也引用挂到考研分组」「看看磨砚是否有独立
  存在的必要，必要时吸收它的精华和特点，合并整合到摘星……独立章节和界面」「从而取消磨砚
  这个应用」；退役方式选「先迁移后退役」，考研入口选「引用到分组」）
- 关系：修订 [ADR 0066](0066-two-english-apps-evolve-independently.md)（两个英语应用各自独立
  发展）与 [0095](0095-one-exam-one-app.md)（一个考试一个应用）在英语上的适用；扩展
  [0116](0116-reference-attach-and-cs408.md) 的引用挂靠；摘星侧的定位修订见
  `subjects/ascent/adr/0025`

## 背景

1. 22408 的英语二由磨砚（`subjects/english`）承载，摘星（`subjects/ascent`）承载四六级、
   专四、专八。两者的底子高度重合：真实句子带出处、词汇放进语境学、间隔复习、读写听说
   都练、考核与练习分离（摘星 ADR 0024 已把后者吸收为原则）。维护两套同类基础设施的成本
   高于收益。
2. 磨砚真正独有、值得保留的是：英语二的内容（55 个文件，1088 条判分条目全带出处）、
   语境先行再提取义项的出题方式、句子题只问切分指代句意、作文只机检字数与衔接、初中高
   三级路线、错题本。
3. 两个应用的技术栈不同（磨砚原生 TypeScript，摘星 React + Tailwind + 三套皮肤），合并
   是「迁内容、重写界面」，不是搬代码。磨砚进度库只有 4 条作答，不迁移。

## 决策

### A. 磨砚并入摘星，先迁移后退役

1. **摘星成为所有英语考试的承载者**：四六级、专四、专八之外，新增独立的「考研英语二」
   章节与界面入口，遵守摘星的视觉与教学规则。英语这一个领域不再按「一个考试一个应用」
   拆分（修订 0095 在英语上的适用；其他考试照旧）。
2. **迁移分阶段，删目录放在最后**：
   - ① 打 `pre-english-merge` 标签，留一版原样基线（ADR 0054）。
   - ② 内容与出处迁进摘星，判分条目的出处在摘星的考试档契约下仍全部达标。
   - ③ 摘星的英语二章节界面可用：练习、考核（平行题、交卷评分）、错题本。
   - ④ 以上都满足后删除 `subjects/english`，并同步根文档、启动器清单与 CI 的应用列表。
   在 ④ 之前磨砚照常可用，22408 的英语二不出现空档。
3. **迁移前必须先定的一件事——参考资料与公开发布**：摘星规定仓库与安装包公开，教材、
   真题原文只放 git 忽略的 `content/private/`（摘星 ADR 0019 补充）；磨砚则把 42MB 公开
   参考资料（词表、教辅摘录、VOA 等）提交在仓库里（磨砚 ADR 0008）。迁移时按条目来源
   分流，规则由 tiger 拍板后写进摘星 ADR 0025，在此之前不迁 `sources/`。

### B. 引用挂靠扩展到领域圈

4. **新增 `app.json` 字段 `also_in`（领域名数组）**：应用在这些领域圈里各多一个引用节点，
   与圈内成员同圈排布、由领域胶囊连线（引用种类，比分支线淡）；同一应用、同一图标、同一
   进程。领域名不存在、与本体所在领域相同的条目忽略。
5. **考研圈的入口**：mathematics（数学二）与 english（英语二）现在就 `also_in: ["考研"]`；
   磨砚退役时由摘星接替这个引用。

## 后果

- 英语只剩一个应用，英语二的内容与界面在摘星里按其规则重做，工作量集中在界面。
- 删除磨砚是不可逆的结构变动，所以放在迁移验收之后，并有标签兜底。
- 领域圈可以引用别处的应用，「考研」圈呈现 22408 的全貌：cs408、数学学习、英语二。
