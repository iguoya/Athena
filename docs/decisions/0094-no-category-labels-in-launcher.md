# ADR 0094：课程性/实验性区分留在内容层，启动器界面淡化

- 日期：2026-10-09
- 状态：已接受（tiger 指示）
- 关系：约束 [ADR 0092](0092-launcher-tree-attach-and-softcert-rename.md)、
  [ADR 0093](0093-drop-practice-panel.md) 的启动器实现；内容层口径见 softcert
  [docs/content-plan.md](../../subjects/softcert/docs/content-plan.md)

## 背景

实践性课程（真硬件/真编码实验）与理论性课程（讲解、测验）在内容与目录层保留
区分——两者的练习形态与验收标准不同（0091、content-plan 归类结论）。承载它们的
应用（如 softcert 内含课程与 lab 实验，dsa、c-gui-lab、pocket-cube 是实践出口）
在挂靠树上并存。tiger 指示：目录区分可以有，启动器界面要淡化。

## 决策

- **启动器界面不表达课程性/实验性分类**：不设「实验」「课程」类别标签、徽章、
  分区或分组字段；应用在思维导图上统一呈现，差别只由领域圈（`group`）与挂靠
  连线（`parent`）表达。
- 区分保留在**内容与目录层**：章节、lab 实验、考核题、验收口径（实践章「真做过」、
  理论章「记住会判」）照 ADR 0091 与 content-plan 执行。
- `app.json` 不新增类别枚举字段；应用 description 不写「实验应用/课程应用」标签。

## 后果

- 启动器开发线实现 0092/0093 时不引入分类展示逻辑。
- 学习者从界面看到的只有「领域—应用—挂靠」的空间关系，学什么用什么由课程
  内容自己引导（章节内的实验指引、考核入口）。
