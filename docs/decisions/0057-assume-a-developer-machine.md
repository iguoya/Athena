# ADR 0057：基线是一台开发机——依赖自行安装，不写兜底

- 日期：2026-09-15
- 状态：已接受
- 范围：**整个仓库**，所有应用与工具
- 关系：给 [ADR 0047](0047-portable-by-default.md) 的跨平台原则与
  [ADR 0049](0049-portability-is-a-cost-benefit-call.md) 的成本判断补上**使用者
  假设**；本条一旦成立，0049 里「成本」的一半（安装与分发）直接归零

## 背景

Athena 是自用的学习软件，使用者就是开发者本人。但代码里长期按「万一他没装」的
假设写东西，攒下了一批只为这个假设存在的路径：

- `apps/dsa` 为「可能没装 clang-format」手写了 22 行伪格式化器，按花括号增减
  4 空格。它连字符串里的 `{` 都会数进缩进（`printf("{}")` 就能把后面整段带偏），
  而且在 clang-format 正常工作、返回内容与原文一致时，前端还会再拿它改一遍——
  **主动让结果变差**。
- `scripts/check.py` 找不到 node 就跳过跨应用出处检查，然后整项检查放过去、
  最终报「通过」。它调用的 `check-app-sources.mjs` 顶上恰恰写着「沉默地通过是
  最坏的结果」。
- `apps/mathematics` 的引擎测试在 venv 不存在时 `return`，测试算通过——而它验的
  是本应用最核心的那条链路（Rust↔Python↔SymPy）。
- Pyodide 被留作备选，触发条件是「本应用要发行给不愿装 Python 的人」。

这些东西的共同点：**它们服务的是一个不存在的用户**。代价却是真的——每一条都是
要长期维护、会悄悄退化、还可能掩盖真问题的代码路径。上面第二、三条直接让验证
变成了摆设。

## 决策

**1. 基线：使用者是资深开发人员，机器是一台完整的开发机。**

Python、Git、C/C++ 编译器、Node、clang-format 这类开发必备工具，**一律假设已装，
或使用者有能力自行安装**。

**2. 因此不写兜底，也不做降级实现。**

不内嵌解释器、不内置编译器、不把功能降级成「没有工具链也能凑合用」、不在文档和
代码里堆「如果你没有 X 怎么办」。**凡是「因为可能没装 X」而存在的劣化替代，一律
删掉。** 判断方法很简单：问这段代码存在的理由，是不是「万一他没有」。

**这一条的首要目的是减少代码复杂度**，不是对使用者的态度表态。少一条兜底路径，
就少一处要维护、要测试、会悄悄退化的地方。

**3. 但要给明确的提示，这不是可以敷衍的借口。**

检测不到某个工具时，要说清楚**装什么、哪个组件、什么命令**，而不是一句「请先
安装」。分寸是**只给查起来费事的那部分**：「VS 要勾哪个工作负载」「MSYS2 的包名
叫什么」值得写；官网 URL、「LLVM 带 clang++」这类常识不写——写进去反而是把人
当小白。

需要使用者动手才能继续的提示（例如缺 clang-format），**用对话框**，不要塞进
状态栏里被忽略。

**4. 技术选型同样不为依赖成本让步。**

判据是这个技术能不能增强软件的威力、效果与体验，不是它好不好装、依赖多不多、
包体积多大、授权是否商业。运行库的安装与分发成本在本仓库**不计入权衡**。

**5. 代码也不为「容易懂」降级。**

该用的语言特性、抽象和库照用；实现要直接，不把一步拆成三步「便于理解」，不加
没人需要的中间层，不写防御性的兜底去挡不会发生的情况。边界是**清晰**而不是
**浅显**。

## 后果

按本条已经清理的：

| 位置 | 原来 | 现在 |
|---|---|---|
| `apps/dsa` 格式化 | 22 行伪格式化器兜底 | 只认 clang-format，缺了弹对话框说装什么 |
| `scripts/check.py` | 没有 node 就跳过出处检查 | 报错退出 |
| `apps/mathematics` 引擎测试 | 没有 venv 就静默跳过 | 断言失败；`check.py` 先建好环境 |
| Pyodide | 降为备选 | 不再是备选（触发条件不会成立） |
| MATLAB / Octave | 因授权与启动开销拒绝 | 需要时可引入；符号判等继续用 SymPy 是**技术对口**，不是成本便宜 |

- 代码路径变少，而且**验证重新变得可信**——前两条此前都会让检查「通过」而实际
  什么都没查。
- 代价：使用者第一次跑某个功能时可能要先装个工具。这正是第 3 条要求把提示写好的
  原因，也是可接受的——他本来就是开发者。
- 本条**不豁免**「无法自行安装」的情形。若某个依赖在某平台上根本拿不到，那是
  ADR 0049 的成本判断范畴，按那条走（写明排除与降级），不要退回来写兜底。
