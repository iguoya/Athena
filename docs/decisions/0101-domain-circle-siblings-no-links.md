# ADR 0101：领域圈成员即兄弟——同领域应用之间不画任何特意连线

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「数学学习和工具应该也是兄弟节点；摘星、磨砚应该也算」）
- 关系：修订 [ADR 0098](0098-minimal-links.md) 决策 4 的保留例外、
  [ADR 0084](0084-math-tools-joins-subjects.md) 决策 3 的 related 声明要求；
  连线语义仍按 [ADR 0083](0083-launcher-mind-map.md)

## 背景

0098 把「非必要不特意连线」落成清单清理，但留了一个例外：math-tools↔mathematics
的 related 线（「配套工具的附属语义」）。tiger 复核思维导图后把这个例外也收回：
数学学习和数学工具同属「数学」领域圈，**领域圈本身已经表达了它们的兄弟关系**，
再多一条线就是把兄弟画成了别的什么。同理磨砚（ascent）与磨砚英语（english）——
同属「英语」圈，兄弟由圈表达，0098 删线的方向是对的，现在把原则说全。

## 决策

1. **同领域圈内的成员即兄弟，成员之间不画任何特意连线**——related、挂靠线、
   演进线都不作为圈内关系的表达；兄弟关系只由领域圈（`group`）承载。
2. **删除 `math-tools` 的 `related: ["mathematics"]`**——兄弟由「数学」圈表达。
   `related` 字段机制保留（跨领域的确要标注关系时仍有用），当前全仓库无使用。
3. 修订 0084 决策 3 的「声明 related」要求：math-tools 与 mathematics 的关联
   由同一 `group`「数学」表达即可，不再要求 related 声明（0084 原文不改，
   状态栏注记）。
4. 单父挂靠线（ADR 0092）与跨领域 `related` 不受本条约束——本条只管**同领域
   圈内**：圈内成员是兄弟，兄弟不连线。

## 后果

- 思维导图上数学圈不再有附属线；磨砚、摘星与数学那对口径一致——圈内皆兄弟。
- `app.json` 的 `related` 解析与渲染代码保留，相关测试以构造数据覆盖。
