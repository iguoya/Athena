# ADR 0122：人工智能五门课骨架一次落齐

- 日期：2026-10-10
- 状态：已接受（tiger 2026-10-10：「如果你觉得划分5个种类是科学 可行 对初学者有好的话
  就新建5个节点 内容先不考虑 挂靠人工智能下面」）
- 关系：执行 [ADR 0120](0120-ai-group-and-llm-curriculum.md) 决策 A 的课程路线；
  0120 的「本次只立项第一门 python，其余逐个立项」由本条取代

## 决策

1. machine-learning、deep-learning、llm-app、llm-finetune 四门今日与 python 同批落
   骨架（壳 + `app.json` + AGENTS/CLAUDE + check.py + 课表占位），五门全部
   `group: 人工智能`，在启动器「人工智能」圈各占一个节点。
2. **不设伞应用**：五门是平级的一级课程（先修关系用 AGENTS.md 文字指引表达，ADR 0032），
   「挂靠人工智能下面」指归属领域圈（`group`），不是挂靠某个主应用——AI 路线没有
   一场真实考试或一个内容实体来当伞（对照 software、cs408：伞应用都有真实内容）。
3. 五门骨架内容均为占位；每门的内容填充开工时，仍按 0120 的定位表立自己的 ADR 并
   声明主原型，骨架阶段 check.py 默认结构校验（ADR 0103 同规）。

## 后果

- 启动器「人工智能」圈呈现五节点全景，路线的形状先于内容可见。
- 四个新壳的图标沿用 letter 退路，icon.svg 待各课内容填充期设计。
