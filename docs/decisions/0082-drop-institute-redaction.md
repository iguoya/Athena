# ADR 0082：撤销院所名脱敏规则，清除全部相关痕迹

- 日期：2026-10-03
- 状态：已接受；撤销 [ADR 0055](0055-no-institute-names-in-product-content.md)（0055 原文
  保留，仅作历史记录）
- 范围：整个仓库

## 背景

ADR 0055 要求软件内容不出现具体院所名、一律用代称「某所」，由 `scripts/check.py`
全仓扫描拦截。该规则落地的前提是仓库里确实存在以某个外部单位为参考的内容。

使用者已决定：把仓库中涉及那个单位的一切痕迹**彻底删除**——不是改称呼，而是不再
保留任何指向它的内容、来源与描述。内容删干净之后，「避讳」这件事就没有对象了，
规则本身（代称要求、检查器、各文档条款）只剩下维护成本和对读者的困惑：它会让每个
新读者以为仓库里存在一个不能提的单位。

## 决策

1. **撤销 0055。** 内容与文档不再执行院所名脱敏；「某所」的代称要求、转义禁用词、
   全仓扫描一并移除。
2. **删除内容痕迹。** 图谱与文档中指向那个单位的内容（参考分支、来源条目、对照性
   描述）全部删除；改写只保留与该单位无关的技术要求主体。人物背景表述按使用者
   后续更正处理：脱敏代称可以保留，具体家庭关系（是谁家的什么人）不进仓库。
3. **历史文档中的痕迹词句一并清除。** 各 ADR 与文档里指向该单位的代称、引用与
   描述（包括活着的 ADR 里的历史叙述）按本条决策直接移除——这是本条的直接后果，
   不适用「原文不改」；原始文本在 git 历史中可取回。
4. **检查器收缩。** `scripts/check.py --sources-only` 从三项检查减为两项（skill 两处
   一致、内容出处）；发版脚本不再有禁用词校验。

## 后果

- 后续内容与文档不再需要考虑院所名避讳；`AGENTS.md` 及各应用文档的对应条款删除。
- 图谱中原来以该单位为「重要参考」的分支整体消失，相关主干只保留自身的技术要求，
  不再有对照表述。
- git 历史中更早的原始文本不在本次清理范围内，是否重写历史另行决定。
