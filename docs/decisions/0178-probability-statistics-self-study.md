# ADR 0178：立项 `self-study/probability-statistics`，修订 ADR 0175 的分期条件与端口，并划定自考范围

- 日期：2026-10-21
- 状态：已接受（使用者明确要求：「现在就立项概率统计：先写 ADR 修订 0175 的分期条件，再按
  new-app 流程建 self-study/probability-statistics；需要时通过 comms 舱让 ZCode 协助采集真题」，
  并补充「这是自考本科版，限度考试范围和习题范围」）
- 关系：修订 [ADR 0175](0175-self-study-math-exam-apps.md) 决策 2 中概率统计「分期落地」一款与
  端口 1526 的预留；其余（目录、出处档位、方法原型、壳与进度库）沿用 0175 不变。宁缺毋滥
  仍按 [ADR 0129](0129-quality-over-quantity.md)

## 背景

ADR 0175 批准了三个应用的结构，但把概率统计放在线代、高数「有第一批可交付内容」之后再建。
使用者现在要求不再等待，直接立项。这并不削弱 ADR 0129：它要求的是「新建应用要有可交付的第
一批内容，不落空骨架」，而不是「必须排在别的应用之后」。分期的真正约束因此保留，只是触发条件
从「前两门有内容」改为「本应用自己有内容」。

另外 0175 预留的端口 1526 已被 `guide/chen-linear-algebra`（ADR 0177）占用，1527、1528 分别在
`programming/gtkmm-lab` 与 `programming/qt`，预留在现实面前失效，需要改号。

## 决策

1. **概率统计立即建**，不再以线代、高数的进度为前提。唯一的门槛是 ADR 0129：创建时必须同时
   提交可交付的第一批内容（至少一章已写出节内容的课表、知识点与判分练习），不提交空骨架。
2. **端口改为 1529**（HMR 1629），其余标识不变：id `probability-statistics`，进程
   `athena-probability-statistics`，知识点前缀 `probstat.`，数据目录
   `AthenaProbabilityStatistics`。0175 里写的 1526 作废。
3. **范围就是自考本科的范围**，不是考研数学的范围：
   - **考试范围以官方考纲为界。** 章节与知识点跟随考纲与指定教材目录；考纲没有列出的内容
     （考研数学一、数学三才要求的部分、纯理论推广与严格测度论表述等）不进判分内容，也不
     作为「拓展」混进正文。
   - **习题范围以历年真题与指定教材习题为界。** 判分练习的出处只能是考纲覆盖内容上的真题
     （`verbatim`）、教材例题与习题的改编（`adapted`），或自造题（`authored`，受 0175 的过渡
     期规则约束：数量只许降不许升）。题目难度向真题看齐，不向考研题看齐。
   - 考研数学内容如需要，走 `postgraduate/mathematics`，两处不互相引用（ADR 0062）。
4. **指定教材与考纲的核对仍是前置动作**：0175 背景表里的教材（孙洪祥、张志刚主编，北京大学出版社
   2023 年版）与代码（13174 / 02197）出自使用者提供的信息，未对照版权页。节级划分与考纲条目
   在逐章编写时与实物核对，出入就地修正并在提交信息里说明；核对和整卷真题采集通过 comms 舱
   `probability-statistics` 派给 ZCode，应用的壳与首批内容由本条的立项者负责。
5. **comms 舱 `probability-statistics`**（ADR 0165）：leader 为 claude-code，worker 为 zcode、
   cursor；worker 只写自己名下的 `content/exams/` 与 `comms/probability-statistics/artifacts/`，
   不改课表、知识点与节内容（与 `self-study` 舱的做法一致，免得两个舱抢同一批文件）。

## 后果

- 概率统计在启动器里与线代、高数同在「自考」分组，不需要改启动器代码（ADR 0046）。
- 首批内容只覆盖第一章，其余章按宁缺毋滥逐章补；课表只登记已写出内容的节。
- 教材节号在 ZCode 核对前只写到章，节级 `textbook_ref` 待核对后补，不凭印象写节号。
