# ADR 0174：数学学习导引——`mentor/` 新增 `mathematics-compass`（数学罗盘）

- 日期：2026-10-21
- 状态：已接受（使用者要求：为数学部分建一个学习导引应用，说明每个数学应用的学习先后顺序、
  学习目的、需要掌握的要点，从教科书角度考虑，先易后难、有所取舍；起因是「目前的教程太多，
  我有点无所适从」。使用者的补充指示：必要时联系 cursor 听取合理建议）
- 关系：落 [ADR 0144](0144-mentor-directory.md)「此后新增图谱/参考类应用进 `mentor/`」的判据；
  覆盖范围是 [ADR 0162](0162-linear-algebra-books-in-guide.md)、[ADR 0163](0163-math-tool-tutorials-in-guide.md)
  建起的「数学」圈与 `postgraduate/mathematics`；形态取 [ADR 0156](0156-jiuzhou-history-atlas.md)
  所在的图谱/参考类先例；两本线代书的取舍立场是对 ADR 0162「选更合口味的」的补足，不推翻它
  （两本书并存、互不干扰的格局不变）

## 背景

数学相关应用已有六个：`postgraduate/mathematics`（考研数学二自编课程，现线代 5 章）、
`guide/selinger-linear-algebra` 与 `guide/siefken-linear-algebra`（两本线代教材精读，按数二
考纲裁剪）、`guide/octave-manual` 与 `guide/sympy-tutorial`（Octave 与 SymPy 两个计算工具的
官方教程精读），外加配套工具 `tools/math-tools`。多线并存是刻意的（教材与工具各有各的学法，
ADR 0162、0163），但没人替使用者回答「先学哪个、为什么学、学到什么程度、什么可以不学」——
这正是学习者站在入口处最需要的东西，缺了它，多线并存就退化成无所适从。

两个事实约束导引的内容：

- **数学部分目前全是线性代数**。考研数学二的大头是高等数学，但高数应用还不存在。导引必须
  如实写明这个缺口，不编造高数路线、不留占位章节（ADR 0129：宁缺毋滥；ADR 0163：缺口如实写明）。
- **应用之间不互相引用路径与内容配置**（ADR 0032、0062）。导引不能运行时去读其他应用的
  `content/`，它的内容是一份自包含的导读快照：写各应用的显示名与定位，其他应用演进时由
  导引自己手工同步。

## 决策

1. **新增 `mentor/mathematics-compass`，中文标题「数学罗盘」。** id 与 `polaris`（北极星）
   对仗——计算机的北极星，数学的罗盘。按三类判据是图谱/参考类：只呈现信息供查阅，给人方向
   与决策依据；不教课、不判分、不建进度库、不建 `content-contract.json`，跨应用教学规范
   不生效（ADR 0144）。
2. **覆盖范围：五个学习应用做路线节点，`math-tools` 提及不占节点。** 节点是 `mathematics`、
   `selinger-linear-algebra`、`siefken-linear-algebra`、`octave-manual`、`sympy-tutorial`。
   `math-tools` 是配套工具不是教程（ADR 0146），占路线位会误导「要先学它」；导引里作为
   随手实验台介绍。`ascent` 是英语，不在范围。
3. **给唯一推荐路径，被排后的内容注明何时回来。** 「有所取舍」是使用者这次明确的要求：
   导引直接说先学什么、后学什么、什么可以暂缓，每一步写明依据。两本线代书给出明确选法
   （先 Siefken 建几何直观，后 Selinger 做体系与习题；只读一本、目标是数二考试则选 Selinger，
   因其按考纲裁剪且习题完整），另一本的适用情形如实写。ADR 0162 的两本书并存格局不变，
   这里补的是「默认怎么走」。
4. **形态：阅读为主 + 一张可点击的学习顺序图。** Tauri 2 + React。正文按「阶段 → 应用 →
   学习目的 → 掌握要点 → 取舍 → 终点标准」组织成可读篇章（教科书导读篇的写法）；顺序图
   把先易后难画成活的（节点可点击、能看清依赖方向）。内容构建期由 Vite 打进前端
   （`mentor/competitions` 模式），Rust 侧薄壳只开窗口，无自定义命令、无运行期内容读取。
5. **如实呈现覆盖缺口。** 高数应用不存在：导引专页写明「现有内容全部在线性代数与计算工具」，
   并说明这对数二备考意味着什么；不编造路线、不落空骨架。
6. **壳：配置骨架复制自 `guide/sympy-tutorial`（HEAD 版本，自带更新器插件，ADR 0172），
   架构取 `mentor/competitions` 的薄壳模式。** 端口 1523（hmr 11523），进程
   `athena-mathematics-compass`，`group` 为「数学」，更新器 endpoint 为
   `mathematics-compass.json`。此后独立演进，不写「沿用某应用」（ADR 0062）。
7. **导引描述的内容现状会过时**（例如某书译到第几章）。同步义务写进导引自己的 `AGENTS.md`：
   其他数学应用的内容格局变化（新增章、换裁剪、新应用入圈）时，导引的对应描述随那次提交
   一起更新；导引的 `check.py` 校验自身结构（节点 id 唯一、图与篇章引用一致、launcher
   命令与 id 一致），不跨应用校验。

## 后果

- 登记三处同步：`docs/REPOSITORY.md`（结构树、名字表）、根 `README.md`、根 `AGENTS.md`；
  `.github/workflows/ci.yml` 加对应作业。
- 使用者学数学的入口变成「先开罗盘，再进对应应用」；启动方式不变，各应用互不感知罗盘的存在。
- 推荐路径是编辑判断，依据写在导引正文里（各书性质、裁剪范围、认知顺序），不是测量结果；
  学习者按自身情形偏离路径时，导引给出的是「偏离的代价与回头路」，不是唯一真理。
- 数学部分没有高数应用这件事被写在显眼处；哪天高数应用立项，导引的缺口页改写成路线节点。
