# ADR 0086：错题必须在强化练习里测过且没出错才能移出备选库（修订 ADR 0085）

- 日期：2026-10-03
- 状态：已接受；修订 [ADR 0085](0085-reinforce-draws-from-all-wrong.md) 决策 2 中「稳固了的轻但不消失」，
  并在决策 3 之上加一条覆盖保证。0085 原文不改
- 影响：`subjects/driver` 的 `lib/reinforce.dart`、`lib/reinforce_page.dart`
- 关系：延续 [ADR 0076](0076-attempt-attribution-and-reinforcement-practice.md)；掌握度仍只由作答写入（ADR 0052）

## 背景

0085 把错题池定为「历史上答错过的全部题」，并让已稳固的题只是权重变轻、不消失，用来抽检遗忘。
使用者看过之后给的意图是：

1. 错题库应当随着掌握而**缩小**，已经掌握的错题不要再反复练，权重变轻直到消失；
2. 但每道错题**至少要在强化练习里测过一次，并且没有出错**，才可以移出强化练习的备选库——
   在别处（练习、模拟考）答对多少次都不算，要在强化练习里验收通过。

「不消失」与「缩小错题库」相反，所以 0085 的那一条要改。

## 决策

1. **移出条件。** 一道错题（历史上答错过的题）从备选库移出，当且仅当：自它**最近一次答错**以来，它在强化练习里
   被测过（有 `kind = reinforce` 的作答），并且那之后的作答全部答对。任何一次答错——不管在强化练习、
   练习还是模拟考——都让它**自动回到备选库**，需要在强化练习里再测对一次才能再移出。
2. **覆盖保证。** 还没有在强化练习里测过的题，每轮优先给它们留名额：错题名额的一半（向上取整）从这些题里按权重抽，
   其余名额照旧按权重从整个备选库抽。名额是一半而不是全部，是为了不让几百道没测过的题把「刚又答错了」的急题挤出去。
3. **没移出之前，权重逐级变轻。** 状态系数：最近一次还是错 3.0 → 学习中 1.2 → 巩固 0.6 → 稳固 0.3。
   权重只是让已经比较熟的题少出现；**只有决策 1 的条件满足才真正消失**，没测过的稳固题即使权重最低也不会被排除。
4. **移出的题不是从系统里消失。** 它们仍在题库里，仍在「到期复习」的间隔复习里（连对越多隔得越久：
   1、2、4、8、16、32 天），只是不再占强化练习的错题名额。
5. **页面如实说明。** 写出历史上答错过的一共多少道、其中还要练的多少道（多少道还没在强化练习里测过）、
   已移出的多少道；移出的题再答错会自动回来。
6. 0085 的其余部分不变：按权重随机不放回地抽、每轮重抽、「换一批」、整轮默认来自错题池、变式占 1/4。

## 后果

- 备选库的大小随验收而缩小：每轮的名额越来越集中在还没验收通过的题上。
- 「测过」用「作答过」近似：一轮里被选中却没来得及答的题不算测过，下一轮还会照顾它。
- 一道错题要退出，至少要先在强化练习里出现一次且答对；刚在练习里把它答对的题，仍要在强化练习里再验证一次。
- 覆盖名额的一半、权重各档系数都是经验值，没有数据支撑；放在 `lib/reinforce.dart` 开头的常量里，
  用过一段时间后可以按「强化练习成效」的数据再调。
- 抽检遗忘的责任回到「到期复习」：移出的错题隔 8 天以上才可能被它抽到。
