# ADR 0088：同考点变式在强化练习里答对，也算原题验收通过（修订 ADR 0086 决策 1）

- 日期：2026-10-04
- 状态：已接受；修订 [ADR 0086](0086-reinforce-coverage-then-fade.md) 决策 1 里「必须原题自己在强化练习里测过」。
  0086 原文不改
- 影响：`subjects/driver` 的 `lib/reinforce.dart`、`lib/home.dart`、`lib/reinforce_page.dart`
- 关系：延续 [ADR 0079](0079-clusters-computed-at-runtime.md)（考点簇）、[ADR 0085](0085-reinforce-draws-from-all-wrong.md)

## 背景

一轮 50 题里约 1/4 是同考点变式（换了问法的同簇题）。0086 的移出条件只认原题自己在强化练习里答对，
所以变式题答得再好，备选库也不缩小：一轮最多只有复测的那三十几题能让它减少。
变式题本来就是用来检验「是真懂还是只背了那道题」的，答对它比答对原题更能说明懂了，却不计入验收，这不合理。
使用者的意图：变式题答对也算验收。

## 决策

1. **验收来源增加一种。** 一道错题（历史上答错过的题）从备选库移出，当且仅当下列之一成立：
   a. 0086 原条件：自最近一次答错以来，它在强化练习里答对过、之后没再错；
   b. **新增：自它最近一次答错以来，它所在考点簇里的另一道题在强化练习里作为变式（`reason = variant`）答对过。**
2. **回来的条件不变。** 原题任何一次答错（不管在哪）都清掉已有的验收，回到备选库；变式题自己答错，
   不影响原题，只是那道变式题按自己的历史进入或留在备选库。
3. **一次变式答对，同簇里所有还在备选库的错题都算验收。** 作答记录里没有「这道变式是为哪道原题出的」，
   而簇本来就是「同一个考点的不同问法」，所以按簇记；要精确到原题，得改作答记录格式，现在不做。
4. **没有考点簇就没有这条来源。** 考点簇后台算好之前、带图片的题（不参与聚类）都只走 1a，行为与 0086 一致。
5. 页面的移出说明加上这一条来源；四个数字块不变。「没在强化练习里测过」仍指原题自己没被强化练习作答过，
   被变式验收而移出的题不再计入它。

## 后果

- 备选库缩小更快：每答对一道变式，同簇的错题一起移出，一轮可能减少的数量超过复测题数。
- 簇里错题多时一次答对就全部移出，偏宽松；簇由文字相似度和共同条款现算，已知有少量相邻考点的误判（ADR 0079）。
  这是用「宽」换「变式有用」，数据够了再看「强化练习成效」里变式的转正率与保持率，必要时改成只验收一题。
- 考点簇算好后要用它重建作答摘要（`HistorySet.build` 多一个可选参数 `clusters`），
  首页在簇就绪时重算一次，不改作答记录与同步格式。
- 抽检遗忘的责任仍在「到期复习」。
