### 变更

- **应用平级**：C++ 教程降为 `apps/cpp`，与其它学习应用同级（ADR 0045）；
  文档与 ADR 按仓库 / 应用分家。
- **声明式启动**：各应用只写 `app.json`，由编排器统一构建与打开（ADR 0046）；
  开发态启动，不再装进系统目录。
- **C++ 教学换代**：大纲 / 过程 / 实验分层；内容改 GTK 承载，去掉 Markdown
  手册路线；知识点补难度、掌握目标与先修；实验证据链纵向排列；移除运行历史
  与 AI 差异讲解。
  - 大纲 / 过程 / 实验三层分工见 ADR 0028；第一章「类型与表达式」按此重写，
    篇幅与掌握目标对齐（ADR 0040）。
  - 插图改由控件与 Cairo 绘制，不再依赖 SVG 渲染（ADR 0038）。
  - 导航重做：首页大入口 + macOS 原生菜单栏取代侧边图标条；C++ 目录与学习图谱
    合并，独立进度页并入学习图谱。
  - 实验证据链为「当前目标 → 真实源码 → 运行验证 → 观察结果」，减少阅读与实验
    之间的横向视线跳跃。
  - 字号改为单一基准加 em，全局基准 20pt。
  - 移除运行历史时一并去掉双记录比较与 git 快照；旧库的 `run_history` 表和记录
    原样保留，不做破坏性删除。
- 构建目录统一叫 `build`（原 `builddir`）；`apps/cpp` 根上散落的源文件按语义归入
  `platform/`、`ui/`、`packaging/`。
- Linux CI / Release 依赖与 Meson 对齐：去掉已不再链接的 WebKitGTK、md4c-html。

### 新增

- **启动器**：托盘 / macOS 菜单栏 / 终端三条前端共用编排器，图块列表打开各应用。
  跨平台托盘窗口用 Rust + Slint，macOS 菜单栏常驻用 Swift（⌃⌥A 唤出），终端命令
  为 `athena-dev`；每个应用自带图标，有演进关系的学科之间画连线（C → C++）。
- **姊妹应用**：`c`、`dsa`、`english`、`mathematics` 入场；DSA 承接原 C++ 空分类。
  - `mathematics`：线性代数五章十六节；可缩放、拖动的线性变换画布；直觉 / 严谨
    两个视图逐条对照；前置诊断、随堂练习与章末小考；本机 Python 符号引擎验算
    推导；全节可用系统语音朗读。
  - `english`：按能力路线组织；分级内容与测评，接入本地公开词表；按错因归组的

  - `c`：Qt Quick 教案式入口，首页画章级知识图谱；LVGL + SDL2 小程序放在
    `playground/`。
- **内容出处**：判分内容必须带来源，检查器入库（ADR 0043）。
- C++ 教程补齐类型与表达式章、知识图谱与随堂考核。
  - 第一章七节学习页全部完成，新增「对象生命周期」知识点。
