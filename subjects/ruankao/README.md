# 软考(软考中级备考)

以软考中级为目标的学习应用:考纲对齐、分值驱动,当前包含**计算机系统基础**
与**操作系统**两门公共共用课程(双证路线里学一遍两科都拿分的部分),章节
课后考核与历年真题演练,掌握度由作答写入 `progress/learning.db`。

- 打开:`launcher open ruankao`
- 验证:`python3 scripts/check.py`
- 结构与规则:`AGENTS.md`;真题导入:`content/past-exams/README.md`

与驾考(`driver`)同构——以考试为学科。考试事实:两科同时 ≥45 分通过;
综合知识 75 空单选;案例分析约 5 道大题;嵌入式设计师每年上半年一考。
