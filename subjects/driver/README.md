# Athena · 驾考学习（独立应用）

与其他学习应用**平级**的独立应用。技术栈：Flutter 桌面。不启动别的应用也可以
完成练习和模拟考。决策见 [`docs/decisions/`](docs/decisions/)，细则见 [`AGENTS.md`](AGENTS.md)。

## 做什么

练中国机动车理论考与场地考的三块，备考小型汽车（C2 优先，最多 C1），考试地河南洛阳：

1. **科目一** 道路交通安全法律、法规和相关知识。含河南地方题，模拟考按考场题型与内容比例组卷。
2. **科目二（C2 四项）** 倒车入库、侧方停车、曲线行驶、直角转弯：评判规则题、动画示意、
   练车日记录与复盘。等科目一模拟考稳定在 95 分以上才开放。
3. **科目四** 安全文明驾驶常识（规章里挂在「科目三」名下，考场是单独一卷、单独记分，
   跟路考不是同一张成绩）。等科目一日常题全部掌握后开放。

不做科目三上路，也不做手机 App。

题目都指到法律、法规、规章或国家标准，答案以与现行规定一致为准。公开题库按
ADR 0008 收录并逐道核对；商业站点只作选题线索（ADR 0046）。标志在界面里自绘。

## 运行

需要 Flutter SDK（stable）。

```sh
cd subjects/driver
launcher open driver
```

环境变量 `ATHENA_DRIVER_ROOT` 指向应用根目录（含 `content/`）。不要打开打包副本。

```sh
python3 scripts/check.py
```
