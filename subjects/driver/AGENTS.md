# 驾考学习 — 项目协作规则

本文档是 **`subjects/driver` 独立应用** 的项目级指令。本应用与仓库里其他学习应用
**平级、可脱离**：不读别人的配置、不链接别人的代码，不依赖别的进程即可完成
开发、构建与练习。

改本应用时以本文为准。启动器通过 `app.json` 发现并拉起它（主仓库 ADR 0032 /
0046），那不是运行本应用的前提。目录 id 是 `driver`，指机动车理论考试，不是设备
驱动；知识点前缀是 `drive.`，与目录名不同，已经写进进度库，不要改。

## 定位

- 目标：把中国机动车理论考里的 **科目一** 和 **科目四** 练到考场规则够用。
- 科目四是安全文明驾驶常识：单独一卷、单独记分，跟路考不是同一张成绩。出处引用
  规章时写全称「科目三安全文明驾驶常识」，界面不要反复纠正学习者。
- 科目二只做 **C2 四项**（倒车入库、侧方停车、曲线行驶、直角转弯）：评判题只从 GA 1026—2022 原文出、每题标条款号；操作讲解是应用内动画示意（运动学轨迹，测试逐帧守住示意动作不出线），经验要点不计分、不写具体点位；练车错因逐条对应评判条款，按考场规则给每一把打分，练车记录不写掌握度（ADR 0036）。配合线下练车有三样：练车前简报（全由练车记录推导）、个人点位卡（只给骨架、内容自己写，照片缩图随仓库走、不进事件同步）、默演（先口述再对照，自评不写掌握度）（ADR 0037）。**科目二的界面围绕「练车日」组织，不套科目一的练习形式**：练车前准备 → 练车后一次复盘整天 → 按练车日看趋势 → 考前看整场就绪度（四项合算一个总分，按最近记录精确组合）；评判题只是规则自测，不是主线（ADR 0039）。动画示意边播边念讲解（动画等讲解念完再进下一步），每一步有标条款号的注意事项和画面标注（线、点、车上部位）（ADR 0040）。不做科目三上路，也不做手机 App。
- 题目必须能指到法律、行政法规、部门规章或国家标准（ADR 0003）。**公开题库可以直接
  收录**（ADR 0008：自用软件，不分发、不商业化），但唯一的硬标准是与现行法规一致——
  分值、期限、额度对不上现行规定的一律改正或丢弃，外部解析的条号要自己核对。科目一按内容分四阶段，**不设解锁**：四个阶段和科目一模拟考全部开放（ADR 0044）；
  科目一日常题全部掌握后才开放科目四（ADR 0006 第 4 条）。
- 界面基准字号 **20pt**，正文、选项、侧栏都按这个尺寸走，不要再按手机控件缩小。
- 掌握度只由作答对错写入，禁止手动标记熟练。练习跳过最近一次答对的题。模拟考按考场的交法：答一题交一题，交了不能改，答错当场给出正确答案；没答的题按错计分但不写作答记录（ADR 0023）。错到不可能及格也不提前结束，照样答完整卷，状态栏只提示「已不及格」（ADR 0041）。模拟考和阶段测试只计时不收卷：顶栏显示「用时 / 考场时长」，超时只变红，到点不自动交卷，只有自己点「交卷」才结束（ADR 0042）。开始模拟考时有没交的草稿就直接续上，不问、不提供放弃重抽；续答的用时只算真正答题的时间，挂起的不算（ADR 0043）。练习与模拟考一页十题；一页十题答完就自动翻页，不看对错（最后一页自动结束本轮）；从最后一题判完算起至少停 5 秒再翻，看清题目和解释；练习最后一题答错先念完解释，念完后至少再停 1.5 秒（ADR 0025、0038）；答题过程中下一道没答的题自动滚到屏幕正中，不用自己拿滚轮翻（ADR 0022）；答完的题可以用题干右侧的「解析」把右栏依据调回来（ADR 0007）。每道题都显示稳定编号（题库 id 去掉 `drive.` 前缀，如 `s1.signals.207`），点一下复制；「第几题」只是这一轮里的位置，反馈题目问题时报编号。答错自动朗读解释，答对不念，蓝条上的「系统朗读 / 停止朗读」随时可手动听（ADR 0005、0007）。**没有「迟疑」这个概念**（ADR 0020 撤销）：答对就算掌握，不看答题用时，避免规则本身产生「答对了却卡在既没算掌握也没重新进练习」的死角。题目按路上会碰到的场面出，分高频 / 常考 / 常规 / 偏难：高频常考多练多考，常规少出；同一档里按公开题库给的全国错误率从高到低练，错误率 20% 以上的在练习里标「易错」，模拟考不标、不按错误率加权（ADR 0027）；偏难怪（特种车、冷门数字、几乎遇不到的场面）默认不练、不挡过关，阶段进度也不算它；模拟考可以抽到，按常规题的权重进袋、每卷封顶 2%（科目一最多 2 道、科目四最多 1 道），不能喧宾夺主（ADR 0032）。题量以覆盖面为准：科目一约 1580 道、科目四约 1560 道。使用者备考小型汽车（优先 C2，最多 C1），题库按这个准驾车型精确裁剪：其他准驾车型（大型客车、牵引车、摩托车等）专属的申领/年审/记分规则不收，拿这些车型举例的通用安全知识（让校车、防追尾大货车等）不受影响照收（ADR 0017）；科目四里危化品运输、营运客车驾驶人自己要处置的事标偏难，大车事故案例照收（ADR 0029）。底子是自己按条文写的 334 道，盖住《道路交通安全法》与《实施条例》中与驾驶人有关的**每一条**（外加记分办法、驾驶证规定、机动车登记规定、事故处理程序规定、刑法第133条与国标标志标线）；其余按 ADR 0008 收录公开题库，地方题和与现行规定冲突的题不收——考试地是河南洛阳，河南地方性题目是例外，照收（ADR 0011）；使用者已确认洛阳考场的科目一会抽河南地方题，科目一模拟考按 GA 1026 表 1 固定抽 10 道地方题（ADR 0023）。题型覆盖考场会出的全部：判断、单选、多选、看图、看动画（GIF），题图随仓库走。四阶段按内容分（章节归属见 ADR 0009），题量随内容走，不设上下限；河南地方题按每道题的内容归阶段（ADR 0026）。不堆换皮；公开题库按 ADR 0008 收录，以与现行法规一致为准。科目一要盖住考试内容的九块（公安部令162号第32条）：通行规则、交通信号（含标志标线）、违法记分与处罚、事故处理、驾驶证申领使用、机动车登记与检验、高速公路、安全带与停放、饮酒疲劳。补题看关键知识点有没有覆盖，不按考场题型比例凑题：一个考点已有判断题覆盖就算覆盖，不为它再补单选换皮；考场题型配比只决定模拟考怎么抽（见「出题」第 5 条）。科目一模拟考随时可考；科目四在科目一日常题全部掌握后才开放。「易混数字」页把记分、限速、距离、期限、罚款、酒精这些同类数字并排对照、配横条比大小，每行指到条文，每组能直接练相关题；内容在 `content/cheatsheet.json`，数字规定改了要跟题一起改（ADR 0028）。「考前复习」收累计答错 2 次及以上的题；累计答对比答错多 1～2 次（错 2 对 3，错 3 次以上多对 2 次）、且最近一次答对才退出，移出后再错自动回来；清单由作答记录派生、不另建表（ADR 0033–0035）。激励（今日目标、连续日、连对、里程碑）只展示进度库派生的统计，两者按仓库 ADR 0052 走同一条回路。

## 技术栈

- **壳**：Flutter 桌面（macOS / Windows / Linux）
- **界面**：Dart；桌面工作台（侧栏 + 主区），不为手机窄屏折中。标志用
  `CustomPaint` 自绘，不嵌 WebView。见 ADR 0004。
- **内容**：`content/curriculum.json` + `content/questions/*.json`
- **跨机器同步**：作答记录是只追加的事件流，推到 GitHub 私有仓库的一个 JSONL 文件，
  按「题号 + 时间」取并集合并（ADR 0010）。走 REST Contents API，不要求装 git；令牌存
  本机用户数据目录的 `sync.json`，不进版本库。本地 SQLite 仍是唯一读写来源。
- **进度**：SQLite，`progress/learning.db`——**随仓库走**，换机器 clone 下来
  掌握度和战绩还在（主仓库 ADR 0053）；拿不到工作树的发行副本退回用户数据目录
  `AthenaDriver/`。自建表、自迁移，知识点 ID 前缀 `drive.`（主仓库 ADR 0037）

不引入 GTK、Qt、Tauri。开发时内容从 `ATHENA_DRIVER_ROOT` 读磁盘，改 JSON
热重启即可看到；发行包才走 Flutter assets。macOS entitlements 关闭 App
Sandbox，否则读仓库题库和写进度库都会被拒，窗口只剩黑框。

## 目录

| 路径 | 职责 |
|---|---|
| `content/` | 课表、题库、出处 catalog；**唯一内容源** |
| `lib/` | 界面、组卷、进度 |
| `app.json` | 怎么构建、怎么启动、怎么算就绪 |

| `scripts/check.py` | 本应用验证入口 |

## 开发与验证

需要 Flutter SDK（stable）。macOS 要编窗口还需要完整 Xcode，不只是 Command Line Tools。
若系统 `xcode-select` 仍指向 Command Line Tools，`scripts/run_dev.py` 会在启动时
把 `DEVELOPER_DIR` 指到 `/Applications/Xcode.app`，不必先 sudo 切换。

```sh
cd subjects/driver
launcher open driver
# 或菜单栏启动器点「驾考学习」；勾预热后登录即编好，点一下窗口现身。
# 改 lib/ 会热重载；改 content/ JSON 要热重启（大写 R，或保存后点重启）。
python3 scripts/run_dev.py
```

不要启动打包副本。已在跑时再点一次只把窗口前置，不会再冷编译。

```sh
python3 scripts/check.py              # JSON + analyze + test + 当前桌面 debug 构建
python3 scripts/check.py --skip-build # 只改了题库时
```

仓库根 `python3 scripts/check.py driver` 会转到这里。

## 出题

1. 打开 `content/sources/catalog.json` 里的来源，核对照条文或标准分类。
2. 每题带 `prompt`、恰好能判分的 `choices`、`explain`、`source_refs`。
3. `relation` 用 `quoted` / `adapted` / `authored`；自造要写 `note`，同一文件
   不得超过一半。
4. 标志题以「看到之后怎么开」为主（让行要不要停、限速能不能超、禁行能不能进）；标志、标线、导向箭头、交警手势「是什么意思」的认含义题也收，同一含义只留一道，每张图都要看过核对；「属于哪一类」的认类别题不收（ADR 0024）。
5. 模拟考按 GA 1026 的题量、时长与题型配比组卷：科目一判断 40 单选 60（4.1.3.1），科目四
   判断 20 单选 20 多选 10（4.3.2.3.1）；科目一还按表 1 的内容比例分块抽（驾驶证与登记 20、
   通行 25、违法处罚 25、事故 10、机动车基础知识 10、地方 10，`curriculum.json` 的
   `exam.blocks`）。题库不够考场题量时折合百分制，并在结果页说明。科目一模拟考随时可考，
   科目四入口要等科目一全部掌握（ADR 0006 第 4 条、ADR 0044）。
6. 仪表、指示灯、操纵件、车辆安全装置这类「机动车基础知识」题没有自己的知识点，出题时
   标 `"exam_block": "vehicle"`，否则组卷会按知识点落进通行块（ADR 0023）。
