# 驾考学习 — 项目协作规则

本文档是 **`subjects/driver` 独立应用** 的项目级指令。本应用与仓库里其他学习应用
**平级、可脱离**：不读别人的配置、不链接别人的代码，不依赖别的进程即可完成
开发、构建与练习。

改本应用时以本文为准。启动器通过 `app.json` 发现并拉起它（主仓库 ADR 0032 /
0046），那不是运行本应用的前提。目录 id 是 `driver`，指机动车理论考试，不是设备
驱动；知识点前缀是 `drive.`，与目录名不同，已经写进进度库，不要改。

## 定位

- 目标：把中国机动车理论考里的 **科目一** 和 **科目四** 练到考场规则够用。（另有科目二 C2 四项，见下；范围变迁见 ADR 0054）
- **叫法统一（ADR 0056）：科目三 = 路考（道路驾驶技能），科目四 = 安全文明驾驶常识（理论卷）。**
  科目四单独一卷、单独记分，跟路考不是同一张成绩。规章原文把这两部分合称「科目三」，
  那只在引用条文原文（`source_refs` 的 `note`）时出现；界面、题面、解释、文档一律按上面
  的叫法，不写「科目三安全文明驾驶常识」，也不用「科二」「科三」这类缩写。
- 界面基准字号 **20pt**，正文、选项、侧栏都按这个尺寸走，不要再按手机控件缩小。

### 科目二（C2 四项）

- 科目二只做 **C2 四项**（倒车入库、侧方停车、曲线行驶、直角转弯）：评判题只从 GA 1026—2022 原文出、每题标条款号；操作讲解是应用内动画示意（运动学轨迹，测试逐帧守住示意动作不出线），经验要点不计分、不写具体点位；练车错因逐条对应评判条款，按考场规则给每一把打分，练车记录不写掌握度（ADR 0036）。
- 配合线下练车有三样：练车前简报（全由练车记录推导）、个人点位卡（只给骨架、内容自己写，照片缩图随仓库走、不进事件同步）、默演（先口述再对照，自评不写掌握度）（ADR 0037）。
- **科目二的界面围绕「练车日」组织，不套科目一的练习形式**：练车前准备 → 练车后一次复盘整天 → 按练车日看趋势 → 考前看整场就绪度（四项合算一个总分，按最近记录精确组合）；评判题只是规则自测，不是主线（ADR 0039）。
- **科目二要等科目一模拟考最近 3 场都在 95 分以上才开放**，锁住时只说明原因、列出最近几场分数，掉一场就重新锁上（ADR 0047）。
- 动画示意边播边念讲解（动画等讲解念完再进下一步），每一步有标条款号的注意事项和画面标注（线、点、车上部位）（ADR 0040）。
- 不做科目三上路，也不做手机 App。

### 题目出处与题库来源

- 题目必须能指到法律、行政法规、部门规章或国家标准（ADR 0003）。
- **公开题库可以直接收录**（ADR 0008：自用软件，不分发、不商业化），但唯一的硬标准是与现行法规一致——分值、期限、额度对不上现行规定的一律改正或丢弃，外部解析的条号要自己核对。

### 答题与考试规则

- 掌握度只由作答对错写入，禁止手动标记熟练。
- 练习跳过最近一次答对的题。
- **全部掌握后练习不再是死路（ADR 0125）**：待练清零时侧栏入口写「重新练习（全部 n 题）」、专题写「标题（重练）」、概览页按钮变「重新练习全部题」，点了先弹「全部掌握，重新练习？」确认一次，确认后把这一组的全部日常题再练一遍。答题记录一律保留——错题本、强化练习、统计趋势与科目解锁（科目四不会重新锁上）都不受影响；这一轮里答错的题按现有规则自然回到待练。不提供清零重练。
- 模拟考按考场的交法：答一题交一题，交了不能改，答错当场给出正确答案；没答的题按错计分但不写作答记录（ADR 0023）。
- 模拟考答错的题也当场讲：右栏答题卡下方显示依据并自动朗读，答对仍不提示（ADR 0052）。
- 错到不可能及格也不提前结束，照样答完整卷，状态栏只提示「已不及格」（ADR 0041）。
- 模拟考和阶段测试只计时不收卷：顶栏显示「用时 / 考场时长」，超时只变红，到点不自动交卷，只有自己点「交卷」才结束（ADR 0042）。
- 开始模拟考时有没交的草稿就直接续上，不问、不提供放弃重抽；续答的用时只算真正答题的时间，挂起的不算（ADR 0043）。
- 练习与模拟考都是一页二十题（科目一百题卷刚好五页，ADR 0086、0088）；一页答完就自动翻页，不看对错（最后一页自动结束本轮）；最后一题答对只停 1 秒就翻（ADR 0053）；最后一题答错从判完算起至少停 5 秒再翻，看清正确答案和解释，有朗读先念完、念完后至少再停 1.5 秒，练习和模拟考都是（ADR 0025、0038、0052）；答题过程中下一道没答的题自动滚到屏幕正中，不用自己拿滚轮翻（ADR 0022）；答完的题可以用题干右侧的「解析」把右栏依据调回来（ADR 0007）。
- 每道题都显示稳定编号（题库 id 去掉 `drive.` 前缀，如 `s1.signals.207`），点一下复制；「第几题」只是这一轮里的位置，反馈题目问题时报编号。
- 答错自动朗读解释（练习和模拟考都是），答对不念，蓝条上的「系统朗读 / 停止朗读」随时可手动听（ADR 0005、0007）。
- **没有「迟疑」这个概念**（ADR 0020 撤销）：答对就算掌握，不看答题用时，避免规则本身产生「答对了却卡在既没算掌握也没重新进练习」的死角。

### 题库范围与分级

- 题目按路上会碰到的场面出，分高频 / 常考 / 常规 / 偏难：高频常考多练多考，常规少出；同一档里按公开题库给的全国错误率从高到低练，错误率 20% 以上的在练习里标「易错」，模拟考不标、不按错误率加权（ADR 0027）；偏难怪（特种车、冷门数字、几乎遇不到的场面）默认不练、不挡过关，阶段进度也不算它；模拟考可以抽到，按常规题的权重进袋、每卷封顶 2%（科目一最多 2 道、科目四最多 1 道），不能喧宾夺主（ADR 0032）。
- 题量以覆盖面为准：科目一约 2490 道、科目四约 1710 道，公开题库剩余题目逐道核对后补收，同考点换问法也收（ADR 0045）。
- 使用者备考小型汽车（优先 C2，最多 C1），题库按这个准驾车型精确裁剪：其他准驾车型（大型客车、牵引车、摩托车等）专属的申领/年审/记分规则不收，拿这些车型举例的通用安全知识（让校车、防追尾大货车等）不受影响照收（ADR 0017）；科目四里危化品运输、营运客车驾驶人自己要处置的事标偏难，大车事故案例照收（ADR 0029）。
- 底子是自己按条文写的 334 道，盖住《道路交通安全法》与《实施条例》中与驾驶人有关的**每一条**（外加记分办法、驾驶证规定、机动车登记规定、事故处理程序规定、刑法第133条与国标标志标线）；其余按 ADR 0008 收录公开题库，地方题和与现行规定冲突的题不收——考试地是河南洛阳，河南地方性题目是例外，照收（ADR 0011）；使用者已确认洛阳考场的科目一会抽河南地方题，科目一模拟考按 GA 1026 表 1 固定抽 10 道地方题（ADR 0023）。
- 题型覆盖考场会出的全部：判断、单选、多选、看图、看动画（GIF），题图随仓库走。
- 四阶段按内容分（章节归属见 ADR 0009），题量随内容走，不设上下限；河南地方题按每道题的内容归阶段（ADR 0026）。
- 公开题库按 ADR 0008 收录，以与现行法规一致为准；考场会出的不同问法（判断、单选、看图）都收（ADR 0045）。
- 科目一要盖住考试内容的九块（公安部令162号第32条）：通行规则、交通信号（含标志标线）、违法记分与处罚、事故处理、驾驶证申领使用、机动车登记与检验、高速公路、安全带与停放、饮酒疲劳。

### 科目一结构与科目四入口

- 科目一按内容分四阶段，**不设解锁**：四个阶段和科目一模拟考全部开放（ADR 0044）；科目一日常题全部掌握后才开放科目四（ADR 0006 第 4 条）。
- 补题看关键知识点有没有覆盖，也收考场会出的不同问法，不因题型比例限制题量；考场题型配比只决定模拟考怎么抽（见「出题」第 5 条）。
- 科目一模拟考随时可考；科目四在科目一日常题全部掌握后才开放。

### 配套页面与激励

- 「强化练习」（主仓库 ADR 0076）从**错题库**（历史上答错过、累计答对还没达到答错 2 倍的题）按权重随机抽一张题单（默认 50 题，主仓库 ADR 0087；错得多、最近又错、隔得久的更容易被抽到，越熟越轻；备选库不够一轮才用薄弱章节、间隔到期补足；主仓库 ADR 0085）。**一道错题累计答对的次数达到答错次数的 2 倍，就移出备选库**——错 1 次要对 2 次，错 3 次要对 6 次；不分在哪里答对（练习、模拟考、强化练习一视同仁）；之后再答错，比例掉下去，题自动回来；页面写出「再对几次才移出」（本应用 ADR 0079，取代主仓库 ADR 0086、0088 的验收规则与本应用 ADR 0075 的常驻规则）。还没在强化练习里测过的题，每轮错题名额的一半优先给它们。每一轮重新抽（做完一轮自动重抽，页面有「换一批」），页面最上方用大号数字块写明备选库的大小（还要练多少题）、其中多少题没测过、已移出多少题和每轮抽多少题（ADR 0087），页面同时给出掌握度漏斗（新题/学习中/巩固/稳固）、优先章节和通过概率（模型估计，必须与真实模拟考成绩并列看）。**它是练习不是考试**：不计时、不占模拟考成绩，作答的`kind` 为 `reinforce`；**模拟考仍从整个题库按考场配比整体抽取**，不偏向薄弱点。作答另记归因字段（主仓库 ADR 0076 阶段 1）：`chosen`（所选选项，多选排序后逗号拼接）、`session_id`（一次练习/复习/模拟考/强化练习是一个会话，模拟考续答沿用草稿里的）、`reason`（仅强化练习：retest/weak/due/fill）；模拟考记录带 `session_id` 与整场 `used_ms`，这就是「作答属于哪场考试」的关联键；答错后右栏解析显示了多久，作为独立事件 `explain-views` 按（题号, 作答时刻）对上那次作答。这些字段都是可选的，旧数据为空。错了一道题，会从它的**考点簇**里出另一种问法的同考点变式（理由 `variant`，占整轮的 1/4），检验是真懂还是只背了那道题；考点簇是 `lib/study/clusters.dart` 的纯函数按题库内容现算的（带图片的题不参与，约五分之一的纯文字题有变式，已知有少量相邻考点的误判，见 ADR 0079），第一次打开强化练习页时在后台算一次。选题与统计全是`lib/study/reinforce.dart` 里的纯函数，由作答记录派生，不另建表；题只从题库里选，不让 AI 造题。强化练习页下半是**学习诊断**（`lib/study/diagnosis.dart` 纯函数、`lib/study/diagnosis_panel.dart` 界面，主仓库 ADR 0076 决策 10「后做」）：记忆保持（隔多久还记得）、错因（用时对比自己的中位数：粗心/不会/不熟）、选错的方式（反复选同一个错选项、多选漏选/多选；要有 `chosen`）、与全国错误率比（盲区/强项/各章差距；只有公开题库的题有错误率）、强化练习成效（转正率/保持率；要有 `reason`）。每一项带样本量，样本不足的明说，没数据的写「还没有」，不编结论。
- **速记专题归属科目**（ADR 0097）：每个专题恰好属于一个科目，注册在 `lib/speed/speed_topics.dart`，侧栏挂在所属科目底下；科目一有易混数字、标志、标线、仪表、手势、考点、河南、记分证照，科目四有易混数字、手势、考点，各用本科目的题、各记各的作答，不混在一起；科目四没解锁前它的速记题也隐藏。
- 事故专题（ADR 0103）：科目一「事故处理与时限」（现场、私了与报警、十日五日三日时限、责任赔偿、逃逸刑责）、科目四「事故处置」（现场防二次事故、高速隧道铁路道口、责任赔偿）；乘员专题与信号灯铁路道口专题（ADR 0106，科目一、科目四各一份）；行车操作与车辆专题（ADR 0107：超车会车掉头倒车、车辆基础与操作、车辆故障与紧急处置）；避让、山区坡道弯道、电动汽车与科目四补充专题（ADR 0108：高速公路、疲劳与驾驶状态、起火逃生）；停车专题（ADR 0104）：科目一「停车与违停」、科目四「停车与停放」。新专题的内容放 `content/topics/<专题 id>.json`，注册表加一行即可。
- 标志速记页有 167 种标志（禁令、警告、指示、指路、高速公路、旅游区、障碍物提示七组）：新增的标志直接用题库里「这个标志是何含义」类看图题的官方题图，题与标志的关联用题目字段 `sign_ref`（`sign` 是题面自绘标志用的，不能复用）；一道红斜杠是「禁止长时停车」、红叉才是「禁止停车」（ADR 0100）。
- 速记页（易混数字、标志、标线、仪表、手势、考点、河南、记分证照）都有「自测」，**只在组内**：每组标题行右侧一个「自测」只考这一组的卡，页头没有全页自测（ADR 0116）。**自测用做题界面**（与错题本同一个做题台，不弹对话框），**全是四选一**，**按条目内容现场出题、不依赖练习题库**：每次点「自测」，正确项从条目要点里随机抽、干扰项从同页别的条目随机取（`freshRecallQuestionOf`）；没有题图的符号卡用说明里的外观描述问；现场出的卷不记所选选项（ADR 0118）。**每张速记卡有稳定编号**（`drive.recall.<s1|s4>.<页>.<哈希>`，知识点号不在课表里，日常题、章节练习、模拟考、解锁判断不带它），**自测的每次作答就是一条普通作答记录**，错题本、考前复习、强化练习用同一份记录（它们用题库里按题号做种子的固定题面）：答错的卡进错题库，错题本、强化练习里按答对到答错的 2 倍才移出（ADR 0094、0079）；**专题自测不套这条**：最近一次自测答对就算掌握，答错就再考（ADR 0121）。自测只考「没考过」和「最近一次答错」的卡，答错的先考，答对的不再出现（ADR 0090、0121）；整组都答对了按钮写「再测一遍」，点了整组重考（ADR 0099、0115）。选项由 `buildQuiz` 生成（去掉解释性括号、干扰项长度与对题干字面重合接近正确项、长句排除与本条目要点近似的，ADR 0094）。易混数字分正向（题干把数字挖成括号，选同组的值）与反向（「某个值对应哪一项」）两类（ADR 0092、0095、0118）。**没有为自测另存任何记录**（`selftest-*.json` 已删除）。**专题掌握只由专题自测写入**（ADR 0112、0119）：判一张卡、一个条目、一组、一个专题都只看**专题自测里**的作答（速记卡题号且没记所选选项，`selfTestHistories`；在错题本、强化练习里答速记卡照样进错题本，但不算专题掌握），关联真题（日常练习）的作答不参与掌握判定——真题练熟了，没在自测里测过的卡照样考；速记组里没有「练这组」（ADR 0117）。速记页的相关题从本科目**全部**题里取，不分偏难、一视同仁（ADR 0112）。
- 侧栏专题按内容分四组折叠（速记对照、事故与停车、通行规则、车辆与安全），组和专题左边有状态圆（按自测作答：红 = 答错未掌握、绿 = 答对过、灰 = 没做过，ADR 0109）；专题右侧常驻「a/b」——a 是自测通过的大类数（组内「自测」按钮变绿的组），b 是这个专题页面上的大类总数（ADR 0122）；速记页的组标题（一级标题，如「记分：最容易混的对子」）左侧**不放**掌握圆点，组的掌握看「掌握 a/b」（分母是页面上看得见的条目数，易混数字按行、一行名下的卡都答对才算一条，全部专题适用，ADR 0119）与组内「自测」按钮的颜色，组内条目的状态点与易混数字的行点保留（ADR 0116）；最近一次自测答错的条目，红点中间写白色数字——还要再答对几次才算掌握（ADR 0120、0121）；判档全部走 `statusOfIds` 一个函数——红 = 有卡最近一次自测答错、绿 = 每张最近一次都答对、灰 = 没测完，只看自测自己的作答（ADR 0112、0121）；速记组里**只有「自测」一个按钮**（全部专题适用，ADR 0117 去掉了「练这组」）：按钮颜色就是这一组自测卡的结果（红/绿/灰），文字写这次要考几题，整组都答对了写「再测一遍」（与组圆同一把尺子），没全对不整组重来（ADR 0099、0115～0118）。
- 易混数字补漏（ADR 0105）：事故处理时限、登记办理日数、满分与学法减分、申领门槛、急救数字五组；数字要写进情形原文由 `clozeStem` 挖空，值不带单位的写成「4.9 以上」。
- 「易混数字」页把记分、限速、距离、期限、罚款、酒精这些同类数字并排对照、配横条比大小，每行指到条文，每组能直接自测；内容在 `content/cheatsheet.json`，数字规定改了要跟题一起改（ADR 0028）。
- 「考前复习」收累计答错 2 次及以上的题；累计答对比答错多 1～2 次（错 2 对 3，错 3 次以上多对 2 次）、且最近一次答对才退出，移出后再错自动回来；清单由作答记录派生、不另建表（ADR 0033–0035）。
- 激励（今日目标、连续日、连对、里程碑）只展示进度库派生的统计，两者按仓库 ADR 0052 走同一条回路。
- **学习方法原型（ADR 0113）**：主原型**检索强化**，无辅原型。驾考判分对应真实试卷、内容是规则与事实，强化练习（选题即检索、连对定复习间隔、同考点变式交错）就是本原型的完整形态；一轮 50 题即有界会话。

## 技术栈

- **壳**：Flutter 桌面（macOS / Windows / Linux）
- **界面**：Dart；桌面工作台（侧栏 + 主区），不为手机窄屏折中。标志用
  `CustomPaint` 自绘，不嵌 WebView。见 ADR 0004。**速记页的主图是规范图**（标志取
  Wikimedia Commons 国标图形、手势用规范 GIF、标线与仪表复用题库官方题图，路径写在各内容
  JSON 的 `image` 字段，ADR 0080），自绘视图只在图读不出来时兜底。
- **内容**：`content/curriculum.json` + `content/questions/*.json`
- **进度（个人数据）——本地优先（主仓库 ADR 0070）**：界面只读写本地 SQLite
  （用户数据目录 `AthenaDriver/local-<学习者编号>.db`，不进仓库；表结构与中心 PG 同名同列
  ——除本地不建的 `user` 列，业务键唯一索引承担幂等合并）。写入在同一事务里落业务表
  和待发送队列（outbox）；`lib/core/sync.dart` 的 SyncEngine 后台把队列幂等上传、按游标增量
  拉取，与软路由上的中心 PostgreSQL（库 `athena_driver`）保持同一份。断网照常做题，
  联网后自动补发；侧栏常驻显示待同步条数。**不再有 `learning.db`、不再走 GitHub
  JSONL 同步**（主仓库 ADR 0067、0068；旧同步代码已删，ADR 0010 仅作历史）。
  表结构管理在服务端，客户端不再建表。知识点 ID 前缀 `drive.`（主仓库 ADR 0037）。
  **题库不进数据库**，仍是 `content/` 的 JSON。
- **多用户（主仓库 ADR 0071～0075）**：同一份题库给多个学习者，各人一份空白历史。
  学习者无口令（应用里不认证，信任模型见主仓库 ADR 0071、0077，防误看不防对抗）。**登录就是输入名字**
  （`UserGateScreen`，`lib/app/user_gate_screen.dart`）：本机缓存里唯一命中就直接进、不联网；缓存里没有的名字
  **默认在这台电脑上新建**（本地学习者，见下条）——**只有同步设置里明确填了外网访问凭据
  （`ApiConfig.wanUsableBase` 非空）才问中心目录**（`lib/core/user_directory.dart`）：找到一个就进
  （异地登录），**重名才再问学习者编号**，目录里也没有才落到本地新建；「我是另一个同名的人，新建」
  在配了凭据时建到服务器（跨机器可同步）。**编号是身份**：服务端在登记时分配的 1～999 纯数字，
  永不变；本地库文件名（`local-<编号>.db`）、照片清单名、请求头 `X-Athena-User`、中心 `user` 列
  用的都是它。名字只是称呼，不要求唯一，**只能改当前登录的自己**（服务端也校验）。新建后用一条
  不挡路的提示条告诉分到的编号。中心目录是权威（后台库 `athena_users`，接口见 `practice/nas_admin`
  的 `docs/user-api.md`），异地首次登录要联网；已在本机用过的学习者离线照常进。本机缓存是应用
  无关的全局文件 `Athena/users.json`（`lib/core/users.dart`，格式见主仓库 `docs/REPOSITORY.md`）。
  首用户 tiger 的记录由 `practice/nas_admin/scripts/driver_migrate_users.py` 收编到数字编号；本机
  残留单用户时代的 `local.db` 时，登录后会问一句归不归到这位名下，客户端不替人猜。
- **本地学习者（ADR 0123、0124）**：新学习者**默认只存这台电脑**——目录连不上时（没配服务器、
  路由器不在身边）登录页给「在这台电脑上新建（不同步）」的出路，没配外网访问凭据时更是连目录
  都不问、输入新名字就本地新建。本地学习者用 **1000～9999 本地段**（`UserRegistry.nextLocalId`，
  本机最大值加一；中心目录只发 1～999，两个段永不重叠），只存本机缓存与本地 SQLite 库，
  **不启动同步引擎、不发任何请求**，侧栏写「本地模式 · 记录只存这台电脑」；改名只写本机缓存。
  想跨机器同步就配好凭据后用中心目录的学习者（显式新建建到服务器），两类人互不迁移。临时断网
  不受影响：中心学习者的新数据照常进出站队列，联网后补发。
- **通路统一走 REST API（主仓库 ADR 0070）**：内网直连 PG 的通道已退役，数据库端口
  不出内网；所有同步走 `practice/nas_admin` 的 `/api/driver/v1`，内网端点连路由器、外网端点过
  Cloudflare，按序尝试。**没有设备令牌**（主仓库 ADR 0077）：应用里不认证，内网可信，外网的门
  放在 Cloudflare 访问规则上。
  **同步节奏（ADR 0062）**：拉取并行（至多 4 路）；答题写入触发的那轮只上传、不拉取，进行中到来的写入
  本轮结束后补跑；每送完一批就刷新待同步数；内网不是当前端点时只探测 3 秒，外网使用期间每 10 分钟
  先试一次内网，通了自动切回。
- **同步配置**：内网端点默认就是路由器地址，在家里什么都不用配、同步总是尝试（连不上就是
  「暂不同步」，离线队列照旧）。离开内网时在「同步设置」里填外网端点和**外网访问凭据**（Cloudflare
  访问规则的服务令牌，全家共用一对，可选；**没配凭据时外网端点根本不进候选**——离开内网
  就是完全本地，不敲门也不报「被 Cloudflare 拦住」，应用 ADR 0123）。读环境变量
  `ATHENA_DRIVER_API`（JSON 串），或用户数据
  目录 `AthenaDriver/api.json`（配置屏保存，POSIX 上 600，不进仓库）；旧配置里的 `token` 字段读取时
  忽略。请求不跟随重定向：被 Cloudflare 拦住（302 到登录页、401/403）时提示检查外网访问凭据，
  不当成网络不通。Cloudflare 一侧的配置与自检见 `practice/nas_admin/docs/cloudflare-access.md`。
  历史数据当年用 `scripts/migrate_progress_to_pg.py` 一次性迁入 PG（已执行完，仅作历史参考）。
- **照片（ADR 0070、0071）**：文件与登记清单（`progress/points/photos-<学习者编号>.json`）
  都随仓库走，不进任何数据库，跨机器靠 `launcher sync`；其余九张表都是按用户同步的
  个人数据。
- **测试**：数据层是本地 SQLite，每个测试文件开自己的临时库（`open(suite:)`，close 时
  删除），并发互不踩、不依赖任何外部数据库；同步器的契约测试用本机 `HttpServer`
  假一个 API（`test/sync_test.dart`）。
- **图标**：应用标志是上色的小汽车，启动器、任务栏、侧栏同一份 `icon.svg`（ADR 0048）。
  界面功能图标只用 `lib/ui/glyphs.dart` 的 `Glyph.xxx`：一个概念一个图标、一个图标一个意思、
  统一 Material 实心风格，不直接写 `Icons.xxx`；加图标先在表里加一行（ADR 0049）。

不引入 GTK、Qt、Tauri。开发时内容从 `ATHENA_DRIVER_ROOT` 读磁盘，改 JSON
热重启即可看到；发行包才走 Flutter assets。macOS entitlements 关闭 App
Sandbox，否则读仓库题库和写进度库都会被拒，窗口只剩黑框。

## 开发与验证

需要 Flutter SDK（stable）。macOS 要编窗口还需要完整 Xcode，不只是 Command Line Tools。
若系统 `xcode-select` 仍指向 Command Line Tools，`scripts/run_dev.py` 会在启动时
把 `DEVELOPER_DIR` 指到 `/Applications/Xcode.app`，不必先 sudo 切换。

```sh
cd subjects/driver
launcher open driver
# 或菜单栏启动器点「驾考学习」；勾预热后登录即编好，点一下窗口现身。
# 改 lib/ 会热重载；改 content/ JSON 要热重启（大写 R，或保存后点重启）。
python3 scripts/run_dev.py
```

不要启动打包副本。已在跑时再点一次只把窗口前置，不会再冷编译。

```sh
python3 scripts/check.py              # JSON + analyze + test + 当前桌面 debug 构建
python3 scripts/check.py --skip-build # 只改了题库时
```

仓库根 `python3 scripts/check.py driver` 会转到这里。

## 出题

1. 打开 `content/sources/catalog.json` 里的来源，核对照条文或标准分类。
2. 每题带 `prompt`、恰好能判分的 `choices`、`explain`、`source_refs`。
3. `relation` 用 `quoted` / `adapted` / `authored`；自造要写 `note`，同一文件
   不得超过一半。
4. 标志题以「看到之后怎么开」为主（让行要不要停、限速能不能超、禁行能不能进）；标志、标线、导向箭头、交警手势「是什么意思」的认含义题也收，同一含义只留一道，每张图都要看过核对；「属于哪一类」的认类别题不收（ADR 0024）。
5. 模拟考按 GA 1026 的题量、时长与题型配比组卷：科目一判断 40 单选 60（4.1.3.1），科目四
   判断 20 单选 20 多选 10（4.3.2.3.1）；科目一还按表 1 的内容比例分块抽（驾驶证与登记 20、
   通行 25、违法处罚 25、事故 10、机动车基础知识 10、地方 10，`curriculum.json` 的
   `exam.blocks`）。题库不够考场题量时折合百分制，并在结果页说明。科目一模拟考随时可考，
   科目四入口要等科目一全部掌握（ADR 0006 第 4 条、ADR 0044）。
6. 仪表、指示灯、操纵件、车辆安全装置这类「机动车基础知识」题没有自己的知识点，出题时
   标 `"exam_block": "vehicle"`，否则组卷会按知识点落进通行块（ADR 0023）。
