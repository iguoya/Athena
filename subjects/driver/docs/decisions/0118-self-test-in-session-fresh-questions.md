# ADR 0118：自测改用做题界面、全是四选一，按条目内容现场出题，不依赖练习题库

- 日期：2026-10-07
- 状态：已接受
- 影响：删除 `lib/speed/recall.dart`（自测对话框与 `RecallEntry`）；`lib/speed/recall_cards.dart`
  （`freshRecallQuestionOf`、`textStemOf`、`askable`）；`lib/speed/recall_status.dart`（`GroupRecallButton` 改按题号计数）；
  `lib/home.dart`（`_startRecall`）；`lib/study/session.dart`（`SessionLaunch.recordChosen`）；六个速记页组件
- 关系：取代 0085、0089 的自测卡片流界面与 0095 的数值手输；0090「只考没考过与错题库里的、答对的不再出现」、
  0094「自测作答就是普通作答记录」、0099 与 0115「整组全对才再测一遍」、0116 组内自测、0117 组里只有自测，全部保留；
  0115 的自测收尾「去做这几个的题」随对话框一起去掉

## 背景

使用者用了组内自测后提出三点：易混数字的填空题手输太慢，要全部用选择题；自测不要弹对话框，
直接用错题本那样的做题界面；自测原则上独立于练习题库——可以借用题库原题，也可以自造题目，
不依赖题库，应当根据条目的实际情况自由出题。

现状：每张速记卡在题库里已有一份按题号做种子的固定四选一（0094，错题本、强化练习用它），
但自测对话框另走一套卡片流，易混数字还出输入框。仪表里胎压、ESC 故障两张卡没有题图，
在题库里出不了题、只能在对话框里看手绘图。

## 决定

1. **自测用做题界面。** 组里的「自测」起一轮普通练习（`SessionStage`，与错题本同一个做题台）：
   一页二十题、答错当场讲、朗读，规矩与练习一致；不再有对话框，`recall.dart` 删除。
2. **全是四选一。** 易混数字的数值卡不再手输，题干照旧挖空，选项取同组别的数值（0095 的手输取消）。
3. **按条目内容现场出题，不依赖练习题库。** 每次点「自测」，`freshRecallQuestionOf` 按这一组条目的内容
   重新出卷：正确项从条目要点里随机抽一条，干扰项从同页别的条目随机取。题号沿用卡的
   （`drive.recall.<页>.<哈希>`），作答照旧进错题库、决定掌握状态；题库里那份固定题面只给错题本、
   强化练习、考前复习用。没有题图的符号卡改用文字问——说明写成「外观：含义」的，取外观描述当题干
   （「看到『黄色蹄形加感叹号』，这是什么？」），所以每张卡都能考，胎压、ESC 也进了题库。
4. **出题顺序不变**：答错还在错题库里的先出、没测过的其次，各自洗牌；答对过的不再出；整组都答对了，
   按钮写「再测一遍 M 题」，点了整组重考。按钮文字写「自测 N 题」，N 是这次要考的张数。
5. **不记所选选项。** 现场出的卷选项每次不同，字母对不上题库里的固定题面；`SessionLaunch.recordChosen`
   为假时作答不带 `chosen`，免得学习诊断的「选错的方式」把不同的卷当成同一个错选项。

## 取舍

- 借用题库原题（关联真题）混进自测是允许的，这次没有做：先让每个条目都有自己的题，混真题要另定
  怎么计掌握（0112 定了掌握只看速记卡自己的作答）。
- 去掉了对话框里的易混对撞大图、答错隔两张重现、收尾「去做这几个的题」：做题台有自己的讲解与翻页规矩，
  两套规矩并存只会让人分不清；想练关联真题走章节练习与强化练习。
- 「自造题目」仍是按内容文件出题，题干、正确项、干扰项都来自有出处的条目，不是 AI 现场造题（主仓库 ADR 0043）。

## 验收

- `test/recall_test.dart`：点「自测」起做题台、题号是这一组的卡、全是单选且正确项唯一、不记所选选项；
  错题库里的先出、答对过的不出；整组答对写「再测一遍」、按钮绿、整组重考；15 个速记页每组都有自测；
  每张卡都出得了题，胎压卡用外观描述问。
