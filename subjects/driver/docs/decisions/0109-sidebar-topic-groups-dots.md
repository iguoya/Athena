# ADR 0109：侧栏专题分组折叠、专题状态圆、「练这组」按钮三色

状态：已接受

## 背景

专题加到科目一 20 个、科目四 16 个，侧栏太长。使用者要求：分组折叠；给每个专题条目左侧加与易混数字行点同样样式的圆，
按答题结果上色；「练这组」按钮也随结果变色——全部掌握才是绿，没做过是灰，有做错的是红。

## 决定

1. **分组**：`speedGroups` 把专题归成「速记对照、事故与停车、通行规则、车辆与安全」四组（按 id 点号后的部分归，两个科目
   同名专题同组，只列各科目有的）。侧栏「专题」小标题下是各组一行（`组名 · 个数`，箭头 `Glyph.groupOpen/groupClosed`，
   与科目的展开收起图标分开），点组展开/收起，默认全部折叠；点进某个专题时它所在的组自动展开。
2. **专题状态圆**：组和专题左边各一个圆（`TopicDot`，样式同 `StatusDot`：实心圆加黑心、红/绿/灰，小一号）。口径是该专题**自测卡的作答记录**
   （同易混数字行点，ADR 0101）：有答错过且未掌握的卡 → 红；答对过 → 绿；一张没答过 → 灰。组的圆取组内最差的：有红取红，否则有绿取绿。
3. **「练这组」按钮三色**（`practiceButtonStyle`，标志、标线、仪表、考点、易混数字各组）：口径是这一组相关真题的作答记录——
   有答错过且未掌握的 → 红；全部掌握 → 绿（文案「这组已掌握 · 再练一遍」）；没做过、只做了一部分 → 灰。

## 后果

- 测试里点专题前要先展开所在分组：`test/nav_helpers.dart` 的 `showTopic`。
- 科目分支是 `AnimatedSize`，展开后要等动画长到位才点得到下面的专题。
