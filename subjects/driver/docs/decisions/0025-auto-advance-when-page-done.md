# ADR 0025：一页十题答完就自动翻页，不看对错

- 日期：2026-09-27
- 状态：已接受
- 影响：`lib/session.dart`、`lib/speak.dart`
- 关系：修订本应用 ADR 0022 第 2、3 条（「全对才自动翻，有错题就停在本页」）和 ADR 0023 里
  「模拟考本页最后一题答错就停下」；其余条款不变

## 背景

ADR 0022 只在一页全对时自动翻页，有错题就停在本页，要自己点「下一组」。实际练下来，
错题在作答当时就已经看到了：选项标红、正确答案标出、解释自动朗读、右栏显示依据。
翻页前再停一次，多数时候只是多点一下。使用者要求一页十题答完就自动更新下一页。

## 决策

1. **一页十题都答完就自动翻到下一页**，不管有没有错题；最后一页答完照旧自动结束本轮。
2. **最后一题答对**：停 0.9 秒再翻，让绿色先落进眼里（沿用 ADR 0022）。
3. **最后一题答错**：练习里先把解释念完，再停 1.5 秒翻页——翻页会停掉朗读，不能
   念到一半被掐断；念不了（没有系统朗读）就只停 1.5 秒。模拟考不讲题，停 2.5 秒让人
   看清标出的正确答案再翻。
4. 停顿期间自己翻走了（按钮、回车、方向键），就不再翻第二次。
5. 错题不会丢：练习一轮结束的结果页、模拟考交卷后的错题卡都列着。模拟考最后一页答完
   不自动交卷，仍由自己点「交卷」。

## 后果

- 有错题的页不再强制停留；想回看某题的解析，用「上一组」翻回去或看结果页的错题卡。
- `Speaker` 多了一个「等当前这段念完」的方法，朗读从「只管开始」变成可以等结束。
