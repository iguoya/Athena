# ADR 0052：模拟考答错也当场讲、自动朗读

- 日期：2026-09-30
- 状态：已接受
- 影响：`lib/session.dart`（右栏答题卡、判分后的朗读与自动翻页）、`test/session_test.dart`
- 关系：修订本应用 ADR 0023「答错……不显示解析、不朗读，讲题留给交卷后的错题卡」和
  ADR 0005 第 4 条「模拟考仍不展示解释，因此也不朗读」；ADR 0023 其余交法
  （答一题交一题、交了不能改、答对不提示）不变

## 背景

ADR 0023 让模拟考照考场来：答错只在选项上标出正确答案，不讲题、不朗读，讲题留给
交卷后的错题卡。使用者用下来的意见：模拟考里答错的题，也应该在右栏讲清原因并念出来。
等到交卷再回头看，那道题当时为什么选错已经想不起来了；当场讲，错因和正确答案是连着
记住的。

## 决策

1. **模拟考答错的题当场讲**：右栏在答题卡下方接着显示这道题的依据（答错、题图、简短
   解释、条文），跟练习的右栏同一份内容；题干旁的「解析」对答错的题也能点，把依据调回来。
2. **答错自动朗读解释**，跟练习一样；蓝条上「系统朗读 / 停止朗读」随时可手动听。
3. **答对仍不提示**：不讲、不念、不能点「解析」，跟考场一样（ADR 0023 不变）。
4. 自动翻页跟练习同一套：一页答完从最后一题判完算起至少停 5 秒；最后一题答错先念完
   解释，念完后至少再停 1.5 秒（ADR 0025、0038）。最后一页不自动结束，仍要自己交卷
   （ADR 0042）。
5. 用时照常计：听解释的时间也算在用时里。模拟考只计时不收卷（ADR 0042），多出来的
   时间只在顶栏看得到，不影响出分。

## 后果

- 模拟考不再是「只测不讲」：错题当场讲过一遍，交卷后的错题卡照旧可看。
- 顶栏用时会比真考场长一些；要按考场节奏测一次，看到依据别停，直接往下答。
