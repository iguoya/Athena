# ADR 0072：下架答案存疑或题面有问题的题

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/questions/subject1.json`（-4 题）、`content/questions/subject4.json`
  （-11 题）、对应的 12 个无人引用的题图、`content/curriculum.json` 与 `AGENTS.md` 里的题量
- 关系：与仓库级「内容工作宁增勿删」（ADR 0054）的关系：那一条防的是借「参考」之名重划
  结构，本 ADR 是使用者明确决定的下架，且只动题、不动结构；不修订任何条款

## 背景

题库大量来自公开题库（ADR 0008），其中有些题经不起逐题核对：答案找不到法规或常识依据、
同一条规则在两道题里答案打架、题面表述含糊、题图与题干对不上、依据的概念已被官方取消。
答错这类题，学习者记下的是错的东西；答对它，也算不出掌握了什么。使用者的决定是：**不能
确定答案正确、没有让人信服的解释、答案模棱两可、题面本身有问题的题，一律去掉。**

## 决策

1. **下架标准**（任一条成立即下架）：
   - 无法确定答案正确（题库答案与法规或图上可见内容矛盾，或图看不清、无法核对）；
   - 解释只能写成「以本题为准」这类没有说服力的话；
   - 答案模棱两可（选项都沾边，或答案靠题干的遗漏判定）；
   - 题面有问题（依据的概念已取消、题图与题干不符、图会误导）。
2. **下架 15 题，逐条留痕**：

   | 题号 | 理由 |
   |---|---|
   | `s1.occupants.111` | 题图是停车让行标志，题干「必须先停车再起步」，答案却是「错误」，与停车让行的规则矛盾 |
   | `s1.signals.200` | 问持续闪烁的黄灯，答案「路口交通信号暂时解除」不是国标说法，国标是「闪光警告信号灯，提示注意瞭望」 |
   | `s1.rules.562` | 问「轻微违规行为」，答案靠官方已取消「违规」这个说法判定，题面概念过时 |
   | `s1.occupants.112` | 漫水路段，题干没写错什么，答案「错误」靠它漏了「停车察明水情」判定，模棱两可 |
   | `s4.weather.060` | 上坡塞车轮的题图，楔块位置无法判断，找不到让人信服的依据 |
   | `s4.civil.358` | 题图画的像灭火器，答案是「消防设备箱标志」，对不上 |
   | `s4.civil.379` | 绕车检查要「顺时针」，规章没有规定方向，答案无依据 |
   | `s4.maneuver.204` | 紧急停车带标志问「临时停车处」，措辞模棱两可 |
   | `s4.civil.389` | 黄昏开哪种灯，答案「示廓灯」没有依据，近光灯同样说得通 |
   | `s4.maneuver.153` | 安全带作用的「错误说法」，「保护颈部」「保持驾驶姿势」是否算错没有定论 |
   | `s4.civil.508`、`509`、`510` | 动画题，动画只有 224×96 像素，违法行为的数目无法核对（其中 509、510 的帧里能看到的情节与现有解释对不上） |
   | `s4.maneuver.437` | 题图会误导，原解释自己写「不要被图片误导」，题与图不匹配 |
   | `s4.lights.151` | 原解释自己写「大家不要误解」，说明答案有争议 |

3. **没下架、但重写了解释的 5 题**：`s4.crash.019`、`s4.civil.002`、`s4.civil.010`
   （案例题，答案经核对成立，原解释只有一句，现按案情逐项写清）、`s4.civil.507`、
   `s4.civil.512`（动画题，按动画里能看清的内容写）。`s1.rules.135` 的选项错字「内测通行」
   改为「内侧通行」。
4. **题图一并删除**：这 15 题的 12 张题图没有别的题引用，随题删去。
5. **不碰作答记录。** 已记在进度库里的这些题号成了孤儿记录：统计与题单都按题库现有的题
   取交集，不会出错；模拟考草稿续答时，题库里没有的题号本来就会被丢弃（`home.dart`）。
6. **题量文字更新**：`curriculum.json` 的 `scope_note` 与 `AGENTS.md` 里的题量改为科目一
   约 2490 道、科目四约 1710 道（旧文字写的是更早的 1580 与 1500）。

## 没做的

- 同一题面、同一选项的重复题 `s1.alcohol.001` 与 `s1.alcohol.008` 没动：重复不是错题，
  只是两份记录。
- 题库里还有一类「答案没错但解释只是口诀」的题，已在解释补写中逐批改写，不在本 ADR 范围。

## 后果

- 科目一 2497 → 2493 题，科目四 1720 → 1709 题；模拟考的抽题范围与题型配比不受影响
  （`content_test` 仍守住模拟考组卷）。
- 将来再发现这类题，按本 ADR 的标准下架，并在本表后续追加（新增 ADR 或在本文件追加
  一节），不要悄悄删。
