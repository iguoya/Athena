# ADR 0115：「练这组」的待练口径与出题一致、含偏难；按钮颜色只看自测；整组重来只在全部覆盖后出现

- 日期：2026-10-07
- 状态：已接受
- 影响：`lib/home.dart`（`_speedPending`、`_speedGroupQueue`、速记页回调）、`lib/speed/{signs,markings,gauges,gestures,notes,numbers}_page.dart`
  （组按钮）、`lib/speed/recall.dart`（「再测一遍」的出现条件）
- 关系：修订 0114 决定 1、2（待练判据、没有待练题时置灰「已通过」）；落实 0112 决定 3（速记页不分偏难）
  到「练这组」的出题；收紧 0099「再测一遍」的出现条件

## 背景

核对 0112～0114 的实现发现三处与使用者意图不符：

1. 按钮上「练这组 N 题」的 N 按「最近一次没答对」数，点下去却经日常练习的 `appearsInPractice`
   再筛一遍——没答错过的**偏难题被筛掉**，违背 0112「速记页不分偏难」；剩下的待练题全是偏难题时，
   按钮写着「练这组 3 题」，点下去什么都不发生。
2. 关联真题都练过后，按钮变绿写「已通过」，旁边的组状态圆（按自测卡）却是灰的「还没测完」。
   使用者指出：按钮的颜色本身就该由自测结果决定。
3. 自测收尾的「再测一遍」以「这次第一次就答对」算全对：一张还在错题库里的卡这次答对一次，
   不一定够移出错题库（累计答对要到答错的 2 倍，0079），收尾却已经当成全对、给出整页重考。

使用者拍板：偏难题纳入；没答错过的题答过一次原则上不再出，除非使用者打算重新练习；
整页（整组）重来只在已经完全覆盖答对时出现，没有全部答对就不全组重来。

## 决定

1. **速记组的待练题**（`_speedPending`）= 关联题里**没做过**的，加上**答错过且还在错题库里**的
   （同 0079 的移出规则）。不看难度档：偏难题一视同仁。按钮上的 N 与点下去出的题是同一个函数算的。
   出题顺序不变：错题库里的在前、没做过的其次，各自洗牌。
2. **没有待练题时给「再练一遍 M 题」**（M 是本组全部关联题），点击对整组起一轮练习，作答照写——
   这是使用者主动重新练习的入口，只在本组已经没有待练题时出现；有待练题时只出待练的，不整组重来。
   本组没有关联题时写「没有相关题」、不可点。
3. **按钮颜色只看自测**：与组标题圆同一个 `statusOfIds`（0112、0113）——红 = 有自测卡答错未移出、
   绿 = 每张自测卡都答对过、灰 = 没测完。真题练完不再把按钮染绿，也不再写「已通过」。
4. **「再测一遍」只在整页每张卡都已答对时出现**：「答对」与 `statusOfIds` 同一把尺子——答过且没有
   未移出错题库的错；这次的作答叠加到打开时的记录上再判（`_cleared`）。所以原来在错题库里的卡，
   这次答对一次不一定够移出；这次答错过的，通常也还差几次。没全部答对时，收尾只给「去做这几个的题」
   与「关闭」，并写明还有几张要再对几次，下次自测照旧只考答错和没测过的。
5. 自测收尾「去做这几个的题」也用决定 1 的 `speedPending` 筛，不再看日常练习的「已掌握」集合；
   速记页与自测因此不再接收 `mastered`。

## 取舍

- 「再练一遍」看的是练习的账（真题有没有待练），颜色看的是掌握的账（自测）：两者分开，
  但颜色不再借练习的账说话。
- 待练判据不复用日常练习的 `appearsInPractice`：那套规则为日常刷题设计（偏难题不主动出、普通题做过一次即止），
  速记页只问「做没做过、错了没移出」，规则更少、与自测抽卡同构。

## 验收

- `test/speed_nav_test.dart`：组关联题全部做对后，按钮写「再练一遍」、可点、颜色仍随自测（没测过为灰）；
  偏难题计入待练。
- `test/recall_classify_test.dart`：`speedPending` 收没做过的偏难题与错题库里的题，做对过一次的与已移出的不收。
- `test/recall_test.dart`：没全部答对时收尾没有「再测一遍」，整页答对（错 1 对 2 移出）后才有。
