# ADR 0098：「这组已掌握」不再禁练——已掌握的组给「再练一遍」

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/home.dart`（易混数字）、`lib/{signs,markings,gauges,notes}_page.dart`
  （标志、标线、仪表、考点/河南/记分证照共五处组按钮，其中四处随 0097 的提交一并入库）
- 关系：修订 0028 页面上「练这组」按钮的禁用行为；不做「重置掌握度」——掌握度只由
  作答写入（0020、主仓库 0052），手动清记录与「禁止手动标记熟练」同源，不开放

## 背景

速记页每组的「练这组」按钮在组内全部相关题都掌握后变成「这组已掌握」并**禁用**——
判定的口径是该组正则匹配到的全部真题最近一次作答都答对（掌握 = 最近一次答对，0020）。
0094 之后自测作答也写进作答记录，这个状态比以前来得更快。使用者撞上后指出：判定可以
有，禁练没有道理——想再练（巩固、或答错几题让它回未掌握）不该被按钮拦住。

## 决策

1. **按钮永远可点。** 组内还有待练的题时照旧写「练这组 N 题」；全部掌握后写
   **「这组已掌握 · 再练一遍」**，点击对全组相关题起一轮练习。
2. **重练即重置的合规路径。** 已掌握的题再练，答错的题最近一次作答变成错，自动回到
   待练、进错题本、被强化练习与考前复习带出——掌握状态由新的作答自然刷新，不需要
   也没有「清空作答记录」的开关。
3. **五个速记页一起改。** 同一交互在易混数字、标志、标线、仪表、要点三页（共用组件）
   是同一份代码模式，只放开一处会让页面间不一致。

## 取舍

- 「重置这组记录」的直球做法（删作答）被否：那等于手动改掌握度，把作答记录从「事实」
  变成「可编辑状态」，统计、诊断、强化练习的依据都会被污染。
- 已掌握时按钮传给练习的仍是全组相关题而非只传未掌握的（那时为空）：重练的意义就在
  把掌握的题再过一遍，答错的自然浮出来。

## 验收

- 各速记页组内全部掌握时按钮显示「这组已掌握 · 再练一遍」且可点，起一轮全组练习；
- 练习中答错的组，按钮回到「练这组 N 题」，行级微点（0096）同步变红。
