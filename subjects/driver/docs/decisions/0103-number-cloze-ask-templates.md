# ADR 0103：易混数字自造题配问法模板——括号进句中，题干不泄漏答案

- 日期：2026-10-05
- 状态：已接受
- 影响：`content/cheatsheet.json`（9 个组级 `ask` + 19 个行级 `ask`）、`lib/cloze.dart`
  （`clozeStemByAsk`）、`lib/models.dart`（`CheatGroup.ask` / `CheatRow.ask`）、
  `lib/numbers_cards.dart`（出卡接入模板，选择卡与手输卡一致）
- 关系：修订 0092 决策里「原文里没有数字可挖的，就在句尾补一个括号」的做法——使用者
  指出句尾硬贴的「→（　　）」题干傻、部分题干把答案印了出来（酒精组印着 20/80、区间
  行只挖一半、手输卡跳过模板）；目标是把括号放进句子该在的位置，题干成句

## 背景

自造卡的题干由挖空算法生成：认得「数字 + 单位」就在句中挖，挖不中一律句尾补
「→（　　）」。三类问题：① 挖不中的组（记分、罚款、刑罚、雾天、实习期限）题干全是
残句；② 有的题干泄漏答案——酒精组情形「达到 20、不到 80」原文印在题面上问的就是
20；「50–100 米」「100–120 次」这类区间只挖走一半；③ 手输卡此前跳过模板，泄漏
集中在它们身上。

## 决策

1. **问法模板进内容文件。** `cheatsheet.json` 的组与行都可带 `ask`（`{case}` 换情形、
   `{blank}` 换挖空），行覆盖组。问法由内容作者撰写，代码只做替换——题感是内容问题，
   不塞进算法。
2. **已能句中挖空的组不配模板。** 限距、事故时限、登记时限、扣分、证照门槛这些组的
   情形原文含「数字 + 单位」，挖空本来就在句中，配模板反而会把答案印回题干。
3. **模板对选择卡与手输卡一致。** 手输卡的括号留在题干里标出空位，答案在输入框填；
   不再因手输跳过模板——泄漏恰恰集中在手输卡。
4. **九组配组模板，十九行配行模板**（最低/最高时速分句、区间行整句重写、酒精两行
   防泄漏重写、急救区间行、期限类无数字行）。没有模板的组走原路。

## 取舍

- 问法是 Formulaic 的（「…，一次记（　　）分。」），同一组内重复句式——这是刻意的：
  同组同问法，比的是数字本身，不比读题能力。
- 酒精两行的问法把「不到 80」写进 20 的题干：80 是另一行的答案，作为边界上下文保留；
  真正要填的 20 已挖去。

## 验收

- 抽查九组题干：句中挖空、成句、无答案泄漏；
- `flutter analyze`、cloze / 数字页 / 自测 / 卡片测试全部通过。
