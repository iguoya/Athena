# ADR 0026：阶段题量随内容走，不设上下限

- 日期：2026-09-27
- 状态：已接受
- 影响：`AGENTS.md`；不改代码、不改题目的 `phase`
- 关系：修订本应用 ADR 0009「按题量摊平（各阶段 110–300 题）」这半句；ADR 0009 的
  章节→阶段归属表和阶段顺序不变，ADR 0006 的解锁规则不变

## 背景

ADR 0009 重划四阶段时顺手写了「各阶段 110–300 题」。按知识点覆盖补题之后（公开题库
收录、认含义题、零覆盖考点），第 2 阶段（通行与让行）到了 517 题，第 3 阶段（信号、
标志与灯光）到了 403 题。

这个区间是当时题库规模下的观察值，不是根据什么学习规律定的。为了回到区间里，要么
把题挪到内容不对应的阶段，要么删掉覆盖考点的题——两样都比「这一关题多」更糟。
通行规则和标志标线本来就是科目一里内容最多的两块。

## 决策

1. **阶段按内容分，题量是多少就是多少**，不设上下限，不为凑题量把题挪阶段或删题。
2. 章节→阶段的归属沿用 ADR 0009 的表。**河南地方题（`drive.s1.henan`，ADR 0011 后加，
   表里没有）按每道题的内容归阶段**：车辆装备归 1，通行归 2，灯光归 3，事故、罚则、
   高速归 4；早先那 28 道都在第 1 阶段，保持不动。
3. 一关题多带来的负担靠已有机制消化，不靠砍题：偏难怪默认不练不考、不挡过关（`rare`），
   常规题少出（ADR 0003、0020）。

## 后果

- 第 2、3 阶段过关要练的题比第 1、4 阶段多，这是内容本身的分量。
- 以后再补题不必检查阶段题量。
