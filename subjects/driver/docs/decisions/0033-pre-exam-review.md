# ADR 0033：考前复习——累计错 2 次以上的题单独成页

- 日期：2026-09-28
- 状态：已接受；第 2 条「答对了也不移走」与后果第 1 条由 [ADR 0034](0034-review-exit-by-correct-streak.md) 修订
- 影响：`lib/home.dart`（侧栏「考前复习」、`_reviewOverview`）
- 关系：与错题本（按最近一次作答）并列；统计从作答记录派生，同主仓库 ADR 0052

## 背景

错题本只看**最近一次**：答错就进，下一次答对就移走。这对日常订正是对的，但考前想回头
确认的恰恰是另一批题——反复翻过车的。一道题错过两三次、最近碰巧答对了，它在错题本里
已经消失，考前却最值得再看一眼。

到 2026-09-28，进度库里累计错 2 次及以上的有 90 道（错 2 次 70 道，3 次以上 20 道）。

## 决策

1. 侧栏新增「考前复习 N」，收**累计答错 ≥ 2 次**的题（阈值 `_reviewMinWrong`）。
   科目一没过关时不收科目四的题，跟错题本一致。
2. **答对了也不移走**，只把状态从「还错着」改标「已订正」。列表按累计错的次数从多到少排，
   同样次数时还错着的在前；错 3 次以上标「顽固」。
3. 页头给统计：共几道、还错着几道、已订正几道（有科目四题时再分科目）。两个入口：
   「全部复习」过一遍全部，「只练还错着的」只做最近一次还错的。
4. **不另建表**。清单由作答记录派生（`wrongCounts` + 最近一次作答）：作答记录本来就在
   `progress/learning.db` 里、随仓库走、跨机器同步；另存一份清单只会和记录对不上。
   复习时的作答照常写进作答记录，照常影响掌握度和错题本。

## 后果

- 考前复习只增不减：做得越多，累计错 2 次的题只会越来越多。这是有意的——它是「容易
  翻车的题」的档案，不是待办清单；「还错着」的数字才是待办。
- 复习会话的 `subject_id` 记为 `review`，跟错题本记 `wrong` 同一个做法。
