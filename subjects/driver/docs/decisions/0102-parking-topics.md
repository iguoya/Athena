# ADR 0102：停车专题——科目一「停车与违停」、科目四「停车与停放」

状态：已接受

## 背景

题库里涉及停车、停放、违停的题科目一约 110 道、科目四约 120 道，分散在通行、安全带与停放、灯光、高速、
恶劣天气、河南地方题等好几个知识点里（「站 30 口 50」、30 厘米、应急车道、地锁罚款等都是反复错的硬点），
却没有一页把「停车」这件事收在一起。

## 决定

1. 沿用 ADR 0097 与 0101 的做法，两个专题各属一个科目、各一份内容文件、各取本科目的题：
   `s1.parking`「停车与违停」→ `content/topics/s1.parking.json`，`s4.stopping`「停车与停放」→ `content/topics/s4.stopping.json`。
2. **科目一**五组：哪里不能停、临时停车怎么停、违停会怎样（含河南地方罚则）、故障/夜间/雨雾天停车、高速公路上的停车。
   **科目四**五组：哪些地方不能停、临时停车与起步、灯光与警示、坡道与山区停车、高速公路上的停车与紧急停车。
   科目一偏法规与处罚（河南题只在科目一），科目四偏安全与场景处置。
3. 条目只写能指到条款的内容：道路交通安全法第五十二、五十六、六十六、六十八、九十三条，实施条例第五十三、五十七、五十八、
   六十、六十三、八十二条，河南省道路交通安全条例与高速公路条例，技术性的坡道与紧急处置沿用题库已核对的出处。
4. 新增界面图标 `Glyph.parkingRules`（`Icons.pin_drop`），`Icons.local_parking` 已是科目二的图标，不重复使用。

## 后果

- 侧栏科目一多「停车与违停」，科目四多「停车与停放」（科目四仍等科目一日常题全部掌握）。
- `scripts/check.py` 对新专题文件的校验沿用 ADR 0101：正则在所属科目里必须有题、出处必须在 catalog、条目必须有条款定位。
