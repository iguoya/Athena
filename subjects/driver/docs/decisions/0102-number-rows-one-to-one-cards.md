# ADR 0102：易混数字行与题一对一——组按钮与自测深链练本组的自测卡题

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/recall_cards.dart`（新增 `recallQuestionsOfNumberGroup`）、`lib/home.dart`
  （组按钮与 `_numbersRecall` 条目的关联题改指向本组/本人的自测卡题）
- 关系：落实 0094 的「速记卡就是题」到练习通路上；修订 0028 以来「练这组」的出题来源
  （组级正则捞真题 → 本组专属卡题）；使用者拍板：**自造题为主**——题库有贴题的更好，
  没有就依据条目自造，目的是彻底掌握专题条目知识

## 背景

易混数字的行与题库真题之间只有组级正则关联：「限速」10 行共用正则命中的 368 题，
「记分分值」5 行共用 113 题。「练这组」「去做这几个的题」起的是这一大锅，行与题没有
对应，使用者指出应该一对一，并拍板不必非要关联现有题库——自造题为主，题库有合适的
更好，没有就依据条目自造，目的是彻底掌握条目。

而 0094/0095 已经把每行造成了题：每条情形一张正向卡（数值手输/选择），每个值一张
反向卡，各有稳定题号（`drive.recall.s1.numbers.<哈希>`）、有出处（条目的条文引用）、
作答进作答记录。**自造这一步早已完成，缺的只是练习通路指向它们。**

## 决策

1. **「练这组 / 再练一遍」练本组的专属卡题。** `recallQuestionsOfNumberGroup` 把组内
   自测卡转成题（正向 + 反向），组按钮起练习用它们，不再用组级正则捞真题。按钮上的
   待练数也随之变成卡口径（答对过的卡不再计入）。
2. **自测收尾的「去做这几个的题」练答错的卡本身。** 条目的关联题（`RecallEntry.related`）
   从组级真题改为这张卡自己对应的题——深链练习与错题完全一对一。
3. **组级真题关联不再用于本页练习**，但保留两处：`locked` 提示（还有多少真题在没解锁
   的阶段里，那是题库口径）与以后按行补充真题关联的数据底座。

## 取舍

- 卡题是「依据条目自造」的：覆盖每条情形与每个值，行行有题，不需要为覆盖率再做标注；
  题库真题的措辞多样性由强化练习的考点簇变式（0079）与以后可选的按行 `question_ids`
  补充，本条不阻塞在数据标注上。
- 练卡题与自测用的是同一批题、同一批作答记录：自测答错的卡，组按钮练它、强化练习也
  抽它（0094），几条通路往同一个「答对到移出错题库」的目标收敛——这正是「彻底掌握
  条目」的回路。

## 验收

- `flutter analyze`、数字页与自测相关测试通过；
- 组按钮「练这组 N 题」的 N 为组内未掌握卡数，「再练一遍」起全组卡题；
- 自测答错的卡在收尾深链练习里原样出现。
