# ADR 0045：补收公开题库剩余题目，同考点换问法也收，逐道核对现行规定

- 日期：2026-09-29
- 状态：已接受
- 影响：`content/questions/subject1.json`、`content/questions/subject4.json`、`content/images/`、
  `content/sources/catalog.json`、`AGENTS.md`
- 关系：修订本应用 AGENTS.md「不堆换皮」「一个考点已有判断题覆盖就算覆盖」两条；
  ADR 0008（公开题库可收录、以现行法规为准）、ADR 0011（只收河南地方题）、
  ADR 0017（按 C1/C2 裁剪）、ADR 0024（认类别题不收、同一含义只留一道）不变

## 背景

题库的公开来源是 `doupoa/DrivingTestSubjectOne`（2022 年 7 月版，科目一 2545 道、科目四 1833 道）。
在 GitHub 上查过，其他公开项目的数据都出自这一份，没有更新的公开题库。

这份题库当初只收了一部分：科目一 1173 道、科目四 1430 道。没收的里面有大量考场会出的题
（快处易赔、爆胎处置、同向四车道高速、防御性驾驶、急救、指示灯、操纵装置等），
也有同一考点换个问法的题（判断题和单选题各一道）。原规则「不堆换皮」让后一类一律不收，
使用者要求：考场怎么问就练怎么问，不因为比例或换皮的顾虑限制题量，但过时的、答案错的一道都不要。

## 决策

1. **补收剩余题目**：先排除外地地方题（科目一 351 道、科目四 156 道，来自上海、成都、福州、
   济南、武汉、北京）、其他车型专属题、与已收题重复的题；剩下的候选（科目一 881 道、
   科目四 222 道）逐道核对。
2. **同考点换问法的也收**：判断题、单选题、看图题问法不同的，都按独立题目收。
   `AGENTS.md` 的「不堆换皮」「一个考点已有判断题覆盖就算覆盖」相应删除。
3. **逐道核对现行规定**：每道对照道交法、实施条例、162/163/164/146/157 号令、刑法、
   交强险条例、GB 5768、GB 4094、GB 19522 和《机动车驾驶培训教学与考试大纲》（2022）的
   原文判断；带图题逐张看图，动画逐帧看过。每道写上条文出处（`source_refs` 内容来源 +
   公开题库 `selection_basis` 留痕），空泛的解析改写成具体规定。
4. **不收的只有三类**：与现行规定冲突或出处不可核的；ADR 0024 规定不收的认类别题；
   与已收题同一标志、同一问法的重复题。
5. 出处目录新增《道路交通安全违法行为处理程序规定》（157 号令）、《机动车交通事故责任
   强制保险条例》。

## 后果

- 题量接近考场规模，考场换个问法也练过；待练题大幅增加。
- 核对口径与 ADR 0008 一致：答案以现行规定为准；与现行规定冲突又改不成确定答案的，不收。
- 2022 年 7 月以后考场新增的题，公开渠道没有可信来源，只能从新规条文出发自己出题（如 ADR 0044 同期补的 31 道）。
