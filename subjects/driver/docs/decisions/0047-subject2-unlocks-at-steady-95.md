# ADR 0047：科目二要等科目一模拟考稳定在 95 分以上才开放

- 日期：2026-09-29
- 状态：已接受
- 影响：`lib/home.dart`、`lib/progress.dart`、`AGENTS.md`
- 关系：ADR 0006 第 4 条（科目一日常题全部掌握才开科目四）不变；ADR 0036、0039
  （科目二的内容与界面）不变，只加一道入口条件

## 背景

科目二原来随时可点。使用者科目一还没考过，而现实里科目一考过才能约科目二，
提前摊开练车日、点位卡这些东西只会分心。科目四已经有锁（ADR 0006 第 4 条），
科目二没有。

使用者给的线：科目一测试正确率**稳定**在 95% 以上。

## 决策

1. **科目二的入口条件**：最近 3 场科目一模拟考都不低于 95 分。模拟考成绩按百分制
   折合，分数就是正确率；只有模拟考写成绩记录，练习不算。
2. **「稳定」= 最近连着 3 场**，不看最高分、不看平均：考出一次 95 不算稳，中间掉
   一场就要重新攒。线和场次写成 `ProgressStore.steadyScore` / `steadyRuns` 两个常量。
3. 锁住时侧栏显示「科目二（未解锁）」，点进去只说明原因并列出最近几场分数，不开
   练车日、项目手册和评判题；科目二的评判题也不进错题本和考前复习。
4. **科目四不变**：仍按 ADR 0006 第 4 条，科目一日常题全部掌握才开。两把锁条件
   不同，各自独立。
5. 不做手动开关：锁由交卷记录推导，跟掌握度只由作答写入是同一个道理
   （主仓库 ADR 0052）。

## 后果

- 考砸一场，科目二会重新锁上，直到再连着 3 场 95 分以上；练车记录不受影响，
  解锁后都还在。
- 解锁看的是本机进度库里最近的科目一模拟考，换机器同步过来的成绩一样算。
- 以后要改线或场次，改两个常量并在这里追加记录。
