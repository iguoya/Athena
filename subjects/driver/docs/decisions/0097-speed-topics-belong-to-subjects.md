# ADR 0097：速记专题归属科目——科目一有科目一的专题，科目四有科目四自己的

状态：已接受

## 背景

速记页（易混数字、标志、标线、仪表、手势、考点、河南、记分证照）原先是侧栏底部的一排全局入口，
不属于任何科目：相关题取的是科目一，自测作答记成 `subject1`，科目四的使用者点进去看到的是科目一的东西，
两个科目的内容混在一起。使用者的要求是「科目一有科目一的专题，科目四也有属于自己的专题，不要混在一起」。

## 决定

1. **每个专题恰好属于一个科目**，注册在 `lib/speed_topics.dart` 的 `speedTopics`（`SpeedTopic`：`s1.numbers`、
   `s4.gestures` 这样的 id）。侧栏里专题挂在所属科目底下，原底部入口去掉。
2. **共通的内容各科目各有一份**：内容文件还是同一份，但每组笔记/数字在 JSON 里用 `subjects` 标明属于哪些科目；
   某科目关联到的题不够多（阈值：本科目关联题 ≥ 40 的专题进入，要点组 ≥ 20）的组不进它的专题。
   目前科目四有：易混数字、手势速记、考点速记；河南、记分证照、标志、标线、仪表只在科目一。
3. **相关题、练习、自测都只用本科目的题**：专题页的「练相关的题」取 `forSubject(科目)`。
4. **速记题题号带科目**：`drive.recall.<s1|s4>.<页>.<哈希>`，知识点号 `drive.recall.<s1|s4>.<页>`；
   自测的作答记录 `subjectId` 取自题号。同一张手势卡在科目一、科目四是两道题、各记各的作答，不互相冲抵。
   （ADR 0094 的题号形态 `drive.recall.<页>.<哈希>` 由此变为带科目的形态，其余规则不变。）
5. **科目四没解锁前（科目一日常题没全掌握），它的速记题也隐藏**：错题本、强化练习、考前复习都不带出，
   与科目四本身的解锁规则一致（ADR 0006 第 4 条）。
6. 新专题的内容走 `content/topics/<id>.json`，载入 `Bank.topicNotes`，加专题只需在注册表加一行。

## 后果

- 旧的 `drive.recall.<页>.<哈希>` 作答记录（如已存在）不再对得上题库里的题，对应不上的记录按普通孤儿记录处理，
  不影响其他统计；这批记录只来自自测上线以来的短时间，不做迁移。
- 侧栏的科目分支多了一行「专题」小标题和专题条目；锁着的科目其专题也锁着。
