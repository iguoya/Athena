# ADR 0074：易混数字加「刑罚档位」组——罪名与刑期的对照

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/cheatsheet.json`（新组）
- 关系：沿用 0028（易混数字页：每行指到条文、数字改了跟题一起改）；
  出处用 catalog 既有的 `criminal-law`（第 133 条、133 条之一）、
  `criminal-law-full`（第 133 条之二）与 `traffic-crime-interpretation`

## 背景

题库里刑罚相关题成体系：科目一命中罪名的题约 28 道（含解释的关联题
更多），覆盖交通肇事罪、危险驾驶罪、妨害安全驾驶罪三个罪名的构成与
量刑。这些题全靠死记，是丢分重灾区；而量刑恰好是「同主题数字比大小」
——拘役半年 < 妨害安全驾驶一年 < 肇事三年 < 肇事逃逸七年 < 逃逸致死
十五年——正是易混数字页横条的表达。

## 决策

1. **`cheatsheet.json` 加「刑罚档位」组，五行**：危险驾驶罪（拘役并处
   罚金，四种情形）、妨害安全驾驶罪（一年以下）、交通肇事罪基本档（三年
   以下）、肇事后逃逸或特别恶劣情节（三年以上七年以下）、逃逸致人死亡
   （七年以上，横条按有期徒刑上限十五年）。`amount` 取各档刑期上限
   （0.5 / 1 / 3 / 7 / 15 年），横条从轻到重一目了然。
2. **出处逐行指到刑法具体条文**：第 133 条之一与第 133 条用
   `criminal-law`，第 133 条之二用 `criminal-law-full`（节选那份不含
   之二）；构成要件类问题（什么算肇事后逃逸）依据 `traffic-crime-interpretation`
   的在组注里说明，行内不展开。
3. **`match` 抓「罪名与刑罚」的题面**（交通肇事 / 危险驾驶 / 妨害安全
   驾驶 / 拘役 / 有期徒刑），组级「练这组」与易混数字页同一通路。

## 后果

- 刑罚题从散在各处变成一张从轻到重的对照表；数字改版时和题一起改
  （0028 的硬规矩）。
- 易混数字页 7 组 → 8 组，页面自动多一组，无代码改动。
