# ADR 0061：图表悬停取值与空态行动入口

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/look.dart`（`ExamTrend`、`DailyActivityChart` 接悬停，`ExamPoint`
  元组）、`lib/home.dart`（错题本空态入口、ExamTrend 调用点）、
  `lib/reinforce_page.dart`（题池空态入口，新可选回调 `onNewPractice`）、
  `test/interaction_test.dart`（新）
- 关系：落实仓库级 ADR 0056「能由数据算出来的画成活的并配互动」；吸取 0018
  撤销（图表点击进流程的误触与副作用教训）；不修订 0058/0060 的动效清单

## 背景

应用里所有自绘图表都是裸 `CustomPaint`：悬停没反应、取值靠柱顶小字。仓库级
0056 明确要求「配互动」，这是欠账。图表点击跳转在 0018 里试过又撤——教训是
点击会进流程（章节测试）时，误触的代价是真实的掌握度污染。另一处欠账是空态：
错题本空、强化题池空时只有一句说明，下一步动作没有入口，界面把人晾在原地。

## 决策

1. **趋势图与每日图接悬停取值。** `ExamTrend`、`DailyActivityChart` 包
   `MouseRegion`：悬停柱高亮描边，图表左上角显示那一格的完整取值
   （模拟考：日期、分数、及格与否；每日：日期、题量、正确率）。悬停是查看，
   不进流程、无副作用，不违反 0018 的撤销理由。
2. **`ExamTrend` 的数据从分数列表升级为 `ExamPoint` 元组**（分数、日期、
   及格与否）。`look.dart` 依旧不认识 `ExamRecord`——只收元组，业务类型留在
   调用方（0018 后果里确立的边界）。
3. **不做点击回溯。** exams 表只存整场分数（无题级作答），点了柱也没有可看的
   「那一场」详情；等数据侧存下题级作答，再另立 ADR 接「点击看那场考试」。
   没有内容的点击不做，悬停取值已覆盖「看清哪一场」的需求。
4. **两处空态接行动入口。** 错题本空（说明错题都清了）→「去强化练习」按钮——
   强化练习在错题库空时本就会按薄弱章节抽新题补满一轮（主仓库 ADR 0085），
   这个出口正好接上；强化题池真正空（整库无题可练的极端状态）→「去练新题」
   按钮，`ReinforcePage` 新增可选回调 `onNewPractice`，不传就不显示。其余空态
   （诊断样本不足、图表无数据）的行动入口就在同页可见位置，保持诚实文案，
   不另加按钮。

## 后果

- 图表从「画」变成「可探查」：悬停即知哪天考了多少、哪天练了多少，
  不用再数柱子对日期。
- 错题本与强化页互为出口：错题清空后下一步是去强化保持手感（新题补满一轮），
  题池真空了还能去练新题，学习闭环没有死角。
- 悬停只在桌面鼠标下有意义；触屏没有悬停，现有柱顶小字标签保持不变，
  信息不受损。
