# ADR 0108：避让、山区坡道、电动汽车与科目四补充专题

状态：已接受

## 背景

ADR 0107 之后再做一次覆盖审计（按各专题的组正则与科目取题，剩余未覆盖的无图题科目一约 230 道、科目四约 220 道），
未覆盖的集中在：行人、非机动车、校车的避让（科目一 39、科目四 42），山区坡道弯道（23 / 37），电动汽车（科目一 13），
科目四的高速公路（41）、疲劳与驾驶状态（19）、起火逃生与危险物品（12）。

## 决定

沿用 ADR 0097、0103：每个专题属于一个科目、各取本科目的题、各一份内容文件（`content/topics/`）。

- 科目一、科目四各一份：`people`「避让行人非机动车校车」、`hill`「山区坡道与弯道」。
- 只有科目一：`s1.ev`「电动汽车」（出行与充电、行驶与制动、保养与环境）；科目四相关题只有一道，不单列。
- 只有科目四：`s4.expressway`「高速公路驾驶」、`s4.fatigue`「疲劳与驾驶状态」、`s4.fire`「起火逃生与危险物品」。
  这几块在科目一已有 `highway` 考点组、酒驾疲劳等覆盖，科目四的题法不同，所以只在科目四补。

新增图标 `Glyph.people`、`hill`、`electric`、`expressway`、`fatigue`、`fire`。校验沿用 ADR 0103。

## 后果

- 剩余未覆盖的主要是带图题（看图识情景，已由标志、标线专题与题图自身覆盖一部分）和个别零散的概念题，不再单列专题。
