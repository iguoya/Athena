# ADR 0101：易混数字行状态点改三态——答对即绿，去掉「部分掌握」的黄色

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/home.dart`（`_rowStatus` 判定与 `RecallRowDot`）、`lib/recall.dart`
  （`StatusDot` 重样式为 40px 实心圆加黑心、三态色，支持自定义悬停文案）、
  `lib/{signs,markings,gauges,gestures}_page.dart`（格子状态点移到图标下方、条目文字
  左侧，去掉角落小点）、`test/numbers_page_test.dart`
- 关系：修订 0096 决策 1（四态改三态）——使用者拍板行点只有三种：红 = 答错过未掌握、
  绿 = 答对过、灰 = 没答过；「答对了一部分」不单独设色。样式与位置随使用者反馈两次调整
  （亮翠绿 #2ECC71、40px 实心圆加黑心、图标下文字左）

## 背景

0096 给行状态点设了四态，其中黄色表示「这一行的自测卡答对了一部分、没全答完」。实际
使用中使用者看到自己答对过的行显示棕黄（警示色的种子色经过色板生成偏棕），指出：答对
就应该是绿色。当初的三态口径（红 / 绿 / 灰）里没有黄色。

## 决策

1. **行状态点三态**：红 = 这一行有答错过且未掌握的自测卡；绿 = 答对过（哪怕只答对了
   一部分卡，只要没有答错未掌握的）；灰 = 一张都没答过。
2. **「没答完」不再用颜色表达。** 一行 6 张卡答对了 1 张也显示绿——行的颜色回答
   「碰过没有、最近对不对」，不回答「答全没有」；进度由自测的「已答对 K / 128」与
   行悬停说明承担。
3. **速记格子的微点统一样式与位置。** 标志、标线、仪表、手势四个格子页的掌握度微点
   从「右上角 10px 小点」改为「图标下方、条目文字左侧的 40px 实心圆加黑心」，颜色同
   三态（答对用亮翠绿 #2ECC71——全局 success 色在小圆点上偏暗），与易混数字的行点
   完全同一套样式；`RecallRowDot` 直接复用 `StatusDot`，只换悬停措辞。
4. **`SymbolStatus.partial` 保留**（`statusOf` 仍返回它），点上一律按绿渲染——
   「答对过一部分」就是答对过。

## 验收

- `test/numbers_page_test.dart`：第一行答错 → 红；第二行答对过（部分卡）→ 绿；
  第三行没答 → 灰。
- 四个格子页测试通过，格子布局不变溢出。
