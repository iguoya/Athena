# ADR 0101：易混数字行状态点改三态——答对即绿，去掉「部分掌握」的黄色

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/home.dart`（`_rowStatus` 判定与 `RecallRowDot`）、`test/numbers_page_test.dart`
- 关系：修订 0096 决策 1（四态改三态）——使用者拍板行点只有三种：红 = 答错过未掌握、
  绿 = 答对过、灰 = 没答过；「答对了一部分」不单独设色

## 背景

0096 给行状态点设了四态，其中黄色表示「这一行的自测卡答对了一部分、没全答完」。实际
使用中使用者看到自己答对过的行显示棕黄（警示色的种子色经过色板生成偏棕），指出：答对
就应该是绿色。当初的三态口径（红 / 绿 / 灰）里没有黄色。

## 决策

1. **行状态点三态**：红 = 这一行有答错过且未掌握的自测卡；绿 = 答对过（哪怕只答对了
   一部分卡，只要没有答错未掌握的）；灰 = 一张都没答过。
2. **「没答完」不再用颜色表达。** 一行 6 张卡答对了 1 张也显示绿——行的颜色回答
   「碰过没有、最近对不对」，不回答「答全没有」；进度由自测的「已答对 K / 128」与
   行悬停说明承担。
3. **`RecallRowDot` 去掉黄色分支**；`SymbolStatus.partial` 保留（速记格子的微点
   `StatusDot` 仍在用四态），只在行点里不再产生。

## 验收

- `test/numbers_page_test.dart`：第一行答错 → 红；第二行答对过（部分卡）→ 绿；
  第三行没答 → 灰。
