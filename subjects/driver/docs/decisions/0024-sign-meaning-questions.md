# ADR 0024：标志、标线、交警手势收「认含义」题，不收「认类别」题

- 日期：2026-09-27
- 状态：已接受
- 影响：`content/questions/subject1.json`、`AGENTS.md`「出题」第 4 条
- 关系：修订本应用 ADR 0003 第 3 条「标志题按含义改写成看到之后怎么开，不靠看图认名字
  凑题；界面若配图则自绘示意」。配图那半句已被 ADR 0008（题图随仓库走）取代，这里一并写明

## 背景

ADR 0003 第 3 条把标志题限定为「看到之后怎么开」，本意是不拿「这是什么标志」凑题量。
但考场上「这个标志是何含义」「这一组交警手势是什么信号」「这个导向箭头是何含义」
这类题很多，公开题库里还没收的有约 170 道。看不懂标志、标线和手势，就谈不上「看到之后
怎么开」——认含义是前一步，本身就是关键知识点，不是凑数。

「认类别」是另一回事：「这属于哪一种标志」「指示标线的作用是什么」考的是 GB 5768 的
分类体系，开车用不上，只对应付少数考题有用。

## 决策

1. **收认含义**：标志、标线、导向箭头、交警手势「是什么意思 / 是什么信号」的题照收，
   判断、单选都收。警告标志的名字就是含义（「反向弯路」「注意落石」），算认含义。
2. **不收认类别**：「属于哪一种（类）标志 / 标线」「某类标志的作用是什么」不收。
   `content_test.dart` 里已有的拦截（「下图所示标志属于哪一类」）保留。
3. **按考点补，不按题数补**：同一个标志、标线或手势，题库里已经有题讲过它的含义就不再收
   （按正确答案的含义文字比对现有题）；同一含义只留一道。
4. **每道都看图核对**：题图从公开题库下载后逐张看，确认图和答案对得上；看不清、
   有歧义的不收。出处写 GB 5768.2—2022（标志）、GB 5768.3—2009（标线）、实施条例第三十一条（手势）。
5. 「看到之后怎么开」的题照旧是标志题的主体，这条只是补上前一步。

## 后果

- 标志块题量上升，但都是不同的标志；四阶段里它们落在第 3 阶段（信号、标志与灯光）。
- 以后出题遇到「认类别」题直接丢弃，不必再逐题讨论。
