# ADR 0101：事故专题——科目一「事故处理与时限」、科目四「事故处置」

状态：已接受

## 背景

题库里事故相关题不少（科目一 `accident` 149 道、科目四 `crash` 71 道），错题里「几个日期」「能不能私了」「逃逸怎么算」
这类硬规则反复出错，却没有任何速记页覆盖它们：考点速记里只有应急处置的一小组，时限散落在题里。
同时 ADR 0097 规定专题归属科目，科目一与科目四不能混用。

## 决定

1. **两个新专题，各属一个科目**：`s1.accident`「事故处理与时限」（科目一）、`s4.crash`「事故处置」（科目四）。
   内容文件各自一份：`content/topics/<专题 id>.json`，结构同考点速记（组 → 情景 + 要点 + 条级出处），
   载入 `Bank.topicNotes`；专题注册表加一行即新增专题，页面与自测复用 `NotesPage`、自测卡生成不改。
2. **科目一**分五组：现场先做什么、能私了还是必须报警、**时限一页看全**（十日认定、鉴定后五日、三日复核、
   十日调解、三日受理、三十日审验）、责任与赔偿、逃逸与刑责。**科目四**分三组：出事之后的处置、高速/隧道/铁路道口
   出事、责任与赔偿——科目四侧重防二次事故与特殊场所的处置顺序，不讲认定书时限与审验。
3. 两个科目的责任与赔偿内容有重叠，各留一份、各取本科目的题，不互相引用。
4. 要点只写能指到条款的内容：道路交通安全法第七十、七十五、七十六、一百〇一条，实施条例第六十、八十八、九十二、
   九十四、九十六条，处理程序规定（公安部令第 146 号）第十三、十四、十八、十九、六十二、七十一条，记分办法，
   刑法第一百三十三条，保险条例第二十二条，隧道与铁路道口处置按 2022 版考试大纲。
5. `scripts/check.py` 增加校验：专题文件里每组的正则在其标明的科目里至少匹配一道题，每条出处都在 catalog 里、都有条款定位。

## 后果

- 侧栏里科目一多一项「事故处理与时限」，科目四多一项「事故处置」（科目四仍要等科目一日常题全部掌握后才出现）。
- 自测卡按要点组出：情景 → 四选一，答后给完整要点；作答记成 `drive.recall.s1.accident.*` / `drive.recall.s4.crash.*`。
