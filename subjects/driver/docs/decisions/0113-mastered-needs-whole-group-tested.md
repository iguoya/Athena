# ADR 0113：整组每张自测卡都答对才算掌握——只测了一部分是灰，不能写「这组已掌握」

- 日期：2026-10-07
- 状态：已接受
- 影响：`lib/speed/recall_status.dart`（`statusOfIds`）及各速记页、侧栏的状态圆提示文案
- 关系：修订 0112 决定 2 里「答对过（哪怕只答对一部分）→ 绿」的口径；0098 的「再练一遍」随之只在整组测完后出现

## 背景

0112 把掌握和真题练习剥离后，`statusOfIds` 仍是「组内有任意一张卡答过、且没有未移出的错
→ 绿」。结果一组十几张标志卡只测了一张，组标题圆就是绿的、按钮写「这组已掌握 · 再练一遍」。
使用者指出：没练过的标志也被标成已掌握，太不严谨。

## 决定

1. 绿（掌握）= 组内**每一张**自测卡都有作答记录且没有未移出错题库的错；红口径不变（任一
   张答错且未移出）；其余——一张没答过，或只测了一部分——都是灰。空组不算掌握。
2. 同一函数管全站：侧栏专题圆、组标题圆、条目微点、「练这组」按钮一起生效。灰的提示统一
   写「还没测完」，绿写「全部答对过」。

3. 进度显示为「掌握 a/b」：各速记页每组标题行（圆与「练这组」按钮之间）写这一组已掌握
   的卡数与总卡数（`masteryOf`，答过且没有未移出错题库的错才算一张），测完变绿。
4. 侧栏的专题圆与「一组专题」圆同样按整体判：把范围内所有自测卡当一整组交给 `statusOfIds`，
   整组每张都答对才绿。此前分组圆是「组内任一专题绿就绿」，一个专题测完、其余从没碰过，
   整组也显示已掌握；现在只测了其中一个专题仍是灰。悬停说明写「掌握 a/b · …」。
5. 要点类专题（考点、河南、记分证照、事故……）的每个条目左侧补上状态点（`StatusDot`，
   一条一张自测卡），与标志、标线、仪表、手势、易混数字的条目点同一套样式；此前只有组标题有圆。
6. 自测出题不变，本就只抽没答对过的卡（答错未移出的先考，没测过的次之，答对的不再出）；
   下一次自测因此直接从没测过的卡里出。

## 取舍

- 没为「测了一部分」另设第四种颜色：圆保持三态，进度交给「掌握 a/b」文字。

## 验收

- 页面测试：记分证照速记每个条目左侧有状态点且从没测过全灰；
- `test/recall_classify_test.dart`：空组灰、只答对一张灰、全答对绿、有答错红；
- 页面测试里「只答对一张标志卡，标志专题仍是灰」。
