# ADR 0090：自测不分轮、按记录区分，答对的不再出现，第二次只考答错的

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/recall.dart`（去掉 `batchSize` 与「第 N 轮」、去掉 `due` 档、收尾不再有「再来 N 个」）、
  `lib/selftest_store.dart`（去掉间隔阶梯）、`lib/{signs,markings,gauges,gestures}_page.dart`（注释）、
  `test/recall_test.dart`、`test/selftest_store_test.dart`、`test/selftest_evidence_test.dart`
- 关系：取代 0089 决策 1（一轮 10 道）与 0083 决策 4（按 1/3/7/21 天间隔回头确认）；
  0083 的「认得以作答记录为准」、0085 的四选一、0089 的版面与自动切换不变；使用者拍板

## 背景

0089 把自测定为一轮 10 道，0083 又让答对的条目按 1、3、7、21 天回头再考。使用者先要求「去掉
10 张这个概念」，随后指出：要**对回答记录进行区分，根据记录有选择地对二次答题进行测试区分，
答对的不用在后续测试中出现**。一轮一轮地弹，到最后常常只剩一两张，没有用处；答对的条目隔几天
又冒出来，也违背「别反复考已经会的」。

## 决策

1. **去掉「一轮几张」。** 自测把所有还没认得的卡按轻重缓急排成一队，逐张过完，没有张数上限；
   卡片头只写「剩 N 张 · 答错 M」。随时可退出，判过的已经记下，下次接着考没认得的。
2. **按记录把每张卡区分成三种状态：** 没考过（`fresh`，先考）、答错过（`wrong`，下次再考）、
   答对过（`selfOnly` / `known`，**以后不再出现**）。抽题顺序：答错过的 → 没考过的 → 相关题只做了
   一部分的；档内随机，档位顺序保留，不再整体打乱把答错过的稀释到后面。
3. **第二次只考答错的。** 第一次自测里「第一次问就答对」的卡不再出现；答错的卡当次隔两张重现，
   直到答对，但这种「提醒后答对」不算数——下次自测还会再考它一次，**下次第一次问就答对才算过**，
   此后不再出现。
4. **去掉间隔复现。** 0083 的 1/3/7/21 天阶梯整个删掉：自测答对过的不会因为隔了几天就回头；作答
   记录证明已掌握的也一直是 `known`，不再按最近作答时间变成 `due`。要重新考，点「重新自测」清掉
   本页自测记录。遗忘问题交给作答通路里的强化练习、考前复习（它们本来就按答题记录处理）。
5. **收尾不再有「再来 N 个」。** 一队过完就是过完：答错的名字列出来，写明「下次自测只再考它们，答对的
   不会再出现」；还剩的、作答记录没证明的，引导「去做这几个的题」；没有要再考的了给「重新自测」。

## 取舍

- 答对一次就永不再出现，对「蒙对」不设防。缓解有两处：答错后重现答对不算数；真正的「认得」仍以
  作答记录为准（0083），自测答对只是「待做题确认」。
- 一次排队的卡可能很多（标线 33 张），但随时能退，且判过的都已记下，不会白做。

## 验收

- `test/selftest_store_test.dart`：答对过的隔 1 天、30 天、400 天都还是认得；答错过的下次再考，第二次
  第一次就答对才变成答对过；重置清本页；0082 版老文件（没有时间戳）答对过的照样认得。
- `test/selftest_evidence_test.dart`：作答记录证明掌握的隔多久都是 `known`；自测答错过的是 `wrong`，
  第二次一次答对变成 `selfOnly`，且 `selfOnly`、`known` 都不在抽题档位里；没有相关题时同理。
- `test/recall_test.dart`：手势页 8 张逐张排好；答错的重现且不算认得；过完没有「再来」，关掉再开只剩答错
  的那 1 张；答对自动切、答错停住；8 个页面都把没认得的卡逐张排出来。
