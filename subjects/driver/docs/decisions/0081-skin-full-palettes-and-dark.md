# ADR 0081：皮肤回到手写完整色板——四套成为真正的主题，暮汐做深色

- 日期：2026-10-05
- 状态：已接受
- 影响：`lib/skin.dart`（每套皮肤手写一份完整 `ColorScheme` 与环境色斑；暮汐改
  `Brightness.dark`）、`lib/look.dart`（`Bs` 增 `onPrimary`；`Bs.dark` 由固定墨色
  改接方案 `onSurface`；`GlassPanel` 玻璃底随皮肤明暗）、`lib/session.dart`
  （实心主色上的白字改 `scheme.onPrimary`，约 6 处）、`test/semantic_test.dart`
  （对比度断言跟着 `onPrimary` 走，新增明暗档位断言）
- 修订：0071 决策 1（皮肤只存种子色、氛围色由 `fromSeed` 生成）；0058 决策 2
  （只做明色，不做暗色）
- 不修订：0058 的令牌门面、圆角与动效分级、环境背景自绘、机器级持久化；0063
  （默认青野）；0071 决策 2（只用现行角色名）、决策 4（语义色不随皮肤变）、
  决策 6（不引系统取色）

## 背景

0071 之后每套皮肤只存一枚种子色，色彩角色全部由 `ColorScheme.fromSeed`
生成。Material 3 方案的 surface 系落在中性灰白：页面底、卡片底、侧栏底、
正文文字在四套皮肤下几乎一样，差异只剩主色露面的少数位置（按钮、选中行、
进度条、环境色斑）。使用者观感「四套之间变化不大」，并明确表示：此前
「每套皮肤手写一整套色板」才是真正的切换主题，要求解除淡色系的约束。

`fromSeed` 的收益（对比度由方案保证、新组件自动配色）与代价（个性被方案
的规律拉平）在这里一头一尾：前者可以由测试守住，后者正是使用者不满意的。

## 决策

1. **每套皮肤手写一份完整 `ColorScheme`**（修订 0071 决策 1）。皮肤即主题：
   主色、surface 各档、outline 系、inverse 面、primary/secondary/tertiary
   容器逐角色手选，不再 `fromSeed`。保留 0071 的结构收益：角色仍走
   `ColorScheme` 载体，组件主题照读方案默认值；`Bs` 门面与全部引用点不动。
2. **解除淡色系约束**（修订 0058 决策 2）。页面底、侧栏、卡片允许带皮肤色调
   （晴空冷蓝、青野米绿纸感、曙途暖米），不再统一压成中性灰白；**暮汐直接是
   深色皮肤**（`Brightness.dark`，深紫夜，夜学场景）。不做「每套皮肤双模式」
   ——一套皮肤一个样子，深色只调暮汐自己的色板，语义色层不动。
3. **实心主色上的前景字跟 `onPrimary` 走。** 答题选项、答题卡方格、翻页条、
   确认作答按钮里写死的 `Colors.white` 改 `scheme.onPrimary`：明色下是白字
   （行为不变），暮汐深色下主色变亮、自动落深字，对比度由测试守住。
   语义色（对错、警示）实心底的白字不动——语义四件套不随皮肤变，明暗都成立。
4. **`Bs.dark`（深色文字与线条）改接方案 `onSurface`。** 0071 阶段 2 的实施
   记录写的正是「`dark` 取方案的 `onSurface`」，代码却是固定墨色（`Sem.ink`）
   ——实现与记录有出入，此处一并对齐：明色下仍是墨色，暮汐深色下变亮字，
   全库图表字、次级文字无需逐处改。
5. **玻璃浮层随皮肤明暗。** `GlassPanel` 的白半透明底与白边改读方案角色
   （`surfaceContainerLow` / `outlineVariant` 加透明度）：明色下观感不变，
   暮汐下成为深紫玻璃，不再是一块白亮面板。
6. **对比度由测试守住**（接替 `fromSeed` 的保证）。`semantic_test` 的「主色上
   能放白字」改为「主色上能放 `onPrimary` 的字，对比度 ≥ 4.5」，新增：暮汐
   `brightness` 为 dark、其余为 light；暮汐页面底 `computeLuminance() < 0.2`。

## 后果

- 四套皮肤成为四套可辨识的主题：晴空冷蓝白（继承观感）、青野米绿纸感
  （默认）、曙途暖米晨光、暮汐深紫夜读。切肤即换装，界面主体也跟着变。
- 以后换口味 = 手写一份 `ColorScheme`（约 25 行）加一团色斑；色彩角色名、
  `Bs` 门面、组件主题全部复用。
- `fromSeed` 不再用于皮肤氛围色；对比度不再由方案自动保证，靠
  `semantic_test` 逐条守（主色/onPrimary、卡片与页面底、语义四件套）。
- 卡片的双层软阴影在暮汐深色下几乎不可见：分层交给「卡片底比页面底亮一档」
  （Material 3 深色的惯例），不另做阴影令牌。
- `Skin` 失去 `seed` 字段（切换器的色点本就用主色与色斑渐变，无其他引用）。
