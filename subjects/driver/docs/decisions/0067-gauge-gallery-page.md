# ADR 0067：仪表速记页——车内符号成为可浏览的内容

- 日期：2026-10-04
- 状态：已接受
- 影响：`content/gauges.json`（新）、`lib/models.dart`（`Gauge`）、
  `lib/content.dart`（加载）、`lib/gauge.dart`（`paintableGaugeIds` 常量，新）、
  `lib/gauges_page.dart`（新）、`lib/home.dart`（侧栏钉住区、页面分发）、
  `lib/glyphs.dart`（`Glyph.gauges`）、`test/gauges_page_test.dart`（新）
- 关系：与 0059（标志）、0065（标线）成对；补上 0064 决策 4「不做图」里搁置的
  一部分——仪表与指示灯的图是几何符号（GB 4094 的标记本身就是抽象图形），
  绘制成本远低于交警手势的连贯人体动作；出处硬标准仍是 0003/0008

## 背景

模拟考按 GA 1026 表 1 固定抽 10 道「机动车基础知识」（占科目一每卷 10%），
题库里 `exam_block=vehicle` 的题有 203 道，其中问仪表指示灯、仪表表盘、开关
操纵件的题约 130 道，出处成体系地挂在 GB 4094—2016（catalog 里
`gb-4094`，99 道题直接引用）。这些符号做错才见到一个，没有速记的地方——
0064 决策 4 搁置了「仪表灯（几十种图标）」，理由是绘制成本；但仪表符号与
交警手势不同：手势是连贯的人体动作，仪表符号是抽象几何标记（红/黄报警、
蓝/绿指示、表盘、简单开关图形），按 GB 4094 的标记画法逐个手绘是可控的。

## 决策

1. **新增「仪表速记」页，侧栏钉住区与「标线速记」并列。** 内容源是
   `content/gauges.json`，每条：`id`、`name`、`kind`（alarm / indicate /
   dial / control）、`band`、`meaning`（一句「亮了怎么办 / 这是什么」）。
   页面按 `kind` 分四组，每组一张 `BsCard` 配读法口诀、组内网格与组级
   「练这组的题」按钮，结构同 0059/0065。
2. **分组按仪表语言分四组：报警灯（红黄，出问题）、指示灯（蓝绿，在
   工作）、仪表表盘、开关与操纵件。** 口诀讲颜色语义——「红色亮了先处理，
   黄色亮了尽快查，蓝绿只是告诉你什么开着」。含义是文件级出处
   （`gb-4094`），不逐条注条号，沿用 0059 决策 2。
3. **挂题用内容文件内的反向映射，不在题库 JSON 上再加字段。**
   `gauges.json` 每条带 `questions`（题 id 列表），加载时按 id 关联到题库。
   与 `sign`/`marking` 的正向字段相比，反向映射把「仪表 → 相关题」的维护
   收在仪表自己的内容文件里，题库行不再加宽；测试断言映射里的题 id 都
   存在、每条至少挂一道题。挂题范围：直接问该符号的题 + 该装置的原理与
   操作题（如 ABS 原理题挂 ABS 故障灯、安全带系法挂安全带提醒灯）；
   安全头枕、儿童座椅等无对应符号的原理题不挂，页面不承诺覆盖整个
   vehicle 块。
4. **painter 支持的 id 集合提取为常量 `paintableGaugeIds`。** 沿用 0059
   决策 4、0065 决策 4：`_GaugePainter` 是 switch 逐 id 手绘符号，测试断言
   `gauges.json` 的每条 id 都在集合里。颜色语义按仪表惯例：红/黄=报警、
   蓝=远光、绿=近光与工作指示。
5. **格子交互与标志、标线页一致**：hover 上浮、点开玻璃浮层看大图、
   高频徽章、组级练习入口走科目一日常题。

## 后果

- 车内符号从「做错题才见到」变成一页可逛的内容；130 道相关题经四组的
  「练这组」直接可练。
- `gauges.json` 是唯一内容源；GB 4094 的符号含义与题库共守「与现行法规
  一致」的硬标准。
- 反向映射是第三种内容关联方式（`sign`、`marking` 字段之外），三种方式
  并存；后续若加新的速记类页面，优先考虑反向映射，题库 JSON 不再新增
  关联字段。
- 交警手势（0064 搁置的另一半）仍不做：人体动作的绘制成本与符号不同量级，
  等有更强理由再议。
