# ADR 0107：行车操作与车辆专题——超车会车、车辆基础、车辆故障与紧急处置

状态：已接受

## 背景

覆盖审计里最后几块：超车、会车、变更车道、转向灯、掉头倒车（科目一约 150 道、科目四约 140 道，是通行规则里口诀和例外最多的一块），
以及车辆相关——科目一的 ABS、胎压、下长坡、自动挡操作，科目四的爆胎、制动失效、转向失控、侧滑水滑、熄火起火等险情处置（科目四约 150 道）。

## 决定

沿用 ADR 0097、0103 的做法，四个专题各属一个科目、各一份内容文件、各取本科目的题：

- 科目一 `s1.maneuver`「超车会车与掉头倒车」：超车、会车与让行、变更车道与转向灯、掉头与倒车（含河南借道、掉头、转向灯距离）。
- 科目四 `s4.maneuver`「超车会车与变道倒车」：超车与让超、会车与让行、变道转向灯掉头倒车。
- 科目一 `s1.vehicle`「车辆基础与操作」：ABS 与制动、轮胎胎压与爆胎、下长坡与油耗、自动挡操作。
- 科目四 `s4.failure`「车辆故障与紧急处置」：爆胎与漏气、制动失效与转向失控、下长坡与坡上停车、侧滑水滑与 ABS、熄火起火与灯光熄灭。

险情处置与技术性要点的出处用 2022 版考试大纲对应章节、GB 7258、GB 26149，法条类要点指到条款。
新增图标 `Glyph.maneuvers`、`Glyph.vehicleCare`。校验沿用 ADR 0103。
