# ADR 0076：速记页交互增强——考我模式、易混对撞卡与格子掌握度微点

- 日期：2026-10-04
- 状态：已接受
- 影响：`lib/recall.dart`（共用考我组件，新）、`lib/signs_page.dart`、
  `lib/markings_page.dart`、`lib/gauges_page.dart`、`lib/gestures_page.dart`、
  `lib/models.dart`（四类符号条目的 `confuseWith`/`confuseNote` 字段）、
  `content/signs.json`、`content/markings.json`、`content/gauges.json`、
  `content/gestures.json`（易混对声明与差异口诀）、`lib/home.dart`（传入
  作答历史）、对应页面测试
- 关系：落实仓库级 ADR 0056（可视化与交互是内容本身）；「考我」的自评
  **不落库、不写掌握度**——掌握度只由作答写入（0020、主仓库 0052），
  参考页不判分的定位不变（0059 决策 2）；不出题、只调既有题库通路
  （主仓库 0043）；玻璃浮层沿用 0058 决策 6；掌握度微点的数据由作答
  历史派生，不另建表（0052）

## 背景

速记页（标志、标线、仪表、手势）目前是纯浏览：摊开、看、点开大图。
浏览即「重读」，是记忆研究里效果最差的学习方式；检索练习（先回想再看
答案）的效果显著更好，且「想不起来」的挫败感本身就是参与感。页面已有
的「练这组」通路负责真正的记忆闭环（作答写入掌握度、进强化练习），
速记页缺的是把「看」变成「想」的那一步。

## 决策

1. **「考我」模式：页面级入口，卡片流式检索练习。** 页面标题区加
   「考我」按钮，点开玻璃浮层全屏卡片流：正面大图（+「这是什么？」），
   点击或空格揭示名称与「看到之后怎么开」，随后自评「记住了（1）/
   没记住（2）」。没记住的条目在隔两张后重新插入队列，直到全部记住了
   或主动退出（Esc）。收尾统计「考了 X 张、没记住 Y 张」，配「去练这组」
   深链调用既有的 `onStartPractice`——自评只影响本会话的重现顺序，
   不落库、不写掌握度、不产生任何作答记录；真正的记仍由练习通路完成。
2. **易混对撞卡：浮层里的双图对照。** 四类符号条目加可选的
   `confuse_with`（对方 id）与 `confuse_note`（一句差异口诀），只在对
   其中一方声明一次，浮层揭示区底部渲染两图并排加差异句。每页 3-4 对，
   挑真实考点（题库里专门考区别的），不硬凑。
3. **格子掌握度微点：浏览时看见自己的进度。** 格子角上加一枚小圆点，
   四级：红 = 相关题最近一次答错（在备选库）、黄 = 相关题部分掌握、
   绿 = 相关题全部掌握、灰 = 从未作答。数据由页面传入的作答历史
   （`HistorySet`）与已掌握集合现算，不另建表；微点是纯展示，点击格子
   仍是看大图。
4. **范围：先铺四个符号页。** 考我模式的图卡形态在标志、标线、仪表、
   手势四页先行；文字条目页（考点速记、河南速记、易混数字）的「遮住
   要点」变体沿用同一原则另批落地，不在本 ADR 内。

## 后果

- 速记页从「看一遍」变成「想一遍再看、没记住的当场再来」；微点让
  「练这组」的动机从抽象数字变成每格的具体颜色。
- 自评不产生数据负担：没有新表、没有同步、没有掌握度污染；退出即消失。
- `confuse_with` 声明是内容工作：写差异口诀要过题库口径（与题面、
  解析一致），条目改版时一起改。
- 共用组件 `lib/recall.dart` 承载卡片流，四个页面只传参；后续文字页
  复用时传入「正面文案 + 遮住的要点」即可。
