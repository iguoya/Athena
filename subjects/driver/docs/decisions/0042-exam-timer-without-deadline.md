# ADR 0042：模拟考只计时，到点不收卷

- 日期：2026-09-28
- 状态：已接受
- 影响：`lib/session.dart`、`lib/home.dart`
- 关系：撤销本应用 ADR 0016 第 5 条中「挂起太久已经超时的，续上后直接按超时自动交卷」；
  取消倒计时到零自动交卷（原先没有单独的 ADR，写在 `session.dart` 里）；与 ADR 0041
  同一方向——模拟考不再仿照考场强行收场

## 背景

模拟考和阶段测试原先是倒计时：科目一、科目四 45 分钟，到零自动交卷，没答的题按错计；
草稿续答时从原始开考时刻算，挂起太久的续上就直接交卷。使用者的要求是取消强制时限、
到期不退出。

跟 ADR 0041 同一个理由：强行收卷砍掉的是练习量，剩下的题没见过、写不进作答记录。
时间感可以靠显示已用时间来练，不必靠收卷。

## 决策

1. 顶栏的倒计时换成「用时 mm:ss / 45:00」：从开考时刻（续答时是草稿里的原始开考时刻）
   算起的已用时间，对着考场时长。超过时长只把数字变红，不收卷、不弹窗。分钟不折小时，
   超很久也读得懂。
2. 一卷只由自己点「交卷」结束；中途退出（ADR 0019）照旧不出分、草稿留着。
3. 续答超时的草稿照常续上，不再自动交卷。
4. 结果页去掉「时间到，已自动交卷」；开考确认框写明「考场时长 N 分钟，这里只计时、
   到点不收卷」。

## 后果

- 考场上 45 分钟的时间压力在软件里只剩一个变红的数字，是否按时答完靠自己看。
- 续答的草稿隔了很久再打开，用时会很长（包含挂起的时间）；这是如实显示，不另外扣除。
