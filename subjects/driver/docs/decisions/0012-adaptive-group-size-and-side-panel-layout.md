# ADR 0012：分组题量按内容自适应，翻页条挪到左栏底部，右栏顶部加统计方块

- 日期：2026-09-20
- 状态：已接受
- 影响：`lib/session.dart`
- 关系：修订本应用 ADR 0007 第 1 条「四题一组」与第 4 条「块宽占栏宽三分之二」，
  其余条款不变

## 背景

练习页固定四题一组、左栏用 `ListView` 铺满。带图或带标志的题比纯文字题占地方
明显更高，四题都带图时这一页经常要滚动才能看全，翻页按钮又压在右栏中间偏下的
浮层位置——按钮位置和左栏内容高度没关系，看着容易觉得飘。选项块宽度定死三分之
二，在窄一点的窗口上偏局促。右栏原来只在模拟考才有「答题卡」网格，练习模式的
右栏没有类似的整体进度视图，只能看到当前聚焦这一题。

## 决策

1. **分组题量按内容自适应，从头到尾摊 3–4 题**：往后看 4 题的候选窗口里只要有
   任意一题带图（`image`）或带标志（`sign`），这一组就退到 3 题；纯文字题维持
   4 题一组。取消固定 `_groupSize`，改成 `_groupSizeAt(start)` 现算，组的起点
   都由同一套规则反推（`_groupStartContaining`），保证正着走、跳页、退组算出
   来的边界一致。
2. **翻页 / 交卷条钉在左栏最下方**，不再是压在右栏中间偏下的浮层。左栏改成
   「题目区（`Expanded` + `ListView`）＋ 底部翻页条」的纵向布局；练习模式一组
   没答完时翻页条不出现，直接留白，不占位置。
3. **右栏顶部加一块「答题情况」统计区**：小方块一排铺开，练习模式按未答/答对/
   答错三色区分，模拟考仍是未答/已答两色（原答题卡的网格逻辑不变，颜色计算
   合并成同一个 `_statCell`）。点方块跳转到对应组的行为不变。
4. **选项块宽度从栏宽三分之二改成八成**，跟题干的呼应关系不变，只是给选项本身
   多留一点横向空间。

## 后果

- 组的边界不再是简单的算术级数，`_jumpTo`、`_prevGroup` 都要经过
  `_groupStartContaining` 反查，不能再用 `index ~/ groupSize` 直接算。
- 练习模式右栏第一次有了「答没答、对不对」的全局视图，跟模拟考的答题卡在
  界面语言上统一，只是练习多一层对错颜色。
- 组题量变小之后单组渲染的高度更容易一屏放下，但不是硬保证——极端窗口尺寸下
  仍可能需要滚动，`_groupColumn` 保留 `ListView` 作为兜底。
