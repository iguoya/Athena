# ADR 0021：以四个工科专业类组织技术体系——计算机、电子信息、电气、自动化，弱电优先

- 日期：2026-10-06
- 状态：已接受
- 修订：ADR 0012（「计算机、电子信息两门学科」扩为四个专业类）；ADR 0009 第 5 条（academic 节点的 `targets` 不再必填）；ADR 0018 决策 1（十二个能力域扩为十四个）；ADR 0016 决策 2（地图与路线增加 `discipline`）
- 相关：ADR 0012、0014、0016、0018、0020；仓库级 ADR 0054（宁增勿删）

## 背景

使用者的理解：中国工科里与本应用相关的是**四个专业类**——计算机类、电子信息类、电气类、自动化类；要把四大学科的**技术体系及其衍生路线**都建起来，**优先弱电**。此前北极星只有两张课程图（计算机、电子信息），电气与自动化两个专业类整块缺席，这和 ADR 0012「盘面上不允许整块缺席」的要求相悖，也让控制与电力电子这两条重要的软硬结合主线没有位置：现有 14 个能力域里没有「控制」与「电力」的专门域，控制被并在信号里，电力电子、电机、电力系统则根本没有。

「弱电」在这里指电子、信息、计算机、控制等低电压、小功率的技术方向；「强电」指电力的发、输、变、配、用。电气类横跨两侧：电力电子、电机驱动、电气测量、电池管理、智能电网通信偏弱电，电力系统、高电压、供配电、继电保护偏强电。

## 决策

1. **四个专业类各有一套技术体系与衍生路线。** 每类一张课程图（底盘，`academic`、`graph_kind: course`，初级、中级、资深三阶段分列），再加该类的**主干阶梯**与若干**方向路线**。现有 `computer-science`、`electronic-information` 保留并补缺；新增 `electrical-engineering`（电气类）与 `automation`（自动化类）。
2. **弱电优先，强电照样入图但排后。** 建设顺序：计算机、电子信息、自动化、电气的弱电侧先做足；电气类的强电侧（电力系统、高电压、供配电、继电保护）纳入体系，但深度先到主干，并在路线里排在弱电之后。电气图的每个节点必须标 `current`：`weak` 弱电、`strong` 强电、`both` 兼有，界面显示并可据此识别。
3. **能力域扩为十四个。** 新增 `control`（控制与自动化，从 `signals` 分出）与 `power`（电力、电机与电力电子）。`ei.control`、`ei.motor_control` 改标 `control`。通才阶梯继续覆盖全部域（测试守着）。
4. **地图与路线带 `discipline`。** 取值 `cs`、`ei`、`ee`、`auto` 与 `cross`（跨专业类，如软硬接口、纵深图、通才阶梯）。开放地图与全部路线必须写；界面按专业类组织入口。
5. **跨专业类的知识只有一个节点。** 电路、信号与系统、反馈控制这类各专业类共用的知识，仍是底盘里的同一个节点（一个 id 只装一个东西，ADR 0054），由各专业类的路线与跨图关联引用，不为每个专业类各抄一份。
6. **academic 节点的 `targets` 不再必填。** 它原本把必要程度追到军工目标图（ADR 0009 第 5 条），而军工是「远方兼顾」（ADR 0014）、目标图在参考层。写了仍须指向有效的目标图。
7. **只增不删，分批到位。** 本次全部是新增：新地图、新节点、新路线、新来源与新字段；现有节点的内容、id、阶段与边不动，只有 `ei.control`、`ei.motor_control` 的 `domain` 取值按第 3 条调整。每个新节点照常有出处、章节（ADR 0020）与能力域；还没覆盖的内容写在各图的 summary 里，不假装齐全。

## 后果

- 契约：十四个域；`discipline`（图与路线必填）；`current`（`ee` 图必填，其余可选）；academic 的 `targets` 可缺省。反例与不变量同步更新。
- 界面：首页按四个专业类加「跨专业类」组织；底盘的图切换按专业类分组；节点显示弱电、强电标记；雷达为十四个轴。
- 内容规模成倍增长，每个新节点的出处必须是目录里已核实可访问的来源；核实不了的来源不引用。
