# 北极星 · 计算机、电子信息、电气与自动化的路线图与指南针

先看见学科的全局、主次和去向，再决定进哪一个学习应用练细节。同一块知识**底盘**，按不同的角度和
技术方向走出不同的**路线**；**软硬结合**是主线——软件看见的硬件、硬件承诺给软件的东西，被当作
一等知识来讲。

## 它有什么

- **路线总览**：路线排成「角度 × 软硬权重」矩阵（偏软件 ↔ 偏硬件），每条路线都有适合谁、
  分阶段的目标和**可检查的终点产物**；还没有路线的格子如实写出来。
- **通才阶梯**：整座底盘的主干，五个阶段、十四个能力域一个不缺。先走它，再选方向，就不会营养不良。
- **四个专业类**（ADR 0021）：计算机类、电子信息类、电气类、自动化类各有一张课程图和一条主干阶梯，再加若干方向路线；
  首页可以按专业类筛选。电气类**弱电优先**（电路、电源、变换器、电池与低功耗在前，电机、电力系统、并网与保护在后），每个节点标出弱电或强电。
- **评级与推荐**（ADR 0022、0023）：每个节点与路线按七个维度评级——实用性、实践性、理论实用性、可验证性、学科核心骨干、市场需求度、技术发展前景，
  每个五级，图面可以按任一维度着色；路线另有优劣、推荐等级与推荐的后续方向，总览按推荐等级列出「推荐发展方向」，并单列「技术前景最好的方向」。
  实践性、可验证性、学科核心骨干由内容推导，其余是带依据的编辑评估；评级只用来强调，不合成总分。
- **均衡度**：每条路线都能看到覆盖雷达，没碰到的能力域会被指出来，并给出补哪些节点；还写着这个方向最常见的偏科。
- **高端纵深**：CPU 与 SoC 架构、数字芯片设计与验证、AI 加速器与推理系统、系统固件与可信、高可靠与航天航电——
  每个节点的出处是公开的工程文档与课程标准，岗位画像只作时效性样本，不构成录用承诺。
- **学习原则**：来自资深从业者与权威论述的几条原则，每条带出处，可点开核对。
- **路线视图**：路线的阶段是列，自左向右走；每个阶段末尾有验收。
- **底盘**：课程图（计算机、电子信息、电气、自动化）、两张实践主干，和一张**软硬接口图**——时序、存储与数据通路、
  总线、功耗、启动与可信、可验证六份跨层契约，每个节点同时写清硬件一侧与软件一侧。
- **读图**：悬停是预览、选中是钉住，邻域高亮、其余压暗，连线沿方向流动；点连线上的编号看这条
  依赖为什么存在、凭什么成立。
- **节点抽屉**：为什么必须学、学完能判断设计什么、能交出什么；先修与来路；跨图关联；所在路线；
  出处（可在浏览器里打开核对）。
- 晴空 / 暖纸两套明亮主题；运行时只有一个窗口；不含进度、岗位评分、账号或云服务。
