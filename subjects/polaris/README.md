# 北极星 · 计算机与电子信息的路线图与指南针

先看见学科的全局、主次和去向，再决定进哪一个学习应用练细节。同一块知识**底盘**，按不同的角度和
技术方向走出不同的**路线**；**软硬结合**是主线——软件看见的硬件、硬件承诺给软件的东西，被当作
一等知识来讲。

## 它有什么

- **路线总览**：路线排成「角度 × 软硬权重」矩阵（偏软件 ↔ 偏硬件），每条路线都有适合谁、
  分阶段的目标和**可检查的终点产物**；还没有路线的格子如实写出来。
- **路线视图**：路线的阶段是列，自左向右走；每个阶段末尾有验收。
- **底盘**：课程图（计算机、电子信息）、两张实践主干，和一张**软硬接口图**——时序、存储与数据通路、
  总线、功耗、启动与可信、可验证六份跨层契约，每个节点同时写清硬件一侧与软件一侧。
- **读图**：悬停是预览、选中是钉住，邻域高亮、其余压暗，连线沿方向流动；点连线上的编号看这条
  依赖为什么存在、凭什么成立。
- **节点抽屉**：为什么必须学、学完能判断设计什么、能交出什么；先修与来路；跨图关联；所在路线；
  出处（可在浏览器里打开核对）。
- 晴空 / 暖纸两套明亮主题；运行时只有一个窗口；不含进度、岗位评分、账号或云服务。
