## 第一要务

1. 界面美观、绚丽、酷炫，吸引年轻女生，让她愿意打开。视觉优先。
2. 学习要有趣、见效快、有成就感和鼓励感：每次打开都有记录和看得见的收获，有奖励、正反馈和阶段性里程碑。

## 教学原则（tiger 的经验，全部要遵守）

- **单词和句子不割裂**：背单词一定不脱离句子。软件里没有“单词 = 中文”对照表，也没有只显示单词的练习。生词复习 = 换一个没见过的真实句子挖空填词。
- **只用现实中的真实句子**：长短不限，但必须有出处。AI 不生成例句。每个义项至少引用 3 条真实例句，不够的先不入库。来源优先级：高考、四六级、专四专八真题原文 → Tatoeba 等 CC BY 句库 → 有链接的新闻和演讲 → 她的课本（只在本机）。
- **单词关**：以高中课标词汇为上限，属于第一章。先用真实句子挖空诊断，只补不熟的词。每个词三层：更简单的英文释义 → 中文 → 更多真实长短句。简单英文释义可由 AI 起草、tiger 审核（这和例句不同）。每天新词最多 15 个。
- **句子为主，难度缓慢增加**：句子 → 句群 → 短文，按熟练度和信心升级，不按日历。前几周以建立信心为主。写短文是最终考核，放在后面。
- **语法藏在真实句子里隐性习得**：不做机械的规则总结，没有单独的语法课。点句子彩色标出主干和从句。
- **读、写、听、说**：按中国英语学习逻辑和考试分值，这既是优先级也是每天的步骤顺序。读、写、听每天必做；说是鼓励项，可以跳过（宿舍里开口不方便），做了额外奖励。学有所用：不要哑巴英语，也要会动手写。
- **按考试分值定重点**（ADR 0015）：阅读在每门考试里最大；四六级听力 35%、阅读 35%、写作和翻译 30%；专四有听写和语言知识；口语不计入笔试。
- **记忆科学和高效学习法**（ADR 0008、0014）：以自我测试和间隔复习为地基（FSRS，ts-fsrs 库），加上连续再学习、交错练习、必要难度、预测试、i+1 句子、精读加泛读、听写、刻意练习、自我决定理论。以后发现更好的方法，先写新 ADR 再落到功能。

## 章节路线（ADR 0017）

| ----------------- | -------------------------------- | ------------ |
| 第一章 · 夯实高中 | 高中常见词和句式，单词关并入本章 | 大一上       |
| 第二章 · 四级     | 四级真题句子、听力、翻译、写作   | 大一下       |
| 第三章 · 专四     | 听写、语言知识，同时准备六级     | 大二         |
| 第四章 · 专八     | 阅读、汉译英、写作、听力         | 大三到大四上 |

第一章按高中句式分单元（时态、被动、非谓语、定语从句、名词性从句、状语从句、情态动词、虚拟语气、倒装、强调），开章先诊断，每个单元学完一张回顾卡（句式名 + 她已掌握的真实句子 + 她自己写对的一句），所有回顾卡连成“高中英语知识地图”。

第一版范围：第一章完整可用，并开始四级起步部分。

## 技术决定

- 离线优先的 Windows 桌面应用，只有 AI 批改走网络（断网时排队）。
- Tauri 2 + Vite + React + TypeScript + Tailwind v4 + shadcn/ui + Motion；Zustand、React Router、ECharts、Tiptap；pnpm、ESLint、Prettier、Vitest。TypeScript 固定在 6.x（typescript-eslint 还不支持 7）。
- 数据：SQLite（rusqlite）只存学习记录，放系统用户数据目录；课程内容是仓库里的 JSON、Markdown 和音频，打包进安装包。
- 字体全部本地打包（@fontsource），不联网加载。
- 三套皮肤已定版：晨光（柔和渐变）、极光（夜间霓虹）、手账（纸张贴纸），共用一套组件，只换 `src/styles/index.css` 里的设计变量（`data-style` = dawn / night / journal）。
- 旧的 2020 年 VuePress 作文站在 `archive/vuepress-2020/`，新软件不使用。
- 自动更新（ADR 0018）：打 v* tag 后由仓库级 Release 工作流编译签名安装包并发布 Release（统一发版，主仓库 ADR 0081；应用内 `.github/` 死工作流已删）；软件启动时用 updater 插件检查并静默更新。签名密钥已配置在 GitHub Secrets（`TAURI_SIGNING_PRIVATE_KEY`），私钥永远不进仓库。本地开发走 `launcher open ascent`（`app.json` 的 `dev` 块声明，ADR 0046），不再用独立时代的「启动 Lumi（开发版）.cmd」一键脚本（已删，ADR 0021）。
- 内容来源和版权（ADR 0019）：仓库和安装包都是公开的，真题和课本只放本机 `content/private/`（git 忽略）。开放来源登记在 `content/sources.json`；`pnpm content:ecdict` 生成高中、四级、六级三个词库草稿（`content/vocab/{hs,cet4,cet6}/`），`pnpm content:stages` 把每个词库按真实难度信号切成先易后难的子阶段（`vocab/*/stages.json`，ADR 0022），`pnpm content:tatoeba` 给每个词挑真实例句（需要能访问 downloads.tatoeba.org），`pnpm content:cet4` 把四级真题句子导入本机并统计各词库的词在真题里的频次。本机教材资料放 `content/private/textbook/<教材名>/words.txt` 后跑 `pnpm content:textbook` 解析（个人自用，不进仓库；ADR 0019 补充、ADR 0022）。选资源以中国英语考试为准，真题句优先于通用句库；出处说不清的词表和例句不用。
- master 上的每次推送都会发布新版本，推送前确认 `pnpm lint`、`pnpm build` 通过。

## 在这台电脑上运行

已在 XIANG-DESKTOP 上跑通（2026-09-30）。这台电脑走 127.0.0.1:7890 代理，Node 24 需要 `NODE_USE_ENV_PROXY=1`；pnpm 12 默认拒绝发布不到 24 小时的包，加新依赖时选发布超过一天的版本。推送用 Windows 自带的 OpenSSH。

需要 Node 22+、Rust（rustup，MSVC 工具链）、VS 2022 C++ 生成工具（“使用 C++ 的桌面开发”）、WebView2。然后 `pnpm install`、`pnpm tauri dev`。安装任何软件前先问 tiger。

pnpm 的提供方式（2026-10-09）：这台机器 corepack enable 需要管理员写 Program Files，实际用
`npm i -g pnpm@12` 装进用户级 `%APPDATA%\npm`（本来就在 PATH）。此前 pnpm 不在 PATH，启动器
执行 dev 块的 `pnpm tauri dev` 会直接报找不到命令——摘星「启动器跑不起来」即此因。
