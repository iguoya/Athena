# 0011 学有所用：写是必修，说是鼓励项

- 状态：已采纳
- 日期：2026-09-30
- 决策人：tiger

## 背景

tiger 要求把听说读写结合起来，不要不会动手写句子、写短文的英语，一定要学有所用。随后补充：国内缺少说英语的环境，在宿舍开口也可能影响别人，所以听读写是重点，说作为鼓励性要求，不和听读写做同样强度的要求。优先级是读、写、听、说，不要脱离考核现实。

四六级笔试的分值是听力 35%、阅读 35%、写作和翻译 30%，口试是单独的考试，不计入笔试成绩（出处：https://cet.neea.edu.cn/xhtml1/folder/19081/5124-1.htm ）。所以听力仍然每天必做，说作为鼓励项。

## 决策

- 优先级是读、写、听、说。**读、写、听**每天必做，三项做完当天才算完成。
- **写**：
  - 每天用当天的生词和句式仿写 1 到 3 句，交给 AI 批改。
  - 写作按阶段加码：先写句子，再写一小段话，最后才写生活场景短文和四级作文（见 ADR 0013）。
  - 题目选生活里真用得上的场景，比如给老师发消息、给室友留言。
- **说**是鼓励项：
  - 跟读重点句，可以小声或默读跟读，不强制录音。
  - 不做不影响打卡和当天完成；做了额外得一枚贴纸。
  - 录下的音保存下来用于前后对比（见 ADR 0009）。
- 第一版没有自动的口语评分。

## 后果

- 她在宿舍也能完整学完当天内容，不会因为不方便开口而断掉打卡。
- 口语能力的提升会慢于听读写，这是有意的取舍。
