# 0026 自用软件：取消「只放本机」分流

- 状态：已采纳
- 日期：2026-10-10
- 决策人：tiger（「只要在互联网出现就是公共领域，怎么方便怎么来，按自用软件看待开发」）

## 背景

ADR 0019 补充与 ADR 0025 第 3 节补充规定：引用了未声明许可来源的内容（真题、教材、第三方
词库句库）只放 git 忽略的 `content/private/`，不进仓库、不进安装包，运行时再读或导入。
落地后，考研英语二 617 题里 415 题走了本机，随之多出一整套机制：Rust 读取命令、导入对话框、
缺题提示、半套卷不记成绩、换机器要手动拷贝。tiger 认定这是自用软件，这些代价不值得。

## 决策

1. **不再按来源授权限制存放位置**：所有内容进仓库与构建。`sources.json` 的 `use` 只记录授权
   情况，不再据此拦截；`content:check` 只查「出处登记过」。
2. **出处照常逐条记录**（主仓库 ADR 0043 的底线不变）：记出处是为了能核对、能换源，与存放
   位置无关。
3. **考研英语二**：617 题全部进 `content/english2/`，构建时打进前端；磨砚的作者侧参考资料
   （词表、句库、教辅摘录，约 42MB）进 `reference/english2/`——进仓库、不在 `content/` 下，
   所以不打包、不被当作题目扫描。
4. **删除为分流而建的机制**：本机读取与导入命令、对话框插件、`private-index.json`、缺题提示、
   缺题考核不记成绩。四级真题与教材的导入脚本改写进 `content/`。`content/private/` 仍在
   `.gitignore` 里，留给真正只想放本机的东西，但没有任何功能依赖它。
5. 取代 ADR 0019 补充中「原文只放 private」的一条与 ADR 0025 第 3 节及其补充。

## 后果

- 换机器 clone 下来英语二就是完整的，不用导入。
- 仓库公开、安装包随推送公开发布，第三方内容随之公开——这是 tiger 知情后的选择。
