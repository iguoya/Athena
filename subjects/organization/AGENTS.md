# Athena 计算机组成原理 — 项目协作规则

本文档是 **`subjects/organization` 独立应用** 的项目级指令，不依赖任何其他应用即可完成开发、
构建、学习与实验全流程。

仓库根 `AGENTS.md` 写各应用共同遵守的规则；**改本应用时以本文为准**。启动器通过
`app.json` 把本应用当独立进程拉起（ADR 0032），那不是运行本应用的前提。

## 定位

- **学习应用**（主仓库 ADR 0115）：承载 408 计算机组成原理——数据表示与运算、存储层次、
  指令系统、中央处理器、总线、输入输出。章节骨架按 408 考纲七章排列，考纲定覆盖范围的
  下限，不定讲法。
- 位于启动器「考研」圈，**主挂靠 cs408**（主仓库 ADR 0116 决策 4、0118、0119）：整门课
  就是 408 的 45 分科目，本体归 408，画布上只出现这个图块；软设第 1 章「计算机系统」与本课
  重叠，靠两边课程树的文字指引承接（0119：夺走即独占，软设一侧不放引用节点）。
- **与 machine（C 与机器）的边界**：那边从 C 程序往下看（变量的内存表示、汇编、调用栈），
  这边从硬件往上看（运算电路、存储层次、控制器、总线与 I/O）。数据表示两边都碰：那边讲
  C 类型在内存里的样子，这边讲运算电路、溢出判断与规格化。各写各的，不共享代码。
- 不以做成硬件描述语言（Verilog）仿真器或通用模拟器为目标；模拟只做到「把考纲里的那个
  过程走出来」为止。
- **出处档位 open**（ADR 0089）：技术学习类，出处是默认习惯不做门禁——408 真题与教材例题
  鼓励当场标出处，未标注只报告不阻断；不凭印象伪造出处（要么如实标 `authored`，要么不标），
  AI 现场出题不计入掌握度。
- **学习方法原型（ADR 0113）**：主原型**机制模拟**，辅**预测–运行**。Cache 映射与替换、
  虚实地址转换、流水线冒险、数据通路与控制信号、中断与 DMA 时序都是看不见的过程：先让
  学习者预测（命中与否、各段时钟周期、有效信号），再单步揭示并解释偏差；补码溢出、
  IEEE 754 精度、访存模式对性能的影响用 C++ 实验真跑验证预期。主计算题是 Cache 地址划分、
  有效地址、CPI 与执行时间、总线带宽。

## 技术栈（本应用自有）

- **壳**：Tauri 2（Rust）
- **界面**：Vite + TypeScript（Web UI）
- **内容**：`content/curriculum.json` + `content/cases/**`（本目录唯一课表）
- **进度**：SQLite，写入本应用自己的 `progress/learning.db`（随仓库走，主仓库 ADR 0053；
  发行副本退回用户数据目录 `AthenaOrganization/`），自建表、自迁移（ADR 0037）。
  知识点 ID 前缀 `org.`。
- **实验运行**：本机 `c++` / `clang++` / `g++`，`-std=c++20`，子进程编译运行。选 C++ 而不是
  汇编或 HDL：数据表示与访存行为用 C++ 就能真跑出可观察的证据，开发机基线自带编译器
  （ADR 0057），不必再引入一套工具链。

壳最初复制自 linux 应用的 Tauri 2 + 本机编译架构（ADR 0115），此后独立演进，不跟随对方改动。

## 目录与所有权

| 路径 | 职责 |
|---|---|
| `content/` | 课表与 C++ 案例；**唯一内容源** |
| `src/` | 前端：导航、导读 / 讲解 / 实验 |
| `src-tauri/` | 窗口、读内容、进度、`compile_and_run` |
| `app.json` | 声明怎么构建、怎么启动、怎么算就绪；由 `launcher` 执行（ADR 0046） |
| `docs/decisions/` | 本应用 ADR |

## 内容与教学分层

- **导读合一**（本应用 ADR 0001）：地图与方向在同一份；章节与大纲优先用图、表、对照、
  可交互示意。
- **随堂测验与章末考核**（ADR 0002）：完成度只由 `checkpoint` 作答后按正确率写入，禁止手动
  「标记熟练」；题量以覆盖本章已写知识点与典型误区为准。
- **实验给骨架**（ADR 0003）：接口与 `main` 驱动已备好，学员只补 `TODO`。
- **步进可视化由 C++ 打印状态快照**（ADR 0004）：快照行前缀 `#org-trace`，前端只回放，
  不在前端重写一份硬件真相。
- 一节内容写完要有可提取物（主仓库 ADR 0096）：机制类节至少一道「先预测再单步」，
  计算类节至少一道计算题。

主线按考纲：计算机系统概述 → 数据的表示和运算 → 存储系统 → 指令系统 → 中央处理器 →
总线 → 输入输出系统。存储系统与中央处理器是机制模拟的重点章。

## 开发与验证

```sh
launcher open organization   # 日常开发（热更新）
```

环境变量 `ATHENA_ORGANIZATION_ROOT` 可强制指定应用根目录（含 `content/`）。

验证走仓库根的统一入口 `python3 scripts/check.py organization`：内容 JSON 校验、
`npm run build`、`cargo check` 与 `cargo test`（只改内容或前端时加 `--skip-rust`）。

## 修改流程

1. 改课：先改 `content/curriculum.json` 与 cases，再补前端展示类型（若有新块）。
2. 改运行时：只动 `src-tauri`，保持命令表面稳定。
3. 改 UI：只动 `src/` 与 `index.html`。
