# 0017 章节路线：先夯实高中英语，再逐级备考

- 状态：已采纳
- 日期：2026-09-30
- 决策人：tiger

## 背景

她高考英语约 100 分（满分 150），高中常见单词和句式并不扎实。tiger 认为章节目录要有高中英语知识的总结和回顾，先夯实高中英语，再考虑下一阶段。

## 决策

### 章节路线

| 章                | 内容                                             | 大致时间             |
| ----------------- | ------------------------------------------------ | -------------------- |
| 第一章 · 夯实高中 | 高中常见单词和常见句式                           | 大一上学期           |
| 第二章 · 四级     | 四级真题的句子、听力、翻译和写作                 | 大一下学期，考四级   |
| 第三章 · 专四     | 听写、语言知识、专四阅读和写作；六级可以同时准备 | 大二，考专四和六级   |
| 第四章 · 专八     | 专八阅读、汉译英、写作和听力                     | 大三到大四上，考专八 |
| 考研（待定）      | 英语专业考研考二外加基础英语，大三再决定         | 大三                 |

- 进入下一章看掌握程度，不看日历；时间只是参考。
- 每一章内部仍然按句子、句群、短文三个阶段慢慢加难（见 0013）。第一章基本停留在句子阶段。

### 第一章怎么做

- 单词关（0012）并入第一章：高中常见词在本章的句子里学。
- 本章按高中常见句式分成若干单元，例如：时态、被动语态、非谓语动词、定语从句、名词性从句、状语从句、情态动词、虚拟语气、倒装和强调。单元清单放在 `content/grammar.json`，每个单元对应一批真实句组。
- 开章先做一次诊断：每个单元各出几道真实句子挖空题。已经扎实的单元直接点亮，她只学没掌握的部分，不从头炒冷饭。
- 每个单元结束有一张"回顾卡"，这就是高中知识的总结：列出这个单元的句式名称，每个句式配她已经掌握的 2 到 3 条真实句子（彩色标出结构），再加一条她自己写对的句子。不写大段规则讲解（见 0007）。
- 全部单元的回顾卡连起来，就是一张"高中英语知识地图"，她能看到哪些已点亮、哪些还没有。点亮整张地图是一个大里程碑（见 0009）。
- 本章句子来源加上高考英语真题原文（阅读、完形、听力），排在四六级真题之前。

## 后果

- 第一版的范围改为：第一章完整可用，第二章（四级）先做起步部分。
- 需要整理高中常见句式清单和高考真题句库。
- 前几周的内容贴近她现有水平，更容易建立信心（见 0013）。
