# ADR 0019：练习与测验必须有所本；每节配标准例题

- 日期：2026-09-14
- 状态：已接受
- 修正：ADR 0017 第 1 节（自由发挥的边界表，「预测题与验证闭环」一行）
- 补齐：ADR 0014 第 2 节（渐隐完形的第一级此前没有内容载体）
- 依赖：ADR 0009（教材坐标）、0012（三遍）、0014（习题设计）、0017（严格表述可核对）

## 背景

使用者指出两件事：

1. **出题测验必须有所本**，要跟现实中的习题——**特别是例题**——结合起来，
   **不要轻易自造测试题**；
2. **每个章节最好配几道标准例题**，配合知识点讲解。

### 1. 现状盘点（2026-09-14）

| 项 | 数量 |
|---|---|
| 已写 topic | 16 |
| 有随堂练习的 topic | 9 |
| 练习题总数 | 31，**全部为选择题** |
| **标出处的题** | **0** |
| **有标准例题的 topic** | **0** |

31 道题全部由本应用自造，一道也指不到外部出处。

### 2. 这是 ADR 0017 没管到的半边

ADR 0017 已经确立「严格表述必须可核对」，并给每节加了 `sources`。但它第 1 节的
边界表把**「预测题与验证闭环」划进了「可以自由发挥」一栏**——于是讲解有出处、
题目没有。

这半边不该放开，理由与讲解那半边不同：

- **自造题没有难度校准。** 自己出的题往往比真实习题简单，或者偏离常考形态。
  做对了说明不了什么，**检验器就失效了**——而 ADR 0014 的全部论证都建立在
  「习题是检验器」上。检验器本身不可信，流畅性错觉反而被它加固。
- **自学者需要能核对，也需要能接着练。** 题目有出处，使用者才能在原处找到同类题
  继续做，也才能判断本应用有没有漏讲、讲偏。这与 ADR 0017 的理由是同一条。
- **典型性是长年教学筛出来的。** 哪道题能暴露哪种误解，是教材经多轮修订沉淀的
  结果，不是一次编写能想周全的。ADR 0014 第 5 节要求「每个错误选项都是一种具体的
  错误理解」——真实习题的标准答案与常见错误，正是这份信息最可靠的来源。

### 3. 标准例题是渐隐完形缺掉的第一级

ADR 0014 第 2 节设计了五级渐隐：

| 阶段 | 给出 | 要求补 |
|---|---|---|
| **1** | **完整解答** | **读懂即可** |
| 2 | 除最后一步外全部 | 最后一步 |
| … | … | … |

**第 1 级此前没有任何内容字段承载。** 现有的 topic 结构是
`hook → overview → walkthrough → widget → predict → drills`，从讲解直接跳到
让使用者自己做选择题。中间缺的正是「先完整看一道做对的」——ADR 0014 明说这一跳
的挫折感是可以靠中间级消除的，而本应用把中间级整个跳过了。

使用者要的「章节配几道标准例题配合知识点讲解」，就是把这一级补上。

## 决策

### 1. 每道练习题与测验题必须标出处

课表的 drill item 增加 `source` 字段，**必填**：

```json
"source": {
  "kind": "adapted",
  "site": "MIT 18.06",
  "ref": "Strang《Introduction to Linear Algebra》2.1 Problem 29",
  "url": "https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/",
  "note": "原题用 0.8/0.2 的 Markov 矩阵，这里保留矩阵、改问法"
}
```

`kind` 三取一，含义与要求都不同：

| kind | 含义 | 要求 |
|---|---|---|
| `verbatim` | 照用原题（可翻译） | 必须给 `url` 或可查的教材位置；遵守来源许可，不整节搬运 |
| `adapted` | 改编：保留题目的数学内容与难度，改数字、改问法、改成选择题 | 必须给原题位置，`note` 写清改了什么 |
| `authored` | 本应用自造 | **必须填 `why`**，说明为什么没有现成的可用 |

### 2. 不得假冒有所本

**没有实地核对过的出处，比自造更糟。** 凭印象写「同济《线性代数》习题 1.3 第 5 题」
——数字对不上、题目根本不存在——会让使用者按图索骥扑空，并且从此不再相信任何一条
出处。宁可老实标 `authored`。

判据：`url` 必须是访问过的；`ref` 里的编号必须是在原文里看见的。

### 3. `authored` 是例外，不是默认

自造题的正当场合是**外部题库确实覆盖不到**的地方，主要是两类：

- 本应用特有的交互形态（看图说出面积变化、拖参数后预测读数）——没有纸面习题
  会这么问；
- 本应用特有的教学顺序（在还没讲计算方法时先问概念判断）。

第一类实际上多半属于 `predict` 实验而非练习题，见第 6 节的分工。

**配额**：同一节的练习题中，`authored` 不得超过半数。全应用的 `authored` 占比
计入 lint 的统计行，长期应当下降。

### 4. 每节配 1–3 道标准例题

课表 topic 增加 `examples` 字段：

```json
"examples": [{
  "id": "e1",
  "title": "从矩阵读出两根箭头",
  "source": { "kind": "adapted", "site": "…", "ref": "…", "url": "…" },
  "given": "题干（支持 `代码` 与 **重点** 标记）",
  "steps": [
    { "do": "这一步做什么", "why": "为什么可以这么做" }
  ],
  "answer": "结论",
  "note": "这道题值得看的地方在哪（选填）"
}]
```

约束：

- **例题是给人读的，不是让人做的**：它总是给出完整解答，不设作答控件，不计入
  掌握度。做题在它后面的 `drills` 里。
- `steps` 的 `why` 必填。只给「怎么算」不给「为什么可以这么算」，例题就退化成
  了答案，与 ADR 0001「工具当裁判不当计算器」的方向相反。
- **紧挨知识点讲解**：渲染位置在 `overview` 与 `drills` 之间，就是渐隐的第 1 级
  落在第 2 级之前。
- 数量与掌握目标匹配（主仓库 ADR 0040）：只要求 `understand` 的节配 1 道即可，
  `master` 的节 2–3 道。**不凑数**。

### 5. 习题来源（2026-09-14 实地核对）

与 ADR 0017 第 2 节的三阶段教材对应，但**讲解来源与习题来源不是同一份清单**
——这是本 ADR 新增的：

| 阶段 | 习题来源 | 核对情况 |
|---|---|---|
| `overview` / `full` | **MIT OCW 18.06 Problem Sets 及其解答** | 已核对。`ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/` 提供 pset 与 solutions；题目按 Strang《Introduction to Linear Algebra》的节号编排，解答完整。Problem Set 1 实际包含 Section 1.2 Problem 23/28、1.3 Problem 4/13、2.1 Problem 29/30、2.2 Problem 20/32、2.3 Problem 29、2.4 Problem 32/36、2.5 Problem 7 |
| `full` | 可汗学院中文版的练习项 | 站点为 SPA，抓取不到题面；**引用前必须逐题人工打开核对**，不得凭单元名推断 |
| `exam` | 同济教材课后习题、真题 | 受版权保护：**只标章节与题号坐标，按题型改编，不整段复制** |

MIT OCW 材料为 CC BY-NC-SA，本应用自用非商业且注明出处，符合其条件；即便如此，
按第 1 节仍以 `adapted`（中文改写）为主，不做整份搬运。

**已知缺口**：18.06 是美国课程体系，题型与数学二不完全对口（例如它重视
四个基本子空间与最小二乘，数学二不考；数学二考的行列式按行展开计算量它很少练）。
这类缺口用同济习题的改编补，不用自造补。

### 6. 与「先猜再验」的分工不变

`experiments` 里的 `predict` 题**不受本 ADR 约束**，仍可自由设计。理由是它的目的
不是检验而是制造好奇（ADR 0014 前言的分工），答错不计掌握度，也就不存在「检验器
失效」的问题。

界限：**任何判分并写进掌握度的题，都要有所本**；只用来引发预期、不判优劣的，
不要求。

### 7. 机械检查，存量记在 baseline 里

沿用 ADR 0014 第 5b 节的通则——「这类缺陷必须靠机械检查兜住，不能靠出题时自觉」。
`scripts/lint-content.mjs` 增加：

- 每道 drill item 缺 `source` 即报错；
- `kind: "authored"` 缺 `why` 即报错；
- 同一节 `authored` 过半即报错；
- `url` 形似但非 http(s) 即报错；
- 每节 `examples` 的 `steps[].why` 缺失即报错。

**存量 31 道题不可能一次补完**，因此 lint 内置一份 `LEGACY_UNSOURCED` 名单予以
豁免。规矩是：**这份名单只能变短，不能变长**——新增或改动一道题，就必须给它
出处，同时把它从名单里划掉。名单长度打印在 lint 的通过信息里，进度可见。

## 后果

- **ADR 0017 第 1 节的边界表修正**：「预测题与验证闭环」一行拆开——`predict`
  留在「可以自由发挥」栏，**练习题与测验题移到「必须依据来源」栏**。
- 写新一节的成本上升：`sources` 之外还要先找到能用的习题，**且不能先写后找**。
  这是本 ADR 的主要代价，与 ADR 0017 的代价同源，理由也同源。
- ADR 0014 第 6 节「题量不设配额」仍然有效，但现在**受来源可得性约束**：找不到
  合适出处时，宁可少出题，不自造凑数。
- SymPy 参数随机化出题（ADR 0014 后果一节）**需要重新定位**：它生成的变式必须
  挂在一道有出处的母题上，`source` 继承母题并标注「参数随机化自 X」。脱离母题
  凭空生成的题属于 `authored`。
- 前端多一个例题区块，侧边栏目录多一项。
- 界面上要显示题目出处并可点击——与 ADR 0017 第 3 节显示 `sources` 的做法一致，
  使用者能当场核对，也能顺着去原处多做几道。
