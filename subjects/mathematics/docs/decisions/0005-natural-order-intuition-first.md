# ADR 0005：按直观、直觉、自然的顺序讲数学；以及两条防线

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0002（思想与直观是主线）、0003（经世致用总纲）、0004（算法与技巧分界）
- 精神对齐：主仓库 ADR 0031（按知识类型选教学动作）、0040（不写八股）

## 背景

前四份 ADR 解决了**教什么**（思想、建模、算法而非技巧）和**为什么教**
（服务现实，考试只是约束）。本 ADR 解决**按什么顺序、以什么姿态教**。

使用者的要求是：用**更直观、更直觉、更自然**的角度学习数学，最大程度上认识
数学并服务于现实；不被象牙塔那类人束缚。

### 1. 「不自然」在数学教材里的四种典型倒置

象牙塔做派落到教学上，不是态度问题，是**顺序问题**。典型有四：

| 倒置 | 教材通常的样子 | 自然的样子 |
|---|---|---|
| **定义先行** | 先给突兀的定义，再证性质，最后（也许）举例 | 先有问题 → 尝试 → 碰壁 → 定义作为化解困难的产物出现 |
| **严格性倒置** | 按逻辑顺序：实数完备性 → 极限 → 连续 → 导数 | 按历史顺序：微积分先用了 150 年，ε-δ 才出现来收拾含混 |
| **符号先于图像** | 梯度＝偏导数组成的向量 | 梯度＝最陡上升方向，然后才是它的坐标写法 |
| **一般先于特例** | 先讲 n 维一般情形，再降到低维 | 先在 2D / 3D 看见，再推广 |

四种倒置都有同一个特征：**对写书的人是最优的（逻辑紧凑、无需重复），对学的人是
最差的（没有动机、看不见东西）。** 这正是「不服务于使用者」的具体形态。

### 2. 但「直观」有它自己的失败模式

直观教学如果只讲好懂的部分，会退化成**糊弄**——让人以为懂了，一碰反例就塌。
真正的直观教学必须包含「直觉在哪里会背叛你」。

### 3. 还有一条反向的风险

反对象牙塔不能反过来削弱应试能力。ADR 0003 把考试降为约束，是为了让它**不再
污染主线**，不是为了让它可以不满足。**约束仍然是硬的。**

## 决策

### 1. 动机先于定义（发生学顺序）

每个概念先呈现它要解决的问题，让使用者自己尝试并碰壁，定义作为化解困难的产物
登场。

**自然性检验**：读者读到定义时应当觉得「**只能这么定义**」，而不是「为什么要
这么定义」。后者说明动机没铺够，该节视为未完成。

例：ε-δ 不作为开场定义给出。先让人用「无限接近」做事，直到遇到一个它说不清的
情形（例如两个「无限小」相除该等于几），再把 ε-δ 作为**被迫的精确化**引入。
此时它不是折磨人的形式，而是一次「把话说清楚」。

### 2. 低维先于一般，具体先于抽象

能在 2D / 3D 看见的，先看见再推广。n 维的一般陈述放在直观建立之后。

例：二次型的主轴、特征向量、梯度、方向导数，一律先在平面或空间里画出来看，
再写一般式。

### 3. 图像与符号并置

每个核心概念必须同时给出**几何 / 物理图像**与**符号表达**，并说明两者如何对应。

**只有符号、没有图像的一律视为未完成**（对齐 ADR 0002 第 3 节：思想层要可交互，
不是写一段话说明它）。

| 概念 | 符号 | 必须同时给出的图像 |
|---|---|---|
| 梯度 | 偏导数向量 | 最陡上升方向；等高线的法向 |
| 特征值 | `det(A-λI)=0` 的根 | 变换下方向不变的那些方向，λ 是拉伸倍数 |
| 行列式 | 展开式 | 有向体积的伸缩比（ADR 0004 已定为重点） |
| 导数 | 差商的极限 | 放大后曲线变成直线；最佳线性逼近 |

### 4. 分阶段严格化——是顺序问题，不是有无问题

允许第一遍用直观说法把事情做对，在**需要精确的地方**（通常是遇到反例时）再引入
严格定义。

这**不是**放弃严格性。ADR 0003 第 4 节已定 ε-δ 是地基必须保留；本条只规定它
出场的**时机**，不改变它必须出场这一点。

### 5. 允许物理式、工程式的直观推导

把 `dx` 当作小量来操作、用无穷小做直观论证、用「流量」理解散度——这类推导在
严格数学的眼光下「不够体面」，但它有效、符合历史、且是工程实践中的实际用法。

**允许并鼓励使用，条件是标注它的适用边界与失效场合。** 因为「不够严谨」就禁用
这类推导，正是本 ADR 要摒弃的象牙塔做派。

### 6. 防线一：反例驱动，直观不得退化成错觉

每处建立直觉的地方，必须配一处**直觉会出错的地方**，用反例打破。

| 直觉 | 打破它的反例 |
|---|---|
| 连续的函数总该在大部分点可导 | 魏尔斯特拉斯函数：处处连续、处处不可导 |
| 加法有交换律，无穷和也一样 | 黎曼重排：条件收敛级数重排后可以收敛到任意数 |
| 偏导都存在就该可微 | 偏导存在但不可微的标准反例 |
| 概率直觉可靠 | 99% 准确的检验仍大量误诊（ADR 0003 已列为建模主题） |

没有反例的直观讲解视为未完成。**这是「直观」与「糊弄」的分界线。**

### 7. 防线二：理念不得成为削弱应试的借口

反象牙塔、重直观、讲建模，都**不得**导致考试要求的计算能力不达标。

- 应试区（ADR 0003 第 2 节、0004 第 2 节）的内容**必须真的练到熟**，不能因为
  它「无甚思想」就敷衍过去。它被隔离是为了不污染主线，不是为了可以少练。
- 定期以考试形式校验：若限时做题的正确率或速度不达标，**优先补应试区**，此时
  暂停主线扩展。
- 判据：软件做得再有思想，考不过就是彻底失败。这条与 ADR 0003 的目标函数不
  冲突——约束不满足，目标无从谈起。

## 后果

- 编写顺序与所有现成教材都不同（发生学顺序 + 低维先行），**内容不能靠改写教材**，
  这与 ADR 0004 的结论叠加，进一步抬高前期成本。
- 第 1 节的自然性检验、第 3 节的图像要求、第 6 节的反例要求，三者都是**否决式**
  判据：不满足即视为该节未完成。审稿时逐条过。
- 第 5 节允许不严格的推导，与第 6 节的反例要求是配套的：**越是使用直观推导，
  越要标清它什么时候失效**。两条不可只执行其一。
- 第 7 节意味着本应用需要一个**独立于学习进度的应试体检**机制，能在任何时点回答
  「现在去考，大致什么水平」。具体形态另行设计。
