# ADR 0009：每个知识点标注教材与考纲坐标

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0004（按统一视角组织）、0007（范围标记）、0008（拓扑序路径）

## 背景

ADR 0004 决定线代按线性变换主线组织、ADR 0008 决定路径按先修图拓扑序编排，
两者都**故意脱离了教材章节顺序**。

这带来一项真实代价，使用者已经指出：学的时候**不知道这属于哪一章**。后果具体有四：

1. 对不上教材——想查细节或看例题时找不到位置；
2. 对不上习题集与真题——做题时不知道这道题考的是哪一块；
3. 对不上他人——和同学、老师、网课交流时没有共同坐标；
4. 复习时无法定位——冲刺阶段按章回扫是通行做法，没有坐标就扫不了。

**组织顺序自由与章节归属清晰，两者不冲突。** 前者是教学设计，后者是导航标注。
本 ADR 补上后者。

## 决策

### 1. 每个知识点必须标注两个坐标

`content/curriculum.json` 的 topic 增加两个字段，**均为必填**：

| 字段 | 含义 | 取值来源 |
|---|---|---|
| `textbook_ref` | 标准教材位置 | 高数：同济《高等数学》；线代：同济《工程数学·线性代数》 |
| `syllabus_ref` | 考研大纲位置 | 数学二考试大纲的章节条目 |

选同济系列作为坐标系，因为它是考研最通行的教材，便于与习题集、网课、他人交流
对齐。**这是坐标系，不是内容来源**——内容仍按 ADR 0004、0005、0008 自行组织，
不得退化成改写教材（ADR 0004、0005、0006 的后果一节均已强调）。

### 2. 允许跨章标注，但必须列全

按 ADR 0004 重组后，部分知识点在教材里**没有对应的独立章节**。例如本应用的起点
「二维线性变换」，教材中并不存在这一节。

这类情况标注为跨章，并**必须列出它覆盖与预铺的具体章节**，不得含糊带过：

```json
"textbook_ref": {
  "kind": "cross_chapter",
  "note": "教材无此独立章节，是本应用按线性变换主线重组的导入",
  "covers":   ["线性代数 2.1 矩阵的概念", "线性代数 2.2 矩阵的运算"],
  "prepares": ["线性代数 1.x 行列式（面积伸缩比）",
               "线性代数 5.x 特征值与特征向量（方向不变的方向）",
               "线性代数 3.x 向量组的秩（压到几维）"]
}
```

`prepares` 字段同时承担教学功能：它就是「这一节在为后面哪几章铺路」的答案，
可直接呈现给使用者（呼应 ADR 0004 第 3 节的审查判据）。

### 3. 界面必须显示坐标，并支持按教材章节反查

- 每个知识点页显著位置显示它的教材与大纲坐标；跨章的显示 `covers` / `prepares`。
- 提供**按教材章节反查**的入口：给定「线性代数第五章」，列出本应用中涉及它的所有
  知识点。冲刺期按章回扫依赖此功能。
- 这是导航信息，不是学习内容，**不占用讲解正文篇幅**。

### 4. 坐标不改变组织顺序

本 ADR 只增加标注，**不推翻** ADR 0004 第 3 节（按线性变换组织）与 ADR 0008
第 1 节（拓扑序路径）。出现「教材顺序与拓扑序冲突」时，以拓扑序为准，由坐标标注
负责让使用者不迷路。

## 后果

- 课表 schema 增加两个必填字段；跨章标注是结构化对象而非字符串，校验需相应处理。
- 编写每个知识点时都要查一次教材定位，增加机械工作量，但这项工作**不可省略**——
  省了就回到使用者指出的问题。
- 教材版本会变（同济高数第七版与第八版章节号有出入）。坐标中**注明版本**，并与
  ADR 0007 的考纲范围表一起每年核对。
- 反查功能要求课表加载后建立章节到知识点的反向索引，属于前端的一次性构建。
