# ADR 0017：每个阶段锚定一份真实教材；严格表述必须可核对

- 日期：2026-09-13
- 状态：已接受
- 修正：ADR 0012 第 4 节（教材的角色）、ADR 0004/0005/0008 中「自行组织」的范围
- 依赖：ADR 0009（教材坐标）、0015（起点假设）

## 背景

使用者指出：**目前的方式自由发挥太多**。他要求严格按已推荐的教材或学习网站规划
讲解过程，先从薄的讲、分阶段学；**建立基础概念时可以自由发挥，但知识的严格表述
要参考依赖现有互联网教材**。

这条批评成立，问题在于：本应用已写的 16 节 `overview` **没有可核对的出处**。
ADR 0009 的教材坐标只回答「这属于哪一章」，不回答「这一节的严格表述在哪里能查到」。
后果是——使用者既无法验证内容对不对、有没有漏，也无法在别处找到对应内容深入。

自学者需要能核对。这是本 ADR 要补上的。

## 决策

### 1. 自由发挥的边界

| 可以自由发挥 | 必须依据来源 |
|---|---|
| 直觉引入、比喻、图示 | **定义**的准确陈述 |
| 预测题与验证闭环 | **定理与性质**的条件和结论 |
| 把概念串成一条主线的方式 | **计算方法**的步骤与适用范围 |
| 现实问题的选取（建模线） | 术语的标准叫法 |

判据：**凡是「这东西是什么、什么时候成立」的陈述，都要能指到一个具体的外部出处；
凡是「怎么想到它、为什么长这样、在图上什么样」，由本应用自己负责。**

### 2. 三个阶段各锚定一份主教材

对应 ADR 0012 的三层深度，界面上用「基础 / 强化 / 冲刺」表达（AGENTS.md）：

| 阶段 | 层 | 主教材 | 为什么是它 |
|---|---|---|---|
| **初级** | `overview` | **3Blue1Brown《线性代数的本质》**，16 课 | 最薄的完整概览；它的主线就是本应用 ADR 0004 采用的线性变换视角 |
| **中级** | `full` | **可汗学院中文版·线性代数**，3 个单元 | 中文、免费、分块极细，定义与计算齐全 |
| **高级** | `exam` | 真题 + 辅导讲义 | 只在应试区使用（ADR 0003 第 2 节） |

**已核实的结构**（2026-09 实地访问，非凭记忆）：

- 3Blue1Brown：`3blue1brown.com/topics/linear-algebra`，16 课，slug 依次为
  `vectors` / `span` / `linear-transformations` / `matrix-multiplication` /
  `3d-transformations` / `determinant` / `inverse-matrices` / `nonsquare-matrices` /
  `dot-products` / `cross-products` / `cross-products-extended` / `cramers-rule` /
  `change-of-basis` / `eigenvalues` / `quick-eigen` / `abstract-vector-spaces`。
- 可汗学院中文版：`zh.khanacademy.org/math/linear-algebra`，三个单元
  `vectors-and-spaces` / `matrix-transformations` / `alternate-bases`。
- **Paul's Online Notes 没有线性代数**（只有 Algebra、Calculus I–III、
  微分方程）。此前把它列为参考时指的是 Algebra/Trig 复习部分，用于前置补齐
  （ADR 0015），线代不适用。`docs/REFERENCES.md` 已据此更正。

### 3. 每节必须标出处

课表 topic 增加 `sources` 字段，**必填**，指向可核对的具体位置：

```json
"sources": {
  "intuition": { "site": "3Blue1Brown", "slug": "determinant",
                 "title": "The determinant" },
  "rigorous":  { "site": "可汗学院", "path": "matrix-transformations",
                 "note": "行列式的定义与性质" },
  "textbook":  "线性代数 1.1–1.6"
}
```

界面在每节显著位置显示这三条，**可点击直达**。这一节说的任何定义或性质，
使用者都能立刻去核对。

### 4. 缺口如实记录，不含糊带过

实地核对发现**两个在线来源都不覆盖**的内容：

| 内容 | 3b1b | 可汗中文 | 处置 |
|---|---|---|---|
| 实对称矩阵的对角化 | 无 | 无 | 只能依同济《工程数学·线性代数》5.5；标 `textbook_only` |
| 二次型与标准形 | 无 | 无 | 同上，同济 5.6–5.7 |
| 正定二次型 | 无 | 无 | 同上，同济 5.8 |

这三节在界面上要**明确标注「在线来源没有覆盖，严格表述以教材为准」**，
不能让使用者以为跟着视频就能学完。

### 5. 对照出的缺漏：本应用漏写的内容

同一次核对暴露了本应用 16 节的遗漏——这正是锚定教材的价值：

| 3b1b 有、数学二也考、本应用缺 | 说明 |
|---|---|
| **点积 / 向量内积** | 数学二考纲内；`orthogonal` 一节用到投影却没先讲内积 |
| **克拉默法则** | 数学二考纲内；`inverse` 一节的教材坐标写了 2.4 却没有对应内容 |
| 三维线性变换 | 二维讲完后需要一节过渡到 n 维 |

（叉积、抽象向量空间属数学二不考，不补。）

### 6. 顺序改为跟随主教材

本应用现有顺序为自行编排（从线性变换起步）。3Blue1Brown 的顺序是
**向量 → 线性组合与张成 → 线性变换 → 矩阵乘法 → …**，张成在线性变换之前。

**改为跟随 3b1b 的顺序**，以减少自行编排。ADR 0008 的拓扑序约束仍然有效——
3b1b 的顺序本身满足先修关系，两者不冲突；拓扑序保证「不出现先用后教」，
主教材顺序在此之上决定具体走法。

## 后果

- ADR 0012 第 4 节「教材只作范围参照与进度锚，不回答怎么讲」**部分作废**：
  教材不回答「直觉怎么建立」，但**回答「严格表述是什么」**。
- ADR 0004、0005、0008 中「内容不能靠改写教材」的结论**范围收窄**：它针对的是
  直觉层与组织方式，不针对定义与定理的陈述——后者本就应当依据权威来源。
- 已写的 16 节需要补 `sources`、按第 6 节重排、并补第 5 节列出的三块缺漏。
- `sources` 必填意味着新增内容前要先去核对来源是否存在，**不能先写后找**。
- 第 4 节的三节没有在线来源，是本应用相对使用者预期的一处真实短板，
  应在界面上说明而不是掩盖。
