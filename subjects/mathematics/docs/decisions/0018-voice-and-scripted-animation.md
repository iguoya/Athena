# ADR 0018：概念节可用语音讲解与脚本动画；二者跟课表走

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0010（视觉手段分工）、0012（overview 求薄）、0015（起点假设）

## 背景

第一章「矩阵就是把平面搬一次」把线性变换、矩阵两列、面积倍数、压维、
不变方向一次摊开。对只假设「会四则、看得懂坐标点」的读者，这不是薄概览，
是四节课叠在一屏。交互画布虽然在，但没有「先看一遍再动手」——读者不知道
该看哪根箭头。

ADR 0010 把「过程演进」留给静态分步图或预渲染动画，把「操控参数」留给
自绘组件。缺的是中间档：**同一张画布按脚本自动演一遍，同时把人话念出来**。
这不是 Manim 视频（不能停在任意参数上继续拖），也不是自由拖拽（没有叙事）。

## 决策

1. **课表可带 `walkthrough`**：一组 `{ say, m }`。`say` 是给语音和字幕用的
   人话，`m` 是 2×2 矩阵关键帧。没有 widget 的节不要硬加。
2. **语音用系统 `speechSynthesis`，不另打包模型。** 离线、无账号、可随时停。
   念的是课表里的 `say`，不另写一份讲稿。
3. **动画是画布插值到下一帧，不是另开视频。** 演完必须能立刻用手拖——脚本
   只是示范，不取代实验。
4. **overview 第一屏只讲这一节必须带走的一件事。** 后面章节的名词（行列式、
   秩、特征向量）可以在「以后会回来」里点名，不得当作本章已经讲过的读数标签。
   第一章读数默认只显示两根箭头的去向。
5. **不自动播放。** 按钮写「先看一遍」；读者可以跳过。禁止做成必看片头。

## 后果

- 第一章先建立「两列 = 两根箭头」，再让后面各节回这张图追问。
- 其他概念节若同样「一上来不知道看哪」，按同一字段加脚本，不必改页面骨架。
- 系统语音的音色一般，但这是讲解通道，不是作品。以后要换本地 TTS，只换
  播放器，不改课表。
