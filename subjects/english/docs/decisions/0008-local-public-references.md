# ADR 0008：有用的公开参考材料落到本地

- 日期：2026-09-14
- 状态：已接受
- 依赖：ADR 0007

## 背景

ADR 0007 要求每个题库能指到来源，但实现上只登记了外链：AWL 写着「不在仓库
复制该词表」，NGSL 只保存了当时用到的 32 个词。写题时每次都要上网，选词也
无法用全表校验。作者随后明确：这是个人练习应用，不考虑商业化版权策略；
大纲词表虽然是版权材料，只要互联网公开能查到、写题用得上，本地保存成本
不大，就放到项目里实时参考。

## 决策

1. **公开能查到、写题用得上的参考材料落在 `content/sources/reference/`。**
   词表、公开考试说明、公有领域课文、写作功能分类都算。练习正文必须引用或透明
   改写其中的具体材料，参考目录不能只充当事后贴上的泛化标签。
2. **不以「会不会商业化」决定保不保存。** 个人练习需要离线对照的，就保存。
3. **英语二大纲附录词形。** 研招网公开页只有试卷结构和部分固定词组，没有
   完整 5500 词电子表。公开页上的结构和词组立刻落盘；完整附录留给
   `exam-outline-lemmas.txt`，作者从手头的大纲粘贴后即进入校验覆盖范围。
4. **教辅摘录可以进作者侧参考目录；整本不塞进练习 JSON。** 词表、搭配、长难句笔记
   放到 `textbooks/`，但“GitHub 仓库公开”不等于获得内容许可，也不能成为学习者界面
   中的正式教材授权声明。进入练习库的条目必须绑定可核对的具体原文或习题；正式来源
   优先使用授权清楚、可稳定访问的材料（ADR 0009）。
5. **校验走全表。** 单词题的 lemma 必须能在本地 NGSL、NAWL、AWL 或已粘贴的
   大纲附录里对上号，不再用 32 词子集冒充「高频」。

## 后果

- `catalog.json` 继续登记来源；`local_path` 指向本仓库里的对照文件。
- 写题时先打开 `content/sources/reference/README.md`；GitHub 词库/句库原件放
  `github/`，教辅摘录放 `textbooks/`。大纲附录词形已用 NETEM 灌进
  `exam-outline-lemmas.txt`。
- ADR 0007 第 4 条仍然成立：题库要有 `source_refs`。本 ADR 只补「参考材料
  本身也要能离线打开」。综合取材与成果可视化见 ADR 0009。
