# ADR 0011：界面可以直接写考试字样

- 日期：2026-09-26
- 状态：已接受
- 修订：ADR 0007「后果」一节「界面使用『英语学习』，不出现『考研』字样」
- 依赖：ADR 0004 第 5 条（实用主线和考试终点同时可见）

## 背景

ADR 0007 的后果里有一句「界面不出现『考研』字样」。之后 ADR 0004 第 5 条已经让考试终点
在界面上如实可见，`AGENTS.md` 也写明「不再把考试目标藏到用户看不见的文档里」，界面上
实际已经在写「英语二」（例如练习页的「高级那条线是给英语二任务用的」）。那句禁令只剩
「考研」两个字还在回避，没有检查器执行，却让写文案的人要记住一条例外。

`subjects/mathematics` 在同一天取消了同样的约束（该应用 ADR 0027），原先那条正是「沿用
`subjects/english` 的做法」。

## 决策

1. 取消「界面不出现『考研』字样」。考试目标（考研英语二）在界面上需要时直接写，不必回避。
2. 保留 ADR 0004 第 5 条的语气要求：应用叫「英语学习」，用「初级 / 中级 / 高级」表达
   进阶，初中级不用冲刺班口吻。它管的是语气，不是字样。

## 后果

- `AGENTS.md`「定位」一节写明考试字样可以直接用。
- ADR 0007 原文不改，索引状态栏注明该句由本 ADR 修订。
