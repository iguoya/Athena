# ADR 0007：内容须有出处；听说读写都进训练，不改考试目标

- 日期：2026-09-14
- 状态：已接受
- 依赖：ADR 0001、0003、0006
- 部分作废：ADR 0001 第 6 条「不做听力、口语」

## 背景

第一期为了对齐英语二「不考听说」，把听力和口语整条关掉。桌面已经具备系统
朗读和麦克风，作者随后要求两件事：

1. 单词、句子、短文必须能追溯到现实中的词表、公开教学材料或官方考试说明，
   不能只是「看起来像教材」的自编。
2. 只要有助于学习，听说读写都可以用上；以前不做听说，是没有条件，不是听说
   无用。

英语二仍然不考听力口语。训练能力和试卷范围不是一回事。

## 决策

1. **考试目标不变。** 过线对象仍是考研英语二。不加听力卷、口语面试或社交打卡。
2. **训练能力补全听说读写。**
   - 读：句子、短文、词在语境里（已有）。
   - 写：仿写、段落、任务回应（已有；开放写作不冒充语义评分）。
   - 听：系统英文朗读；有授权的原声/视频才嵌入播放器。
   - 说：跟读录音、当页回听；不上传、不落库、不把音量或时长当发音分数。
3. **内容必须能指到来源。** 每个练习和考核条目自身都要有 `source_refs`，不能只在
   整套题库上挂一个泛化词表或能力框架。关系只能是：
   - `selection_basis`：频率表或能力框架决定「先学什么」；
   - `quoted`：可核对的原文节选；
   - `adapted`：据原文改写，须写清改了什么；
   - `exam_alignment`：对齐考试任务类型，不复制真题正文。
   题目可以把已引用材料转成判断、翻译或选择活动，但必须从具体原句、篇目或现实教材
   习题出发；自编只用于解释、受控变式和干扰项，不能凭空创造例句、短文和考核情境。
4. **来源集中登记，条目精确定位。** `content/sources/catalog.json` 是唯一来源表；
   条目可用 `locator` / `locator_url` 定位到句号、篇名、页码或习题页。界面展示
   原教材、发布者、授权、定位和关系；点开外链核对。校验器拒绝未知 `source_id`、
   空的条目级 `source_refs`、只有 `selection_basis` / `exam_alignment` 却没有具体材料，
   以及没有来源的媒体。
5. **原声不是系统朗读的替代。** 没有稳定授权文件就不嵌播放器，只保留来源链接
   和 TTS。
6. **三条内容主线不变，四种学习动作贯穿。** `Track.skills` 明示每条轨实际提供的
   `listen / speak / read / write`；每个阶段的三条轨合起来必须覆盖四种动作。阶段
   资格仍按单词、例句和作文三项分别判定，不另造与英语二无关的听力卷和口语面试。
7. **录音隐私优先。** 跟读录音只保存在当前 WebView 的临时 Blob 中，换题或返回路线
   即销毁，不上传、不写 SQLite。首期不做自动语音识别和发音评分。
8. **视频必须承担教学动作。** 只有能提供真实场景、口型、语调或字幕对照，且来源授权
   清楚时才显示；默认不自动播放，远程媒体失效时文字和系统朗读仍可完成核心练习。

## 后果

- ADR 0001 第 6 条改为：不做社交打卡和账号云同步；听说作为训练通道，见本文。
- 界面使用「英语学习」，不出现「考研」字样；听说按钮写「朗读 / 跟读」，不写
  听力考试。
- 词表优先级继续参考 NGSL / NAWL / AWL，全表落在 `content/sources/reference/`
  （ADR 0008）；语境优先用可核查的公开教学材料（如 VOA Learning English）；
  高级阶段用英语二公开大纲对齐任务，不搬真题阅读篇。
- macOS 包通过 `Info.plist` 说明麦克风用途，首次录音由系统向用户请求权限。
