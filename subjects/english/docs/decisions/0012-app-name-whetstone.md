# ADR 0012：界面名改为「磨砚」· Whetstone

- 日期：2026-10-01
- 状态：已接受
- 修订：ADR 0007「后果」一节与 ADR 0011 第 2 条里写的界面名「英语学习」
- 依赖：ADR 0004 第 5 条（实用主线和考试终点同时可见）

## 背景

「英语学习」太笼统，分不清它和同仓库里另一个英语应用（`subjects/ascent`，「拾阶」，面向
英语师范生的四六级、专四专八）。使用者要求两个应用各取一个贴合自己目标的名字：
**表层目标性弱，内在目标清楚**。

## 决策

1. 界面名「磨砚」，英文名 Whetstone。「砚」与「研」音近，磨砚、磨刀石都是长期打磨，
   表面不露考试，内里指向考研；与 ADR 0011 一致，名字隐晦，**路线终点和高级阶段仍必须如实
   写明衔接英语二**。
2. **只改显示名**：`app.json` 的 `title`、窗口标题、`index.html`、应用信息里的标题。目录
   `subjects/english`、进程名 `athena-english`、知识点前缀 `en.`、`identifier`、
   `productName` 都不动（已写进进度库的前缀不改）。
3. 旧决策里的「英语学习」按本条理解为「磨砚」，不回头改写（只增不改）。

## 与 subjects/ascent 的关系

两个英语应用各自演进，不互相对齐、不趋同（Athena ADR 0066）。对方的做法只是参考素材。
