# Athena English — 项目协作规则

本文档是 **`subjects/english` 独立应用** 的项目级指令。本应用与 C++ 教程
（`subjects/cpp`，GTK / Meson / `resources/athena.json`）**平级、可脱离**：不读它的配置、
不链接它的代码、不依赖它的进程即可完成开发、构建与练习全流程。

仓库根 `AGENTS.md` 写各应用共同遵守的规则；**改本应用时以本文为准**。启动器通过
`app.json` 把本应用当独立进程拉起（主仓库 ADR 0032），那不是运行本应用的前提。

## 定位

- 目标：通过**考研英语二**。主练**句子**和**短文**，并强化英语二词表范围内的
  词在语境中的认识（ADR 0001）。
- 首页使用「英语学习」而不是冲刺班口吻，用「初级 / 中级 / 高级」表达进阶；但
  **路线终点和高级阶段必须如实标出衔接英语二**，让实用基础知道最终服务于什么，
  不再把考试目标藏到用户看不见的文档里。
- 做题只在桌面进行；手机 / 公众号只看，不判分（ADR 0002）。
- 不以整卷模考或专业英语为目标。听说读写都用于训练（ADR 0007）；英语二不考
  听说，所以不做听力卷或口语面试。

## 技术栈（本应用自有）

- **壳**：Tauri 2（Rust）
- **界面**：Vite + TypeScript（Web UI，非 GTK，非 Flutter）
- **内容**：`content/curriculum.json` + 分级练习目录 + `content/assessments/`
- **进度**：SQLite，写入 `progress/learning.db`——**随仓库走**，换机器 clone
  下来连续天数和徽章还在（主仓库 ADR 0053）；发行副本退回用户数据目录
  `AthenaEnglish/`。自建表、自迁移（主仓库 ADR 0037）。`--store` 仅为兼容而接受并忽略。
  知识点 ID 前缀一律 `en.`。

不引入 `subjects/cpp` 的 Meson、gtkmm、Blueprint、`athena.json`。

## 目录与所有权

| 路径 | 职责 |
|---|---|
| `content/` | 课表、词表、句子、短文；**唯一内容源** |
| `src/` | 前端：能力路线 / 练习台 / 错题本（ADR 0005） |
| `src-tauri/` | 窗口、读内容、进度与复习 |
| `app.json` | 声明怎么构建、怎么启动、怎么算就绪；由 `launcher` 执行（ADR 0046） |
| `tools/publish/` | 日后把讲解导出为公众号草稿；本期可空 |
| `docs/decisions/` | 本应用 ADR |
| `AGENTS.md` | 本文 |

## 内容与教学分层

精神对齐「大纲 → 讲解 → 练习」，载体与 C++ 教程无关。课表唯一源是
`content/curriculum.json`。

- 词必须带义项和例句，禁止「单词 = 一个中文」。练习时先给语境、再提取本句义项，
  **不要把词形当题干标题与中文选项同时摊开**；答对后再出示词形和义项，并用新句
  挖空提取词形。干扰项用近义或本句也可能说得通的误读，不用离题很远的无关词。
- 句子练习问切分、指代或句意，不考语法名称本身。
- 短文用 Markdown 正文 + JSON 题目，挂在需要成篇语境的轨上（`track.passage`），
  篇幅短于真题阅读篇。
- 作文只机检字数下限和 `required_any` 里的连接方式；组织和用词由作者对照
  `reference` 与 `checklist` 自己看，不进掌握度（ADR 0004）。
- 掌握度只由做题结果写入，禁止手动标记熟练。
- 编写时优先对照和例句，不堆长文（ADR 0003）。
- 练习内容按 `content/<类型>/<beginner|intermediate|advanced>/` 分层；独立考核只放
  `content/assessments/<等级>/`，不得把练习原题复制过去（ADR 0006）。
- 选材先覆盖生活、学习、工作中的高频通用英语，再逐步进入抽象论证、长句、英译汉
  和英语二任务。每个练习与考核条目自身必须带 `source_refs`，定位到
  `content/sources/catalog.json` 里的具体例句、篇目或现实教材习题（ADR 0007）；
  只在整套题库挂词表或官方考试说明不算有所本。写题时对照的词表、
  公开大纲和公有领域课文放在 `content/sources/reference/`，离线打开（ADR 0008）。
  自编只用于解释、受控变式和干扰项，不得凭空创造例句、短文与考核情境。有引用价值的原件放
  `content/sources/reference/github/`；教辅摘录、笔记可进
  `content/sources/reference/textbooks/`。写题时多家综合权衡，不要求一家正确
  （ADR 0009）。练习 JSON 负责把有出处的材料转成学习动作，避免把课表变成书库。
- 首页要能看见学习成果：连续天数、稳住的条目、通过的考核和徽章。激励是本机
  统计，不是社交打卡（本应用 ADR 0009；仓库 ADR 0052：激励与统计同一条回路）。
- 听说读写是贯穿三条内容主线的学习动作：原声/系统朗读负责听，跟读录音回听负责说，
  可见原文和题目负责读，仿写/翻译/作文负责写。录音默认只在本次页面内存在，不上传，
  也不以音量、时长冒充发音分数。

当前主线是三个等级，每级同练三条轨（ADR 0004）：

| 等级 | 单词 | 例句 | 作文 |
|---|---|---|---|
| 初级 | 高频词义与搭配 | 主干、因果、转折、指代 | 仿写与扩写成段 |
| 中级 | 一词多义与抽象搭配 | 一到两层从句、让步 | 观点 + 理由 + 收束 |
| 高级 | 熟词生义与立场词 | 短文里恢复主干与态度 | 限时完成任务回应 |

## 架构原则

- **独立可运行**：`launcher open english`（编排器执行 `tauri:dev`）不经过任何别的应用。不要启动打包 `.app`。
- **内容驱动 UI**：改课优先改 `content/`，不为新节复制整页。
- **壳要薄**：Rust 侧负责路径、进度；业务文案与课树不进 Rust。
- **与 C++ 教程零编译耦合**：`subjects/cpp` 的 Meson / `scripts/check.py` 不构建本应用。

## 开发与验证

```sh
cd subjects/english
launcher open english       # 日常开发（热更新）；启动器和图谱走的也是这条
```

`npm run build:app` 只在真正要交付一份可分发的包时才跑，**不是**打开本应用的步骤，
也不要把产物装进 `/Applications`。

环境变量 `ATHENA_ENGLISH_ROOT` 可强制指定应用根目录（含 `content/`）。

验证以本目录为准：前端 `npm run build`、Rust `cargo check`（在 `src-tauri`）。
**不必**为改本应用而跑主仓库 `scripts/check.py`，除非同时改了 `subjects/cpp` 的 discover。

## 修改流程

1. 改课：先改 `content/`，再补前端展示类型（若有新练习形态）。
2. 改运行时：只动 `src-tauri`，保持命令表面稳定。
3. 改 UI：只动 `src/` + `index.html`。
4. 学科地图在北极星（`subjects/polaris`），不在 C++ 教程里再挂入口。
