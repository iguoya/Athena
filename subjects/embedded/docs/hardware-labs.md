# 真硬件实验包（现有硬件，零采购）

> 硬件为 tiger 现有设备（2026-10-10 盘点）。按 LEARNING-METHODS 路径 A（真硬件
> 实验）组织，每课固定节奏：**先写预期 → 接线/编码 → 上板运行 → 观察记录 →
> 对照修正**。对齐《嵌入式系统设计师教程（第 2 版）》第 2 章（硬件基础）与
> 第 4 章（系统软件/RTOS）。

|---|---|---|

## 主线一：F103ZET6 实验递进（第 2、4 章考点全覆盖）

1. **寄存器级点灯** → 库函数点灯：同一盏灯两遍，理解「库函数之下是寄存器」。
2. **按键 + 中断**：EXTI 外部中断 + NVIC 抢占优先级（考纲「中断与异常」）。
3. **定时器**：TIM 定时中断 → PWM 呼吸灯（定时器/计数器考点）。
4. **串口**：USART 发送与接收；串口助手抓字节，起始位/数据位/停止位与波特率
   一一对上（第 2 章总线通信考点，P1：先写预期字节再看实际帧）。
5. **DMA + ADC**：采板载电位器/传感器，DMA 搬运免 CPU。
6. **总线读写**：板载 AT24C02（I²C）与 SPI Flash 读写，逻辑分析仪看时序
   （逻辑分析仪约 ¥30–50，可选；没有就用示波功能或先跳过）。
7. **FreeRTOS**：多任务点灯 → 信号量 → 队列 → **优先级反转与继承**实验
   （第 4 章任务管理考点；优先级反转是嵌入式面试与考纲的双料重点）。

## 第二线：Mini2440（ARM9 体系结构与系统级）

1. 裸机：启动代码、时钟 MPLL 初始化、看门狗——不开任何库，直接摸 S3C2440 寄存器。
2. **Nor/NAND 双启动对照**：同一程序两种启动方式，理解教材「存储系统」的差异。
3. U-Boot：使用、环境变量、裁剪编译（第 5 章 bootloader 考点）。
4. 嵌入式 Linux：内核裁剪 + 根文件系统（buildroot），跑一个自写应用。

## 第三线：树莓派 4B（网络与通信，第 6 章）

1. socket 编程：TCP/UDP 收发（真网络，不是本机回环）。
2. MQTT：发布/订阅，与 nas-admin 或另一台设备联动。
3. Linux 应用与系统服务：systemd 服务、GPIO 基础（libgpiod）。

## 扩展线：龙芯 2K1000（非考纲）

LoongArch 交叉编译工具链、PMON 固件、LoongArch Linux 启动——国产平台视野，
考试主线之外，全部主线完成后再上。

## 已确认（2026-10-10 tiger 盘点）

## 模块驱动实验清单（创乐博套件，标配模块）

每个模块 = 一个「看模块手册 → 写驱动 → 读真数据」的完整循环，正好各踩一个
总线/外设考点：

| 模块（标配） | 总线/外设 | 教材考点 |
|---|---|---|
| DHT11 温湿度 | 单总线 | 单总线时序（µs 级握手，最考细心） |
| AT24C02 EEPROM | I²C | I²C 起停/应答/地址（与主线 6 合并） |
| 光敏/电位器模块 | ADC | 模拟量采样与量化 |
| HC-SR04 超声波 | 定时器捕获 | 脉冲宽度测量（回波时间换算距离） |
| 红外接收头 + 遥控 | 外部中断 + 解码 | 中断驱动与协议解码 |
| 数码管 / LED 流水灯 | GPIO | 动态扫描与推挽输出 |
| 步进电机 / 舵机 | PWM | 脉宽控制（与主线 3 呼吸灯合并） |

以实际开箱清单为准；有缺的模块就跳过对应行，不影响主线。
