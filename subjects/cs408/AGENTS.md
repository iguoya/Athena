# Athena 408 计算机学科专业基础 — 项目协作规则

本文档是 **`subjects/cs408` 独立应用** 的项目级指令。仓库根 `AGENTS.md` 写各应用共同遵守
的规则；**改本应用时以本文为准**。

## 定位

- **考试主应用**（主仓库 ADR 0116、0118、0119）：考研 408 计算机学科专业基础综合。本应用只管考试本身——
  考试结构与分值、分科真题、组卷与整卷模拟。**各科的讲解与实验不在这里写**，它们在课程应用里：

  | 科目 | 课程应用 | 与本应用的关系 |
  |---|---|---|
  | 数据结构 | 数据结构（data-structures） | 主挂靠（本体在本应用下）；软设以课程树文字指引承接第 3 章 |
  | 算法设计大题（第 41、42 题） | 算法设计（algorithms） | 主挂靠（本体在本应用下）；软设以课程树文字指引承接第 8 章 |
  | 计算机组成原理 | 计算机组成原理（organization） | 主挂靠（本体在本应用下）；软设以课程树文字指引承接第 1 章 |
  | 操作系统 | 操作系统（os） | 主挂靠（本体在本应用下）；软设以课程树文字指引承接第 4 章 |
  | 计算机网络 | 计算机网络（network） | 主挂靠（本体在本应用下）；软设以课程树文字指引承接第 10 章 |

  课程树里用文字指引去对应应用学习，不引用对方的路径或代码（ADR 0032）。
- 启动器「考研」圈的首个成员。目标考试是 22408（ADR 0116 决策 5）：英语二在 english、数学二
  在 mathematics，政治的应用以后建在同一圈。
- **出处档位 exam**（ADR 0043、0089）：408 对应一张真实的全国统考试卷，判分内容（真题、
  组卷题目）必须有出处，违规阻断；考试结构与分值等硬事实写进内容时注明出自哪一年的考试
  大纲。AI 现场出题不计入掌握度。
- **学习方法原型（ADR 0113）**：主原型**检索强化**，辅**辨析决策**。首页优先到期复习与
  分科真题；真题按考点跨科交错组卷；整卷模拟限时、交卷才评分，与练习模式在界面上可见地
  区分。辨析题（如「这道题考的是哪种调度 / 哪种 Cache 映射」）同卷混出。

## 技术栈（本应用自有）

- **壳**：Tauri 2（Rust），界面 Vite + TypeScript。壳最初复制自 organization 应用，此后独立
  演进；真题判分与组卷逻辑落地时按考试需要改造，不跟随对方。
- **内容**：`content/curriculum.json`（本目录唯一课表）。
- **进度**：SQLite，写入本应用自己的 `progress/learning.db`（主仓库 ADR 0053；发行副本退回
  用户数据目录 `AthenaCs408/`），知识点 ID 前缀 `cs408.`。
- 端口 1503，进程 `athena-cs408`。

## 开发与验证

```sh
launcher open cs408
python3 scripts/check.py cs408
```

环境变量 `ATHENA_CS408_ROOT` 可强制指定应用根目录（含 `content/`）。
