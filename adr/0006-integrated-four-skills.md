# 0006 听说读写结合，每天一篇短文

- 状态：已采纳
- 日期：2026-09-30
- 决策人：tiger

## 背景

tiger 认为听说读写结合起来，把单词、句子、短文连在一起学，才能更健康地学好英语。

## 决策

每天的学习单元是一篇短文（第一版取自四级真题），按四步走完，四步用的是同一批句子和生词：

1. **听**：先听全文一遍，再逐句复听。
2. **读**：逐句精读，点词收入生词本。
3. **说**：跟读重点句，录音后和原声对比。
4. **写**：用当天的生词和句式仿写三句话，交给 AI 批改。

生词复习、错题和每周一次的限时重读旧文是配套。

## 后果

- 同一个词一天里会被听到、读到、说出来、写出来各一次。
- 需要短文配音频和逐句时间戳。
