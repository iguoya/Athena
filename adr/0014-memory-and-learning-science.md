# 0014 系统融入记忆理论和高效学习方法

- 状态：已采纳（补充 ADR 0008）
- 日期：2026-09-30
- 决策人：tiger

## 背景

tiger 要求把前人总结的优秀记忆理论、高效的英语学习思想融入软件设计；他也说自己认知有限，如果有更好的理论和方法，也可以融进来。ADR 0008 已列出第一批方法。这条 ADR 补上证据最强的几项，并规定以后怎么吸收新方法。

## 决策

### 选方法的标准

1. 优先采用有大量实验或综述支持的方法。Dunlosky 等（2013）评估了十种常见学习技巧，只有"自我测试"和"分散练习"被评为高效用，这两项是本软件的地基。
2. 每个方法都必须落到一个具体功能上，写不出功能的不采用。
3. 不能违背已有原则：单词不离句子（0005）、只用真实句子、读写听说的顺序（0006）、先建立自信（0013）。

### 补充的方法

| 方法 | 在软件里怎么用 |
| --- | --- |
| 自我测试 / 提取练习（Dunlosky 2013 高效用） | 所有复习都是先回想再看答案：真实句子挖空、听句子写出来、看中文写英文句子 |
| 分散练习（Dunlosky 2013 高效用） | FSRS 排复习；同一个词或句式分几天出现，不在一天里反复刷 |
| 连续再学习（Rawson & Dunlosky, 2011） | 一个词或句式要在不同日子里连续答对几次才算"掌握"，只答对一次不算 |
| 交错练习（Rohrer） | 复习时混排不同语法点和场景的句子，不按单元一块一块做 |
| 必要难度（Bjork） | 复习故意换一个没见过的真实句子，让回想稍微费点力；但难度不能高到让她受挫（见 0013） |
| 预测试效应（Kornell 等, 2009） | 学新句子组前先让她猜一两个词的意思，猜错不扣分 |
| 精细加工 / 自我解释 | 写作题让她把新句式用在自己的宿舍、课堂、家乡生活里 |
| 句子挖矿 i+1（来自 AJATT / Refold 学习者社区） | 优先选"只有一个新东西"的句子：一个生词，或一个新句式，其余都已掌握 |
| 精读加泛读（Day & Bamford 泛读研究） | 句子阶段以精读为主；到短文阶段加入她读得懂的轻松泛读，只计数量不做题 |
| 听写（Dictation） | 听的一步加入逐句听写，同时练听力、拼写和语法；专四有听写题 |
| 刻意练习（Ericsson） | 系统记录她反复出错的句式和词，把薄弱点单独安排进下一次练习，并给出即时反馈 |
| 自我决定理论（Deci & Ryan） | 激励设计照顾三点：自主（可以选今天的场景和皮肤）、胜任（看得见的进步，见 0009）、关联（学的句子和她的生活、将来当老师有关） |

### 以后怎么加新方法

- tiger 或开发中发现新方法时，新增一条 ADR，写清楚来源、证据和对应的功能，不直接改代码。
- 每学期回看一次学习数据（正确率、遗忘率、坚持天数），效果不好的方法可以用新 ADR 取代。

## 后果

- 数据库要记录每次作答的对错和用时，才能判断"连续答对"和薄弱点。
- 选句要能判断一个句子里有几个新东西，所以句库需要词和语法点的标注（见 0010）。
