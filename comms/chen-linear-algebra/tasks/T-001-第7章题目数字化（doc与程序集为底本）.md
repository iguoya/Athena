## 目标
把原书第 7 章（在科技及工程中的应用实例，7.1–7.15 节）的例题与习题录成机器可判的题目，
追加到 `guide/chen-linear-algebra/content/exercises/ch7.json`（现有 2 道是 leader 写的格式
范本，保留不动，新题接在后面）。

## 底本（都在仓库里，不改）
- 文字：`guide/chen-linear-algebra/upstream/第7章-线性代数在工程中的应用实例.doc`
  （用 `antiword -m UTF-8 <文件>` 提取文本；`[pic]` 是 Word 公式占位，公式按上下文与
  M 文件重排 LaTeX，note 注明「公式重排」）。
- 代码：`guide/chen-linear-algebra/upstream/programs/pla701.m` … `pla715.m`（文件头有例题号，
  代码逐字核对；MATLAB 写法改写成 Octave 等价形式，差异处加注）。

## 做法
1. 每节至少 1 题（7.1 的已由 leader 录入，跳过），题 `id` 用原书编号：例题 7.2 → `exl7-2`，
   习题 7.3 → `ex7-3`（正则 `exl?\d+-\d+[a-z]?`）。
2. `relation` 只许 `verbatim`（原书原样）或 `adapted`（note 写明改动）；**authored 一律不录**。
   `locator` 必须给到页码与例题号，如「第7章官方doc 第16页 例7.14」——doc 目录里的页码。
3. 题型两种：`numbers`（必须带 `verify` 字段：一段 Octave 代码，把答案算进 `result`）或
   `choice`（恰好 1 个 `ok`，每个选项都要有 `why`，干扰项写成真实学习者会犯的错）。
4. **答案不许心算入库**：本机已装 Octave，每道 numbers 题的 `verify` 都要真跑一遍
   （`octave --no-gui --norc --quiet --eval "…"`），跑出的数填进 `check.answer`。
   符号方程/文字题可用 `choice`。
5. 题面让学习者「先预测，再运行」：先给原书情境与代码，要求预测输出，再核对。
   原书笔误照录并在 note 说明（范本 exl7-14 的 pla614/pla714 就是这么处理的）。
6. 禁用词：「显然」「容易看出」「不难证明」「易知」等，`check.py` 会拦。

## 验收口径
- `cd guide/chen-linear-algebra && python scripts/check.py --skip-rust` 全绿（它会逐题查
  出处门禁与 Octave 复算）。
- `artifacts/cursor/T-001-核对记录.md`：逐题一行——题 id、doc 页码、M 文件名、verify 运行
  输出摘要。
- 每节至少 1 题、全部带 source_refs；总量 15–20 道即可，不为凑数降低质量（ADR 0129）。
