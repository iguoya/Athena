  EN: The `value` argument is the initial value of the
adjustment, usually corresponding to the topmost or leftmost position of an
adjustable widget. The `lower` and
`upper` arguments specify the possible range of values
which the adjustment can hold. The
`step_increment` argument specifies the smaller of
the two increments by which the user can change the value, while the
`page_increment` is the larger one. The
`page_size` argument usually corresponds somehow to
the visible area of a panning widget. The `upper` argument
is used to represent the bottommost or rightmost coordinate in a panning
widget's child.

[1] para
  EN: The group which treats the values as arbitrary numbers includes the
`Range` widgets (`Scrollbar` and
`Scale`), the `ScaleButton` widget,
and the `SpinButton` widget. These widgets  are typically
"adjusted" directly by the user with the mouse or keyboard. They will treat the
`lower` and `upper` values of an
adjustment as a range within which the user can manipulate the adjustment's
`value`. By default, they will only modify the
`value` of an adjustment.
  ZH: 把值当作普通数字来用的一组部件包括 `Range` 系（`Scrollbar` 和 `Scale`）、`ScaleButton` 和 `SpinButton`。这些部件通常由用户用鼠标或键盘直接「调整」。它们会把 `lower` 与 `upper` 值当作范围的上下限，把 `step_increment` 作为单击步长。

[2] para
  EN: The other group includes the `Viewport` widget and the

particular category of widgets create its own adjustments.
