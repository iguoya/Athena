### 页 sec-textview-buffer  (page status=translated)
[0] para
  EN: The `TextView` widget can be used to display and edit
large amounts of formatted text. Like the `TreeView`, it
has a model/view design. In this case the `TextBuffer` is
the model.
  ZH: TextView部件可以用于显示和编辑大量的格式化文本。与TreeView一样，它具有模型/视图设计。TextBuffer是它预期的模型。

[1] para
  EN: `Gtk::TextBuffer` is a model containing the data for the
`Gtk::TextView`, like the
`Gtk::TreeModel` used by `Gtk::TreeView`.
This allows two or more `Gtk::TextView`s to share the same
`TextBuffer`, and allows those TextBuffers to be displayed
slightly differently. Or you could maintain several
`Gtk::TextBuffer`s and choose to display each one at different
times in the same `Gtk::TextView` widget.
  ZH: Gtk::TextBuffer是一个包含Gtk::TextView数据的模型，和Gtk::TreeView所使用的Gtk::TreeModel类似。这允许复数个Gtk::TextView共享同一个TextBuffer，并允许以不同方式显示文本缓冲区。你也可以维护多个Gtk::TextBuffer并让同一个Gtk::TextView部件于不同时候分别显示它们。

[2] para
  EN: The `TextView` creates its own default
`TextBuffer`, which you can access via the
get_buffer() method.
  ZH: TextView会创建一个由它拥有的默认TextBuffer，你可以通过get_buffer()方法访问这个缓冲区。

[5] para
  EN: A `Gtk::TextBuffer::iterator` and a `Gtk::TextBuffer::const_iterator`
represent a position between two characters in the text buffer. Whenever the buffer
is modified in a way that affects the number of characters in the buffer, all outstanding
iterators become invalid. Because of this, iterators can't be used to preserve positions
across buffer modifications. To preserve a position, use `Gtk::TextBuffer::Mark`.
  ZH: Gtk::TextBuffer::iterator和Gtk::TextBuffer::const_iterator表示文本缓冲区中两个字符之间的位置。只要以影响缓冲区中字符数量的方式修改了缓冲区，所有越过修改范围的迭代器都将失效。因此，迭代器不能用于保存越过缓冲区被修改部分的位置。如果想保存位置，请使用Gtk::TextBuffer::Mark。

  EN: `TextView` has various methods which allow you to change
the presentation of the buffer for this particular view. Some of these may be
overridden by the `Gtk::TextTag`s in the buffer, if they
specify the same things. For instance, set_left_margin(),
set_right_margin(), set_indent(),
etc.
  ZH: TextView具有多种可以让你修改特定视图中缓冲区的显示方式的方法。如果它们指定同一区域，则其中一些可能会覆写缓冲区中的Gtk::TextTag。例如：set_left_margin()、set_right_margin()、set_indent()等。
