  EN: You might want to be notified whenever the user types in a text entry widget.
`Gtk::Entry` provides two signals,
`activate` (since gtkmm 4.8) and `changed`, for this purpose.
`activate` is emitted when the user presses the Enter key in
a text-entry widget; `changed` is emitted when the text in
the widget changes. You can use these, for instance, to validate or filter
the text the user types. Moving the keyboard focus to another widget may also
signal that the user has finished entering text. The `leave`
signal in a `Gtk::EventControllerFocus` can notify you when
that happens. The [ComboBox with an Entry](#sec-comboboxentry)

  ZH: 你可能希望在用户于文本输入控件中键入时得到通知。`Gtk::Entry` 提供两个信号：`activate`（自 gtkmm 4.8 起）和 `changed`。用户在输入框中按下回车时发出 `activate`；控件中的文字变化时发出 `changed`。可以用它们校验或过滤用户的输入。在控件内移动光标不会发出这两个信号。

[5] para
  EN: If you pass `true` to the set_activates_default()
method, pressing Enter in the `Gtk::Entry` will activate
the default widget for the window containing the `Gtk::Entry`.

the dialog buttons, which e.g. will close the dialog box. To set a widget as the
default widget, use Gtk::Window::set_default_widget().
  ZH: 若给 set_activates_default() 传入 `true`，在 `Gtk::Entry` 中按下回车将激活所在窗口的默认控件。这在对话框里尤其有用——默认控件通常是对话按钮之一，比如关闭对话框的那个。把某个控件设为默认控件用 Gtk::Window::set_default_widget()。

### 页 sec-spinbutton  (page status=translated)
[0] para
  EN: A `SpinButton` allows the user to select a value from a
range of numeric values. It has an `Entry` widget with increment and decrement buttons
at the side. Clicking the buttons causes the value to 'spin' up and down across
the range of possible values. The `Entry` widget may also
be used to enter a value directly.
  ZH: SpinButton允许用户从一个数值范围内选择一个值。它包含了一个Entry部件在其侧边有递增和递减按钮。单击按钮会使得值在可能的范围内“旋转”。你也可以直接在Entry部件中输入一个值。

[1] para
  EN: The value can have an adjustable number of decimal places, and the step size is
configurable. `SpinButton`s have an 'auto-repeat' feature
as well: holding down the increment or decrement button can optionally cause the value to
change more quickly the longer the button is held down.
  ZH: 这个值的小数位可以进行调整，步长也可以进行配置。SpinButton具有“自动重复”功能：长按递增、递减按钮该值的变化速度会越来越快。

[2] para
  EN: `SpinButton`s use an [Adjustment](#chapter-adjustment) object to hold information about
the range of values. These Adjustment attributes are used by the Spin Button
like so:
  ZH: SpinButton使用调整(Adjustment)对象保存值的范围信息。下述调整属性由微调按钮使用：

[3] listitem
  EN: `value`: value for the Spin Button
  ZH: value：微调按钮的值

[4] listitem
  EN: `lower`: lower range value
  ZH: lower：微调按钮允许的最小值

[5] listitem
  EN: `upper`: upper range value
  ZH: upper：微调按钮允许的最大值

[6] listitem
  EN: `step_increment`: value to increment/decrement when pressing
mouse button 1
  ZH: step_increment：鼠标键1(通常是左键)点击一下递增/递减的值

[7] listitem
  EN: `page_increment`: value to increment/decrement when pressing
mouse button 2
  ZH: page_increment：鼠标键2(通常是右键)点击一下递增/递减的值

[8] listitem
  EN: `page_size`: unused
  ZH: page_size：目前没作用

[9] para
  EN: Additionally, mouse button 3 can be used to jump directly to the
`upper` or `lower` values.
  ZH: 另外，鼠标键3(通常是中键)用于直接跳到upper或lower values。

[10] para
  EN: The `SpinButton` can create a default
`Adjustment`, which you can access via the
get_adjustment() method, or you can specify an existing
`Adjustment` in the constructor.
  ZH: SpinButton可以创建一个默认状态的Adjustment，然后你可以调用get_adjustment()方法访问这个Adjustment，也可以通过SpinButton的构造函数直接使用一个已经存在的Adjustment。
