## 背景

T-011（点位标定闭环）前半（标定引导 + 就地显示）已验收 done。本任务承接它的第二批两项，
一次交齐：

1. **命中反馈**（T-011 目标第 3 项）：练车日复盘（`review.dart`）里每一把可顺手标注
   「点位准 / 偏早 / 偏晚」三选一（字段命名你定），写进练车记录，点位卡上显示最近几次
   命中情况，帮学员修正点位。不做打分、不写掌握度（ADR 0036、0037）。
2. **照片标注**（ADR 0130 第 5 条追加）：学员在自己车里拍的照片上**点选位置并加标签**，
   形成「我的参照物标注」，沿用 T-014 的 marks 数据形态（归一化坐标 + type + label），
   在项目页该步**优先于**通用素材显示。个人照片与标注随仓库走、不进事件同步（ADR 0070）。

## 做法

- 先读 `lib/core/progress.dart` 现有表与 outbox，命中标注按既有迁移方式加表/加字段，
  不新增同步概念。
- 复盘页标注入口要顺手（一把一次点击），不弹窗打断；点位卡只显示最近几次（如最近 3 次），
  不堆历史。
- 照片标注交互参考 T-014 渲染组件的 marks 形态，标注结果与照片一起存个人库。
