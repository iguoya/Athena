## 目标

使用者反馈：「感觉目前是记录为主，操作步骤、注意事项、内部和外部视角似乎都没有体现」。
事实是 T-003 已把数据层做全（四项 22 步，每步决策点四行 + 车内/车外双视角 + caution 带
GA 条款），drill「练一把」里也有 CabinPanel 车内同屏——**是手册阅读页没有把这些做成
视觉主角**：步骤列表是紧凑行，`look`/`done`/`caution` 要展开当前步才看得见，双视角
阅读时根本不出现。数据在、界面藏，等于没有。

把手册阅读页重排成教学主轴：操作步骤 → 决策点四行 → 车内/车外双视角 → 注意事项。

## 现状

- `lib/subject2/subject2.dart` 步骤列表（约 1555 行起）：紧凑行只有步骤标题，
  决策点内容靠展开 `i == current` 分支。
- `lib/subject2/guide.dart` 已有 `StepInside`/`StepOutside` 模型与文本拼装（约 125 行起）。
- drill 的 `CabinPanel`（车内深色面板）在 subject2.dart，可复用或抽到 guide.dart。

## 做法

1. **决策点四行直接可见**：阅读页每个步骤不展开就显示四行——在哪（车外 focus）、
   盯哪（车内 look）、做什么（车内 action）、怎样算完（done）；`wrong`（别按这个来）
   有则附带。不再只给标题 + tooltip。
2. **双视角分栏进阅读页**：每步车内/车外视觉分区（车外=位置与风险，车内=视线与手脚），
   风格与 drill 的 CabinPanel 一致；宽屏左右分栏，窄屏纵向堆叠，不出屏。
3. **注意事项高亮**：每步 `caution` 红色警示条 + 条款出处角标，每步必有、不折叠、
   不藏在二级交互里。
4. **建议顺序标注**：手册 tab 四张项目卡已有 1-4 序号（learnItems），加一句
   「顺序只是建议，随时从任何一项开始」，呼应使用者「不要人为限制学习次序」。
5. **「偏了怎么修」块**（2026-10-16 09:40 加，配合使用者「完善操作细节把握」定调）：
   T-006 会给每步加 `fix` 字段（迹象→动作）。阅读页把它呈现为与「别按这个」
   并列的强调块——「偏了怎么修」，迹象一句、动作一句；用警示色系（可救）与
   「别按这个」（danger 红）区分。没写 fix 的步骤不渲染该块。
6. **内容字段只接 T-006 的 `fix`**，不另造新字段；其余内容层 T-003 已定稿，本任务纯呈现。
