## 背景（使用者定调，2026-10-17）

「尽量用真实视频或者真实图片标记参照物的方式讲解，避免单纯文字讲要点。」决定见应用 ADR 0130
（`certification/driver/docs/decisions/0130-subject2-real-media-with-reference-marks.md`，先读）。
你负责**找素材、核对语义、写标记数据**；cursor（T-014）负责渲染组件。

## 目标

为四项的**有参照物的步骤**采集真实素材，每步一到两份：优先「驾驶座视角」的实拍图——后视镜里看到的库角/库线、
挡风玻璃里看到的控制线/边线/弯口、车外视角的车位关系；需要过程的用短视频转动图。

1. **采集**：网络公开素材（ADR 0159，自用，出处照记）。可看：驾考教学站点/文章配图、知乎、B 站/抖音教学视频截帧或片段
   （能下载到的）、汽车之家/太平洋汽车等。逐张核对：图中画面必须和本步 `reference` 的语义一一对应
   （例如倒库第 3 步「后视镜壳刚过库口边线、后视镜里能看到库角」，图里就得是右/左后视镜里的库角画面），
   对不上的不收。不确定的写进缺口清单，不要硬凑。
2. **落库**：图放 `content/images/subject2/<项目id>/`，命名 `<步骤号两位>-<简述>.jpg`（动图 `.gif`/`.webp`）；
   视频用 ffmpeg 转动图（本机有，`C:\Users\tiger\AppData\Local\Programs\GNU Octave\Octave-11.3.0\mingw64\bin\ffmpeg`），
   每段 ≤ 5 MB、≤ 10 秒、宽度 ≤ 960。单个项目的素材合计别超过 15 MB。
3. **数据**：新建 `content/subject2_media.json`（你独占，不碰 cursor 的 `subject2.json`）：

```json
{
  "reverse": {
    "3": [
      {
        "file": "images/subject2/reverse/03-right-mirror-bay-corner.jpg",
        "kind": "image",
        "view": "右后视镜",
        "caption": "后视镜里能同时看到库角和车身",
        "note": "示例：点位以你自己的车为准",
        "source": {"title": "…", "url": "…", "accessed": "2026-10-17"},
        "marks": [
          {"type": "point", "x": 0.42, "y": 0.61, "label": "库角"},
          {"type": "line", "x1": 0.10, "y1": 0.70, "x2": 0.88, "y2": 0.72, "label": "库口边线"}
        ]
      }
    ]
  }
}
```

   `x/y` 与 `x1..y2` 都是 0～1 的归一化坐标（相对图宽高），`type` 为 `point` / `line` / `arrow`（arrow 同 line，带箭头），
   `label` ≤ 8 个字。`kind` 为 `image` 或 `anim`。步骤号对应 `subject2.json` 里 `steps[]` 的 1 起下标。
4. **出处登记**：`content/sources/catalog.json` 里为用到的来源加条目（id、标题、url、访问日期）；
   `media[].source` 指过去。不凭印象写出处（ADR 0043 底线）。
5. **缺口清单**：写 `comms/driver/artifacts/T-104/缺口清单.md`，列出没找到合格素材的步骤，我转给使用者在自己车里补拍。

## 做法（先交一半）

先做**倒车入库**全部步骤 + **直角转弯**的「内角到位再打满」「打满后看内后轮」两步，交 review，附：数据文件、
每张图配一句「为什么这张图对得上这一步」、缺口清单。我验过素材口径再推全四项，避免整批返工。

## 约束

- 只动 `content/images/subject2/`、`content/subject2_media.json`、`content/sources/`、`artifacts/T-104/`。
- 不改 `subject2.json`、不动 `lib/`。标记坐标先用目测+测量，渲染组件出来后与 cursor 对一遍。
- 图的版权/出处按 ADR 0159：不查许可证，但出处必须记；体积按上面的限额控制。
- 不要用 AI 生成图冒充实拍；示意图、插画不算「真实图片」。

## 验收

1. 倒库每步至少一份合格素材（或缺口清单里明写为什么没有）。
2. 数据文件通过 JSON 校验，坐标全在 0～1，`file` 都存在，出处齐全。
3. `python scripts/check.py driver` 退出码 0。
