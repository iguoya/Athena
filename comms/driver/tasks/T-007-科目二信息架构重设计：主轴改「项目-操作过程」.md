「科目二不是答题的啊，科目二是实操考试，怎么能用跟科目一相仿的界面子章节设计思路

现状（截图证据）：侧栏科目二分区 =「待练 6 题 / 合格标准与通用评判 4 / 倒车入库 2 /
侧方停车 / 曲线行驶 / 直角转弯」，按章节列、显示题数；项目页主视图是题目列表 + 答题
交互（答题情况、点选项出对错）。实操项目被降格成了评判条款的记忆单元。

## 目标骨架

科目二的主轴从「章节→题目」改成「项目→操作过程」。侧栏科目二分区定稿：

    科目二（C2）
    ├─ 倒车入库        ← 操作过程
    ├─ 侧方停车        ← 操作过程
    ├─ 曲线行驶        ← 操作过程
    ├─ 直角转弯        ← 操作过程
    ├─ 注意事项        ← 科目二出题的归口章节
    └─ 考试流程        ← T-901 已有「考试日怎么走」承接

1. **四个项目页 = 操作过程**（以倒车入库为样板）：
   - 静态分步俯视图：每步一张（库位线框、控制线、车身位姿与走向、方向盘角度示意、
     参照物高亮）。简笔风格先落地（车=带朝向的矩形、方向盘=圆盘+角度），再谈精致。
   - 决策点四行直接可见（吸收 T-005 第 1/2/3/5 条：在哪-盯哪-做什么-偏了怎么修，
     车内/车外双视角分栏，caution 高亮），数据来自 T-006 的
     steer/reference/skill/fix/caution 字段。
   - 项目页**不出题**。
2. **「注意事项」章节 = 科目二出题的归口**：把「合格标准与通用评判」的题和各项目名下
   的题（s2.reverse.* 等）**合并**到这里，保留现有答题交互（含解析、错题联动），
   定位是「以题考察注意事项与评判条款」。项目条目不显示题数；注意事项章节作为
   出题章节可显示。
3. **动画是第二档，本任务不做**：俯视图数据保持步骤化（每步一份几何参数），
   后续交互动画（车身-方向盘-轨迹联动）在同一数据上插值即可。
4. **几何放呈现层**：俯视图几何参数（车位姿、方向盘角度、库位）先做 Dart 常量表
   （每项目每步一条），不进 subject2.json——几何是呈现素材，不是教学内容文本；
   等动画档位再议数据化。
