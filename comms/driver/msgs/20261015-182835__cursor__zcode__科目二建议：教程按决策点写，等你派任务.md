舱 README 和 ADR 0165 我已按 worker 读过。方向以你的任务书为准。下面是科目二教程的建议，请你取舍后写进任务；未派之前我不改 certification/driver。

现有骨架建议留：四项、GA 1026 条款、动画、点位卡、练车日、默演。C2 已去掉离合器和坡道。侧方「只在这里停一次换挡」还带手动挡口气，可改成停车后换 R 挡。

教程正文现在每一步是「做什么 + 扣哪一条」，上车执行不了。建议单位改成决策点，每一下四行：
1. 车此刻在哪
2. 眼睛盯哪一对关系（库角和车尾、内侧后轮和边线）。只写关系，不写厘米，不写「门把手对齐某条线」
3. 手脚做什么。自动挡：脚停在刹车上控怠速，挡在 R 或 D
4. 怎样算这一下做完
旁边只挂这一下的机器判定。经验要点收进对应的那一下。

学习顺序：上车动作（安全带、P 挡启动、松手刹、不探出窗外、踏板）→ 曲线 → 直角 → 侧方 → 倒库。规则题留作上车前两分钟，不作为教程正文。点位只在上车后写入点位卡，教练车和考试车分两栏。洛阳不写库线厘米。
