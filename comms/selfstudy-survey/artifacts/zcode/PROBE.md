# 五省来源探路报告（zcode，T-001）

探路日期 2026-10-24。每省按任务书口径：官方入口、专业考试计划的位置与格式、页面可见字段、版本标注、第三方线索、采集耗时估计与最大风险。所有 URL 均实际访问验证过。

通用发现（先说结论）：
1. **五省五种形态**：江苏（计划简编 PDF 全文本）、湖北（440 页计划 PDF 全文本 + 课程级教材 Excel）、四川（汇编 PDF 全文本 + 双轨代码）可全自动；广东（通知 PDF 文本 + 顶替表 JPG 图片 + 简表在超大 zip 尾部取不全）半自动；北京（FineReport 报表系统交互查询 + 北京自有专业代码）最难。
2. **考期模型**：任务书/DESIGN 只列 2025-04、2025-10、2026-04、2026-10 四个考期，但广东一年三考（1/4/10 月）、江苏一年四考（1/4/7/10 月）。「考期」必须按省建模，不能只按全国统考的 4/10 月。
3. **专业代码三种形态**：全国码（湖北 080701 直接用）、省前缀码（四川 H080901 社会型/W080901 应用型、湖北时间表 S080901、江苏 X2080903）、北京完全自有码（01B0015，无国标码可对照）。`local_code` 字段必须有，且四川同专业双码需要拆两条 offerings。
4. **2026 年是新计划切换大年**：广东 2026-01 起新计划（粤考委〔2023〕5号/〔2024〕5号），江苏 2024 版过渡期到 2026-06，湖北 2024 版已实施，四川 2025 版已实施。「新旧计划并存」在广东/江苏是现实，`state: current/superseded` 会大量使用。

## 广东（已深挖，见 evidence/guangdong/）

- **官方入口**：广东省教育考试院自考栏目 https://eea.gd.gov.cn/zxks/index.html（公告流）；「广东省自学考试管理系统」https://www.eeagd.edu.cn/selfec/（公告按栏目分类，POST API `/selfec/notices/detail` 可编程访问，附件经 `DownGgfjServlet?ggxh=&fjxh=` 下载）。无需登录，无验证码。
- **专业计划在哪**：
  - 现行（2026 新计划）：公告 227「2026年专业调整相关文件及资料.zip」内含《各专业考试计划简表（2026年起使用）》《新旧计划课程顶替表（逐专业 JPG 图片）》《各专业面向社会主考学校》表 + 粤考委〔2023〕5号、〔2024〕5号 PDF（均扫描件，无文本层）。
  - **硬伤**：该 zip 52.7MB，服务器传输多轮在 20~27MB 处中断（curl 续传与 python 流式共 14 轮验证），不支持 Range（返回 200 无 Content-Range）。zip 尾部的简表与主考表拿不到。
  - 可用替代：粤考办〔2025〕20号附件（https://eea.gd.gov.cn/attachment/0/602/602026/4833531.pdf ，47 页**文本 PDF**）：附件1/2 为 2026-04/10 按专业×考期的开考课程表（课程代码、名称，无学分），附件3 为课程级使用教材表（代码、名称、教材、主编、出版社、版次）。
- **页面能看到什么**：课程代码/名称/教材/版次（时间安排+教材表，有）；学分、类别、选考规则、总学分（顶替表 JPG 可看部分，无文本层）；实践考核（不进笔试时间表，只能靠顶替表/简表）；毕业环节（同前）；主考院校（2026-08-05 调整通知 PDF 文本可读：080701 增电子科技大学中山学院、080901 增广东工业大学；完整表在 zip 尾部）。
- **版本**：2026 新计划，生效 2026-01-01（粤考委〔2023〕5号原文，深圳市招考办 .gov.cn 转载页可读全文），过渡期 2023-11-01~2025-12-31。旧计划（2021 版）停用。
- **开设情况**：080901、080902、080905、080701 开考（时间表）；080701 为新开考（顶替表无 0807 类）；080903 等未见。
- **第三方**：zikao365、搜狐/知乎有新旧课程对照转载（report 级）；深圳招考网 szeb.sz.gov.cn（政府官网，official 级）有「专业×主考学校×专业课程组」目录，但 080701 不在其中。注意：广东一个专业**多主考学校×课程组**（如 080901 有华南师范/深圳大学/广东财经[嵌入式技术、计算机及应用、移动商务技术组]/华南理工/广东外语外贸大学）。
- **耗时与风险**：试点两专业实际花了本会话约一半时间。估计全省 × 每专业 0.5~1 小时（简表拿不全时更长）。**最大风险：52.7MB zip 尾部文件取不到**（总学分、选考规则、080701 学分唯一源），需要人工浏览器下载或换网络环境重试。

## 江苏

- **官方入口**：江苏省教育考试院 https://www.jseea.cn/ ，自考频道 https://www.jseea.cn/webfile/examination/selflearning/ （子栏目：考试计划、专业建设、考试日程、计划简编、政策规定）。无需登录。
- **专业计划在哪**：《江苏省高等教育自学考试专业考试计划简编（2024年版·2025年修订）》https://www.jseea.cn/webfile/self_learning_jhja/2026-05-25/7464464743114215424.html → 附件 PDF（68 页，**全文本**）。每专业一节：新旧计划（2021/2024）并排表格，列有课程代码、名称、学分、考核方式（笔试/实践）、◆学位课程标记、学分合计、主考学校、说明（过渡期 2024-07~2026-06、换考课程、替代关系）。
- **页面能看到什么**：全部所需字段都有（代码/学分/类别/实践/毕业环节/主考/教材另见日程教材通知）。教材：《…2026年10月和2027年1月考试日程及开考课程教材计划的通知》附件 PDF（58 页文本，课程×考期×教材）。
- **版本**：2024 版（2025-05 修订），2024-07 起用，两年过渡至 2026-06；简编封面明标版本。另注意 2025-11-20《关于调整…计算机科学与技术（专升本）专业课程的通知》（课程微调，采集时要叠加）。
- **开设情况**：080901（主考南京航空航天大学）、080903 网络工程（X2080903）、080905 物联网工程开考；**080701 电子信息工程未见**，最接近 080703 通信工程（简编专升本目录有）。江苏一年四个考期（1/4/7/10 月）。
- **第三方**：无需；官方全覆盖。
- **耗时与风险**：全自动，每专业分钟级。风险最低。唯一注意点：新旧并排表的文本抽取要处理跨行单元格（实践课缩进行）。

## 四川

- **官方入口**：四川省教育考试院 https://www.sceea.cn/ ，自考频道 https://www.sceea.cn/Html/ZXKS.html ；新闻列表 https://www.sceea.cn/List/NewsList_60.html 。无需登录。另有 zk789.net（第三方）。
- **专业计划在哪**：《四川省高等教育自学考试社会型专业考试计划汇编（2025版）》https://www.sceea.cn/FileUpload/file/ZXKSshx.pdf （158 页，**全文本**）：每专业「课程设置与学分」表（课码/名称/学分/备注）+「新旧考试计划衔接表」（逐专业：旧计划 vs 新计划，含顶替关系）。计划列表页 https://www.sceea.cn/Html/202507/Newsdetail_4371.html ；调整通告 Newsdetail_4372.html（新计划 2025 版规则：专升本不少于 70 学分 13 门等）；20 问 Newsdetail_4373.html；课程免试规则（2026 修订）Newsdetail_4663.html。
- **页面能看到什么**：代码/名称/学分有；主考院校（汇编内未逐专业见，另有来源待查）；教材（另有教材文件，未在本次探路范围）；类别（表内有序号分组与备注，无显式类别列）。
- **版本**：2025 版（封面明标），7 月发布。
- **开设情况**：080901 开考且**双轨**：社会型 H080901（对应旧 B082208 计算机信息管理、B080702 计算机及应用）与应用型 W080901（对应旧 Y082208、Y080702、Y080787 移动商务技术）——**同一专业两套省码、两类办学、可能不同主考**。080701 待查（汇编内未见独立 080701，旧口径并入上面衔接表）。
- **第三方**：zk789.net（四川自考网）可作线索。
- **耗时与风险**：半自动（文本可抽，衔接表跨行要清理）。风险中：社会型/应用型双轨要在 offerings 层拆分建模；应用型（高校助学）计划与主考院校数据在「应用型」汇编/高校端，可能需要逐校。

## 北京

- **官方入口**：北京教育考试院 https://www.bjeea.cn/html/selfstudy/index.html （政策/信息发布/自考指南）；综合服务平台 https://zikao.bjeea.cn/ （办理类，登录）；**专业计划查询系统 http://zkxcx.bjeea.cn/ （FineReport 报表，交互查询，无需登录但接口会话化）**。
- **专业计划在哪**： zkxcx.bjeea.cn 的「专业计划查询」——逐专业交互查询，底层帆软报表（/ReportServer），**无静态全量文件**，编程采集需模拟报表会话，成本高。替代静态源：《关于公布北京市高等教育自学考试2026年考试安排及有关事项的通知》 https://www.bjeea.cn/html/selfstudy/xxfbt/2025/1125/87664.html ：正文含 44 个专业的「专业代码/专业名称/旧专业名称/专业状态」表 + 附件（4/10 月笔试时间表 PDF、实践类安排 PDF、**2026 年教材信息表 PDF**，均为文本 PDF 可抽取）。
- **页面能看到什么**：专业清单/状态/新旧名称（通知正文有）；课程×考期（时间表 PDF）；教材全表（教材 PDF：代码/名称/教材/出版社/版本/作者/教材类型/考核方式）；**学分、类别、选考规则在 FineReport 系统里**（探路未深入）。主考院校：主考院校自考平台（如中国地质大学北京 zikao.cugb.edu.cn，official 级）可逐校查。
- **版本**：北京 2024 起执行新计划（多个「关于开考/调整…专业的通知」在 zkzc 栏目）；01B0015 计算机科学与技术（原计算机信息管理）三年过渡期 2024-07-01~2027-06-30（zikao365 转载通知，report 级线索，待官方核对）。
- **开设情况**：01B0015 计算机科学与技术（专升本）正常开设；**电子信息类未见**（2026 安排正文无「电子信息」）。**北京专业代码为自有体系（01A/01B+序号），与国标码（080901 等）无直接对照**——映射须靠「旧专业名称」列手工对。
- **第三方**：zikao365 转载北京各通知较全（report）。
- **耗时与风险**：**五省最难**。专业级计划（学分/类别）要么逐个过 FineReport、要么逐主考院校平台，估计每专业 20~40 分钟人工。最大风险：北京代码体系导致 scope.json 的专业映射大量靠人工判断。

## 湖北

- **官方入口**：湖北省教育考试院 http://www.hbea.edu.cn/ ，自考栏目 /html/zxks/index.shtml ，**「自考计划」栏目 /html/zkjh/index.shtml** 。无需登录。
- **专业计划在哪**：《省教育考试院关于调整湖北省高等教育自学考试开考专业考试计划的通告》（2024-07，/html/2024-07/14357.shtml）附件 zip → **《湖北省高等教育自学考试考试计划（2024年版）》PDF，440 页全文本**：每专业一节（指导思想/学历层次及规格[总学分、门数]/培养目标/课程设置与学分表[代码/名称/学分/备注，备注含「学位课程」]/主要课程说明/使用教材表[书名、作者、出版社、年份]）+ 新旧专业对接课程顶替表（专升本/专科分册）+ 新旧代码名称对照表。报考简章（每年 11~12 月发）附件为课程级 Excel：**《面向社会开考专业大纲及教材使用情况.xls》（课程代码/名称/学分/大纲名/教材名/编著/出版社/版次/启用时间）+ 统考课程时间安排.xlsx（专业×考期×课程）**，结构化程度五省最高。
- **页面能看到什么**：全部字段：代码/名称/学分/学位课标记/实践课（独立学分行）/毕业考核/教材/总学分门数。主考院校：计划正文写「由主考学校副署/授予学位」但**未见逐专业主考表**（在计划每节正文里，需抽；本次未逐节核对）。
- **版本**：2024 年版（文件名明标）。湖北仍用旧思政码（03708/03709），2026 计划尚未切换 1504x——新旧思政并存是全国现状的一部分。
- **开设情况**：080701 电子信息工程开考（专升本，15 门、71 学分，主考待抽）；080901 计算机科学与技术开考（时间表 S080901）。统考课程时间表用 S 前缀（专升本）/X 前缀（专科），计划正文用国标码。
- **第三方**：无需；官方全覆盖。
- **耗时与风险**：全自动为主，每专业分钟级。风险低；唯一坑：440 页 PDF 的跨页表格与「接表」需要清洗逻辑。
