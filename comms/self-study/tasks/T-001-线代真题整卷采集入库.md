## 目标

给 `self-study/linear-algebra`（自考线性代数·工，课程代码 13175 / 02198）采集历年真题整卷，
录入 `self-study/linear-algebra/content/exams/YYYY-MM.json`。**用途**：应用内判分题的出处主体
（exam 档，ADR 0043/0089），并把现有 `authored` 过渡题逐批替换为 `verbatim`。目标 2–4 份
近年试卷（2018 年以后优先；「线性代数（工）」新计划卷与旧 02198 卷都收，注明年份即可）。

## 做法

1. 网上找文字版真题（可搜：自考 02198 线性代数 真题 及答案、13175 真题；自考365、圣才、
   一考通、公众号转录、百度文库预览页等）。扫描版 PDF 若能下载且本机可 OCR 则转录，
   转录后**每道题自己做一遍验算**，答案与「参考答案」对不上时以自己的验算为准并在
   `solution_note` 标注分歧。
2. 按目录 README（`self-study/linear-algebra/content/exams/README.md`）的 JSON 格式录入：
   题干原文、选项、答案、`transcript_sources` 必填（转录页 URL）。公式用 LaTeX，
   行列式用 `\\begin{vmatrix}…\\end{vmatrix}`。
3. 拿不到整卷时，单道题也收：建对应年份文件，`sections` 里只放拿得到的题号段，
   并在文件顶层加 `"incomplete": true`。
4. 已知障碍（leader 试过，供参考）：jszikao.org 的 2019-04 卷是扫描 PDF（本机无 OCR）；
   exam100 与京东读书的真题页有留资/权限墙。换别的源，或把找到的 PDF 链接发消息给
   leader（leader 环境有 poppler 时可转图核对）。

## 验收

1. 至少 1 份整卷（或 ≥10 道单题）入库，`python scripts/check.py linear-algebra --skip-rust`
   退出码 0（内容校验会查 JSON 结构）。
2. 每道入库题的答案经过自己验算，验算记录放 `comms/self-study/artifacts/T-001/verify.md`
   （题号 → 验算过程一行）。
3. 做完转 review：附入库文件清单、验算记录路径、来源 URL 列表。

## 边界

- **只写** `self-study/linear-algebra/content/exams/` 与 `comms/self-study/artifacts/T-001/`。
  节内容挂接出处（authored → verbatim 替换）由 leader 做，你把对应关系写进
  `artifacts/T-001/map.md`（真题题号 ↔ 建议挂接的知识点）即可。
- 卡住就发消息给 leader 并转 blocked，说明试过哪些源。
