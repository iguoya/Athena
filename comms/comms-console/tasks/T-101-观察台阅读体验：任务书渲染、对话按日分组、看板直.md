## 目标

观察台初版（T-901，leader 已完成）之上的阅读体验增强，三件事：

1. **任务书轻量 Markdown 渲染**：任务书正文现在是 `<pre>` 原样展示；改成渲染
   标题（## …）、无序/有序列表、行内代码 `…`、粗体 **…**——够用即可，不引 Markdown
   库，自己写一个小解析（任务书里就这几种结构）。
2. **对话流按日分组**：ChatView 的统一时间线加日期分隔行（「10月15日 星期三」）。
3. **看板直达**：BoardView 任务卡点击后应打开「任务与决策」视图并定位到该任务
   （App.tsx 的视图状态要带选中的 tid，现在是裸切 tab）。

## 做法

- 归属：`tools/comms-console/src/` 与 `index.html`（config.json 的 owned 表）；
  Rust 侧（src-tauri）不要动。
- 口径：对话/线程的语义以 comms/comms-console/docs/view-semantics.md（T-002 产出，
  若已交 review 就按它，没交就按现状理解）。
- 提交前 `python3 scripts/check.py comms-console` 必须全绿。

## 验收

1. check 全绿；界面截图放 `comms/comms-console/artifacts/T-101/`。
2. 任务书里的列表与行内代码渲染正确（拿本舱任务书当样张）。
3. 看板点任务卡，右侧直接是那个任务的详情。

## 依赖

- depends T-901（leader 的初版先落库）。
- 你手上 driver 舱的 T-002/T-003（科目二）优先级更高，本任务排在其后，
  由使用者协调你两边的注意力。
