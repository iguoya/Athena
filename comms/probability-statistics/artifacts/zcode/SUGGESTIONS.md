## 二、2023 版教材目录（已核实的二手底稿）

来源：馆配书目页（安徽万品，ahwp.tsxcfw.com/bookshow.asp?id=2605279）转录，**节级编号在动笔前必须与教材实物/版权页目录核对**（ADR 0175 后果条款；T-002 对线代、高数做过同样的核对，这门课照做并出一份核对记录）。教材自带考纲与**试题样卷+答案**（大纲部分 19–24 页），是第一批 verbatim 出处现成的来源。

- **第一章 随机事件与概率**（§1 随机事件：随机现象/随机试验与样本空间/事件概念/关系与运算；§2 概率：频率与概率/古典概型/定义与性质；§3 条件概率：条件概率与乘法公式/全概率公式与贝叶斯公式；§4 事件的独立性：独立性/n 重伯努利试验）
- **第二章 随机变量及其概率分布**（§1 离散型：概念/分布律/0-1 与二项/泊松；§2 分布函数：概念/性质；§3 连续型：概率密度/均匀与指数/正态；§4 随机变量函数的分布：离散型/连续型）
- **第三章 多维随机变量及其概率分布**（§1 概念：二维分布函数/二维离散型及边缘/二维连续型及边缘；§2 独立性：两个/二维离散/二维连续/n 个；§3 两个随机变量函数的分布：离散/独立连续型之和）
- **第四章 随机变量的数字特征**（§1 数学期望：离散/连续/二维/性质；§2 方差：概念/常见分布的方差/性质；§3 协方差与相关系数：协方差/相关系数/矩与协方差矩阵）
- **第五章 大数定律与中心极限定理**（§1 切比雪夫不等式；§2 大数定律：伯努利/独立同分布切比雪夫；§3 中心极限定理：独立同分布/棣莫弗–拉普拉斯）
- **第六章 统计量及其抽样分布**（§1 引言；§2 总体与样本；§3 统计量及其分布：统计量与抽样分布/经验分布函数/样本均值/样本方差与标准差/样本矩/顺序统计量/正态总体的抽样分布）
- **第七章 参数估计**（§1 点估计方法：替换原理与矩法/极大似然；§2 评价标准：相合性/无偏性/有效性；§3 区间估计：置信区间概念/单个正态总体参数的置信区间）
- **第八章 假设检验**（§1 基本思想：基本思想/统计假设/两类错误/基本步骤；§2 正态总体均值：u 检验/t 检验；§3 正态总体方差：χ² 检验）
- 附表 5 张：标准正态、泊松、t、χ²、F；书末习题解答或提示。

### 考纲边界（写教材时别越界）

这份目录比通用工科概率统计**窄**，这些「没有」就是考纲边界，不铺开（ADR 0040）：

- 假设检验只有单总体 u/t/χ²，**没有 F 检验、没有两总体检验**；
- 区间估计**只有单个正态总体**；
- 第三章到二维 + n 个独立性的概念为止，没有 n 维联合密度运算；
- 第六章有经验分布函数与顺序统计量（通用教材常略讲，这里考纲列了）。

另一面：大纲章名「样本与统计量」与教材章名「统计量及其抽样分布」不一致，入课表时以教材章名为准并并记大纲章名。

## 三、编写建议

1. **第一批交付**：第一章 §1–§4 四节完整闭环（节首 retrieval → prose → example 折叠分步 → pitfall → exercise → figure），外加教材大纲样卷整卷入 `content/exams/`（格式照 `self-study/linear-algebra/content/exams/README.md`）。课表只登记写出的节。
2. **重点配重**：官方考纲已逐章给出重点与难点（见 [VERIFICATION.md](VERIFICATION.md) 第二节），example/exercise 往那里压；学时最重的是随机变量章（46–54 学时），最轻的是大数定律与 CLT（6–10 学时，大数定律只识记）。命题比例：识记 30%、领会 40%、应用 30%；题型四种（单选/填空/计算/证明）。
3. **数值复核硬流程**：统计题的分位数、临界值、置信区间、p 值手算极易错。每道计算题用 Python（scipy.stats）复算一遍再定稿，像线代那门用 Octave 复算的先例；附表引用的数值与教材附表核对（附表是分位数给法可能与 scipy 默认不同，注意尾部约定）。
4. **可视化机会**（ADR 0056 强制，这门课是三门里最富的）：
   - §1.2 频率稳定于概率：抛硬币收敛动画；
   - 第一章伯努利/第二章二项→正态：高尔顿钉板；
   - §2.3 正态曲线随 μ、σ 的滑块变形；标准化变换前后对比；
   - 第五章 CLT：样本均值分布随 n 增大的直方图动画；
   - 第六章三大分布：χ²、t、F 曲线随自由度变化，与正态叠画；
   - 第七章置信区间：重复抽样画区间、观察覆盖率的模拟；
   - 第八章：接受域/拒绝域阴影随 α 移动。
   静态先出 SVG（`content/sections/assets/`），能由数据算出来的后续做成交互，不放假交互。
5. **先修链**：这门课大量用一元微积分（密度积分、EX 计算）与少量二重积分（联合密度）；而高数工本不含一元微积分。先修缺口走知识点 `requires` + prereq 层点到为止（积分在概率里的用法），不铺开讲考纲外内容（ADR 0175）。
6. **真题采集**：仿 T-001 开一门「概率统计（02197/13174）历年真题整卷采集入库」的任务。02197 考了二十多年，卷源充足；过渡期规则同线代（authored 先上线、真题入库后逐批替换、只降不升）。
7. **协作通道**：本舱 `comms/probability-statistics` 已按 ADR 0178 决策 5 开设（leader claude-code，worker zcode、cursor）。任务书由 leader 建并派发；exams 录入派 cursor（有 T-001 先例），cursor 只写 `content/exams/`，节内容挂接出处由内容负责人做，互不踩。
