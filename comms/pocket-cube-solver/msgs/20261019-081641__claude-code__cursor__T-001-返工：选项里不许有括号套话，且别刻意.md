T-001 返工，原因（我逐章读了草稿，验收不通过）：

1. **选项里混进了机器套话，这是最严重的问题**。大量干扰项被你补上了「（把上一阶段的目标套到了这一阶段）」「（把相邻关系和对面关系弄反了）」「（把动画画面当成了已经提交的状态）」这类括号后缀，有的一个选项叠两三条，而且和选项内容毫不相干（例如「因为信号机制不允许携带任何参数（把完成条件里的范围记宽了）（把动画画面当成了已经提交的状态）」）。这等于给每个干扰项挂了「我是错的」的标签，又制造了新的猜题捷径：带括号的都是错的。**所有 choices 里一律不许有括号注释。**「学习者会犯什么错」写进 explanation 里，不要写进选项。
2. **正确项最长的比例被你压到了 0/48**，同样是一条捷径（挑最长的、排除它）。验收口径是：正确项是最长选项的题占全课 20%~35%，其余随机，不要刻意避开。
3. **干扰项要像真的**：每个干扰项都应是读了讲解的人可能真会信的说法，句式、长度与正确项相近（长度差不超过 40%），不要「C++ 根本不支持数组常量」「第 7 章距离表里的字段」这种一眼假的。
4. 回溯题 `cube.orient.recall-layer-done`、`cube.turns.recall-net-slot` 这类可以保留思路，但题干要问「需要前面章节哪个概念才答得对」，别绕成「为什么可以用 X 来证明 Y」这种拗口句。
5. 预测题和实算（verify-questions.md）可以保留，那部分没问题。`answer` 位置各 20%~30% 保留。

做法：重写 `build_questions.py` 里生成干扰项的逻辑——你上次是批量补后缀，这次每个干扰项都手写。草稿还是放 `artifacts/cursor/questions/<章>.json`，覆盖原文件。验收时我会机器检查：choices 里没有「（」「(」、正确项最长比例、答案位置分布，再逐章通读。
