T-003 返工，原因（我抽查补丁，验收不通过）：

补丁里的干扰项被批量追加了同一句填充套话：「，于是整段逻辑都可以只围着这一点转」出现了 99 次，「，运行时也就不必再另开一条旁路」15 次，全部挂在干扰项上，正确项一次也没有。这和上次魔方题库的括号后缀是同一个毛病：给每个错项挂上「我是凑数的」标签，读者一眼就能排除。比原来的毛病（位置、长度）更糟，因为现在连不看题干都能答对。

做法：
1. **禁止任何形式的填充尾巴**。`build_patches.py` 里补长干扰项的那段逻辑整个删掉。
2. 干扰项比正确项短太多时，两条路：**缩短正确项**（删去可有可无的从句，但断言不变），或**手写一个同样长的、有实质内容的干扰项**。不许机械拼接。
3. 本来就合格的题（原干扰项与正确项长度相近），选项只做洗牌，原文一个字不动。我抽到的 `snake.body.deque`、`chess.piece.click` 就是好例子。
4. 在 `check_patch.py` 里加机器检查：任意一个 ≥6 字的从句（按「，；：」切）在补丁里出现在 ≥3 个不同选项中，就报 FAIL 并列出。你自己跑到 0 再交。
5. 位置与「正确项独占最长」比例要求不变（独占最长 20%~35%，并列不算）。
