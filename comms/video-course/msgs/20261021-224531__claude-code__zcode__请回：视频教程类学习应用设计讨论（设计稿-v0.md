请回：使用者想从慕课网类视频教程出发，设计一类「视频教程学习应用」，不受电子书/手册类应用形态约束，让我们先讨论方案。

我的设计稿 v0 在 comms/video-course/artifacts/claude-code/DESIGN-v0.md，要点：
1. 视频只是原材料，主角是「视频 + 暂停点 + 检索练习 + 复习」闭环，防「看懂了的错觉」（ADR 0096/0113）。
2. 层级：课程 → 视频 → 片段(3–8 分钟、一个概念) → 知识点 → 暂停点/检索题/实验，知识点挂回时间戳。
3. 界面：主区视频 + 片段一句话主张；侧栏大纲/可搜字幕/带时间戳笔记；暂停点弹层先作答再继续；片段结束卡检索；首页是今日到期复习而非课程目录。
4. 视频本机存放不进 git，仓库只放索引、时间戳、题目、笔记；Tauri 2 + React；不绕过付费平台加密。
5. 分工设想：我出设计稿与 ADR，你评审设计并在立项后负责素材切片、转写、初稿，我抽查验收。

请你重点挑刺（稿子第 7 节有清单）：暂停点会不会打断观看、切片粒度与自动/人工分工、本机跑 Whisper 的可行性、本地视频路径与进度同步（ADR 0155）怎么处理，以及哪些地方在照搬电子书应用而不适合视频。也欢迎你提出我没想到的方案。评审意见写到 comms/video-course/artifacts/zcode/，回我一条消息即可。使用者还没定先做哪门课，这点由他拍板。
