# 评估：翁恺《C 语言》B 站版 + 西电课件与周次对照（zcode，2026-10-21）

回应 DESIGN-v1 第 9.1 节的派工：翁恺课四项核实（给结论）与西电课件 rar 解开对照。

## 一、翁恺《C 语言》B 站公开版评估

B 站底本：`BV1Ls411w7rx`《C语言程序设计 浙江大学：翁恺》（2018-07 上传）。

1. **完整性与可取性：可行。** 132 P 全（经 B 站 pagelist API 核实），总 1163 分钟，
   标题自带「周.节」编号（1.1 计算机和编程语言 … 8.4，尾部附 ACLib 入门选修 A0-x），
   与「周 → 节」结构天然对齐。公开普通视频，无付费加密，BBDown 可取。
   注意点：这是转载版（标题带 SHD 后缀），与 MOOC 官方课（icourse163 `ZJU-9001`
   《C语言程序设计》、《程序设计入门——C语言》）的期次对应关系未逐条核，**要向使用者
   确认他指的就是这个 B 站版**。
2. **字幕：无 CC，Whisper 兜底。** P2 经 player API 抽查无 CC 字幕；2018 年转载视频
   基本可判定全片无 CC。C 语言讲解术语标准、中英混杂少，faster-whisper small/medium
   预期可用；代码念白（变量名、运算符）会有转写误差，按段落级校对（不逐字入库，与
   设计一致）。
3. **单节时长：合适。** 平均 8.8 分钟/P，多数 5–10 分钟。比「片段 3–8 分钟」略长，
   但每 P 本就是一个概念点，**一 P = 一个学习单元**正好，暂停点每 P ≤ 2–3 个成立。
4. **与仓库已有 C 内容：无归属冲突，并存合理。**
   - `programming/machine`（C 与机器）：Beej 教程卷（内存/指针/数组/字符串/结构体/
     动态分配），C23 语义、系统视角。翁恺课是零基础程序设计入门——层次与视角都不同，
     两应用独立、知识点前缀独立、不互引（ADR 0032），ADR 里写清边界即可。
   - `comms/legacy-archive`：其 manifest 已明确「C 语言基础（栈溢出、指针、glade 界面）
     归 machine」，与翁恺课无关。

**结论：翁恺 B 站版可作「本地文件完整闭环」的首发验证课**，前置只有两条：使用者确认
底本版本；BBDown 实测下载一 P 走通。
