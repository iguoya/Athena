## 写法差异明细（PPT 原样保留，程序集为可运行版本）

1. p21/p28：PPT 把方程组分写为 A 与 b 两个语句，程序集直接写增广矩阵或分开赋值后
   合并 `C=[A,b]`——同一矩阵的不同书写顺序。
2. p28：PPT 用 `-.25` 简写，程序集写 `-0.25`；PPT 原文含全角空格（`-0.25;　0`），快照逐字保留。
3. p30：PPT 行内混入全角逗号（`-330]，`），逐字保留；程序集为半角。
4. p32：PPT 首字符为全角 `Ａ`，逐字保留；程序集用半角 A 且多一行 `format rat`。
5. p26 的 `T` 是转置记号（数学写法），非 MATLAB 语法——做上机任务时改 `X'` 或取 rref 末列。
