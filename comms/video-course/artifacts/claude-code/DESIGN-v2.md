# 视频课学习应用：设计稿 v2——课堂工作台（claude-code，待 zcode 共同修订）

起因：使用者 2026-10-22 的三条要求——①视频只是应用界面的一个组成部分，不是全部；
②把课堂练习、本节要点都做出来，把握上课节奏、随时练习、抓住注意力，用各种任务类型提高专注度、练习度与参与感；
③不能只是看视频、没有参与感、收获感、体验感。登录、清晰度这类事由使用者在播放窗格里自己处理。
在 v1（档位 ①②③）之上，本稿改的是「界面与节奏」，不改数据底座（时间锚点、题源门禁、掌握度只由作答写入）。

## 1. 技术前提（已验证，见 SPIKE-player-bridge.md）
B 站官方外链播放器页面可以放进主窗口的一个 webview 窗格（或单独的伴随窗口），应用能读播放时间、seek、暂停、
自然播放跨过暂停点时触发（拖动越过不触发）；页面可能意外暂停，设计要容忍。登录/清晰度由使用者在窗格里处理。

## 2. 界面：课堂工作台（一个窗口，三个区）
```
┌─────────────────────────────┬──────────────────────────────┐
│ 课堂区（左，应用自己的 UI）   │ 视频窗格（右，B 站播放器）       │
│  · 节拍条：本节 N 个节拍，当前高亮 │  可收起为小窗/全屏；登录、清晰度 │
│  · 任务卡：当前节拍的任务（作答区）│  在这里自己处理                │
│  · 要点卡：本节要点（边学边累积） ├──────────────────────────────┤
│  · 上机区：Octave/C 小任务入口   │ 笔记/转写（可搜，点句子跳时间）  │
└─────────────────────────────┴──────────────────────────────┘
```
- 视频窗格可收起：没有视频文件、没有网络、或只想做练习复习时，课堂区自己完整可用（课件段落 + 任务 + 要点）。
- 主导航仍是周/节；首页是「今日到期复习 + 继续上次的节」。
- 作答时视频自动暂停且窗格变暗，课堂区放大，零打扰（ADR 0113 专注原则）；答完一键继续。

## 3. 课堂脚本：一节课 = 一串节拍（beats）
一节（3–15 分钟的视频）按概念切成 3–6 个**节拍**，每个节拍 = 「看一小段 → 一个任务 → 一句要点」，
节拍之间的间隔（连续只看不动手的时间）上限默认 4 分钟，超过就要补一个轻任务。
```
开场(≤60s)：本节目标 + 看前提示（先预测）
节拍 i：视频区间 [start,end] → 暂停点任务(0–2 个) → 结束任务 → 要点卡一句
收尾(≤2min)：出口题 2–3 道（不看视频）+ 要点确认 + 加入间隔复习
```
课堂脚本是内容文件（跟课件段落一起入库），字段：`beats[] {start,end,slide_refs,pause_tasks[],end_task,takeaway}`。

## 4. 任务类型库（按「想让你做什么」选，不是随便弹题）
| 类型 | 做什么 | 何时用 | 判分 |
|---|---|---|---|
| 预测 | 暂停在讲师给出结果之前，先写/选你的预测，再看对照 | 开场、讲到结果前 | 不判分，记「预测是否命中」 |
| 填空补全 | 讲师写到一半的公式/代码，你补全 | 推导、代码演示 | 机器核对 |
| 你来做 | 视频暂停，去 Octave/终端里做一小步，粘结果或自动核对 | 上机段 | `verify` 复算 |
| 找错 | 给一段有错的步骤/代码，指出哪一步错 | 易错点 | 选择/行号核对 |
| 排序 | 把消元步骤、算法步骤排成正确顺序 | 流程性内容 | 机器核对 |
| 自我解释 | 用一句话说「为什么这一步成立」，再看参考解释 | 概念转折 | 不判分，自评 |
| 速答 | 2–3 道检索题，不看视频 | 节拍结束/出口 | 机器核对，进掌握度 |
| 要点确认 | 把本节要点的一句话改写成自己的话 | 收尾 | 不判分，生成效应 |
| 回看 | 答错后一键让视频回到该概念的区间 | 错题 | — |
每个节拍最多一个「重」任务（你来做/速答），其余是秒级轻任务，避免课堂变成刷题。

## 5. 参与感与收获感（只展示由记录派生的量，ADR 0052）
- 节内进度环按「完成的任务」而不是「看了多久」：看过不算，答过才算。
- 收尾页：「这一节你做了：预测命中 x/y、速答 a/b、上机 1 次、写下 3 条要点」，以及「待巩固：2 个点，明天复习」。
- 间隔复习首页给出到期卡片（错题 + 要点），点开可跳回视频对应区间。
- **不做**：番茄钟、打断式提醒、连续打卡奖励、自动播放下一集。吸引注意力靠任务设计与节奏，不靠弹窗。

## 6. 数据与门禁（与 ADR 0180 一致）
- 进掌握度的只有 `exercises/` 的题（机器可核对、有出处，题源只许课件/原课代码/程序集）；预测、自我解释、要点确认是教学动作不判分。
- 观看位置与掌握度两张表；视频路径不进同步库；窗格关闭时课堂区全功能。
- 暂停点与节拍的时间戳由「边看边标」工具产生：看视频时按键把当前时间记给当前节拍，半自动对齐课件/转写。

## 7. 要和 zcode 共同定的

2. 课堂脚本字段与课件段落的关系（一个节拍对应几页课件？节拍切分谁出初稿）。
