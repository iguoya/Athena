# 视频教程类学习应用：设计稿 v1（以西电慕课《实用大众线性代数（MATLAB版）》为基准）

合并了 v0（claude-code）、design-brief-v1 与 REVIEW-DESIGN-v0（zcode）；使用者 2026-10-21 指定首门课：
中国大学 MOOC 西安电子科技大学《实用大众线性代数（MATLAB版）》（陈怀琛、杨威、樊松涛主讲，
<https://www.icourse163.org/course/XIDIAN-1001775006>）。下面所有设计以这门课的真实结构为准，
课程结构取自课程页公开大纲（2026-10-21 读取）。

## 1. 这门课的真实形状（设计的出发点）

- 14 周；每周 3–4 个「节」（一节 = 一个视频），共约 50 节左右（待核实实际条数）。
- 五章，每章末有章测验：线性方程组 / 矩阵运算 / 行列式 / 平面和空间向量 / 线性变换。
  其中第七至八周讲「后续课中的高阶线性方程组应用」，第十三周讲应用举例，第十四周结束语。
- 每周都有「习题及课件」「题解及课件」小节——**课件与题解是官方配套文本**。
- 全程要上机（MATLAB；本仓库用 Octave 等价写法，与 `guide/chen-linear-algebra` 一致）。
- 课程定位：非数学专业、重建模与计算机求解、不为考研；这决定了学习闭环是「建模 → 上机算 → 解读」，
  不是「推公式」。

## 2. 文本底本不靠字幕，已经在仓库里

| 来源 | 位置 | 用途 |
|---|---|---|
| 官方课件 rar（5 MB） | `guide/chen-linear-algebra/upstream/实用大众线性代数课件.rar` | 每节的文本底稿（PPT），段落锚点的主来源 |
| 程序集 `pla1xx–pla7xx.m`（115 个） | 同上 `programs/` | 上机任务与核对源（可机器复算） |
| 第 7 章官方 doc | 同上 | 应用章全文 |
| 平台字幕 / Whisper 转写 | 待取 | 视频原话，补课件没有的讲解 |

所以 HANDOFF「没字幕不建」这条对本课不构成阻碍：**文本主底本是课件 + 程序集，字幕只是补充**。
（对其他慕课课程这条仍要逐门核对。）视频文件的取得方式由使用者自己决定，应用只读本机路径，
不内置、不绕过任何平台保护。

## 3. 应用形态

- 一门课一个应用（ADR 0032、0132），独立壳、独立知识点 ID 前缀，**不引用** `guide/chen-linear-algebra`。
  内容重叠（同一位作者、同一套程序集、同一批例题）是客观事实，但两个应用各管各：
  图书应用以书题为单位、重原书；视频应用以「周 → 节」为单位、重观看后的检索与上机。
  ——这是 ADR 要写清的第一个取舍，**使用者待拍板**（备选：只做视频视图并入图书应用）。
- 归类：新应用放 `guide/`（底本是外部课程）还是新开分组目录——待使用者拍板；我倾向 `guide/`，
  ADR 里同时修改 LEARNING-METHODS「不做视频课」措辞为「不做无检索闭环的纯视频被动消费」。
- 技术栈：Tauri 2 + React（ADR 0138），课程壳走 `athena-course-shell`（ADR 0161）。

## 4. 学习单元骨架（主原型 P 预测–运行 + E 真做校验；ADR 0113）

一「节」= 一个视频 = 一个学习单元：

1. **看前提示**：1–2 句「看到 mm:ss 先暂停，想一想……」，建模类问题先让学习者自己列矩阵方程。
2. **观看**：本地文件模式下播放器嵌在应用内，**暂停点**自动停住（默认开、可限时放行、
   一节 ≤ 2–3 个）；无本地文件时降级为课件段落 + 时间戳外链。
3. **片段检索卡**：看完不回看，答 2–3 题（概念辨析用选择/判断，数值用手算后输入）。
4. **上机任务**：给 Octave 骨架（不改也能跑，ADR 0059），先预测输出，再运行对照；`verify` 字段
   由 `check.py` 在有 Octave 时复跑。题源只许来自课件习题/题解或程序集例题（复用图书应用
   的题源门禁精神：verbatim / adapted，locator = 周-节-课件页码或例题号）。
5. **章测验前的混合练习**：跨节交错抽题（ADR 0096），每章一轮。

首页是「今日到期复习 + 继续上次看的节」，不是课程目录；主导航是**周/节时间轴**，不是知识点列表页。

## 5. 可视化是内容本身（ADR 0056）

这门课最适合重做成互动的：平面线性变换与形变（第 11 周）、向量与线性相关、方程组的几何解释、
最小二乘拟合、qr/特征值的几何意义。每门课先挑 3–5 个，用 `@athena/viz` 重做，并与节内片段互链；
不求全。

## 6. 数据与进度

- 内容快照入库：`节 → 片段(text/课件页/start/end/外链) → 知识点 → 暂停点/检索卡/上机任务`。
  记取得日期与源版本，外链失效文本仍可用。
- 本机视频库根目录是用户配置，视频用「相对 key」引用，**绝不进同步库**，缺文件自动降级。
- 掌握度只由作答写入，观看完成度不算（ADR 0052）；进度库按 ADR 0037/0155 声明 `progress`。

## 9. 补充（与 zcode 往返后）

### 9.1 首门课候选：两种视频形态各有一门

使用者先后指定了两门：西电慕课《实用大众线性代数》（讲解 + 上机型）、翁恺《C 语言》（程序设计入门，
实操录屏型，课程在中国大学 MOOC 与 B 站都有）。两门恰好对应两类形态，也对应两种播放档：

| | 西电·实用大众线性代数 | 翁恺·C 语言 |
|---|---|---|
| 形态 | 讲解 + 建模 + 上机 | 讲概念 + 现场写代码 |
| 文本底本 | 课件 rar + 程序集（已在仓库） | 待核对（课件、B 站字幕/需 Whisper） |
| 视频文件 | 慕课平台流为加密 HLS，明文文件拿不到，要使用者自供 | B 站公开版需核对是否无加密可取 |
| 可先跑通的播放档 | 文本 + 外链（降级档） | 本地文件（完整暂停点）若文件可得 |
| 主原型 | P 预测–运行 + E（Octave） | P + E（C 编译运行、输出比对） |
| 验证的东西 | 文本为底的精读壳、上机任务、题源门禁 | 暂停点、代码抽取、本地播放全链路 |

结论待使用者拍板：想先验证**完整闭环（含暂停点和本地播放）**，倾向先做翁恺（前提：B 站版文件能无加密取得）；
想先用**手头已有素材做出可交付的第一批**，先做西电（降级档，不依赖视频文件）。两门迟早都做，关键是先后。

### 9.2 对 zcode 四个深化问题的回应

1. 复习卡：同意从片段结束卡错题 + 知识点派生；背面链时间戳，有本地文件则壳内 seek 播 10–20 秒对照，
   没有则外链；「看片段」不给掌握度。
2. 暂停点题目：初稿 AI、人工抽查可以，但**进掌握度的题必须机器可核对**（选择/数值/Octave 或 C 运行输出），
   且上机题题源只许课件习题、程序集例题或原课代码（延续图书应用「不凭空出题」的门禁精神）；
   纯开放式的预测提示只作为教学动作，不记掌握度。
3. seek 精度：同意 rAF 轮询 currentTime，越过暂停点按「已过」处理；**不强制回跳**，该点的题在片段结束卡补问。
4. 观看位置与掌握度分两张表：同意，写进数据模型。
