# 视频教程类学习应用：设计稿 v0（claude-code，待 zcode 评审）

## 1. 核心判断
电子书/手册是可检索的文本；视频线性、被动，最大风险是「看懂了的错觉」。所以视频只是
原材料，应用的主角是「视频 + 暂停点 + 检索练习 + 复习」闭环。依据 ADR 0096（检索/间隔/交错
为主）、ADR 0113（按课程选方法原型：P 预测–运行、M 机制模拟、E 真做校验、D 辨析、R 检索）。

## 2. 内容层级
课程 → 视频(讲) → 片段(3–8 分钟、一个概念) → 知识点 → 暂停点 / 检索题 / 实验。
每个知识点挂回视频时间戳，点一下跳回原讲解。

## 3. 每个视频的加工流水线
1. 取素材：视频文件 + 字幕（没有则本地 Whisper 转写）
2. 切片段：按概念边界切，不按时长；每段一句话主张 + 起止时间戳
3. 挑暂停点：每段至少一个，播到处自动暂停，先预测/回忆再继续
4. 配练习：题型随学科选原型，不给每段硬配，没价值的段留成「只看」
5. 记出处：知识点 → 时间戳
6. 宁缺毋滥，不逐字转写（ADR 0040、0129）

## 4. 界面
- 主区：视频 + 当前片段一句话主张 + 时间轴上的片段分界与暂停点标记
- 侧栏（可切）：大纲 / 可搜索字幕 / 带时间戳的笔记
- 暂停点弹层：视频停住，先作答再继续，答完给对照与错因
- 片段结束卡：不看视频答 2–3 题，结果写掌握度
- 首页：今日到期复习 + 继续上次片段（不是课程目录）
- 专注：作答时零打扰，一轮有界，不做番茄钟

## 5. 技术
- 视频体积大：本机目录存放、不进 git；仓库只放片段索引、时间戳、题目、笔记
- Tauri 2 + React（ADR 0138）；WebView2/WKWebView 播 H.264 无问题，WebKitGTK 依赖系统
  GStreamer，Linux 允许降级（ADR 0051）
- 付费平台视频多有加密，应用不绕过；用本地文件
