# Athena Axler 线性代数精读

精读 Axler《线性代数应该这样学（第四版）》（Linear Algebra Done Right, 4e）官方中文版
的应用：以线性映射/算子为中心的定理型线代，全书 9 章。原书习题逐字入库（页码与题号
可反查），判分做证明思路选择与概念辨析，证明本身对照参考解答自评。

属于 Athena 仓库 `guide/`「数学」圈的教材精读应用（主仓库 ADR 0179）。技术栈
Tauri 2 + React + KaTeX，dev 端口 1530。

```sh
launcher open axler-linear-algebra   # 打开
python3 scripts/check.py             # 本应用验证入口
```

底本与出处见 `upstream.json`；应用规则见 `AGENTS.md`。
