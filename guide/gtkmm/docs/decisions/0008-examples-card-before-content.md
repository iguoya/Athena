# ADR 0008：官方示例卡移到节页最上方——先演示，后读教程

- 日期：2026-10-12
- 状态：已接受
- 修订：应用 ADR 0006 决策 5 的位置描述（原：翻译正文之后、随堂测验之前）

## 背景

ADR 0006 把 exercise/ 官方示例卡挂在教程节页尾部，与「Example 在正文
末尾」的官网结构一致。但本应用的学习方法原型是**预测–运行**（先预测、
真机运行、再读文验证）：示例卡放在正文之后，学习者读完全节才见到
「可以跑的官方代码」，演示被排在了阅读之后，与主导方法相反。

正文内嵌的官网源码（ADR 0007）是教程文本的一部分，位置跟随官网结构，
不在此列；动的只是 exercise 官方示例卡的挂载点。

## 决策

官方示例卡渲染在节页**最上方**（页头导航与标题区之后、翻译正文之前）：
进入一节先看到「本章官方示例」，先编译运行、观察界面与信号，再往下读
教程正文。锚定规则不变（translation_ref 锚章、page_ref 锚节、章级示例
随本章各节页出现）。

## 后果

- 阅读动线与「预测–运行」同向：演示在前、文档在后；官方示例卡与正文
  内嵌代码（ADR 0007）各在其位——前者是动手入口，后者是教程原文。
- 节页顶部信息密度上升（示例卡 + 正文首屏同屏），卡片保持折叠源码、
  单行 purpose 的紧凑形态，不做展开式大卡。
