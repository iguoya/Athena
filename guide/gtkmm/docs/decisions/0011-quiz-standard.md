# ADR 0011：测验标准版——不靠位置和长度就能猜对，答后有解析，掌握度只认首次作答

- 日期：2026-10-17
- 状态：已接受（试点：第 3、6 章；其余章逐章推进）
- 延续：主仓库 ADR 0052（掌握度只由作答写入）、0096（检索练习优先）、0113（预测–运行主原型）；
  审查依据 `comms/gtkmm-review/SUMMARY.md`

## 背景

审查发现：全书 112 道测验题里 68% 的正确答案在 B 位，80% 的正确项是最长的选项，所有题没有解析，
答错后可以立刻重试、逐个排除，「答对过一次即计通过」。结论是通过测验不能说明学会了，
「学习闭环」里「修正理解」一环也缺失。

## 决策

1. **题型与字段**：测验题新增 `explanation`（答后显示，1~3 句，说明为什么对、常见误解错在哪，并指向原文节）
   与 `code`/`lang`（题干附代码，读代码预测、找错）。`QuizItem` 与 `QuizView` 同步支持。
2. **标准版标记**：课表章加 `quiz_standard: 2`，`scripts/check.py` 对带标记的章强制：每题有解析、至少 3 个选项、
   任一答案位置的题数 ≤ ⌈40%·n⌉、「正确项是唯一最长项」的题数 ≤ ⌈40%·n⌉、带代码的题 ≥ ⌈n/3⌉、题 id 唯一。
   没带标记的章不受影响，逐章推进。
3. **答案位用作者端均衡，不做运行时洗牌**：洗牌会让 localStorage 里存的选项下标与题库对不上，也让评审看不到真实顺序。
4. **掌握度只认每题的首次作答**：答错后「再试一次」仍保留，但只用于学习，不计入。
   页内测验与章末考核的点亮条件统一为：本组题全部答过且首次正确率 ≥ 80%。「重置本章作答」保留，
   重置后可重新获得首次作答。
5. **题目标准**：读代码预测约 1/3 以上，其余为辨析、找错、机制因果，纯定义回忆不超过 1/6；
   干扰项取自本章常见误解，长度相近；预期输出必须可由官方示例或语义基准核对；术语按 glossary。
6. **新题用新 id**：重写的题不沿用旧 id（旧 id 下的作答记录对应的是另一道题）；旧题的删除在提交信息里写明。

## 后果

- 历史作答记录里的首次作答照常计入；章末考核的「点亮」以首次作答重新计算，部分旧章可能由此失去点亮，
  这是预期的。
- 试点期间同一应用里新旧两种测验并存；`quiz_standard` 标记决定哪一章按新标准检查。
- 解析与代码题增加了写题与核对成本，换来「通过」可信、答错有反馈。
