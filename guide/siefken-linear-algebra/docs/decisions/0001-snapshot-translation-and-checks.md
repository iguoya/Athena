# ADR 0001：段落快照 + 逐段译文 + 练习题核对点

- 日期：2026-10-14
- 状态：已接受
- 依赖：主仓库 ADR 0162（选书）、0043/0089（出处，open 档）、0052（掌握度只由作答写入）、0155（进度同步）

## 决策

1. **快照是中间层**：`sync_upstream.py` 把上游 LaTeX 解析成块流（段落、列表、定理/例/证明/要点盒子、展示公式、表格、图），每个可译单元带
   `en`（逐字）、`sha`（指纹）、`zh`（手写）。`\SavedDefinitionRender{key}` 引用的定义内联为定义盒子。公式保持 LaTeX，前端 KaTeX 渲染。
2. **只收讲解与练习题**：上游主文件里的课堂核心探究题、教师批注、幻灯片不进快照（没有标准答案、依赖课堂组织）。
3. **练习题**：`moduleN-exercises.tex` 的每道 `\prob` 一题，带原书解答（`solution` 环境）；核对点另存 `content/checks/`，用 SymPy 复核。
4. **掌握度**只由核对点作答写入 `attempts`；没有核对点的题只展开原书解答，不做自评。
5. **图**：TikZ/pgfplots 源码按指纹存 `content/figures/src/`，开发期用本机 TeX 编译成 SVG 入库；使用者不需要 TeX。
6. 译文不得改公式（导入时校验）。

## 后果

- 译文量大，按页推进，课表里每页显示译文进度，未译的页直接显示原文（标「待译」）。
