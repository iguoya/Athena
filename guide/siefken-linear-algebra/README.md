# Siefken 线性代数精读

精读 Jason Siefken 的开源教材《MAT223 Workbook: Linear Algebra》（多伦多大学一学期线代课程，CC BY-SA 4.0，原书 284 页）：
几何直观先行，每个模块先讲思想再练习。本应用收模块 1–16 与附录 1–4 的讲解与练习题，逐段对照译文，练习题带可核对的最终答案。

- 覆盖与缺口见 [`docs/COVERAGE.md`](docs/COVERAGE.md)；许可与署名见 [`docs/LICENSE-NOTICE.md`](docs/LICENSE-NOTICE.md)。
- 启动：`launcher open siefken-linear-algebra`；验证：`python3 scripts/check.py`。
- 与 `guide/selinger-linear-algebra`（另一本书）互不引用，方便并排对比。
