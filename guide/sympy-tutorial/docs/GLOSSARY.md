# 术语对照与译文约定

首次出现用「中文（English）」，之后用中文。代码标识符（函数名、类名、关键字）一律不翻译。

| English | 中文 | English | 中文 |
|---|---|---|---|
| symbolic computation | 符号计算 | numerical computation | 数值计算 |
| computer algebra system (CAS) | 计算机代数系统 | expression | 表达式 |
| symbol | 符号（变量） | substitution | 代入 |
| immutable | 不可变 | evaluate / evaluation | 求值 |
| simplify / simplification | 化简 | expand / expansion | 展开 |
| factor / factorization | 因式分解 | rational function | 有理函数 |
| derivative | 导数 | integral (definite / indefinite) | 积分（定积分 / 不定积分） |
| limit | 极限 | series expansion | 级数展开 |
| finite difference | 有限差分 | equation | 方程 |
| solve / solver | 求解 / 求解器 | differential equation | 微分方程 |
| matrix / matrices | 矩阵 | determinant | 行列式 |
| inverse | 逆 | nullspace | 零空间 |
| column space | 列空间 | eigenvalue / eigenvector | 特征值 / 特征向量 |
| characteristic polynomial | 特征多项式 | diagonalization | 对角化 |
| pretty printing | 漂亮打印 | LaTeX | LaTeX（不译） |
| assumption | 假设（符号的取值范围假设） | identity | 恒等式 |
| gotcha | 容易踩的坑 | doctest | doctest（不译） |

## 译文约定

- 公式、行内代码一律不动；中文标点用全角（，。；：？！），公式、代码与中文之间不强求空格。
- 不要出现「显然」「容易看出」「不难证明」等把难度推给读者的词（内容检查会拦）。
- 对读者说话用「你」或「我们」，与原教程一致。
