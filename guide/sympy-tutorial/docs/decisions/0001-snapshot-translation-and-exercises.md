# ADR 0001：rst 段落快照 + 逐段译文 + 自编「试一试」

- 日期：2026-10-14
- 状态：已接受
- 依赖：主仓库 ADR 0163（选源）、0043/0089（出处，open 档）、0052（掌握度只由作答写入）、0155（进度同步）

## 决策

1. **快照是中间层**：`sync_upstream.py` 把上游 reStructuredText 解析成块流（段落、列表、提示框、展示公式、表格、代码块），
   每个可译单元带 `en`（rst 行内标记规整成 `$公式$`、`` `代码` ``、`**粗**`）、`sha`、`zh`（手写）。代码块逐字保留，不译。
2. **示例必须是真的**：`verify_examples.py` 用真 SymPy 复跑教程示例；旧输出登记在 `KNOWN_STALE`。
3. **练习自编**：原教程没有习题；`content/exercises/<页>.json` 手写，答案由 `verify` 代码用真 SymPy 复算，标 `authored`。
4. **掌握度**只由核对点作答写入；不做自评。
5. 译文不得改公式与行内代码（导入时校验）。

## 后果

- 译文量较小（约 430 单元），按页推进；未译的页直接显示原文并标「待译」。
- 本机 SymPy 版本与钉点不同时，`verify_examples.py` 会暴露哪些示例已不成立。
