# 翁恺 C 语言 · 课堂工作台（weng-c-programming）

浙江大学翁恺《C语言程序设计》视频课（B 站 2022 年版 BV1dr4y1n7vA）：视频只是界面里的一个窗格，课堂区按节拍发预测、速答、上机等任务，
掌握度只由作答写入。登录 B 站与选择清晰度由你在应用里的「登录 B 站」窗口自己处理。

```sh
launcher open weng-c-programming    # 打开
python3 scripts/check.py            # 验证
```
