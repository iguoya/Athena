# ADR 0001：段落快照 + 逐段译文 + 习题核对点

- 日期：2026-10-14
- 状态：已接受
- 依赖：主仓库 ADR 0162（选书与裁剪）、0043/0089（出处，open 档）、0052（掌握度只由作答写入）、0155（进度同步）

## 背景

要「吃透一本书」：原文可核对、译文逐段对照、习题能练、练了有反馈。上游是 LaTeX 源码，用自定义宏与环境。

## 决策

1. **快照是中间层**：`sync_upstream.py` 把上游 `.tex` 解析成块流（段落、列表、定义/定理/例/解/证明盒子、展示公式、表格、
   图占位），每个可译单元带 `en`（逐字，仅做 LaTeX→轻量标记转换）、`sha`（en 的指纹）、`zh`（手写）。
   公式保持 LaTeX，前端用 KaTeX 渲染；自定义宏在 `src/macros.ts`。**不手写原文**。
2. **按指纹对齐**：上游变动后，指纹相同的单元保留译文，不同的为空，由人补译。
3. **译文不得改公式**：校验 `zh` 里的 `$…$` 与 `en` 一致，防止翻译时手滑改了数学。
4. **习题**：原书习题逐字入库（`stem`/`sol`，`relation: verbatim`）。核对点另存 `content/checks/`，是手写的、可机器判的
   最终答案：`numbers`（若干个数，支持分数）或 `choice`（带每个选项的解释）。先作答，再展开原书解答。
5. **掌握度**：只由核对点的作答写入 `attempts`；没有核对点的题（需要写证明、答案是文字描述等）只展开原书解答，
   不做「看懂了」自评，不计入进度。节的完成度 = 有核对点的题中最近一次答对的比例。
6. **图**：TikZ 不移植，占位并指向原书；以后有价值的图单独做，不动快照。

## 后果

- 译文量大，按节推进，课表里每节显示译文进度，未译的节直接显示原文（标「待译」）。
- 核对点要逐题写、逐题用 SymPy 复核，成本高，所以优先做考纲核心节。
