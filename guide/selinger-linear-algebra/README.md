# Selinger 线性代数精读

精读 Peter Selinger 的开源教材《Linear Algebra: A First Course》（CC BY 4.0，基于 Lyryx Learning 与 Ken Kuttler 的原作），
按**考研数学二线代考纲**裁剪：保留体系骨架与理解必需的章节，去掉抽象向量空间专章、叉积、直线平面、有限域与各类应用章。

- 章节编号与顺序跟随原书；原文段落逐字入库，译文逐段对照；例题与习题并存，习题带可核对的最终答案，再展开原书解答。
- 范围与理由见 [`docs/COVERAGE.md`](docs/COVERAGE.md)；许可与署名见 [`docs/LICENSE-NOTICE.md`](docs/LICENSE-NOTICE.md)。
- 启动：`launcher open selinger-linear-algebra`（`app.json` 声明，Tauri 2 + React）。
- 验证：`python3 scripts/check.py`。
- 与 `guide/siefken-linear-algebra`（另一本书）互不引用，方便并排对比。
