# 大众线性代数（chen-linear-algebra）

陈怀琛《实用大众线性代数（MATLAB版）》（西安电子科技大学出版社 2014）精读：题目逐字取自
原书（页码与题号可反查，自编题不入库），答案由本机 Octave 复算，先预测再运行；配套慕课
作视频版。`guide/` 圈「数学」圈，学习应用。

```sh
launcher open chen-linear-algebra    # 打开
python3 scripts/check.py             # 验证（结构、出处门禁、Octave 复算、构建）
```

底本与配套资源见 [upstream.json](upstream.json)。
