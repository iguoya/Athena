# 实体书拍照接口（使用者 → 代理）

使用者手上有《实用大众线性代数（MATLAB版）》（陈怀琛，西电出版社 2014）的**实体书**，
整本 PDF 一直没有合法来源（渠道试探见 `comms/chen-linear-algebra/tasks/T-002-*` 与
`comms/chen-linear-algebra/artifacts/cursor/T-002/`）。需要看原书某页时，由使用者拍照放进本目录。

## 怎么交照片

- 直接把照片文件放进本目录，git 里入库（ADR 0159：出处照记——这里出处就是使用者实体书）。
- 文件名：`p<书页码>-<内容标识>.jpg`，例如 `p112-例7-14.jpg`、`p043-习题1-5.jpg`；
  同一页拍几张就 `p112a`、`p112b`。书页码印在书页上，别用 doc/课件的页码。
- 拍摄：整页入框、光线均匀避免反光，公式和图表页尽量端平。图表（曲线图、程序输出截图）
  是重点——这些在 doc 底本里只是 `[pic]` 占位。

## 照片到手后怎么用

1. **转录与核对**：文字、公式按照片重排成 LaTeX；图表按照片描述或重绘。原有的
   「公式重排」「图略」类 note，凡照片能核对的都回头核一遍（如 content/exercises/ch7.json 的题面）。
2. **页码对照**：照片同时建立「书页码 ↔ 第7章 doc 页码」的对照表，后续数字化任务的
   locator 从此优先写书页码。
3. **不用等整本**：哪个任务需要哪几页就拍哪几页，按需解锁，不追求整本电子化。

当前等照片的工作：见 `comms/chen-linear-algebra/tasks/T-002-取得书PDF底本（渠道线索见文）.md` 的进展注记。
