# 0025 承接考研英语二：磨砚并入摘星

- 状态：已采纳（迁移规则第 3 节待定）
- 日期：2026-10-10
- 决策人：tiger

## 背景

tiger 决定取消磨砚（`subjects/english`），把它的内容与特点并入摘星，作为独立章节和界面
（主仓库 ADR 0117）。这推翻了本应用 ADR 0020「两个英语应用并列、不合并」与 ADR 0024 的
「不趋同、不共享内容」前提。

## 决策

1. **摘星承载全部英语考试**：四六级、专四、专八之外，新增「考研英语二」章节，有自己的
   界面入口，与四条章节路线（ADR 0017）并列而不并入——它服务的是 22408 考生，不是英语
   专业的进阶路线。视觉、皮肤、教学原则（真实句子、出处、语法隐性习得、FSRS）照本应用
   规则执行。
2. **从磨砚收下的特点**（落地时按本应用规则重写界面，不搬代码）：
   - 英语二的句子、短文、词表与考核内容，出处原样保留；
   - 语境先行、答对后才出示词形与义项，再用新句挖空提取词形（与 ADR 0005 同向）；
   - 句子题只问切分、指代与句意，不考语法名词（与 ADR 0007 同向）；
   - 作文只机检字数与衔接方式，组织与用词对照范文和清单自查，不进掌握度；
   - 初级、中级、高级三级路线终点如实标出衔接英语二；
   - 考核与练习分离、错题出库双条件（ADR 0024 已采纳，英语二章节同样执行）。
3. **参考资料与公开发布（待定）**：本应用规定教材、真题原文只放 git 忽略的
   `content/private/`（ADR 0019 补充），磨砚则把公开参考资料提交在仓库里（磨砚 ADR 0008）。
   迁移时按来源逐条分流的规则，由 tiger 定下后补进本节；定之前不迁磨砚的 `sources/`。
4. **ADR 0020、0024 中「不合并、不共享内容」的表述由本条取代**；0024 的三条掌握度原则
   继续有效。

## 后果

- 本应用多一个面向非英语专业考生的章节，首页与导航要给它一个清楚的入口，又不打乱
  四章路线。
- 磨砚的删除在迁移验收之后（主仓库 ADR 0117 决策 2），之前两边并存。

## 2026-10-10 补充：第 3 节定案——按本应用规则分流

tiger 选择按本应用现行规则分流（仓库 `iguoya/Athena` 公开，安装包随推送公开发布）：

- **进仓库与安装包**：来源许可允许再分发的条目——Tatoeba（CC BY，逐句保留作者与链接）、
  VOA Learning English（公有领域）、NGSL/NAWL（CC BY-SA，按 ADR 0019 单独存放并标明协议）、
  英语二考试大纲公开说明的结构与词组、本应用自写（`authored`）条目。
- **只进 `content/private/`（git 忽略，不进安装包）**：引用了未声明内容许可来源的条目——
  kylebing 考研/四六级词库与句库、Oxford 3000/5000、AVL、BNC/COCA、
  zhenghaoyang 英语二词表、netem 词频表（NC 许可）——以及磨砚 `sources/reference/` 的
  全部参考资料。由「导入本地资料」加载，与真题同一条路径。
- 磨砚迁移前统计：约 750 次出处引用中约 475 次落在 kylebing 系列，即英语二题目的多数
  将走 private。它们的历史版本由 `pre-english-merge` 标签保留；换机器时随本机资料一起拷贝。
- 一条条目引用了多个来源时，按其中最严的一个分流。
