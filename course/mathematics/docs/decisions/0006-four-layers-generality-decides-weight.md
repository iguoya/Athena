# ADR 0006：思想、方法、算法、技巧四层；通用性决定权重

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0004（算法与技巧分界）——本 ADR 细化其二分，不推翻
- 相关：ADR 0002（`idea_leverage` 标记）、0005（发生学顺序）

## 背景

使用者提出：数学思想、数学历史、数学方法工具，都比单纯解题更重要；相对于特殊
解题技巧，**通用解题思想和方法更重要**。

ADR 0004 已把计算方法二分为算法与技巧，判据是「计算机会这么做吗」。但那条判据
处理不了**比算法更高的一层**：化归、不变量、对称性、反向工作、特殊化与一般化
——这些是波利亚（G. Pólya）意义上的启发法，不是计算流程，却是最能迁移到现实
问题的东西。恰恰是它，在 ADR 0004 里无处安放。

同时，ADR 0005 已把历史用作**教学顺序的依据**（发生学顺序），但使用者把历史抬到
了「比解题更重要」的地位，需要相应升格。

### 两个必须提前堵住的失败模式

1. **启发法变成一张要背的表。** 把「化归、类比、反证」列成清单让人记，就又造出
   了第二套要背的东西，而它因为没有反馈会被直接跳过（ADR 0002 第 3 节已警告）。
2. **历史变成掌故。** 人物八卦、年表、优先权之争（牛顿与莱布尼茨谁先发明微积分）
   对理解概念零贡献，是装饰不是思想。

## 决策

### 1. 四层分类，通用性决定权重

所有可复用的东西按**迁移范围**分四层。ADR 0004 的算法/技巧二分是本表的下两层。

| 层 | 是什么 | 迁移范围 | 例 | 归属 |
|---|---|---|---|---|
| **思想** | 看待问题的方式 | **跨学科** | 化归、不变量、对称性、逼近、线性化、极端原理 | 主线，权重最高 |
| **方法** | 可复用的操作套路 | 跨题型 | 换元、消元、分离变量、待定系数、母函数 | 主线 |
| **算法** | 确定的计算流程 | 整类问题 | 高斯消元、牛顿迭代、施密特正交化 | 主线 |
| **技巧** | 依赖特定结构的招法 | 单题或小类 | 爪型行列式凑法、特定构造的递推 | 应试区 |

**篇幅与权重按层次分配：越通用越值得花篇幅。** 这条为 ADR 0002 的
`idea_leverage` 标记提供判据——能归入「思想」层的一律 `high`。

### 2. 通用思想独立成层，但禁止列表背诵

思想层的内容**必须从具体题目中提炼，并标注回题目上**，不得单独成章罗列。

具体做法：

1. 主线每道题标注它用到的思想（一道题可多条）；
2. 做完一批题后**回看**：这些题为什么能用同一条思想串起来；
3. **反向练习**：给一道新题，先只问「该用哪条思想」，不要求做出来。这一步才是
   思想层真正的训练，也是考试从不考的。

### 3. 通用性检验：一条思想要能在至少两处独立出现

宣称是「思想」的东西，必须能举出**至少两个不同科目或领域**的实例，否则它只是
方法，降层处理。

以**化归**为例（四科加现实，全部命中）：

| 领域 | 化归的形态 |
|---|---|
| 微积分 | 换元积分：把不会算的积分变成会算的 |
| 线性代数 | 初等变换：把矩阵化成标准形 |
| 概率 | 全概率公式：把复杂事件拆成互斥情形 |
| 现实工程 | 把新问题转述成已有解法覆盖的问题 |

以**不变量**为例：

| 领域 | 不变量的形态 |
|---|---|
| 线性代数 | 特征值在相似变换下不变；秩在初等变换下不变 |
| 微分方程 | 守恒量（能量、动量） |
| 物理 | 守恒定律 |
| **算法（`apps/dsa`）** | **循环不变式** |

### 4. 跨应用呼应要主动建立

上表最后一行不是巧合：数学的不变量与 `apps/dsa` 的循环不变式**是同一个思想**。

编写时遇到这类呼应应主动指出并互相引用。这是 Athena 作为一个**平台**而非一堆
孤立应用的价值所在，也是使用者要求的「全局意识」在跨学科尺度上的形态。

技术上不耦合（各应用仍独立可运行，主仓库 ADR 0032、0037 不变），呼应只在**内容
层面**通过文字与示例建立。

### 5. 数学史升格为主线，但只讲「卡住 → 突破」的关头

历史不是背景装饰，是思想产生现场的记录，也是 ADR 0005 发生学顺序的依据。

**判据（否决式）：这段历史能不能解释某个概念为什么长成现在这样？**

| 该讲 | 因为它解释了 |
|---|---|
| 贝克莱对无穷小的诘难 → 柯西、魏尔斯特拉斯 | ε-δ 为什么必须绕成那样 |
| 伽罗瓦与五次方程 | 数学为何从「找公式」转向「研究结构」——思维方式的根本转折 |
| 黎曼重排定理的发现 | 为什么无穷和不能随便交换顺序 |
| 傅立叶用三角级数解热传导遭质疑 | 收敛性问题为什么变得性命攸关 |

| 不讲 | 因为 |
|---|---|
| 牛顿与莱布尼茨的优先权之争 | 对理解微积分零贡献 |
| 数学家生平轶事、年表 | 掌故，非思想 |

## 后果

- 思想层的三步做法（标注 → 回看 → 反向练习）需要课表支持「一道题挂多个思想
  标签」并支持按标签反查，`content/curriculum.json` 的 schema 要预留。
- 第 3 节的双实例检验会让「思想」层比预想的窄——很多看似通用的东西只能举出一处，
  它们是方法。这是有意的：思想层稀少才有权重意义。
- 第 2 节的「反向练习」是一种新题型（只问思路不求解答），引擎无法判分，需要人工
  给出参考答案让使用者自比。这与 ADR 0001 的「只判不算」不冲突——它连算都不算。
- 第 5 节的否决式判据会砍掉大部分通俗数学史材料，**历史内容同样不能靠改写现成
  读物**，与 ADR 0004、0005 的结论叠加。
