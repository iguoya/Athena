# ADR 0003：经世致用是总纲；建模独立成线，考试只是约束

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0002（思想、直观与现实闭环是主线）
- 精神对齐：主仓库 `AGENTS.md`「教学方向由知识点和教学大纲主导」、
  `docs/CODE_ROLES.md` 的边界意识

## 背景

ADR 0002 把思想与现实闭环提为主线，但仍把「通过考试」与「理解思想」并列为双重
目标。实际使用者的立场比那更彻底，需要在此记录清楚，否则后续内容编写会不断
回到应试惯性。

### 1. 使用者的立场

所学知识要**服务现实**——用来认识世界、改造世界，解决现实问题、提升对现实的
认知。明确摒弃三样东西：

- 把学问的最高目标定义为**发论文**；
- **以脱离现实为高洁**的治学态度（点名哈代，与魏晋清谈、程朱理学空疏的一面并举）；
- 把知识当**晋身工具**，为文凭而学，用完即忘。

对考试的批评是：重计算轻思想，偏难怪题对认识现实毫无用处，把数学封闭化、
小圈子化。

这条立场在思想史上有原型——明清之际顾炎武、王夫之、黄宗羲对理学空疏的批判，
颜李学派主张习行、反对静坐读书。Athena 一贯的「学练合一」正是同一脉络。

### 2. 一个必须同时守住的事实

哈代 1940 年断言数论永远不会有实际用途；今天数论是全球金融与通信的基础设施。
非欧几何当年是纯逻辑游戏，现在 GPS 不做相对论修正每天偏差以公里计。

**这个事实支持而非削弱使用者的立场**：它证明「无用」是个不可靠的判断，人在预判
什么知识有用这件事上历史成绩很差。该批评的是哈代**以无用为荣的态度**，不是他
做的数学。

因此「批评脱离现实」与「保留抽象内容」不冲突，但需要一条精确的取舍判据，
见决策第 4 节。

### 3. 不对称：建模比求解难，而考试只考求解

考试递来的是**已经抽象好**的题目。现实递来的是一团混乱：哪些因素重要、忽略
什么、用什么模型、假设是否成立，全要自己决定。

这一步是真正的数学意识，也恰恰是符号引擎帮不上忙的地方——SymPy 只会求解。
使用者感到的「封闭」，本质就是这一半被砍掉了。

## 决策

### 1. 考试降为约束，不再是目标之一

**目标函数**：用数学认识与改造现实。
**约束条件**：通过研究生入学考试数学。

约束需要满足，不需要认同。ADR 0002 中「双重目标」的表述作废，AGENTS.md 定位节
同步改为「一个目标 + 一个约束」。

实际收益：刷偏题与学思想不再互相污染。练应试技巧时明确是为过关，不指望它给
启发，因而不会因其无聊而怀疑整件事；学思想时不受考纲限制，不会因「这个不考」
而心虚。

### 2. 应试区显式隔离并标注

纯为区分度存在的题型（特定凑微分的凑法、构造性极强的行列式技巧、技巧考古式的
不等式证明）进入明确标记的**应试区**，不混入主线。

标注文案要诚实说明它为什么存在——它是选拔机制的产物，不是数学的产物。使用者
练它时心里清楚自己在做什么，这本身就减少消耗。

界面文案仍受 AGENTS.md 约束，不出现「考研」字样；用「过关训练」一类中性说法。

### 3. 建模独立成线，由问题组织

新增一条与考纲**并行且独立**的建模主线。组织顺序由**问题**决定，不由章节决定；
需要什么数学就调什么数学，允许并鼓励跨章。

**禁止**用「每个知识点挂一个应用例子」冒充这条线——那是装饰，练的仍然是求解。

这条线必须包含从现象到模型的那一步：哪些因素保留、哪些忽略、假设在什么范围内
成立、结论何时失效。**只给数据让人算结论的，不算建模。**

候选主题（跨章性质是选择理由，不是巧合）：

| 问题 | 汇合的内容 |
|---|---|
| 复利、人口、传染病早期为何同形，后来又为何都不是指数 | 一阶微分方程、logistic、极限行为 |
| 一堆散点里怎么找规律 | 线代的投影、微积分的极值、概率的回归（三科汇合） |
| 为什么 99% 准确的检验仍会大量误诊 | 条件概率、贝叶斯 |
| 网页/节点的重要性怎么定义 | 特征值、马尔可夫链稳态 |
| 三体问题为何没有解析解 | 混沌；打破「数学＝算出精确答案」的错觉 |

每条产出**可留存物**：能跑的模型、一张图、一个记下来的结论（ADR 0002 第 2 节）。

### 4. 取舍判据：砍掉它，后面会不会塌

判断一处抽象内容该留该砍，**不问「它现在有没有应用」**（第 2 节已说明这个问题
人类判断不可靠），而问**「砍掉它，后面的内容会不会塌」**。

- **留**：ε-δ（极限、连续、导数、积分的严格定义全建在上面）、线性空间的抽象
  定义（让人看出函数空间、解空间、多项式空间是同一回事）。它们的用途不在第一层，
  但是地基。
- **砍**：不支撑任何后续内容、只用于出题的纯技巧——这类进应试区（第 2 节），
  不进主线。

这条判据守住地基，同时不给「为抽象而抽象」留口子。

## 后果

- ADR 0002 的「双重目标」表述被本 ADR 取代；两份文档需保持一致，AGENTS.md 已同步。
- 建模主线与考纲主线并行，内容量增加，且建模线的编写难度高于讲解线——它要求
  作者自己先完成一次从现实到数学的抽象，不能靠改写教材。
- 应试区的存在是自觉的妥协，不是失败。它被隔离和标注，正是为了不让它污染主线。
- 第 4 节的判据可能被误用为「凡抽象都留」。审稿时要反向检查：留下的每处抽象，
  都要能指出它具体支撑了后面的哪一节。指不出来的，说明它属于应试区。
