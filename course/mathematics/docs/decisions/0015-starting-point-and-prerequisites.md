# ADR 0015：显式声明学习者起点；前置基础独立成层并按需诊断

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0007（范围标记）、0012（三遍）、0013（信心）
- 修正：ADR 0007 的 `scope` 取值、`docs/REFERENCES.md` 第六节的资源推荐

## 背景

前十四份 ADR 讨论了教什么、怎么教、按什么顺序教，但**从未显式声明假设学习者
已经会什么**。默认的隐含起点是「标准考研生」——高数线代都学过一遍，现在来复习。

使用者指出这个假设不成立：**他的基础较差，需要从更基础、更直观的概念学起。**

同时他对主流考研网课提出两条批评，两条都成立且直接影响本项目：

1. **长篇大论在解题技巧** —— 正是 ADR 0003、0004、0006 摒弃的方向；
2. **讲课过程中各种 PUA** —— 「这都不会你还考什么研」这类话术制造的正是
   ADR 0013 要消灭的归因：把卡住归因于「我笨」。这是放弃的最短路径。

**起点不同，路线就不同。** 对已经学过一遍的人有效的路径，对基础薄弱的人是劝退。

## 决策

### 1. 起点假设必须显式写明

本应用的目标学习者起点：

- **不假设**高数、线代学过或记得；
- **不假设**中学代数、三角、函数图像仍然熟练；
- **只假设**能做四则运算、能看懂坐标系上的点。

任何内容编写都以此为准。需要更高前置的地方，要么补前置，要么在 `requires` 里
显式声明依赖，**不得默认读者会**。

### 2. `scope` 增加第四类：`prereq`

ADR 0007 定义了 `math2` / `math1` / `beyond`，现增加：

| 标记 | 含义 | 处理 |
|---|---|---|
| **`prereq`** | 考纲不考，但不补就学不下去的前置基础 | 独立成层，**按需补**，不计入应试要求 |

它与 `beyond` 的区别：`beyond` 是「学有余力才看」，`prereq` 是「不补就卡住」。
两者都不考，方向相反。

### 3. 前置基础清单（起始版）

| 前置 | 后面哪里会卡住 |
|---|---|
| 函数与图像（定义域、值域、单调、奇偶） | 极限、导数、一切函数性质题 |
| 坐标系与平面几何直观 | 线性变换、二重积分区域、几何应用 |
| 三角函数（定义、图像、基本恒等式） | 三角极限、换元积分、级数 |
| 指数与对数（运算律、图像） | 求导公式、微分方程、增长模型 |
| 数列与求和记号 | 极限定义、定积分的黎曼和 |
| 不等式与绝对值 | ε-δ、收敛判定、放缩 |

清单会随编写过程增补——**遇到「这里其实需要某个前置」就补一条，不预先穷举**。

### 4. 按需诊断，不从头重学一遍

**基础差不等于所有基础都差。** 要求把上述六项从头学一遍，既浪费时间又打击信心。

因此提供**前置诊断**：每项 2–3 道题，只判「需不需要补」，不打分、不排名。
诊断结果只用于把对应的 `prereq` 节点插入学习路径（ADR 0008 的先修图），
不产生任何评价。

诊断本身的呈现须遵守 ADR 0013：不显示「正确率」「你的水平」这类标签，
只显示「这一项建议先补 / 可以跳过」。

### 5. 明令禁止 PUA 式表达

ADR 0013 第 1 节的禁用词表针对的是数学写作的毛病（「显然」「容易看出」）。
本节补充**另一类**必须禁止的表达——针对学习者本人的贬低或施压：

| 禁止 | 例 |
|---|---|
| 贬低读者能力 | 「这都不会」「这么简单还错」 |
| 用他人施压 | 「别人都会了」「这题百分之九十的人都对」 |
| 用后果恐吓 | 「这都掌握不了就别想考上」「现在还不会就晚了」 |
| 制造稀缺焦虑 | 「只剩 X 天了」「再不抓紧就来不及」 |

与 ADR 0013 的禁用词表一样，这些**可机械扫描**，并入同一个 lint 步骤。

理由不只是体验：ADR 0011 已论证外部压力挤出内在动机，而 ADR 0013 已论证
「归因于我笨」直接导致放弃。PUA 同时触发这两者。

### 6. 资源推荐随起点调整

`docs/REFERENCES.md` 第六节原把「B 站考研网课 + 辅导讲义 + 真题」列为主力，
**该建议基于错误的起点假设，现予修正**：那条路径适用于已经学过一遍、
现在来复习的人，对本应用的实际学习者是劝退。

调整后的第一遍主力见 REFERENCES.md 第七节。

## 后果

- 内容量增加一层（`prereq`）。但按第 4 节只补诊断出的缺口，实际增量可控。
- `requires` 先修图需要包含 `prereq` 节点，拓扑排序随之变化（ADR 0008 第 1 节）。
- 第一章「二维线性变换」的选择在新起点下**更加正确**：零先修、看得见、
  不需要任何代数基础（ADR 0008 第 4 节的判断成立）。
- 高数起点需要重新考虑：在新起点下更不能以「函数、极限、连续」开局，
  须先经过函数与图像的 `prereq` 层。
- 本 ADR 把「起点假设」写成显式条款。**今后若起点变化（例如第一遍走完后基础
  已经补齐），应新开 ADR 修订，而不是让假设继续隐含。**
