# ADR 0007：先做数学二；范围用标记表达，不做物理删除

- 日期：2026-09-13
- 状态：已接受
- 依赖：ADR 0003（考纲决定覆盖下限，不决定上限）、0006（四层权重）

## 背景

使用者决定：**先考虑数学二，以后再考虑数学一**。

这是本应用第一个确定的硬性范围约束。处理方式有两种：按数学二裁一份内容，
以后加数学一时再补；或者内容带范围标记，课表按标记筛选。选前者会在扩展时
大面积返工，因此本 ADR 选后者。

另需澄清一个常见误解：**数学二不是数学一的子集**——曲率与曲率半径是数学二考、
数学一不考。所以不能用「数学一减掉几章」的方式生成数学二范围。

## 决策

### 1. 内容带 `scope` 标记，不物理删除

`content/curriculum.json` 中每个知识点标注 `scope`：

| 标记 | 含义 | 当前处理 |
|---|---|---|
| `math2` | 数学二考纲内 | 主线，计入应试要求 |
| `math1` | 数学一考、数学二不考 | 暂不编写；结构预留，不删不改 |
| `beyond` | 两者都不考，但按 ADR 0003 第 4 节判据应保留 | 进建模线或思想线，**不计入应试要求** |

课表按当前科目筛选展示。以后开数学一，改筛选条件与补 `math1` 内容即可，
已写好的 `math2` 与 `beyond` 内容零返工。

### 2. 数学二范围（编写起点）

> **免责与维护要求**：下表依据公开考纲整理，考纲细节可能逐年微调。
> **每年招生简章发布后核对一次**，以最新官方大纲为准；本表只作编写起点，
> 不作为权威依据。

**分值结构**：高等数学约 78%、线性代数约 22%、**不考概率论与数理统计**。

#### 高等数学（`math2`）

| 模块 | 范围 |
|---|---|
| 函数、极限、连续 | 全部 |
| 一元函数微分学 | 全部，**含曲率与曲率半径**（数学一不考此项） |
| 一元函数积分学 | 全部，定积分应用含物理应用（功、压力、质心形心等） |
| 多元函数微分学 | 偏导数、全微分、复合与隐函数求导、极值与条件极值（拉格朗日乘数法） |
| 多元函数积分学 | **仅二重积分** |
| 常微分方程 | 一阶（可分离变量、齐次、一阶线性）、可降阶的高阶、二阶常系数线性 |

#### 线性代数（`math2`，与数学一**范围相同**）

行列式、矩阵、向量、线性方程组、特征值与特征向量、二次型。

**这意味着线代内容以后开数学一时零返工**，可放心按 ADR 0004 的线性变换主线
一次写到位。

#### 数学二不考（标 `math1` 或 `beyond`）

- 向量代数与空间解析几何
- **无穷级数**（整章）
- 三重积分、曲线积分、曲面积分
- 方向导数与梯度；空间曲线切线与曲面法平面
- 伯努利方程、全微分方程、欧拉方程
- 概率论与数理统计（整科）

### 3. 不考但保留的内容，及其理由

按 ADR 0003 第 4 节判据（**砍掉它，后面会不会塌**）逐项裁定，不是一律照考纲砍：

| 内容 | 裁定 | 理由 |
|---|---|---|
| **方向导数与梯度** | `beyond`，**保留在建模线** | 「最陡上升方向」是理解多元微分的自然终点，也是一切优化与机器学习的基础。砍掉它，多元微分学只剩计算 |
| **泰勒公式** | `math2`，**重点** | 数学二考泰勒公式（有限项＋余项）。ADR 0002 中「用多项式局部逼近」的思想由它承载 |
| **泰勒级数 / 幂级数** | `math1` | 无穷级数整章不考；逼近思想已由泰勒公式覆盖，不展开 |
| **贝叶斯与条件概率** | `beyond`，**保留在建模线** | ADR 0003 已列为建模主题（99% 准确的检验仍大量误诊）。它是「数学意识」最好的例子，与考不考无关 |
| **三重积分及以上** | `math1` | 「累积」的思想已由二重积分完整承载，不再展开 |
| **空间解析几何** | `beyond`，**按需最小量补** | 二次型的主轴与特征向量需要一点空间直观（ADR 0005 第 2 节：低维先于一般）。只补这点，不成章 |

**保留项一律不计入应试要求**（ADR 0005 防线二只约束 `math2` 内容），使用者在
时间紧张时可以跳过而不影响过关。

### 4. 对前几份 ADR 中举例的修正

前面 ADR 举例时未限定科目，以下几处需按本 ADR 理解，**不改动原 ADR 决策**：

- ADR 0005 第 3 节以**梯度**作「图像与符号并置」范例 → 该范例仍成立，但归
  `beyond`（建模线），不是应试内容。同层次的 `math2` 范例改用**曲率**
  （符号是那个分式，图像是「最贴合的圆有多大」）。
- ADR 0002、0006 提及**泰勒展开** → 在本应用指**泰勒公式**，不是泰勒级数。
- ADR 0003 建模主题「散点找规律」三科汇合 → 数学二下线代的投影与微积分的极值
  两支在考纲内，概率回归一支归 `beyond`，该主题整体仍成立。

### 5. 编写顺序

高数占 78%，但**线代零返工**且 ADR 0004 已为它定好线性变换主线。

因此先写线代主线的第一章验证整套 ADR 是否可执行（内容形态、标记机制、
思想标注、应试区隔离），再转入高数大头。第一章的具体选择另行决定。

## 后果

- `content/curriculum.json` 的 schema 需要 `scope` 字段，且课表加载需支持按科目
  筛选。这是本 ADR 唯一的技术性要求。
- `beyond` 内容会让实际编写量大于考纲——这是 ADR 0003 目标函数的直接代价，
  自觉接受。但它们不计入应试要求，时间紧时可跳过。
- 第 2 节的范围表有时效性，**必须每年核对**。把它写在 ADR 里而非代码里，正是
  为了让这次核对是一个明确的文档动作。
- 以后开数学一时，本 ADR 状态改为「部分取代」，另写新 ADR 说明双科目并存的
  课表组织，不修改本文的历史记录。
