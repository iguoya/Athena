# ADR 0015：北极星改用 Web 壳重写，内容契约校验迁出 C++

- 日期：2026-10-06
- 状态：已接受
- 修订：ADR 0013（决策 5「用满 Qt 6 桌面栈，不做成浏览器套壳」；决策 2 里列举的 Qt 专有能力；决策 7 里「不做 QML 热重载」一句）、ADR 0007（决策 1–5 的实现机制；「运行时只有一个进程」的要求保留）
- 相关：ADR 0002（内容契约）、0012（指南针）、0014（阶段分层）、仓库级 ADR 0046、0047、0049、0051、0054、0057、0062、0065

## 背景

北极星现在是 Qt 6 Quick / QML（约 3200 行）加 C++20（约 1300 行）加 CMake。ADR 0013 当时押注的是「桌面栈能力用满」，并明确不做浏览器套壳。回头看，这个押注没有兑现成读图上的优势，反而留下了三类成本：

- **图本身很小，用不到 Qt 的重能力。** 现在是 17 张图、125 个节点、138 条边、5 条跨图边，单张最多 20 个节点；界面是节点卡片、连线和专页。这些 Web 的 DOM / SVG 都能承载，而排版、动效、配色迭代在 Web 里快得多。
- **迭代成本高。** 要装 Qt（`app.json` 里写死了 `C:/Qt/6.8.1` 等候选路径），改一行 QML 要重启（ADR 0007 的取舍），调色要重编。使用者对现有暗色基调（窗口底色 `#07151A`）也不满意，认为不够明快。
- **内容契约的守门员藏在 C++ 里。** 这一条是本次迁移前才查到的：`scripts/check.py` 自己只校验 JSON 语法和吸收契约（`check_json`、`check_absorption`），然后调 CMake 和 ctest；真正的契约校验——relation 取值、`requires` 与虚线来路、出处引用、阶段与 `stage_reason`、先修不得指向更高阶段等，约 46 处错误分支——全部在 `PolarisCatalog::validateDocument` 里，应用启动时也会再跑一遍，并靠 `tests/polaris_catalog_test.cpp` 的 9 个用例在 ctest 里守。**弃 Qt 而不迁出校验，契约就没人守了。**

ADR 0013 的**目标**没有错：图谱就是产品，表达深度与可视化是一等目标，内容正确是底线。错的是把「用满 Qt」当成手段。本 ADR 只换手段。

## 决策

1. **壳与前端：Tauri 2 + React 19 + TypeScript（Vite），样式用 Tailwind 4，动效用 Motion，图面以 SVG + DOM 承载。** Rust 端只做壳（单实例、窗口），不碰内容。图面的交互库（React Flow、d3-zoom 或自写）、动效细节、具体色板都由实现选择，不属于架构边界，不在本 ADR 里定。按仓库级 ADR 0057，判据是合不合适，不是好不好装；按 ADR 0062，不因为别的应用用了什么而选。

2. **内容单一来源不变，契约校验迁入 `scripts/`。** `content/polaris.json` 与 `content/sources/catalog.json` 仍是唯一内容来源，前端直接导入，不复制、不在代码里再硬编码节点和边。契约校验用 Python 重写为 `scripts/contract.py`，由 `scripts/check.py` 调用，成为**唯一**的校验入口；应用运行时不再重复校验，前端只用 TypeScript 类型描述形状。迁移顺序是硬约束：
   1. 先移植，并让新旧两套校验在同一份内容上结论一致，**再**退役 C++；
   2. 现有 9 个领域用例里和内容有关的断言迁成 Python 断言（例如「只开放 4 张学术图」「每个节点都带自己的实践」）；
   3. 旧校验只有在真实内容上通过是不够的，每一类规则至少补一个构造出来的反例（删出处、`requires` 指向更高阶段、`stage` 缺 `stage_reason` 等），确认它真的会失败；
   4. 在迁移完成之前，`legacy-qt/` 里的 C++ 测试仍是守门员，不能先停。

3. **布局与派生状态写成与视图无关的纯 TypeScript，带单元测试。** 现有 `layoutByStage` 的规则（按阶段分桶、桶内按必要程度再按原顺序）和 `layoutGraph` 对「同一份内容在三个平台得到同一位置」的确定性要求保留；阶段解锁、可打开的图这类派生量同样放在这一层。视图只读它的输出，不自己推导。单元测试用 Vitest。

4. **单实例保留要求，换机制；热重载由工具链提供。** ADR 0007 的目标「永远只有一个北极星窗口，第二次启动请第一份前置」不变，机制改为 `tauri-plugin-single-instance`；`QLocalServer`、陈旧套接字清理等 Qt 专有部分随之作废。「不做热重载」作废：Vite 的热更新是工具链现成的，不由应用自己维护。`dev.prepare` 对「增量构建、不得清空 `build/`」的约束也随 CMake 一起结束。

5. **启动方式：仍只声明、不打包。** `app.json` 的 `dev` 块改为 `npm run tauri:dev`，就绪用 http 探测，端口取 1470（1420–1460 已被占用）；`prepare` 在 `node_modules` 缺失时安装。启动器和编排器不改（ADR 0046）。图标沿用 `icon.svg` 派生（ADR 0065）。

6. **重组授权与边界。** 使用者于 2026-10-06 明确：在尊重大局方向的前提下，界面结构、交互模型、状态管理、内容的加载与布局方式，凡是不合理、实现繁杂、逻辑不清的地方，可以改写，**不以 QML 现有的控件清单、页面划分、交互手势为模板**。这是 ADR 0013 决策 3（允许推翻当前页面）的延伸，具体落实为：移植的是「读图要回答的判断」（ADR 0013 决策 4），不是「控件」。
   - **大局方向不变**：北极星是其他学习应用的指南针（ADR 0012）；内容正确是底线（ADR 0013 决策 1）；不加入学习进度、掌握度、岗位匹配分数、账号、网络同步，也不启动其他 Athena 应用。
   - **内容本身不在本授权之内，仍受 ADR 0054 约束**：节点与边的内容、`id`、真先修、阶段、出处，一个 `id` 只装一个东西，不改嫁；字段的重命名、合并或删除不属于「编写方式」，要先另行决定。这不是 ADR 0080 的重组豁免，也没有声明过豁免。
   - **开放范围不变**：只有 `view_kind` 为 `academic` 的 4 张图（`computer-science`、`electronic-information`、`computer-practice`、`electronic-practice`）可打开，其余 13 张仍保留在内容里、界面锁住（ADR 0012）。新版保持同样的可打开范围。

7. **平台。** 以 macOS 和 Windows 为准；Linux 上的 WebKitGTK 停在如实降级提示，不为它写平台分支（仓库级 ADR 0049、0051）。

8. **旧 Qt 代码的退役。** 动手前打 tag `pre-web-polaris`；`qml/`、`src/`、`CMakeLists.txt`、`tests/` 整体 `git mv` 到 `legacy-qt/`，不再参与构建；`app.json` 立即指向新版。**`legacy-qt/` 保留到新版覆盖了上述 4 张可打开的图和节点专页，并且决策 2 的校验迁移完成**，之后单独一个提交删除。

## 后果

- Qt 6、CMake 不再是北极星的依赖；`app.json` 里的 Qt 路径候选删除，`scripts/check.py` 里的 CMake 与 ctest 步骤改为前端构建、Vitest、`cargo check` 与 `scripts/contract.py`。
- ADR 0013 的目标和决策 1、3、4、6 继续有效。决策 5 不再适用，**「用满 Qt 栈」「Quick 3D」「原生暗色窗口」都不能再当理由**；如果将来需要三维表达，评估的是 Web 的方案，另行决定。
- WebView 在 macOS（WKWebView）和 Windows（WebView2）上渲染有差异。图面主体用 SVG / DOM，避免依赖重的滤镜；ADR 0013 决策 7 的验收要求不变：必须在 macOS 或 Windows 上真实打开窗口去拖、悬停、选点、进专页，构建通过不等于读图成立。
- 多一个 Tauri 应用意味着多一份约几 GB 的 `src-tauri/target`（`dsa`、`gtkmm` 现在各约 2.3 GB）。这是各应用构建隔离（ADR 0063）的已知代价，不为此改壳。
- 迁移期内容由 `legacy-qt/` 的 C++ 测试和新增的 `scripts/contract.py` 同时看守，直到决策 2 的四步做完。迁完之后，`scripts/contract.py` 是仅有的一份契约校验，新增规则只改它。
- 本 ADR 落地时同步更新 `AGENTS.md` 的「技术与目录」与「验证」两节。`AGENTS.md` 里「两章课程图、28 个节点、体系 / 实操地图」的内容现状描述早已过时（ADR 0054、0082 之后实际为 17 张图、125 个节点），与本次换壳无关，另起文档提交修正。
