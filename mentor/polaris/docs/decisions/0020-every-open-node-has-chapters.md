# ADR 0020：开放地图里的每个节点都细化到章节

- 日期：2026-10-06
- 状态：已接受
- 修订：ADR 0019 决策 4（「五条纵深路线用到的节点必须全部有章节」）扩大为全部开放地图的节点；ADR 0019 的其余决策不变
- 相关：ADR 0014、0018、0019；仓库级 ADR 0043、0054

## 背景

ADR 0019 把五条纵深路线用到的节点细化到章节后，使用者要求把其余路线用到的节点也补上。查实：路线引用的 66 个节点里只剩 9 个实践主干节点没有章节，开放地图里另有 2 个（端到端数据管线、操作系统与网络接口）也没有。把这 11 个补齐，开放地图的全部节点就都有章节了，没有必要再留「哪些有、哪些没有」的例外。

## 决策

1. **开放地图（academic、codesign、frontier）的每个节点必须有章节**，格式与规则同 ADR 0019。由测试守着，新增节点时必须同时写章节。
2. **给这 11 个节点追加出处。** 它们原有的出处多是课程方案与机构资料，没法支撑章节级的引用。因此在节点上**追加**目录里已有的权威来源（教材、官方文档、规范、工具手册），关系用补充说明 `see_also`；章节的 `ref` 引用这些来源。只加不改，原有出处原样保留（ADR 0054）。
3. 其余沿用 ADR 0019：章节按学习顺序排、先修只指向前面的章、最后一章是做出来的验收。

## 后果

- 契约不变（章节规则已在 ADR 0019 里写好）；测试从「纵深路线的节点有章节」扩大为「所有开放节点有章节」。
- 11 个节点各多了一批 `see_also` 出处，原有的 `adapted` 出处不动，跨应用的出处检查仍然达标。
- 以后新增开放节点，节点与章节一并提交，不再分两步。
