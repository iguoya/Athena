# ADR 0017：取消阶段解锁，初级 / 中级 / 资深默认全部可看

- 日期：2026-10-06
- 状态：已接受
- 修订：ADR 0014 决策 2 中「原则上一个阶段没解锁，不应该学习高阶课程」「默认锁住更高阶段、点锁住的课只能查阅」的关卡部分，以及决策 5 中「更高一层默认锁住，完成当前层主干后才解锁下一层」；阶段分层本身与 `stage` / `stage_reason` 不变
- 相关：ADR 0012、0014、0015、0016

## 背景

ADR 0014 把阶段当成关卡：默认只瞄准初级，中级与资深带锁，要手动「解锁下一阶段」，理由是指南针不该让人跳层。新版界面（ADR 0015）按这条实现之后，使用者看过并明确要求：**默认全部解锁**。

关卡在一张只读的图上也确实说不通：北极星不记进度、不判分（ADR 0012），所谓「解锁」只是一次点击，它不能证明谁打完了前一阶段，却让一半的图在第一屏就变灰，读图的人先要和界面斗一下才能看见全局。

## 决策

1. **阶段只是列与标签。** 初级、中级、资深三档照旧分列、照旧写 `stage_reason`，但默认全部可看、可点，没有解锁关卡，也没有「锁」这个界面状态。
2. **「该先学什么」靠先修与路线表达，不靠关卡。** 强先修仍由 `requires` 守（不得指向更高阶段，契约照旧）；顺序建议由路线的阶段给出（ADR 0016）。
3. 内容不变：`stage` 是必填的分级字段，阶段分层布局不变。

## 后果

- 界面里删掉解锁按钮、节点锁标记与抽屉里的未解锁提示；store 里不再有瞄准阶段的状态。
- 以后若又想要某种学习门槛，应当落在「记录由作答产生」的应用里（仓库级 ADR 0052），不放回这张地图上。
