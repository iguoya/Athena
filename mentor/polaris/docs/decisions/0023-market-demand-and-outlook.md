# ADR 0023：就业需求度改称市场需求度，新增「技术发展前景」维度，并用它重新审视路线的推荐

- 日期：2026-10-07
- 状态：已接受
- 修订：ADR 0022（决策 1 的第六个维度改名并放宽口径；维度由六个增为七个；决策 7 的推荐等级增加「技术发展前景」作为参照）
- 相关：ADR 0021、0022；仓库级 ADR 0054（宁增勿删，`id` 不改嫁）

## 背景

使用者指出两点：一是「就业需求度」应改为「市场需求度」；二是要从「技术发展前景更好」这个角度来评判。

第一点的道理在于：岗位数量只是需求的一个侧面，一项技术的需求还体现在产品、项目与行业的规模上（例如新能源、电动车、工业数字化的市场规模，并不等于招聘帖的数量）。把它叫「就业需求」，既窄，也容易被读成「学完能找到工作」，这正是 AGENTS.md 要避免的暗示。

第二点补的是时间方向：前六个维度回答的是「今天这项知识怎么样」，没有回答「它往后怎么样」。一项技术今天需求大、但正被替代，和今天需求中等、但处在快速成长期，对选方向的人意义不同。

## 决策

1. **第六个维度改称「市场需求度」。** `id` 仍是 `demand`（不改嫁，已有的评级与引用不动），只改显示名与口径：在典型技术岗位的公开要求里，以及在产品、项目与行业应用的规模上，这项技术被需要得有多普遍；仍是评估日期当时的估计，不是统计，不暗示录用。五级名称改为：小众、偏小、一般、较大、很大。
2. **新增第七个维度「技术发展前景」，`id` 为 `outlook`，编辑评估。** 回答：这项技术在未来数年的发展态势如何。五级：萎缩（正被替代，新项目很少）、成熟（技术稳定，增量有限，以存量维护与渐进改进为主）、稳健（稳定增长或长期有效，演进渐进）、看好（增长明显，技术在持续演进，投入在加大）、前景广阔（处于快速成长或重大变革期，是多个新兴行业的支撑技术）。基础性、长期有效的知识（电路、数学、操作系统）评「稳健」，不因为它不「新」而被压低，也不因为它长期有效而被抬高。
3. **前景是时点判断。** 与市场需求度一样写 `as_of`，依据逐条写出（技术趋势、行业投入、被替代的迹象），随时间重评。「前景好」不等于「好学」或「好找工作」，也不是对个人的建议。
4. **路线的汇总评级自然包含新维度**（由节点汇总，契约重算，规则同 ADR 0022 决策 6）。
5. **推荐等级把前景作为参照之一。** 路线的 `verdict` 仍是编辑评估，不是算出来的分数；判断时除了原有的参照，还看市场需求度与技术前景汇总的强弱。前景好但前置多的方向保留「进阶」，并在依据里写明；市场与前景都在上升、门槛适中的方向可上调。弱电优先（ADR 0021）的约束不变。
6. **总览新增「技术前景最好的方向」。** 按路线的技术前景汇总评级从高到低列出（≥4 级），同级按推荐等级排序；这是对已有评级的另一种排列，不引入新的编辑判断。
7. **只增不删。** 新增 `outlook` 维度、节点与路线的对应评级、契约与界面的相应变化；`demand` 的 `id` 与已有 `level` 保留，仅对市场口径下明显不同的几个节点复评并改写依据。

## 后果

- 契约：维度列表为七个，顺序为实用性、实践性、理论实用性、可验证性、学科核心骨干、市场需求度、技术发展前景；节点与路线都必须写齐。
- 内容：140 个开放节点新增 140 条前景评级与依据；市场需求度对少数节点复评。
- 界面：着色条多一个维度；迷你条与抽屉评级区为七项；总览多一个「技术前景最好的方向」区块。
- 风险与缓解：前景评估主观性比其他维度更强。缓解办法同 ADR 0022：口径明文、依据逐条可见、标「编辑评估」与评估日期，不合成总分，不据此删节点。
