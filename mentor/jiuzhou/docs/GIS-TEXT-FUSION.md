# 先进 GIS × 史书数字化：九州的融合路线

使用者要求（2026-10-14）：充分利用 GIS 的先进技术，与中国古籍/史书数字化成果结合。本页是路线与取舍；
调研见 `DESIGN-REFERENCES.md` 第五节，概念验证见 `poc/text-geo-anchors.md`。

## 一句话
**让每一句史料都能落到一个时空坐标上，让每个地点都能回到它被写进史书的那几句话。**

| 成果 | 内容 | 获取 | 备注 |
|---|---|---|---|

## 融合的三条线

### 线 A：文→图（史料锚定）
事件 `source` 里的原文 → 词典匹配地名（places + CHGIS 政区名，按事件年份过滤）→ 每句话得到坐标锚点 → 界面里原文旁出现「文中地名」，点击飞到地图；反过来，点地图上的地点可看到「史书怎么写它」。
**不用机器学习**：最长匹配 + 年份过滤 + 人工确认，每个锚点都能回溯到原文那一句，符合出处底线。

### 线 B：人→图（CBDB）
给我们的 77 位人物挂 CBDB ID → 籍贯、任官地、行迹带时间；地点剖面显示「此地出身/任官的人物」，按朝代统计成「人才地理」密度图。需要 CBDB 的 `addresses` 表有坐标且能对到 CHGIS（待核）。

### 线 C：地理空间技术（让「为什么」可计算）
- **PMTiles 矢量瓦片**：把学术层、疆域、地名点打成单文件瓦片，MapLibre 直接读，冷启动与大数据量都更稳（T-032 先做基准，不盲目迁移）。
- **最小成本路径 / 等时圈**：以粗 DEM + 水系为成本面，复用 T-029 的日行程常数，回答「从长安出发步兵 10 天能到哪」，这是 ORBIS 思想的落地（T-033 原型）。
- **时空聚合**：事件、人物按「地点×时代」做核密度/六边形聚合，随年份滑块变化（后续）。
- **谭图扫描件叠加**：已纠正的谭图栅格作可选对照层，带不透明度滑块（后续，工程量大）。
