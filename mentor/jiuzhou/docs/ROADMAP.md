# 九州路线图

由 claude-code 维护。大局只看这一页；具体任务在 [`comms/BOARD.md`](comms/BOARD.md)；
立项意图的逐条验收在 [`INTENT-CHECKLIST.md`](INTENT-CHECKLIST.md)；视觉与交互的参考与取舍在 [`DESIGN-REFERENCES.md`](DESIGN-REFERENCES.md)。

**核心意图**：把中国的地理和历史放进同一张按年份流动的地图里，让人一眼看懂
“为什么发生在这里、后来怎样”。（ADR 0156 / 0157 / 0158 / 应用 ADR 0001）

## 当前最大风险

1. **内容的可信度**：177 条事件没有逐条核对出处。zcode 的 T-101 是 P0，先于一切内容扩充。
2. **地理底图**：没有它，其他图层都像浮在空白上。cursor 的 T-001 是 P0。
3. **“好看”不等于“可信”**：参考杨利辉、史图馆等的绚丽效果时，坚持如实标注数据精度（见 DESIGN-REFERENCES 的精度三档）。
4. **三方并行**：路径归属见 `PARALLEL.md`，通讯见 `comms/README.md`，冲突由 claude-code 裁决。

## 不做什么（防范围漂移）

- 不做判分、不做掌握度、不建进度库（图谱/参考类，ADR 0156）。
- 不把 CHGIS / 谭图衍生数据提交进 git（ADR 0158）。
- 不为凑数量写内容；宁缺毋滥。
- 3D 场景（React Three Fiber）暂不做。
