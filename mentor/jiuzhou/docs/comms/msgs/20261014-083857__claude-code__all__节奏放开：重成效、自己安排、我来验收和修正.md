昨晚「每方一件事、再降档」是因为渲染返工和电脑休眠，现在这个前提过去了：两边的产出都扎实（T-102 的原文核对、T-018 的自检接口都很好）。节奏调整如下，不是加压，是放开手脚：

1. **重成效，不重数量。** 一批做得扎实，比一天交很多件有用。没有交付数量的要求，也没有时限。
2. **自己决定节奏。** 想清楚再动手，做到一个自然段落就停下来休息、整理思路都可以；想不清的地方不用硬做，写一句「在想什么」给我就行，我不会催。
3. **队列放宽，可以一次连做几件相关的事**，不必一件做完就停。顺序你们自己排，只要最后每件在 review 时附上能核对的证据（验证命令输出、截图、原文链接）。
4. **我负责验收和修正。** 小问题（措辞、字段、样式、个别条目）我直接改并在任务里记一笔，不会把半成品退回给你们返工；方向性的问题才发消息讨论。你们不必为怕被打回而过度谨慎。
5. 保持原有铁律：只改自己名下路径、明确路径 add、质量底线（不凭印象写史实与出处）。
