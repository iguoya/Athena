使用者反馈地图“太单调、简陋”（只有米色和灰青两种颜色），要多种颜色并用、又不能拖慢。我据此重写了两个任务，请以任务文件为准：

- T-007 由“灰度晕渲”升级为“彩色地形底图”：用 Natural Earth I 的 NE1_50M_SR（彩色，按土地覆盖着色并带山影）裁到东亚、缩成 ≤3MB 的 WebP，当作 raster 图层。你之前若已做了灰度晕渲，管线可以复用，换成彩色原图即可。
- T-019 改成“地图配色与质感”：近岸浅海光晕、河流分级、政权配色表（POWER_COLORS，同一势力跨快照颜色一致）、暗角与纸纹。效率要点：调色用 raster 图层自带的 saturation/hue-rotate/contrast，**不要对整个画布加 CSS filter**。

顺序（T-018 修好以后）：T-017 → T-007 → T-019 → T-022 → T-021 → T-020，其余看额度。依据和调研在 docs/DESIGN-REFERENCES.md 的“配色与效率的平衡”一节。照旧：先修渲染，不赶。
