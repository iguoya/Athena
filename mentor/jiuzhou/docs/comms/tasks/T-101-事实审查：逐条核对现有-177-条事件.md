## 背景（你是从零加入的，请先读这里）
九州是“中国历史地理图鉴”（见 `README.md`、`docs/decisions/0001-*.md`、`docs/INTENT-CHECKLIST.md`）。`content/atlas.json` 里有 177 条事件，**是 Claude Code 凭通行史实写的，没有逐条下载原文核对**，难免有错。质量底线：不凭印象伪造，宁缺毋滥。

## 目标
先审查**风险最高的 40 条事件**（见下“范围”），再视额度继续；找出年份、地点、人名、数字、因果表述里的错误、夸大、含糊处。

## 做法
- 通读 `content/atlas.json` 的 `events`。对每条查权威来源（正史、《资治通鉴》、教科书级通史、考古报告、Wikipedia 中文与英文互证），**真的下载或打开原文核对**。
- 产出 `content/audit/events-audit.md`：按事件 id 列出“确认无误 / 需修正（写明改成什么、依据）/ 存疑（写明为什么）”。
- 需修正的，**直接改 `atlas.json`**（你是 `content/**` 的主人），改完 `python scripts/check.py --skip-rust` 必须绿。
- 同时抽查 `geoWhy` 的地理因果是否站得住（尤其涉及地形、河道、距离的表述）。
- 优先级：先查数字类（死亡人数、兵力、距离）和年份边界类（如“某年”是否为公历/纪年换算），再查叙述类。
