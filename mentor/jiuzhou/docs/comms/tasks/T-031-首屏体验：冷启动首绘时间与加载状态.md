## 目标
首次打开的第一印象。我实机冷启动 dist 时，页面先出现**数秒只有海色底和零散标签、没有陆地与疆域**的状态，然后图层才陆续画出；期间没有任何加载提示，会让人以为坏了。

## 做法
1. 先量：冷启动（无缓存）到「陆地+疆域+标签都画出」的时间，记录在任务里（浏览器面板在前台时测）；找出主要耗时（19 个学术切片的解析？大 JSON 同步解析？地形 webp？样式重建？）。
2. 针对性优化：学术切片只在需要的年份按需解析（不要启动时全量），大 JSON 放 worker 或分块；首屏先画陆地与当前年快照。
3. 加加载状态：地图区域在首绘完成前显示轻量骨架或进度（与纸本风格一致），首绘完成后淡出；不要闪烁。
4. 目标：典型机器上冷启动首屏完整出图 ≤ 3 秒，切年份 ≤ 0.5 秒（现已满足）。

## 验收
- 任务里写前后对比数字与测量方法；附前后两张截图；`check.py --skip-rust` 绿。
- 隐藏态：`document.hidden` 时不要因为节流产生误判（配合 T-030 第 4 项）。
