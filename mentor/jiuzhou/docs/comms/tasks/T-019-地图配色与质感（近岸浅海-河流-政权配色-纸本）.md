## 背景
使用者反映目前的地图“太单调、简陋”：只有米色和灰青两种颜色。目标：参考网上历史地理讲解（杨利辉、史图馆、舆图类）和 GIS 地形图的做法，**多种颜色并用**，在**效率与绚丽之间平衡**。取舍理由见 `docs/DESIGN-REFERENCES.md`；彩色地形底图在 T-007。

## 配色分层规则（经典分层设色 + 历史地图套色）
1. **海**：基色偏青蓝 `#a9c7cc`；近岸做“浅海光晕”——沿海岸线叠 2–3 层由宽到窄、由淡到浓的青白色带（`line-blur` 约 6–10，宽 14/8/3px，不透明度 0.25–0.5），形成近岸浅水渐变；不需要真实水深数据。
2. **陆地**：由 T-007 的彩色地形提供绿—黄—褐层次，不再单色铺底。
3. **水系**：河流 `#4f86a6`，大河（黄河、长江、淮河、珠江）线宽约 2.4px，其余约 1.2px，各配一层 0.6 不透明度的白色底线（casing）；运河 `#2f6f8f` 虚线；湖泊 `#a7cbd6` 配 `#6b9bb0` 描边。
4. **国界/省界**：现代国界 `#8b7d6b` 细虚线（0.8px），不抢戏。
5. **政权色块（最重要，也是目前最单调的地方）**：
   - 填充不透明度约 0.5 并用 `multiply` 混合，让地形在色块下面仍然看得见；边线用同色系更深一档、1.6–2px；相邻势力之间留 1px 纸色缝。
   - 在 `packages/maps` 里建 `POWER_COLORS`（势力名 → 颜色），**同一势力在不同快照里颜色一致**，同时出现的势力色相差至少 40°。起始建议（可看效果微调）：秦 `#b5483a`、汉 `#e08a3c`、魏 `#4f78b5`、蜀 `#5f9e6e`、吴 `#d1a93b`、唐 `#c2564f`、宋 `#8d63a8`、辽/契丹 `#3e8f9e`、金 `#d0a53e`、西夏 `#7ea35a`、大理/南诏 `#cf6f9a`、吐蕃/乌斯藏 `#9a7d5b`、匈奴/鲜卑/柔然/回纥/蒙古诸部 用草原系 `#a98a5a`/`#8f9a5a`/`#b79a6a`、元 `#3f6fa8`、明 `#b8423f`、清 `#e0b13c`、其余未登记的势力按名字哈希从一个 16 色色盘里取。`content` 里快照自带的 `color` 仅作后备，不再作为主色。
   - 势力名在多边形质心用大字、宽字距、纸色描边（史图馆风格），低缩放时显示、放大后淡出。
6. **文字**：所有 DOM 标签加纸色描边（`text-shadow` 多向 1px，或 `paint-order: stroke`），保证压在彩色地形上也能读。

## 氛围（成本低）
- **暗角**：地图容器上叠一层径向渐变 div（`pointer-events:none`），四角压暗约 12%。
- **纸纹**：一张 <20KB 的可平铺噪点 PNG，`mix-blend-mode: multiply`，不透明度约 0.05。
- 图例旁一个“纸本质感”开关（默认开）关闭暗角与纸纹。
- **不要对整个 GL 画布加 CSS filter。** 调色用图层自带的 raster 色调参数；矢量色块直接定颜色。

## 效率预算
- 本任务新增资源 ≤200KB（不含 T-007 的 ≤3MB 地形图）。
- 平移缩放不得出现明显掉帧；在回报里写测量方式（例如 Chrome Performance 面板录 5 秒平移的平均帧时间）。

## 验收
- 对比截图两张（改前、改后），路径写进回报；
- 前 260 年（战国七雄）、前 100 年（汉与匈奴）、745 年（唐与吐蕃、回纥、南诏、渤海）、1050 年（宋辽夏）四个年份，同屏势力之间**颜色一眼可分**；
- 关掉“纸本质感”开关后暗角与纸纹消失，其余不变。
