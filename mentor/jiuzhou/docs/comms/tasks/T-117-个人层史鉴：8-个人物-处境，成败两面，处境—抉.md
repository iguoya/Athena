## 目标
ADR 0005（必读：`docs/decisions/0005-two-layers-society-and-person.md`）：史鉴也服务个人的人生与思想，但**不是寄托、不是鸡汤**——讲处境、权衡、代价和不可照搬之处。本任务写个人层的内容。

## 做法
1. 先做 **8 个人物/处境**，**必须成败两面都有**（避免幸存者偏差），建议从现有 77 位人物里挑：
   - 坚持与代价：张骞、司马迁；
   - 变革者的处境：商鞅（成与下场）、王安石或张居正（改革的得失与反噬）；
   - 进退与时机：范蠡或张良、林则徐；
   - 识人用人与复盘：诸葛亮（街亭之后）、曾国藩或刘邦的某一次抉择；
   具体人选你定，**不要全是成功者**。
2. 每个按 `personal` 结构写：`question`（人生问题标签）、`situation`（当时的信息、选项、约束）、`choice`/`outcome`（可核对，含代价和副作用）、`reflection`（可借鉴的思维方式，一句话，不是格言）、**`limits`（必填：幸存者偏差？事后诸葛？时代差异？）**、`basis`（本传/史料 + 当代研究，下载原文核对，署名出处）。
3. 不写励志金句，不给人生下处方；不神化不贬低；不同解读并列；**不评价在世人物**。
4. schema 说明写进 `content/`，字段可选，供 cursor 做界面。
