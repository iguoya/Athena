# ADR 0001：空间自有历史——年份驱动多图层与地点剖面

- 日期：2026-10-13
- 状态：已接受（采纳并行代理审视意见；使用者确认按此调整）
- 衔接：仓库级 [ADR 0156](../../../../docs/decisions/0156-jiuzhou-history-atlas.md)、
  [0157](../../../../docs/decisions/0157-athena-maps-shared-package.md)、
  [0158](../../../../docs/decisions/0158-jiuzhou-local-academic-maps-expressiveness.md)；
  内容篇幅精神对齐仓库 [ADR 0040](../../../../docs/decisions/0040-lesson-length-matches-mastery-goal.md)

## 背景

1. 审视（代码/数据阅读、未跑界面）指出：示意河/疆域过粗、地点大量未被事件引用、灌水补字、
   文档「八段」与七段 atlas 不一致；并主张「地图上每样东西都带生命周期，由一个年份滑块驱动」。
2. 部分问题在审视之后已部分缓解（`@athena/maps` 已建、UI 已有按年/按事件双轴），但数据模型
   与内容纪律仍不足以支撑「空间要有自己的历史」。
3. 数据模型与交互骨架变动属本应用架构边界，须先 ADR 再动代码（根 `AGENTS.md`）。

## 决策

1. **年份是唯一时间真源。** 滑块按真实公元年（负数为前）；阶段色带与事件密度柱挂在年轴上。
   「按事件」是次要浏览模式。自动播放默认「年/秒」，遇事件可暂停并弹卡（实现分期）。
2. **图层要素一律带生命周期 `from`/`to`（可缺一）。** 含：地点古名与地位档、水系改道/运河分段、
   长城段、水利工程、行军/迁徙路线、多势力疆域快照。当年不可见的不画或降透明。
3. **地点剖面是一等入口。** 点地点进入剖面：名称沿革、隶属/地位变化、地理角色、该地事件时间线。
   三个入口并行：**按时间 / 按地点 / 按主题**（主题叙事 10–15 条，分期）。
4. **事件模型扩展（字段可分期落地，id 不改嫁）：**
   - `kind`：政治 / 军事 / 经济 / 文化 / 科技 / 灾害 / 民族；
   - 多地点（主 `placeId` + 可选 `placeIds`）；
   - `lede`（一句话摘要 ≤40 字）、`geoWhy`（地理因果）、`impact`、可选 `source`；
   - 禁止用补字数脚本往 summary/impact 塞复述套话（违反言简意赅）；存量灌水先剥再扩质量。
5. **疆域：** 关键时段用**多势力快照**（战国、三国、南北朝、五代十国、宋辽金夏等），禁止「一阶段一矩形」冒充。
   示意帧可暂留并标明；CHGIS 本机可选不入库（0157/0158）；公域底图走 Natural Earth + 自绘加密。
6. **建设顺序：**
   - **P0** 基础：`@athena/maps` 岸线/真河网密度/离线晕渲方向；年轴为主；删灌水；文档统一七段；tier 中文。
   - **P1** 地点剖面、多势力快照、都城迁移与人口重心层。
   - **P2** 路线动画、主题叙事、卷帘对比两年。
   - **P3** Wikidata/CHGIS/NE 拉取管线、搜索增强、人物页、按质量扩事件。
7. **只做一件事先做哪件：** 年份驱动的多图层地图 + 地点剖面页（P0→P1 头刀）。
