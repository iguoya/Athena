# ADR 0006：先还原时代，再谈借鉴——时代语境与收录标准的修正

- 日期：2026-10-14
- 状态：已接受（使用者：不做流水账，但在当时影响很大的也应该收录；学历史不能脱离那个时代的生产力、社会结构和当时人们的思想认识，不然就会出现认知偏差）
- 修订：[ADR 0004](0004-charter-history-serves-reform.md) 的「判据」与「答不上来的不收」——收录门槛放宽为「当时重要 **或** 对今天有可对照的机制」
- 衔接：[ADR 0003](0003-history-as-reference.md)、[ADR 0005](0005-two-layers-society-and-person.md)

## 为什么要改
ADR 0004 把「今天对应什么」写成了门槛，会把一些在当时起过决定性作用、但看不出今天直接对应的事件挡在门外。更根本的是：**脱离时代去读历史，会读出认知偏差**——用今天的生产力、制度和观念去评判古人（现在主义），或者因为知道结局而觉得当年的选择显而易见（事后诸葛）。借鉴的前提是先还原当时的条件。

## 决定
1. **收录标准：满足其一即可收**
   - **当时影响大**：在其时代改变了力量对比、制度、生产方式、人口与地理格局，或是当时人行动的关键约束；
   - **今天有可对照的机制**（ADR 0003）。
   两者都不满足的，才是流水账：不收长文，最多作为地图上的时空坐标，或不收。
   机制（`geoWhy`/`mechanism`）仍然必须说清——没有机制的罗列不论大小都不收长文。
2. **每个重要条目先立「时代语境」，再谈机制与借鉴。** 新增可选字段 `context`：
   - `productive`：**生产力**——技术、农业、交通、人口与资源的条件；
   - `social`：**社会结构**——阶层、土地与赋役制度、政治结构、权力关系；
   - `mind`：**当时人的认识**——当时的观念、信息条件与认知局限（当时人怎么看这件事，他们不知道什么）；
   - `basis`：依据。
   史鉴（`lessons`/`personal`）**必须以 `context` 为前提**：没有语境的借鉴不合格。
3. **时代底座（时代层）**：8 个 `eras` 各有一张「时代底座」`base`（同样三项 + 依据），在时间轴上随年份显示，让人读每个事件时看得到它所处时代的条件。
4. **评审增加两问（防认知偏差）：**
   - 这条是不是**用今天的条件去评判当时**了？（现在主义）
   - 这条是不是**因为知道结局**才显得显而易见？（事后诸葛）；个人层另有幸存者偏差一问（ADR 0005）。
5. **ADR 0004 其余条款不变**：不做精神寄托、不炫耀、不做流水账；失败与成功同等篇幅；不预测。

## 后果
- 新数据字段 `eras[].base`、`events[].context`，可选；前端读不到时静默降级；
- T-116（去流水账）改按本 ADR 的收录标准处置：**当时影响大的不删**，补出机制与语境；只有「当时不重要、今天也无可对照、又说不出机制」的才降级或删；
- 新任务：T-118（zcode：8 个时代底座 + 重要事件的 `context`）、T-037（cursor：时代底座面板与事件「时代语境」区）；
- 当代篇（T-113）与史鉴（T-115、T-117）同样遵守：**先语境，后借鉴**。
