# ADR 0007：解释当时优先，现实参照其次；不用今天的框架套当时的社会

- 日期：2026-10-14
- 状态：已接受（使用者：一方面服务现实，一方面说明当时为什么那样，不能用现代社会框架去套当时的历史社会环境；「服务现实」有点说重了）
- 修订：[ADR 0004](0004-charter-history-serves-reform.md)、[ADR 0003](0003-history-as-reference.md)、[ADR 0005](0005-two-layers-society-and-person.md) 的措辞与权重——「指导变革」「服务现实」降为**有边界的参照**
- 衔接：[ADR 0006](0006-era-context-before-lessons.md)

## 校正
前几条 ADR 把「服务现实」写重了，容易滑向拿古人的事去给今天开药方，或者拿今天的框架去评判古人。校正为**两件事，主次分明**：

1. **主：还原并解释当时为什么那样。** 按**当时**的生产力、社会结构、制度和人们的认识来解释：他们面对什么条件、有哪些选项、为什么选了这个。这是历史自己的任务。
2. **次：在解释清楚之后，提供对今天的参照。** 只是参照，有边界、可检验；**不是指导变革，不是开药方，不是每条都必须有**。能对照的才写，对不上就不写。

## 不用现代框架套当时（术语与方法的纪律）
- **用当时的概念说当时的事**：编户齐民、郡县与封建、士与庶、宗法、里甲、田制、漕运、朝贡……不用「国家治理现代化」「资本主义」「民主」「阶级斗争」这类今天的分析框架去直接套。
- **确需借用今天的概念时必须标明**：「今天的概念，仅作类比，当时并无此概念」，并说明类比哪里成立、哪里不成立。
- **不用今天的价值判断评判古人**：不写「进步/落后」「先进/反动」式的定性；写当时的条件下这个选择意味着什么、带来了什么。
- **评价性判断署名来源**（古人评论或今人研究），不替史料下结论；有分歧并列。
- 不把古人写成今天人的样子（现在主义）；不因为知道结局而觉得选择显然（事后诸葛）。

## 对已有规定的调整（权重下调）
1. **宗旨措辞**：由「用于指导变革、服务现实」改为「还原并解释当时；在此基础上提供对今天的有边界的参照」。`AGENTS.md` 已同步。
2. **四问放宽**：①「回应什么现实问题」改为**可选**；②机制、③得失可核对、④今日对照与不可类比之处：有参照时必须写 `limits`，没有参照时不强写。**时代语境（ADR 0006）仍是每个重要条目的前提。**
3. **收录标准**不变（ADR 0006：当时影响大 **或** 今天有可对照的机制，满足其一）。
4. **界面权重**：时间、地点、时代底座与事件解释是主入口；「按现实问题找历史」「按人生问题找历史」降为次要入口，不占首屏主位，措辞克制，不用「指导」「启示」这类重词，用「可参照」。
5. 当代篇同样用「当时的条件」去解释（例如五十年代计划经济的资源、国际环境、人才与技术条件），不用今天的标准倒推。

## 后果
- 优先级调整：T-118（时代底座）、T-113（当代篇，按当时条件解释）最先；T-115/T-035（社会层史鉴）、T-117/T-036（个人层史鉴）降为 P2，且措辞按本 ADR 校正；
- 评审增加一问：**用了今天的框架或价值判断吗？** 用了就退回；
- 术语清单：`docs/ANACHRONISM-GUIDE.md`（现代词与当时概念的对照，随写随补，由 zcode 维护）。
