# ADR 0002：时间轴延伸到当下，历史与现实不剥离

- 日期：2026-10-14
- 状态：已接受（使用者：近现代也要讲，不要只到 1949，一直讲到最新时间点；不要把历史和现实剥离开）
- 衔接：本应用 [ADR 0001](0001-year-driven-spatial-history.md)；仓库 [ADR 0156](../../../../docs/decisions/0156-jiuzhou-history-atlas.md)（原写「中国历史地理图鉴」，范围止于民国）；仓库 [ADR 0159](../../../../docs/decisions/0159-jiuzhou-academic-layer-in-repo.md)

## 背景
现状时间主轴止于 1949（`modern` 段 1840–1949，事件最晚 1938）。使用者要求把近现代一直讲到当下，并且让历史与现实相连，而不是「讲完古代就停」。

## 决定
1. **时间范围延伸到当下。** 数据带 `asOf`（数据截至年）；时间轴终点取 `asOf`，右端标「今」。起步 `asOf = 2025`，之后只推进到**已核实**的最新时点，不预测、不填未发生的事。
2. **新增第八段 `contemporary`（当代 · 1949 至今）。** `modern`（1840–1949）的 `id` 与范围**不动**（`id` 不改嫁，根 `AGENTS.md`）；「政治秩序七段」改称「八段」，朝代仍只作标签。
3. **历史与现实不剥离，三个落点：**
   - **地点有「今天」**：`places[].today`（可选）——今名、现行省级行政区；地图可叠「今天」的现行省界。已有的古今地名三态切换继续用。
   - **事件有「今日回响」**：`events[].legacy`（可选，一句话）——今天还能在哪里看到、用到它（例：灵渠今天仍通航，京杭运河仍在使用……）。
   - **当代篇用同一套模型**：年份、地点、人物、出处、`geoWhy`，没有独立页面、没有另一套规则。
4. **近年内容的纪律（比古代更严）：**
   - 出处必须有且可核对：官方统计公报、白皮书、权威机构与学术文献；不凭印象，不用自媒体二手转述。
   - 争议性内容按**可多方核对的事实**陈述，写清依据；不做评论、不写评价性套话、不预测。
   - 时效数字写明「截至某年」；近十年内的事件标 `recent: true`，每年复核一次。
   - 地名用通行称谓，行政现状按事实写，不夹带立场。
5. **内容范围（质量优先，不凑数）：** 制度与政治（建国、宪法、改革开放等）、国土与行政（区划变迁、港澳回归等）、基建与地理（三峡、南水北调、青藏铁路、高铁网、港珠澳大桥等）、灾害与应对、经济地理（特区、浦东、城市群）、科技（核、航天、北斗等）、对外关系、人口与城镇化。
6. **数据层：** 现行省级行政区边界（Natural Earth admin1 等公开数据）作「今天」图层；国界取通行版本；当代快照取关键节点（1949、1950 年代大行政区、1988 海南建省、1997 重庆直辖与香港回归、1999 澳门回归，示意，标精度）。

## 后果
- 改 `AGENTS.md`（七段→八段、时间范围）与路线图；数据模型新增可选字段 `today`、`legacy`、`recent`、`asOf`，均可选，前端读不到时静默降级。
- 新任务：T-034（cursor：时间轴延伸、八段、「今」标记、today/legacy 展示、现行省界层）；T-113（zcode：当代篇第一批事件）；T-114（zcode：`today` 与 `legacy` 补全）。
- 先改内容与校验（zcode），再改前端读取（cursor）；schema 变更先经 claude-code 裁决，本 ADR 即裁决。
