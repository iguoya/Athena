# ADR 0005：史鉴的两层——服务社会现实，也服务个人的人生与思想

- 日期：2026-10-14
- 状态：已接受（使用者：服务于社会现实，也服务于个人人生思想指导）
- 补充：[ADR 0004](0004-charter-history-serves-reform.md)（宗旨）、[ADR 0003](0003-history-as-reference.md)（史鉴）

## 与「不做精神寄托」怎么不矛盾
ADR 0004 反对的是**寄托与慰藉式**的历史：怀旧、神化、替少数人提供情绪出口。本 ADR 要的是**指导式**的历史：把前人面对选择时的处境、权衡、结果和代价讲清楚，让一个人**在自己的选择里更清醒**。区别在于：指导式的历史**讲机制、讲代价、讲不适用的地方，可以被检验**；寄托式的历史只讲情怀。

## 决定
1. **两层服务，同一套方法：**
   - **社会层**（ADR 0003）：制度、治理、变革、区域与资源问题——主题叙事的 `lessons`。
   - **个人层**（本 ADR）：一个人如何面对选择、取舍、逆境、进退、识人、学习与担当——人物与处境的 `personal`。
2. **`personal` 的结构（可选字段，挂在 `people[]` 或事件上）：**
   - `question`：它回应的**人生问题标签**（初版：抉择与取舍、逆境与坚持、进退与时机、识人与用人、学习与积累、权责与担当、失败与复盘，可增补）；
   - `situation`：当时的处境与约束（信息有多少、选项有哪些、代价是什么）；
   - `choice` / `outcome`：做了什么选择、结果与代价（可核对，含失败与副作用）；
   - `reflection`：可借鉴的**思维方式**（不是结论、不是格言）；
   - `limits`（必填）：不可照搬之处——**幸存者偏差、事后诸葛、时代与处境差异**；
   - `basis`：依据（本传、史料、当代研究，署名出处）。
3. **界面（cursor）：** 在「按现实问题找历史」之外，新增并列入口**「按人生问题找历史」**；人物页有「处境与抉择」区。
4. **纪律（防成功学与鸡汤）：**
   - 失败者、被误判者与成功者**同等篇幅**；不只挑成功案例（避免幸存者偏差）；
   - 写**处境与权衡**，不写励志金句；不给人生下处方，只提供参照；
   - 不神化、不贬低；有不同解读并列；
   - 不对在世人物做评价；当代人物只写权威来源可核对的公开事实。

- 新任务：T-117（zcode：先做 8 个人物/处境，覆盖成败两面）、T-036（cursor：第二入口与人物页展示）。
