# ADR 0004：宗旨——历史用于指导变革、服务现实

- 日期：2026-10-14
- 状态：已接受（使用者：我们的历史不要变成少数人精神寄托的工具，也不是显摆的工具；都是用于指导变革、参考、服务于现实，这是我们历史的主旨；而不是简单的记流水账）
- 统领：[ADR 0002](0002-timeline-to-the-present.md)（到当下、不剥离现实）、[ADR 0003](0003-history-as-reference.md)（史鉴）；本 ADR 是它们的上位约束，内容取舍冲突时以本 ADR 为准

## 宗旨
九州存在的目的是：**让人从历史里看出机制与得失，用来理解现实、参考决策、指导变革。**

## 反目标（三件事不做）
1. **不做精神寄托。** 不渲染情怀，不把历史写成少数人的怀旧或慰藉；不神化人物、不神化时代。
2. **不做炫耀。** 不为显示知识渊博而堆冷僻史实、辞藻、典故；篇幅不是成绩。
3. **不做流水账。** 只罗列「某年某地发生了某事」而说不出它与现实的关系，就是流水账，不收。

## 判据：每一条内容过四问
1. **它回应什么现实问题？**（可对应 ADR 0003 的问题标签）
2. **机制是什么？**——为什么会这样（`geoWhy` / `mechanism`），不是复述经过。
3. **结果与代价可核对吗？**——得与失同等篇幅，有出处。
4. **今天对应什么？**——今日对照 + 不可简单类比之处（`today`/`legacy`/`limits`）。
答不上来的，**不进主题叙事、不写长文**；最多作为地图上的一个点（事实性的时空坐标），或者干脆不收。**可用性优先于完备性**（与仓库 ADR 0129「宁缺毋滥」一致）。

## 写作与评审
- 去修饰、去赞叹；不用「伟大」「辉煌」「奠定了基础」之类的套话（已有套话检测，扩大范围）。
- 失败、代价、副作用与成功同等对待；不挑对自己有利的看法；争议并列。
- 现实问题导向的入口排在前面：「按现实问题找历史」是一等入口，不是附属功能。
- 评审（claude-code）以四问为准：只有时间地点人物而无机制与现实关联的条目，退回或删。
- 现有存量也按此检视：**没有 `geoWhy` 的事件**（177 条中 68 条）逐条判断——补出机制，或降级为地图点，或删（不为凑数量保留）。
