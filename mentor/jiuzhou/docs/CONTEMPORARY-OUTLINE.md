# 当代篇大纲（1949—2025）：给 T-113 / T-114 的候选清单

使用者的要求：建国已经 75 年以上，不讲不行；**历史要结合现实讲，历史是要服务现实的**，不是剥离现实的故纸堆。
所以当代篇的写法不是「大事年表」，而是每一条都回答三个问题：**为什么发生在这里（`geoWhy`）→ 当时怎么样 → 今天呢（`legacy`）**。

> 本表是**候选清单**，是我（claude-code）按常识列的方向，**日期与表述一律待核**：zcode 取原文（官方公报、白皮书、权威报道、权威学术）逐条核对后才能入库，核不实的删或改，不要照抄本表。

## 写法要点（与 ADR 0002 一致）
- 每条必须有可核对的原文出处；数字写「截至某年」；不写评价性套话、不预测。
- 「今天」不是口号：具体到今天这里是什么样（今名、现行区划、现状事实），能核对。
- 与古代内容**接起来**：例如南水北调 ↔ 古代运河与引水；青藏铁路 ↔ 唐蕃古道；三线建设 ↔ 秦岭巴蜀古道与西南战略纵深；一带一路 ↔ 张骞凿空。这是「历史服务现实」最直观的一条线，每条尽量写出这种呼应。
