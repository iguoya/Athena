# 立项意图验收清单

由 Claude Code维护。把 ADR 0156、0157、0158 与应用 ADR 0001 里说过的“要做成什么样”逐条拆开，
对照现状标注 ✅ 已达成 / 🟡 部分 / ❌ 缺失，并写明谁来补。状态以**实机运行**为准，不是以代码存在为准。

核心意图一句话：**把中国的地理和历史放进同一张按年份流动的地图里，让人一眼看懂“为什么发生在这里、后来怎样”。**

## 四、当前最大缺口（2026-10-14 更新，决定下一步顺序）

M1（看得见地理）、M2 的主体（因果、古今地名）与 M3 的学术层已实机验收通过。剩下的：

1. **地理注记**：山川湖海名称（T-022，进行中），城邑分级符号（T-023）。
2. **人物与动画**：人物沿路线移动、流动与生长动画、人物轨迹小地图（T-024、T-025、T-011）。
3. **内容仍偏薄**：事件 177 条、地点 163 个（目标 250，质量优先不凑数）、人物 77 人；快照 13 组。
4. **学术层的局限要如实表达**：镜像来源的 Hartwell 是现代县域拼接的近似，秦只有东南 13 郡，唐代关中无面；T-110 用它核对我们自己的内容。
5. **发行验证**（T-016）与自检脚本对「territories.json 改动后需重跑裁剪」的过期检测。
