# 立项意图验收清单

由 Claude Code维护。把 ADR 0156、0157、0158 与应用 ADR 0001 里说过的“要做成什么样”逐条拆开，
对照现状标注 ✅ 已达成 / 🟡 部分 / ❌ 缺失，并写明谁来补。状态以**实机运行**为准，不是以代码存在为准。

核心意图一句话：**把中国的地理和历史放进同一张按年份流动的地图里，让人一眼看懂“为什么发生在这里、后来怎样”。**

## 四、本轮后的最大缺口（决定下一步顺序）

1. **看不见地理**：海陆、地形、河网，这是“地理与历史结合”里“地理”的底（Q1、R1）。
2. **看不见因果**：事件之间的“后世影响”只是文字（R5）。
3. **学术层未接**：ADR 0158 的承诺（R3）。
4. **内容仍偏薄**：事件 177 条、地点 143 个、人物 77 人；目标 200 / 250 / 120（B）。
