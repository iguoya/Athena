# 时代错置对照指南（ANACHRONISM GUIDE）

- 依据：ADR 0007（解释当时优先，不用今天的框架套当时的社会）。
- 维护：zcode（随写随补）。规则：**用当时的概念说当时的事**；确需借用今天的概念，标明「今天的概念，仅作类比」；不用「进步/落后」式定性。
- 用法：写作与自查时对照本表；左侧词在讲当时的事时避免直接使用（转述分析除外，转述时保持平实、不加价值判断）。

## 已收录对照

| 现代词/框架 | 问题 | 当时概念/写法 |
|---|---|---|
| 治理/治理体系 | 现代政策语 | 行政、管理、经略、整顿；具体说谁对谁做了什么 |
| 国家治理现代化 | 现代框架 | 不用；写当时的制度安排（郡县、编户、里甲……） |
| 资本主义萌芽 | 争议框架 | 用当时的经营方式描述（雇佣、作坊、商帮），定性需署学术来源 |
| 阶级斗争 | 现代框架（古代语境） | 写具体的身份与关系（士庶、主佃、良贱），当时概念优先 |
| 锁定/路径依赖 | 经济学术语 | 长期沿用、积重难返、例行之规 |
| 精英结构 | 社会学术语 | 写具体阶层（士绅、门阀、军功集团、官僚） |
| 宪制节点 | 现代宪法学语 | 制宪、立宪、国家机构常设化（按当时文件说法） |
| 安全算术/地缘棋局 | 现代战略学术语 | 平实说：安全上的考虑、兵力和距离的账 |
| 动员能力 | 可用但慎 | 当时语境用「征发」「调发」「签军」等；现代转述时注明是概括 |
| 进步/落后、先进/反动 | 价值判断 | 禁用；写「当时的条件下这意味着什么」 |
| 伟大/辉煌/奠定了基础 | 评价套话 | 禁用；写可核对的结果（ADR 0004） |
| 腐朽/反动政权 | 价值判断 | 禁用；写结构与其行为 |
| 民族国家 | 现代概念（古代语境） | 古代说王朝/国家/天下；明清以降的转变需专门论证 |
| 主权 | 现代概念（古代语境） | 古代用「疆界」「封贡」「辖土」；近代条约语境可用（当时已入约文） |
| 公民 | 现代概念 | 古代说编户齐民、子民、国民（近代）；1949 后「人民」「公民」为当时法定语 |
| 计划经济/市场经济（1949–1956 前） | 时段错置 | 1956 年社会主义改造完成前说「计划建设」「统购统销」逐步展开；此前小农与市场仍占大头 |
| 改革开放（1978 前） | 时段错置 | 1978 年前不预支此语；写当时自己的提法（调整、整顿） |
