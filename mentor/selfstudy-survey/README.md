# 自考专业调查

2025–2026 年全国各省计算机类（0809）、电子信息类（0807）自考本科的调查：开设格局、主考院校、课程计划、
实践环节、参考教材、报考与毕业条件、新旧计划变动，可跨省比较。数据逐条带来源与核对日期，查不到的如实标
「待查」。只供查阅，不教课、不判分、不建进度库（图谱/参考类，主仓库 ADR 0186）。

- 启动：`launcher open selfstudy-survey`（`app.json` 声明，Tauri 2 + React 薄壳）。
- 验证：`python scripts/check.py`（采集时自查用 `--data-only`）。
- 数据在 `content/`，字段与采集规程见 `comms/selfstudy-survey/artifacts/claude-code/DESIGN.md`；规则见 `AGENTS.md`。
